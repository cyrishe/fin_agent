## 研究覆盖与是否达标

整项研究覆盖1/3/7日持有期、分类与回归任务、逻辑回归/Ridge/决策树模型，共12个候选实验。开发约束检查显示：最终选定模型（horizon=3, classification, linear）在each_fold_win_rate项未达标（两折信号胜率分别为51.9%和无信号），但each_fold_beats_constant通过（Brier优于常数基准）。约束含义明确：each_fold_beats_constant检查Brier/MSE改善，非胜率。研究未找到完全满足所有门槛的模型，如实报告。

## 预测/信号/组合的实际差异

新时间段留出切片（13家公司，2025-08至12月）：信号仅3个，扣成本胜率66.7%（Wilson区间[20.8%,93.9%]），组合总收益0.45%（2笔成交记录），同期基准收益5.46%，超额-5.01%。新公司+新时间段切片（3家公司）：信号0个，无成交收益观测。两切片均观察到负技能（Brier技能分别为+0.87%和-0.33%），ROC AUC约0.55-0.56。信号数量极少，成交记录有限，组合收益为正但仅基于2笔交易。

## 证据边界与下一轮方向

本研究未做统计显著性检验，也无多组独立公司或新时期的重复验证。16家公司、重叠持有期标签、少量成交记录，仅能描述当前切片观测：新时间段信号胜率偏高但样本极小，组合收益为正但不足以确认稳定盈利或泛化能力。结论强度限于“本切片观察到……；尚不足以确认……”。下一轮应针对未来未揭盲的新时间窗口（不重训调参），增加独立公司数量与信号密度，以验证模型是否具备可重复的预测能力。
