## 研究解读

以下为基于上述事实的语言分析，用于解释局限与下一轮假设；数值与筛选结论由程序生成。

根据您提供的研究证据，以下是对该次研究的解读：

**当前结果能支持的认识**

本次研究在16家公司、485个交易日的日K数据上，系统比较了逻辑回归、Ridge和决策树模型，预测持有1、3、7个交易日到期上涨概率。开发阶段所有候选模型均未同时满足信号数量、各折胜率和预测损失优于常数基准三项约束条件。最佳候选（逻辑回归，持有1日）在留出时段（原公司后续时段）的Brier损失为0.24897，较常数基准改善0.29%，但信号数量为零，未触发任何交易。这表明在60%概率门槛下，模型未能产生足够可信的上涨信号。预测层面，模型概率校准在0.4-0.5区间与观测频率基本吻合，但ROC AUC仅0.525，区分能力微弱。组合层面零成交意味着模型在当前设定下不具备实际交易能力，无法产生超越基准的收益。

**证据局限**

研究覆盖范围有限：仅16家公司、485个交易日，且留出时段仅约4个月。开发集使用时间序列交叉验证，但未实现开发期留公司交叉验证，整家公司留出仅用于最终评估。留出评估中，原公司后续时段和新公司后续时段均无信号，无法评估信号胜率和组合收益的稳定性。重叠样本（同一交易日多个持有期信号）和少量成交记录（开发验证折中部分候选信号数不足15个）不能证明模型泛化能力。未做统计显著性检验，Brier改善0.29%可能源于随机波动。交易成本假设（佣金、滑点、印花税）已计入，但未模拟A股100股整手、涨跌停排队等实际执行细节。历史窗口此前已被使用，本次留出结果仅作流程复验，不能视为新的盲测证据。

**下一轮可验证的假设**

假设一：降低概率信号门槛（如从60%降至55%）可增加信号数量，但可能降低胜率。建议在开发阶段设置多个门槛（50%、55%、60%）进行敏感性分析，观察信号数量与胜率的权衡曲线，并保留新的未使用时段（如2026年1月后数据）作最终评估。假设二：增加特征维度（如加入动量因子、波动率结构）或使用非线性模型（如梯度提升树）可提升预测区分能力。建议在开发阶段先进行特征重要性筛选，再对候选模型进行超参数调优，避免将留出结果作为调参目标。假设三：持有期延长至7个交易日可能改善信号稳定性。开发验证折中部分7日候选信号数量较多（如决策树模型达1035个），但胜率仅50.7%，需进一步验证是否能在独立时段保持。所有假设需在开发阶段通过时间序列交叉验证检验，最终使用未参与任何训练或选择的留出时段评估，避免数据泄露。

## 本次研究要求

使用 KingdomAI 库 2024-01-01 至 2025-12-31 的日K，随机选取16家公司，研究持有1、3、7个交易日到期的上涨概率与收益回归，仅比较逻辑回归、Ridge和决策树。使用全部样本，技术特征及已有的行业、市值、估值和新闻数量特征，不使用分钟数据。最多12个候选实验、2轮、2个按时间验证折，保留其他公司和后续时间段作评估，考虑佣金、滑点和印花税。概率信号门槛60%，每轮研究至少15个信号、最低胜率50%、最大回撤30%；不保证找到达标模型，没有符合条件的模型也要如实报告。输出研究设计、样本划分、候选比较、阶段回测、最终留出结果和大模型评审。最多运行15分钟。历史窗口已使用过，本次仅验收流程，不将重复留出结果称为新的盲测。

## 口径与限制

- 研究回测使用复权价格及1份单位，未完整模拟A股100股整手、开盘涨跌停排队与停复牌可成交性；不作为实盘回报。
- 交易成本为任务假设，不自动推断历史税费制度；复权数据可能被供应商修订。
- 信号胜率是重叠持有期样本统计，不能视为独立已成交交易胜率；组合收益另由逐日现金账本计算。
- horizon定义：收盘后信号，下一交易日开盘买入，持有h个交易日后开盘退出；不是期间触及目标价概率。
- 随机起始股票池可含后来退市股票，但退市清算和历史数据库完整性尚未认证。
- 所有盲测只评估开发集选定的一名候选；本轮报告不触发自动再训练或交易。
- 估值按下一自然日可用处理；原库未提供历史修订版本，不能证明原始发布时点。
- 行业按 SW2021 生效区间对齐，未取得分类历史版本；用于研究特征和分组，非严格历史成分认证。
- 新闻热度为已入库新闻的7日数量代理，不代表全网热度；不读取或上传新闻正文。
