### 整体覆盖与样本规模

本研究在开发阶段探索了**3个持有期（1、3、7日）、2种任务（分类、回归）和2类模型（线性、树模型）**，共完成8个成功实验。最终选定的候选模型为：持有期7日、分类任务、线性模型（逻辑回归），使用增强特征集。

样本规模方面，整个面板包含**7760行**数据，覆盖**16家公司**，时间跨度约485个交易日。开发集使用了4679行输入数据，其中3406行用于拟合，1169行用于校准。测试集分为两部分：
*   **新时间段（`new_period`）**：包含1156行，来自开发集已有的13家公司，时间跨度为2025年8月至12月。
*   **新公司及时间段（`new_companies_and_period`）**：包含267行，来自3家完全留出的公司，时间同样在2025年。

**样本规模限制**：整个研究仅基于16家公司，且测试集的新公司部分仅有3家、267行数据。这导致所有结论，尤其是跨公司泛化能力的结论，都受到极大限制。本切片观察到的结果仅能作为初步探索，**未能提供稳定泛化的证据**。

### 预测质量

**开发约束检查**：最终选定的模型**未满足所有开发约束**。具体而言，`each_fold_beats_constant` 检查失败。根据 `constraint_meaning`，这意味着在开发集的两个时间折中，该模型的**分类Brier分数并未一致地优于常数预测（即预测无条件上涨概率）**。其他三项约束（信号数量、胜率、回撤）均达标。

**测试集预测表现**：
*   **新时间段**：Brier分数为0.247，略优于常数基准的0.250，技能分数（skill_vs_constant）为+1.47%。ROC AUC为0.551，表明模型区分上涨与下跌的能力非常微弱。校准曲线显示，模型在概率区间[0.5, 0.6)的预测较为准确，但在[0.3, 0.4)区间严重高估（预测35%上涨，实际仅11.4%）。
*   **新公司及时间段**：Brier分数为0.253，**劣于**常数基准的0.251，技能分数为-0.51%。ROC AUC为0.532，同样非常微弱。校准表现更差，尤其是在概率区间[0.5, 0.6)和[0.6, 0.7)，模型预测的上涨概率显著高于实际观察到的上涨比例。

**评估**：模型在开发集上未能稳定超越常数预测，在测试集上对新时间段有微弱的正向技能，但对新公司则完全失效。**本切片观察到模型预测质量极不稳定，尤其是在跨公司场景下，未能提供可靠的上涨概率估计。**

### 阈值决策

决策策略设定了0.6的概率阈值来生成买入信号。

*   **新时间段**：在1156行预测中，有41个样本的概率超过0.6，生成了信号。这些信号的扣成本胜率为**56.1%**，高于50%的门槛。信号的平均净收益为+0.97%。
*   **新公司及时间段**：在267行预测中，有12个样本的概率超过0.6。但这些信号的扣成本胜率仅为**25%**，远低于50%门槛，平均净收益为-3.76%。

**评估**：0.6的阈值在熟悉的时间段内似乎有效，但在面对新公司时完全失效。**本切片观察到阈值决策的泛化能力极差**，其有效性高度依赖于与开发集相似的数据分布。

### 组合收益

*   **新时间段**：基于信号构建的组合实现了**16.33%的总收益**，年化夏普比率高达2.00，最大回撤仅-6.22%。该表现显著优于等权基准（总收益8.48%，夏普1.22）。但需注意，该组合仅有**12笔成交记录**（`trade_count`），样本量极小，收益可能由少数交易驱动。
*   **新公司及时间段**：该组合总收益为**-1.78%**，夏普比率为-0.70，表现劣于基准（总收益-0.94%）。该组合仅有**2笔成交记录**，**本切片观察到该组合没有交易收益证据**。

**评估**：组合收益在两个测试集上呈现巨大差异。在新时间段上表现亮眼，但极低的成交笔数使其结果高度不稳定。在新公司上则直接亏损。**证据强度不足以支持该策略在任何场景下具有稳定的盈利能力。**

### 跨公司/时期差异

这是本研究最关键的发现。模型在**新时间段（熟悉公司）** 上表现出一定的预测能力和正收益，但在**新公司及时间段（完全留出公司）** 上，预测质量、阈值决策和组合收益全面崩溃。这种巨大的差异强烈表明：

1.  **模型可能过度学习了开发集公司的特定模式**，这些模式在新公司上并不存在。尽管特征中不包含股票代码，但公司特定的量价关系、行业分布等特征组合可能被模型记忆。
2.  **开发期未进行跨公司交叉验证**（`整家公司留出只用于最终评估，未实现开发期留公司交叉验证`），导致模型对“新公司”这一维度的泛化能力完全没有得到评估和约束。

**评估**：本研究观察到了显著的跨公司差异，但**不能推断模型存在公司ID泄露**。证据仅表明模型在跨公司场景下表现不稳定，其泛化能力**仍未得到验证**。

### 总结与建议

**开发约束达标情况**：**未达标**。核心原因是模型在开发集上的预测能力（Brier分数）未能一致优于常数基准。

**核心结论**：本研究在有限的16家公司上，探索了多种模型和持有期。最终选定的模型在熟悉的时间段内表现尚可，但在面对完全留出的新公司时，其预测、阈值和组合收益均失效。**本切片观察到该策略不具备跨公司泛化的能力，其表现高度依赖于与开发集相似的数据环境。**

**未来研究方向**：
1.  **增强跨公司验证**：在开发阶段引入留出公司的交叉验证，强制模型学习跨公司通用的模式，而非公司特定的噪声。
2.  **改进校准**：当前Platt校准在测试集上表现不佳，尤其是在新公司上。可以研究其他校准方法（如保序回归、Beta校准）或调整校准集构建方式。
3.  **扩大样本**：增加研究的股票数量和时间跨度，以获得更稳健的统计结论。
4.  **特征工程**：探索更具普适性的特征，例如基于市场微观结构或宏观因子的特征，减少对公司个体量价模式的依赖。
