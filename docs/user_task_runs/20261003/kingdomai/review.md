**研究覆盖与是否达标**

整项研究覆盖了1/3/7日、分类/回归、线性/树模型共8个实验，最终选定7日分类线性模型（enriched特征）。开发筛选未达标：`each_fold_beats_constant`检查失败，即两折Brier均未优于常数预测基准（第一折skill -0.007，第二折+0.013）。其余门槛（信号数、胜率、回撤）均通过。开发集样本含16只股票、4679行，测试留出3只新公司及未来时段。

**预测/信号/组合的实际差异**

新时段切片（13只公司，1156行）：信号41个，扣成本胜率56.1%（Wilson区间[41%,70%]），平均净收益+0.97%；组合12笔成交，总收益+16.3%，年化夏普2.00，优于基准（+8.5%）。新公司+新时段切片（3只公司，267行）：信号12个，扣成本胜率25%（Wilson区间[9%,53%]），平均净收益-3.76%；组合仅2笔成交，总收益-1.78%，弱于基准（-0.94%）。两切片方向相反：新时段观测到正收益，新公司观测到负收益；成交记录均有限，不足以确认稳定模式。

**证据边界与下一轮方向**

本研究未做统计显著性检验，也无多组独立公司或新时期的重复验证。16只股票、重叠标签、少量成交（新时段12笔、新公司2笔）仅支持当前切片描述，尚不足以确认泛化能力或过拟合原因。下一轮应在未来未揭盲的新时间窗口（如2026年）独立验证，不在本轮测试集重训调参；可考虑增加公司数量、引入开发期留公司交叉验证，并评估校准稳定性。
