# R54：最后一个验证月的四 K 与当时实际近 5／10 日表现

**测试月 M 是 D0 盘后选股所属月**：用当月冻结日线模型每天排 Top3，次一交易日 D1 决定是否买入，按原 B2 在 D2 收盘卖出。D1、D2 可以跨到下个月；R52 简表的“月收益”仍是连续账户按日历日归属的收益。

[31 月简表](31月简表_加末月四K及末5末10.csv)保留 R53 原有列与顺序，最右侧追加四列。括号是样本或已卖笔数，数值版见[31 月原始数值](31月末月四K与实际末5末10_数值.csv)。

| 新列 | 计算口径 |
| --- | --- |
| 末月四 K 再板率 | 目标月 M 选中的四 K 规则，应用到验证期后一个月 M−1 的已成熟 Top1 样本；与 R52 两月“四 K 再板率”同口径。此标签指标未执行额外实体门槛及延迟买价。 |
| 末月四 K D2 费后胜率／笔均 | 同一批 M−1 验证 Top1，继续执行实体 >−8%、同股下一合格分钟买价、D2 收盘卖和买卖各 0.1% 费用。 |
| 验证末月实际末 5／10 日 | **当时实际运行的原 B2** 在 M−1 最后 5／10 个交易日的账户净值涨跌幅；胜率取该窗口内 D2 已卖交易费后盈利笔数比例。窗口按交易所交易日数，不按出现信号的天数。括号是窗口内已卖笔数；0 笔时胜率为“—”。 |

前两列用目标月规则回看**参与该规则选择的验证样本**，只能作诊断，不能当独立测试。最后两列用 M−1 当时已经运行的月模型与四 K 规则，而不是事后把目标月规则套回上月。账户涨跌幅包含持仓的每日估值；胜率只看窗口内已卖交易。这两种指标各有分母，不能视为同一个收益率。对测试月 2024-03，R54 使用的 R35 原 B2 实际账户从 2024-03 才开始，缺少 2024-02 净值，近 5／10 日记“—”。“—”是未计算，既不是亏损，也不是零候选；后来[R55 扩展回测](../20261020_b2_recent_loss_resume_r55/README.md)用 R41 更早的影子历史补出 2024-02 的 8 个最终候选和两个窗口收益。
