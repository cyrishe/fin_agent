# 2026 年 1–7 月：保留可入场 ST 的 20 日全量训练对照

此前[完全去 ST 实验](../20261010_mk_1m_jan_jul_nonst_rolling/README.md)从**训练与推理两侧**都删除了所有历史 ST。本次从同一份 59,959 条 14:40 七因子候选出发，只删除信号时**已到有效涨停价**的 1,642 条 ST；其余 1,824 条历史 ST 与 56,493 条非 ST 全部保留，共 **58,317 条**。涨停价按信号日历史 ST 状态、板块规则和昨收分位取整计算；其他七因子、3%–6% 候选条件及次晨四分类目标不变。没有为了凑比例而删除非 ST，也没有人工挑选个股。

保留的 ST 占 **3.13%**，8–9 月参照候选池历史 ST 占 **3.90%**；逐月占比见[候选汇总](cohort_summary.json)。保留 ST 中有次晨标签的 1,751 条，目标涨幅至少 3% 为 **278/1,751（15.88%）**，固定 09:40 卖价达标 **175/1,751（9.99%）**；8–9 月参照 ST 的目标达标为 **85/575（14.78%）**，固定卖价达标 **64/575（11.13%）**。两段数据来源及流通市值估算口径不同，比例接近不能证明分布完全一致。

仅训练**20 日全量**一组：每个测试日用前 20 个已成熟标签交易日的全部保留候选拟合一棵与旧实验相同配置的提升树，当天 14:40 推理。没有随机抽样、P3 选模或额外调参。2026-02-02 至 07-30 共 118 个折外测试日；每日训练行数和日期见[折记录](folds.json)，逐日选股见[Top1](top1_verified.csv)。逐日重训只用于历史滚动验证，不表示部署后每天都要重训。

逐日联表见[可读表格](daily_effect_market_context.md)和[CSV 明细](daily_effect_market_context.csv)：列出前一交易日候选池总数、当日模型正向信号的达标／可接受／严重错误数、第一名次晨 09:40 卖出收益，以及前一交易日沪深 A 股涨跌家数和截至前一交易日的近五个交易日沪深股票成交额。候选池总数是前一天的市场背景，不是当日模型三类结果的分母。统计口径和缺失标签说明见表格开头；[市场逐日底表](market_daily_context.csv)与[来源清单](daily_effect_manifest.json)支持复核。

本次 Top1 有 **8 只历史 ST**，信号时均未涨停、次晨价格均可观察；这 8 笔没有一笔达到 3%，平均固定卖价收益 **−0.565%/笔**。[次晨 ST 卖出观察](nextday_st_sale_audit.csv)显示它们在 09:40 均未涨停，前五分钟均有成交量。模型总体均值稍高不能解释为“选中的 ST 贡献了收益”。

与完全去 ST 的 20 日组逐日配对，两者共同选股的 **112 天**中，57 天选同一只，换股的 55 天里本次好 28 天、差 27 天；共同日期平均收益反而**低 0.027 个百分点**。两组全期均值差异受到非共同选股日影响，其中本次独有的 06-10 选股次晨价格收益约 +11.94%。固定卖价的本次月均收益按 2–7 月为 **+1.573%、+0.246%、−0.799%、−0.031%、+1.248%、−0.904%**，跨月波动仍大。详细对照见[comparison.json](comparison.json)。

相同 Top1 用既有分段四规则卖出，平均 **+0.023%/笔**、价格代理复利 **−3.61%**；去掉反弹规则平均 **+0.094%/笔**、复利 **+4.21%**。逐笔及月度数据见[卖出账本](exits/top1_exit_trades.csv)与[卖出汇总](exits/exit_summary.json)。这些收益按分钟收盘价回放，未验证真实入场成交，未计费用、滑点和订单约束。本次实验说明保留可入场 ST 后总体数值略升，**没有足够证据表明 ST 信息带来稳定的折外增益**。
