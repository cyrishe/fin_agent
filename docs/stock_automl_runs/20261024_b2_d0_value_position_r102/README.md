# R102｜D0 Top3 的股价、市值和 PE 历史位置

2026-10-24，只读研究。沿用 R100 登记的 2018-01—2026-09 冻结月 RF51 分数，取每个 D0 的原 Top3，共 6,369 股票日；不重训、不替换 `imac/B2_V2`，不写生产库。D1—D3 收盘再封板标签有 6,365 条可观察。该标签是 **D0 候选结果**，不是 V2 实际买入或可成交收益。

## 时点和变量

- D0 股价：KingdomAI `kcrp_stock_price.adjclose`，截至 D0 收盘，按个股自身最近 20、60、252 个有效交易日计算 `小于等于当前值的比例`；另算当前价/窗口最高价。仅比较相对位置，使用复权收盘价以减轻除权跳变。
- 市值：`kcrp_stock_pricevaluate.total_mv`，**只取 D0 上一交易日**；同法计算最近 20、60 个有效交易日的百分位和市值/窗口最高市值。PE TTM 同样止于上一交易日，算最近 252、504 日正 PE 的百分位。20/60/252/504 日至少分别有 15/45/120/250 个有效值；缺值不填成低位。
- 估值表的当前历史版本没有逐次修订档；本研究只能保证查询使用的交易日期没有晚于 D0，不证明数据库中该历史值从未在事后修订。原始估值行 `update_time` 留在取数过程但未形成逐次版本核查。
- 估值日期若不是 D0 上一交易日，市值和 PE 及其位置全部置空。PE 非正与缺失分开设计，但这批数据中有效行未出现非正 PE；空 PE 不等于已确认亏损企业。

观察指标一是 D1—D3 是否至少一天收涨停；二是 D1 开盘低于涨停且全天有成交时的 `D2收盘/D1开盘−1` **价格代理**。第二项使用事后全日成交量排除零成交，不能证明开盘能买、D2 能卖，未算费用、资金占用和跌停延期退出。

## 冻结标签的分组对照

下表“低”是自身历史分位 ≤40%，“高”是 ≥80%。百分位不是全市场横截面排名。人数是可观察标签且该特征有效的 D0 股票日；分组内未扣除同一天三只候选之间的相关性。

| 特征和时期 | 低位命中 | 高位命中 | 观察 |
| --- | ---: | ---: | --- |
| 股价 252 日，2018—22 | 103/164，62.8% | 1,220/1,823，66.9% | 低位没有优势 |
| 股价 252 日，2023—24 | 99/177，55.9% | 636/1,010，63.0% | 同向 |
| 股价 252 日，2025—26 | 25/46，54.3% | 742/1,154，64.3% | 低位样本很小 |
| 市值 60 日，2018—22 | 71/117，60.7% | 1,341/2,028，66.1% | 低位没有优势 |
| 市值 60 日，2023—24 | 49/96，51.0% | 722/1,147，62.9% | 同向 |
| 市值 60 日，2025—26 | 11/33，33.3% | 246/391，62.9% | 仅新近估值可用子样本 |
| PE 252 日，2018—22 | 160/240，66.7% | 523/799，65.5% | 差距小 |
| PE 252 日，2023—24 | 82/125，65.6% | 241/399，60.4% | 低位略高 |
| PE 252 日，2025—26 | 25/40，62.5% | 115/171，67.3% | 方向反转，覆盖仅 239/1,270 个可观察候选 |

短窗口分位的判别空间很小：所有可算 20 日股价分位的 5,084 个候选中，4,951 个（97.4%）已在自身近 20 日**最高五分位**。D0 本来就是涨停后的筛选，若再要求近月股价“低位”，实际只剩极少数。近 60 日价格距离高点 ≥98% 的股票占多数，其封板率在探索／验证／较近时期分别为 66.1%／62.6%／64.5%；低于高点 90% 的分别为 52.9%／54.2%／56.4%。不过按有两组候选的月份比较，较近时期的差异不稳定，不能据此锁定 98% 门槛。

在估值较完整的 2018—24 年，可用样本中股价与市值的 20／60 日分位相关系数为 0.777／0.885；市值历史位置大部分是在重复股价走势，是否能给原 RF51 的 `log_price` 和流值代理增加信息，仍需模型增量检验。

## D2 价格代理和可推广性

在 PE 252 日分位有效、且 D1 日 K 开盘未封死的候选中：

| 时期 | 低 PE 分位 D2 价格代理均值 | 高 PE 分位均值 | 两组同月均出现时的月均差；约 95% 区间 |
| --- | ---: | ---: | ---: |
| 2018—22 | 162 笔，+0.31% | 484 笔，−0.36% | 46 月，+0.68 个百分点；−2.25～+3.61 |
| 2023—24 | 72 笔，+0.40% | 273 笔，−1.17% | 20 月，+3.04；−0.86～+6.94 |
| 2025—26 | 21 笔，+2.78% | 96 笔，−0.86% | 9 月，+2.63；−2.98～+8.24 |

三个时期的原始均值方向一致，但每段同月差异的近似区间都跨零；同 D0 日真正同时出现低／高 PE 候选分别只有 40、30、5 天，逐日成对比较不稳定。按原 D0 排名分开后也不呈一致优势。此处多个窗口/阈值已经在历史数据上被观察，2025—26 也非新的盲测，不能称为已验证增益。

**结论：**在 D0 Top3 中，“近月股价／市值较低”没有提高再封板标签，价格位置偏高反而更常见且标签率较高。PE 历史低分位对 D2 价格代理有研究价值，但样本缺失、时点覆盖、同日及同月对照和可成交性都不足以支持加入现行买前过滤器。下一轮若要验证，需要先补齐 2025—26 估值历史，预先冻结一个 PE 阈值及覆盖规则，用未参与选阈值的新月份做原 V2 买卖与资金占用回放。
