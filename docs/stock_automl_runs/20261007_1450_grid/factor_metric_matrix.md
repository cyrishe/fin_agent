# 因子与评测指标矩阵

所有输入因子仅用 14:49 及以前的数据；14:50 分钟收盘价只作入场价代理。`T` 为信号日，`T−1` 为前一交易日。市场和行业统计的分母是 **T 日 14:49 已通过信号时过滤的股票池**。逐字段实现见 `scripts/experiment_automl_1450_grid.py`。

| 维度 | 字段 | 定义 / 信息截止 |
|---|---|---|
| 市场/行业 | `market_return` | 股票池当日 14:49 涨幅等权平均 |
| 市场/行业 | `market_breadth` | 股票池中当日涨幅大于 0 的占比 |
| 市场/行业 | `market_dispersion` | 股票池当日涨幅标准差 |
| 市场/行业 | `sector_return` | 有效申万一级行业内的当日涨幅等权平均 |
| 市场/行业 | `sector_breadth` | 同行业内当日上涨股票占比 |
| 市场/行业 | `sector_relative` | `sector_return − market_return` |
| 个股近几日 | `prior_return_1` | T−1 日收益 |
| 个股近几日 | `prior_return_3` | 截至 T−1 的 3 日复合收益 |
| 个股近几日 | `prior_return_5` | 截至 T−1 的 5 日复合收益 |
| 个股近几日 | `prior_volatility_5` | 截至 T−1 的 5 日日收益标准差 |
| 个股近几日 | `prior_amount_ratio_5` | T−1 成交额 / T−2 至 T−6 平均成交额 |
| 个股近几日 | `prior_turnover` | T−1 换手率 |
| 个股当日 | `day_return` | 14:49 最新价 / T 日参考昨收 − 1 |
| 个股当日 | `open_return` | 14:49 最新价 / 开盘价 − 1 |
| 个股当日 | `tail_return_19m` | 14:49 最新价 / 14:30 最新价 − 1 |
| 个股当日 | `tail_return_9m` | 14:49 最新价 / 14:40 最新价 − 1 |
| 个股当日 | `tail_return_4m` | 14:49 最新价 / 14:45 最新价 − 1 |
| 个股当日 | `tail_amount_ratio` | 14:41–14:49 成交额 / 14:31–14:40 成交额 |

| 评测字段 | 定义 | 解读边界 |
|---|---|---|
| `signals`、`days` | 选股笔数、有信号交易日数 | 空仓不硬凑样本 |
| `unobserved` | 次晨缺完整 5 根分钟记录的信号数 | 留在分母，按未命中处理；不能推断真实收益 |
| `hit_rate` | 次晨 9:31–9:35 最高价相对入场价达到 +1% 或 +2% 的比例 | 价格触及，不代表可成交卖出 |
| `hit_after_30bp` | 将目标提高 0.3 个百分点后的触及率 | 仅是成本缓冲敏感性，不是成交模拟 |
| `safe_rate` | 次晨五分钟最低价相对入场价不低于 -0.5% 的比例 | 衡量盘中路径，严于 9:35 退出 |
| `severe_down_rate` | 次晨五分钟最低价低于 -1% 的比例 | 衡量下探风险 |
| `exit_safe_rate` | 9:35 价格相对入场价不低于 -0.5% 的比例 | 仍缺真实委托成交证据 |
| `exit_nonnegative_rate` | 9:35 价格不低于入场价的比例 | 未扣费用 |
| `exit_severe_or_unobserved_rate` | 9:35 跌超 1% 或次晨结果缺失的比例 | 缺结果按风险计，更保守 |
| `mean_exit_return_net_30bp` | 有观察值的 9:35 平均价格收益减去假设的 0.3% 往返成本 | 未观察值不计入均值，须同时查看 `unobserved`；不是实盘 P&L |

`summary.json` 是全部 7 组 × 2 目标 × 2 类决策方案的聚合评测原始结果；`grid_matrix.md` 便于人工比较。单个因子的因果有效性尚未验证，不能把组间差异解释为因子重要性排序。
