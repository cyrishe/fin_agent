# R8：涨停 D0 模型对 scikit-learn 1.7.1 / 1.9.1 的敏感性

日期：2026-10-14。对象为 R5 的 D0 收盘评分、D1 开盘激活、D1～D3 任一日再封板三日标签。训练行 23,645，验证已激活行 4,280，验证 D0 全部可评分行 4,485。使用同一特征值、样本权重、随机种子、训练/验证切分，只替换 scikit-learn wheel；NumPy 等其他运行依赖不变。1.7.1 原提升树在 4,280 条验证样本的分数与 R5 保存文件逐行一致。

版本“抖动”以**同一 D1 日期 Top1 是否选到同一只股票**为首要指标；另列概率绝对差和三日标签命中。总体 AP 相近不能代替每日名单稳定。训练期 Top1 是模型内样本；验证期 2026-04-01～06-25 是模型未拟合日期。四种方案均只用训练期拟合并在验证期比较：R5 原 255 档浅层直方图提升树、仅把最大分箱改为 32 的同类模型、固定参数的随机森林、带缺失值填补和标准化的逻辑回归。后两种模型只将无穷值转为缺失后填补，训练与推理使用同一处理；原提升树输入不变。

| 模型 | 训练 Top1 同股 | 验证 Top1 同股 | 验证分数绝对差中位 | 验证 AP 1.7 / 1.9 | 验证三日命中 1.7 / 1.9 |
|---|---:|---:|---:|---:|---:|
| R5 原提升树 | 304/357 | 48/57 | 0.0075 | .3331 / .3320 | 27/57 / 27/57 |
| 32 档提升树 | 273/357 | 47/57 | 0.0132 | .3351 / .3329 | 26/57 / 28/57 |
| 随机森林 | 315/357 | **55/57** | **0.0059** | .3351 / .3383 | **29/57 / 30/57** |
| 逻辑回归 | **357/357** | **57/57** | **0** | .3309 / .3309 | 23/57 / 23/57 |

粗分箱并未改善稳定性。逻辑回归在这两版完全一致，但验证 Top1 命中比原模型少 4 天、比随机森林少 6～7 天。随机森林是本次**稳定性与验证分类效果的折中候选**，但 55/57 不是跨版本不变。

在以上验证结果后，冻结随机森林参数，使用 R5 的训练＋验证集 28,115 条重拟，仅做一次 2026-07-01～10-08 测试段核查。为判断“减少抖动”而同口径重拟原提升树作为参照：

| 模型 | 测试全池 Top1 两版同股 | 三日命中 1.7 / 1.9 | D0 Top5 有开盘候选日 | Top5 开盘候选两版同股 |
|---|---:|---:|---:|---:|
| 原提升树 | 55/66 | 38/66 / 34/66 | 65/66 | 55/65 |
| 随机森林 | **57/66** | **41/66 / 41/66** | 64/66 | **57/64** |

测试段随机森林只比原模型多 2 天同股，仍有 **9/66 天 Top1 不同**。森林的 1.7.1 与 1.9.1 测试概率绝对差中位为 0.0055，90% 分位为 0.0152。D0 Top5 规则会在全部前五只均未于 D1 开盘激活时轮空；因此 Top5 的分母与全池 Top1 不同，也不能直接拿 40/64 对 37/65 作为等样本收益比较。新增单元测试固定了这一空窗行为。

## 判断与限制

这次只建立一个 **R8 挑战者**，不修改 R5 原评分或任何实时选股。随机森林在训练、验证、测试三个时间段均减少了两版 Top1 换股，并且验证分类指标没有明显牺牲；但测试期已在此前 R5/R6/R7 研究中被看过，不能称为全新盲测。三日再板标签也不是实际交易收益。部署时仍应锁定软件版本、保存模型与输入哈希；跨版本升级时以影子评分比较每日名单，不能直接替换生产模型。进一步确认需在新的日期上冻结规则后前瞻记录，尤其核实开盘可成交性和卖出收益。
