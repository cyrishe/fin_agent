# R6：仅首板的 D0 评分、D1 开盘激活实验

2026-10-14。本实验独立于 R5 的全封板日模型，研究**第一次收盘封板**是否也能形成可排序的次晨机会。R5 的 Top1 几乎全部来自 D0 已连续封板至少两天；因此本实验只保留 `board_streak_days=1`，不把连板延续的强基率当作首板模型能力。

## 口径与数据

- 从 R5 同源的 `kingdomai.kcrp_stock_price` 历史日线构建。D0 为当前涨停段的首个收盘封板日；普通股涨跌幅档位与历史 ST 排除沿用 R5。D0 每只股票用当日及此前特征评分，D1 开盘价为正且低于按当日制度计算的涨停价时激活，D1 收盘或全日成交量**不参与激活**。D1～D3、D1～D4、D1～D5 任一日收盘再封板分别为三个标签；D1 开盘未封、收盘又封板算命中。
- 原 R5 面板中有 28,035 条首板 D0，按上述开盘条件激活 26,410 条。每日从同一激活候选池按昨晚分数选 Top1／3／5；无候选日轮空。首板的 16 个模型输入均取自 D0 或更早，包括首板形态、成交量／额相对前五日、换手率、前五日收益和市场广度。连板天数、连板累计涨幅及在首板子集内与 D0 重复的字段不进入训练。
- 按 D0 日期切分：验证始于 2026-04-01，测试始于 2026-07-01；较早集合需留足目标观察窗，同一涨停事件不可跨相邻集合。各观察窗尾部未成熟标签不当作失败。使用 R5 相同的浅层 `HistGradientBoostingClassifier`、训练类别权重和 scikit-learn **1.7.1**；验证由训练集模型评分，测试由测试前已成熟的训练＋验证行重拟模型评分。训练指标是拟合内结果。

测试 Top1 的 D1 当天重新封板分别为 **12/22、10/25、7/22** 次。因此模型命中仍有相当部分来自开盘后当天再封板；余下才是 D2 及以后首次达到目标的选择。作为固定简单对照，若每日只选 D0 换手率最高的首板股票，三个测试目标的 Top1 分别是 **11/66、12/65、13/64**；同池均匀随机选一只的期望命中数分别约 **12.6、14.6、15.9**。模型在这段历史中的排序好于该简单换手规则，但验证与测试命中并不稳定到可宣布交易规则。

## 解释边界与证据

R5 全封板池的 Top1 测试命中高于这里的首板子集，但两者的候选池、特征和训练集不同，不能将差值全归因于连板本身。R6 使用已被反复研究的 2026 年测试时段，是探索性历史对照，不是未看过数据的前瞻测试。开盘低于涨停价只是可买机会的价格代理；无委托簿、成交回执、实际买价、退出价、费用、滑点或资金占用回测。分类命中率不能解释为投资收益。

R5 全池有少量“开盘价有效但全日成交量为零”的历史行。R6 三个测试目标合计 195 次 Top1 选择已逐行与源日线核对，**没有**选到全日零成交行；这仍不能证明开盘价可实际成交。
