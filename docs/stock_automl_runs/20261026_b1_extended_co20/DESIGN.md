# CO20：原七因子滚动模型扩展回测与个股条件筛选

结果计算前固定于 2026-10-26。使用 CO7 保存的 sklearn 1.7.1、七因子、前 20 个交易日逐日训练的历史折外 Top1；CO14 已将 2026 年共同交易与 B1R 逐笔核对。回测 2025-08-01—2026-09-30 的 284 个信号日，不重新训练、不替换候选、不递补 Top2。2025 年扩展日期中有部分候选由后来重建，并非当时冻结的全部预测；不能称完全新盲测。该实验与 ACTIVE 的最高收益冻结拼接回放是不同序列。

固定原成交额门槛、14:40 分钟收盘买入代理、次晨 09:40 分钟收盘卖出代理。与 CO17 的直接对照统一每边 0.1% 费用：`net = sell*(1-.001)/(buy*(1+.001))-1`。只统计卖价已知且原本允许交易的样本，未知单列。月度按信号日归属；报告逐月复利、交易数、强势标签、大亏（净亏超过 2%）、盈利误拦、结算回撤，并补同月同笔数随机轮空。

因素全部在 D 日 14:40 前可知。价格用 D−1 或更早的复权收盘：此前 5/20 日收益需 6/21 个完整交易日价格；20/60 日价格位置为 `(D−1收盘−窗口最低)/(窗口最高−窗口最低)`，无价差记未知。资金用 D−1 及更早的缓存买卖额，净流强弱 `(买−卖)/(买＋卖)`，5 日取金额合计后计算；缓存历史版本可见性尚未证实，所以资金组只作探索，不能据此升级实时规则。任何缺值都不视作零或自动通过。

事前固定单因子门槛：前 5/20 日涨跌以 0 为界；20/60 日位置以 0.5 为界；前一日与前 5 日资金强弱以 0 为界。方向两侧都报告，不预设低位、弱势或流入必然更好。另看“前 5 日上涨且 60 日位置低半区”和“前 5 日上涨且前 5 日资金净流入”两个交叉。筛选只可在 2025-08—12 发现段执行；2026-01—06 为顺序验证，2026-07—09 为后续检查。门槛若在发现段需至少 20 笔、保留原交易 20%—80%、相较全做减亏且至少 4/5 月改善，才成为候选；选择以发现段净值增益排序，平局按门槛列序。验证和检查不参与选择。所有门槛及三段结果一并披露，不能只展示赢家。

最终判断着重多数月份能否获利、最大回撤、严重亏损拦截和盈利误拦；删最好月仅作辅助压力检验。市场已被多次研究，本次即使按时间切分也不是全项目盲测。
