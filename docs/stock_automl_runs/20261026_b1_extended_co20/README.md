## 因子筛选

只取D−1及以前复权收盘，考察此前5/20日涨跌和20/60日价格位置；资金只取D−1及以前的主力买卖额，计算1/5日净流强弱。过去完整交易日的需求、缺值处理、预设门槛和2025发现/2026验证切分见设计。219笔中价格因子都有值，60日位置218笔有值；资金缓存219笔有值，但**无法证明历史缓存每条当时14:40前已发布**，资金结论只供探索。相关系数按期均很弱，未经多重检验校正，不作显著性结论。
