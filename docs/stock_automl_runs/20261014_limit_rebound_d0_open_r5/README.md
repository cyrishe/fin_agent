# R5：封板日收盘评分，次日开盘激活

2026-10-14。此实验按拟交易时序重建样本，**不沿用 R2/R4 的冷静日收盘分数或命中率**。D0 是任一收盘封板涨停的股票日；连续封板的每一天都可以成为新的 D0，不需要提前知道整段连板何时结束。D0 收盘计算分数。下一市场交易日 D1，若当时不是 ST、开盘价为正且低于按当日涨跌幅制度计算的涨停价，则激活；按同一 D1 的各股 D0 分数排序选 Top1/3/5。D1 若开盘未封而收盘重新封板，计入成功。没有激活候选的日期空仓。

标签分别是**激活后的 D1～D3、D1～D4、D1～D5** 是否至少一次收盘封板。只有对应窗口内每日行情都可观察的样本进入该期限实验；未来没有激活的 D0 信号不记为 0。标签来自后续行情，但候选特征严格来自 D0 及之前；D1 开盘信息仅用于当日能否激活。封板标记取源日线的 `is_limit_price=1` 且收盘上涨，并非固定的 5% 或 10% 收盘涨幅阈值。

样本取自 R2 已保存的 2024-09-20～2026-10-13 `kingdomai.kcrp_stock_price` 日线，D0 从 2024-10-01 开始。按 `kingdomai.kcrp_stock_st` 历史有效区间排除 D0/D1 的 ST；支持主板 10%、创业板和科创板 20%、北交所 30% 的普通股。D0 收盘价与按相应制度计算的涨停价偏差超过 0.02 元者不纳入，以免特殊交易日误判。D1 开盘价达到涨停价的信号不激活。**激活条件不使用 D1 全日成交量或收盘信息。**42,523 个 D0 封板股票日中，36,329 行有受支持的普通股制度、标准封板及 D1 行情；其中 32,800 行按开盘价激活，5,060 行 D1 收盘再封板。以上是候选统计，并非实际可成交笔数。

## 输入、切分和训练

同一只股票连续封板至 D0 已发生的天数作为 `board_streak_days` 特征。其他 22 个 D0 可知特征包括首板及 D0 的 K 线形态、从首板累计涨幅、D0 成交额与换手率、相对首板及 D0 前五日的量额比例、D0 前五日收益/换手、D0 全市场封板数和上涨广度等。没有使用 R2 的任何冷静日当日或路径特征。固定使用原 R2 的浅层 `HistGradientBoostingClassifier`（scikit-learn 1.7.1）；只在拟合时以类别权重粗略均衡正负样本。

按 D0 日期顺序切分：验证始于 2026-04-01，测试始于 2026-07-01。较早集合的标签观察窗必须在后一集合开始前结束；跨集合的同一连板段从较早侧剔除。测试模型只使用在测试开始前能观察完整标签的训练＋验证行重拟。各期限尾部需要等完整窗口，因此有效天数不同。日期与逐行分数见本地 `summary.json` 和 `h{3,4,5}_{valid,test}_scores.csv.gz`。

## 重要拆分与限制

- 测试 Top1 里，D1 当天重新封板分别占 D1～D3 命中的 **29/38**、D1～D4 的 **27/38**、D1～D5 的 **23/43**。即便只看 Top1，总命中并不等同于“完整一天或数天未封板后再涨停”；D1 开盘低于板价、收盘封板在这里按用户的可买机会口径算命中。若单独研究 D1 收盘确未封板的后续再板，应把这部分列为事后分层，不能在 D1 开盘选股时预先剔除。
- 三个模型测试的每日 Top1 **全部来自 D0 当天已连续封板至少两天**。连续封板天数是强特征：只按 D0 已知连板天数最长来选，测试 Top1 命中依次为 **35/66、37/65、39/64**，与模型的 **38/66、38/65、43/64** 接近；模型是否提供超出简单连板规则的稳定 Top1 增量，目前没有证据。该对照在验证分别为 29/57、32/56、32/55，模型为 27/57、29/56、31/55。不可将总体命中率解释为模型已经学会独特的冷静期信号。
- 验证、测试窗口恰好每天都有激活的普通股候选；最低分别约 26、28 只。一般运行日可能没有，规则允许不选。准确计算 D1 的开盘涨停价依赖当日身份、板块和交易制度，历史特殊交易日的处理仍需复核。
- 开盘低于板价不证明能以开盘价买到。本次仅凭 D1 日 K 开盘价激活，有 **92 行开盘价为正但全日成交量为零**，这类记录尤其不能当作可成交；若用全日成交量作事后质量过滤，测试 Top1 的 3/4/5 日命中分别变为 **37/66、37/65、40/64**，说明模型选择对少量异常行敏感。真实执行必须改用开盘当时可见的逐笔或竞价成交确认，不能把全日成交量放进开盘规则。尚未核验集合竞价挂单、延迟、滑点、交易费用、持有期卖出和收益。这里仅是**封板分类命中率**。
- 这是已查看大量相邻历史数据后的新口径探索，测试集并非完全盲态。模型训练/验证/测试按时间隔离，但不能消除研究者反复看历史测试区间形成的选择偏差。下一步应冻结目标、候选和评分规则，在新日期验证。
