# 三分类边界处理：硬标签、边界降权和模糊标签

## 要解决的问题

三分类让 0%–1% 成为缓冲类。它比把所有 ≤1% 合并为一类更符合用户的风险偏好，但 **0% 和 1% 仍是硬标签边界**；训练时 0.99% 和 1.01% 会被当作不同类。普通交叉熵不会记录同一类内涨幅的大小，所以 1.5% 和 5% 有相同的硬标签。模型仍可通过七因子学习类别概率，但标签本身没有保留连续收益信息。

本实验在上一轮七因子三分类滚动实验的**相同候选、相同日期窗口、相同开收高训练／交叉验证口径**上，只比较边界附近的训练损失。仍只训练 14:40 涨幅 3%–6% 的 14,292 条候选，09:31–09:40 十根精确 1 分钟 K 设标签；按 `P(>1%) − P(<0%)` 取每日前二。三种方案在每个训练折都使用相同的四个标准化数值因子、三个二值因子和 `C=0.2` 的正则化强度；测试日期不参与训练。

- **硬标签**：`<0%`、`0%–1%`、`>1%` 三类原定义，作为控制组。与上轮保存的三分类逻辑回归 **450 个前二排序位置全部一致**。
- **边界降权**：标签不变。距离 0% 或 1% 边界 **0.2 个百分点以内**的样本，权重从边界处的 0.5 线性升至区间外的 1；把整体权重重新标准化为均值 1。让模型少受临界标签摆动影响。
- **模糊标签**：在每个边界两侧各 **0.2 个百分点**内，向相邻两类线性分配软标签。例如恰在 0% 或 1% 的目标各给相邻两类 0.5；区间外保持硬标签。用带 L2 正则的软目标交叉熵优化。这是本实验自定的边界过渡，不是已校准的概率模型。

这两项宽度和降权幅度在运行前固定，没有按结果扫描参数。训练是逐日滚动的 10、15、20 个可用信号日；三档共同的比较日期为 09-02 至 09-30 的 20 天。最高价只是曾触及的价格，不是成交回报。

## 判断

**边界降权比模糊标签更值得继续观察，但没有达到可宣称策略改善的程度。**在共同 20 天的 27 个窗口 × 训练价 × 验证价组合中，相对硬标签，边界降权使达标增加／持平／减少的组合数分别为 **13／13／1**，严重错误减少／持平／增加为 **17／8／2**。模糊标签的对应数量分别为 **10／14／3** 和 **13／4／10**。这些组合共享相同股票和日期，不能当作 27 次独立验证。

具体看，20 日最高价同口径验证：硬标签为达标 24、中性 10、严重错误 6；降权后为达标 24、中性 11、严重错误 5；模糊标签则为达标 24、中性 8、严重错误 8。10 日收盘价同口径验证在各窗口全部测试日期里，降权方案的严重错误反而从 15 升至 16、达标从 22 降至 21。效果不是处处一致。所有日期均已被反复研究，尚无新的盲测样本，因此不要再依据当前表格调边界宽度或宣称稳定提升。
