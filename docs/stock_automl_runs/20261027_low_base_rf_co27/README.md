# CO27：随机森林、时间窗口和因子相关性

2026-10-27。按用户要求补充CO26未做的随机森林和因子相关性。**随机森林在2026年测试的Top3比逻辑回归少亏，但仍低于同日候选池；历史区间有限、配对区间跨零，尚不支持作为正式交易模型。**

## 口径与范围

复用CO26同一批低位L股票日和22项D日收盘及以前量价因子：近60日区间位置≤35%、20日涨幅≤8%；不要求严格收敛。D+1开盘参考买入，D+2或D+3收盘参考卖出，单边费用0.1%。标签为净收益<−2%、−2%～+2%、>2%。一价入场、疑似锁跌停退出和缺价保持未知。完整历史ST、真实订单和重叠账户尚未核实。

每月用过去6个完整自然月、标签在预测月开始前成熟的样本训练。2025-01—12为逐月向前验证，2026-01—09为逐月向前测试；预测2026年前，2025验证选型只使用2026-01-01前已成熟的结果。2026历史此前已研究，新增随机森林是事后提出的挑战模型，不是全新盲测。

例如D+2预测2026年9月，实际训练信号日期为2026-03-02—08-27，共124日、345,532个股票日，最后标签在08-31成熟；测试09-01—09-30，共21日、35,738个候选股票日。训练集中跌超2%/中间/涨超2%分别为29.42%/46.33%/24.25%。预测2026年1月时，训练集中跌超2%为17.43%，显示分布会变化。

## 因子相关性

22项因子之间既计算全样本Pearson，也逐日计算候选池内Spearman后按日期等权汇总；后者能减少市场整体涨跌对个股排序关系的混淆。2026年例子：

|因子对|2026股票日Pearson|2026日内Spearman均值|
|---|---:|---:|
|5日涨幅 / 5日相对市场超额|+0.828|+1.000|
|10日涨幅 / 相对20日均线|+0.902|+0.869|
|当日涨幅 / K线实体|+0.914|+0.899|
|5日涨幅 / 5日均线斜率|+0.864|+0.834|

相对市场超额＝个股5日涨幅−同日共同的市场5日涨幅，因此同日排序相同；两者的日间水平差也可携带市场背景，不能仅凭相关性直接删除。完整[22×22矩阵](factor_pearson_2026.csv)、[逐日相关汇总](factor_pair_daily_summary.csv)。

每个交易日内另按候选股票计算因子与D+2/D+3后续净收益的Spearman，以及与涨超2%、跌超2%标签的秩相关。2026年D+2：5日波幅与净收益平均日内相关−0.057，与涨超2%相关+0.090、跌超2%相关+0.152；20日波动率相应为−0.052、+0.102、+0.153。较高波动同时关联两端结果，不是大涨保证。3日涨幅与净收益的平均日内相关2024/2025/2026分别+0.019/−0.035/+0.036，方向变化明显。这些是相关性，不是因果或直接可执行规则。完整[逐年相关](factor_ic_year.csv)、[逐月相关](factor_ic_month.csv)。

样本共有666个交易日，其中664日达到至少30个已知样本、可计算日内相关；不同因子缺失数量不同。66项跨年份独立SciPy抽查通过，包含120日位置缺失的成对重排；因子与标签统计均以已知价格代理为准。

## 随机森林结果

模型固定80棵树、最大深度7、每叶至少200条、每次分裂抽70%因子、每棵树用10%训练样本自助抽样、随机种子42；按训练日期等权。原本50%抽样的试运行因耗时过长在任何模型结果出现前中止，随后固定10%完成全期。不同参数和更大抽样比例未在本轮比较，结论限于这套随机森林。逻辑回归和HGB是CO26同窗口、同标签已保存模型。

未知价格不填零：2026年181个预测日中，森林D+2/D+3分别有12/17日的Top3至少一笔未知；逻辑回归为23/21日。共同日期会比各模型单独可核定日期少；上述收益也不是经过资金和延期退出处理的账户收益。

## 模型区分度、训练表现与头部概率

对每个测试日的全部已知候选分别计算上涨端/下跌端AUC，再按日等权。森林D+2验证期为0.613/0.657、测试期为0.587/0.609；D+3验证期为0.591/0.623、测试期为0.555/0.573。[逐月日均AUC](daily_auc_monthly.csv)。整体排序有一定区分度，不能据此推断Top3一定盈利。

每个模型的训练折随机抽1000条，按每棵树的袋外预测计算拟合诊断；测试期每月另随机抽1000条有结果候选。D+2测试期训练折袋外上涨/下跌AUC均值约0.639/0.650，向前月份抽样约0.594/0.567。它们按股票日抽样、在月内汇总，和上一段日内等权AUC口径不同；袋外并非时间留出检验。这些及下述概率偏差均为事后诊断，没有参与选参。[逐折拟合诊断](fit_diagnostics.csv)。

森林2026年D+2 Top3自身均已知的169日中，平均预测涨超2%概率37.40%、跌超2%概率22.17%；实际比例25.84%和38.46%。这是选中且已知头部样本的描述，未知样本尚未纳入，不证明全候选池概率校准。它提示上涨端可能被高估、下跌端可能被低估。[概率与实际对照](score_quality_summary.csv)。

森林D+2在2026年9个测试折中，20日波动率和5日波幅的平均分裂重要性分别约27.93%和24.44%，合计约52.37%。两项波动因子相互关联且同时关联涨跌两端，与头部同时出现大涨和大跌的现象相符；分裂重要性受相关因子和树结构影响，不等于独立增量或因果解释。[逐折重要性](rf_feature_importance.csv)。

## 核验与归档

42个模型的训练成员、标签成熟时点与CO26完全一致；每份模型回读并抽样复算预测。5项定向测试、66项独立因子相关性计算通过。模型、概率、样本、逐日结果、因子矩阵与代码保存于本地；数据库及云端状态见归档回执，云端独立回读前为待同步。未修改生产策略。
