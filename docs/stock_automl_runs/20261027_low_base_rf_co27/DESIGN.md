# CO27：CO26宽低位样本的随机森林与因子关联

2026-10-27冻结。应用户要求，在CO26相同的低位候选、D收盘因子、D+1开盘至D+2/D+3收盘净收益代理（双边各0.1%）、三分类阈值及未知处理下增加随机森林。训练月份、标签成熟界限、每日日权重和预处理与CO26一致，每月使用此前6个完整自然月成熟样本。2025-01—12为向前验证，2026-01—09为向前测试；2025年底验证汇总只用2026-01-01前成熟标签。2026已在CO26中观察，随机森林是后续提出的探索性挑战，不能称全新盲测，也不根据2026结果挑超参数或决定部署。

随机森林固定80棵、最大深度7、叶最少200、每次分裂抽70%特征、每棵树bootstrap抽取10%训练样本、seed42，不设类别平衡；所有符合条件的日期样本均有机会参与森林训练，每棵树抽样口径如上。50%抽样的首个无结果试运行因耗时过长提前终止，在任何训练结果出现前固定为10%；这是一种资源与结果稳定性的权衡，不同于每棵树使用全部样本。样本缺失中位数和1%/99%截尾仅由训练折计算，日期等权，排序仍为P(>2%)−P(<−2%)。D+2、D+3分别训练，每月都预测全部候选；模型不因看到测试收益而选择。相同候选和已成熟交易标签时，对CO26已验证选择的逻辑回归、同日候选池和最低位置规则同时比较，每日Top1/3；共同已知样本与未知数量分开。2025 HGB仅用于历史验证比较，2026没有HGB测试，不能伪称其与RF有完整测试对照。

补充输入因子22×22的Pearson相关矩阵，分别按2024、2025、2026和全期展示，缺失采用成对有值；同时按每个交易日计算因子与后续收益的Spearman秩相关及两端标签的相关，分月/年汇总，避免把全市场行情变化混作个股因子优势。相关性是观察不等于因果；已观察的历史不是新盲测。报告逐月实际训练开始/结束、最后标签成熟日期、训练日/样本数、类别分布、预测日/候选样本量和未知标签。

记录模型、训练成员、概率、因子相关表、逐日月对照、代码和哈希；独立复核训练成员/时序、模型回读与排名。无账户复利、生产策略或新阈值调整。
