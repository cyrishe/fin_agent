# CO11：独立下跌模型校准后与固定 B1 结合

2026-10-15，新结果产生前冻结；已有历史已反复研究，本轮仍为探索，不是全新盲测。

## 不变部分及时间边界

- 复用 CO10 已冻结的 nonfall_hist（主）与 extreme_hist（对照），不重训、不使用 B1 身份训练风险树。
- 风险事件：次晨正式开盘价/信号日14:40价−1≤−2%。它与次晨09:40实际退出亏损不是同一事件。
- 每月原60日树训练后，原40验证日的前20日做概率校准，后20日独立检查校准；下一月测试。所有校准标签必须在检查期首日14:40以前成熟。检查结果不用于选阈值或改方案。
- 校准用完整标签分布，包含−2%至0之间的样本，无大跌加权、无按结果抽样。逐日等权，logit(score) 上 Logistic(C=1) 拟合概率；斜率为负时退回校准期事件频率。少于30个正例或30个负例时同样退回频率。
- 同时做全市场校准和事先定义的当日涨幅4%–9%子群校准。后者用于该子群，其余股票用全市场校准。不针对 B1 小样本单独拟合。
- B1名单、原成交额规则和手续费均沿用CO8；14:42 open成交代理，次晨09:40 close退出，10万元初始现金，不借款。概率缺失时保留原交易，另报告缺失数。

## 全部预设方案

1. 原成交额 B1。
2. 主方案：子群校准概率≥30%轮空。
3. 20%、40%、50%三个阈值敏感性，全部报告。
4. 全市场校准概率≥30%轮空，检验校准人群是否重要。
5. nonfall 与 extreme 的子群概率均≥30%时轮空。
6. 分档仓位：主模型子群概率<20%用全仓，20%–40%半仓，≥40%轮空。
7. 相对风险：主模型原分数达到校准期同类4%–9%股票90%分位时轮空；非该子群用全市场90%分位。分位只用前20日，无测试收益参与。

不根据测试收益挑一个方案作为已有效结论。下层风险概率不能直接与B1的“次晨第二高价达标概率”相减来当预期收益，事件及价格口径不同。

## 评价与可复核材料

- 全部方案逐日、逐月净收益、结算及持仓分钟回撤、交易数、每笔全额交易净收益、实际账户单次收益、平均仓位；避开亏损和大亏、错过盈利；开盘事件覆盖单列。
- 全市场/4%–9%子群/B1 的概率均值、实际发生率、Brier、固定概率分箱；月度检查，避免将加权分数称为真实概率。
- 各方案同月同仓位分布随机置换1000次，及原B1恒定平均仓位对照；作为事后诊断，不作为可部署策略或多重研究修正的显著性。
- 主方案相对基准及各方案相对恒仓位对照的5/10日配对块区间。额外10bp执行成本敏感性；最大贡献日剔除诊断。
- Top1原始达标/可接受/错误率保持不变；本轮未取得同身份完整Top5和对应14:42成交路径，Top5递补不混用其他版本数据，不纳入正式收益比较。
- 保存校准样本、模型参数、检查/测试B1分数、源文件哈希、时间审计、逐日明细及归档回执。CO10原树与原始全市场测试分数使用其已归档不可变包作为依赖。
