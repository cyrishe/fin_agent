# CO11 结论：可以叠加，但高概率硬拦截尚未证明可靠

本轮实际比较了9个预设方案。B1选股、原成交额规则、独立风险树均固定；新增的是概率校准和交易/仓位处理。原Top1第二高价达标21.13%、可接受29.58%、错误49.30%（284个已知标签）在各方案中相同。次晨开盘风险标签已知283个，其中35个大跌；成交额通过的222笔全部有开盘标签，其中27个开盘大跌、51个09:40净亏超过2%。这些分母不能混用。

## 1. 有概率估计，原始分数不能直接叫概率

全体B1已知开盘标签样本中，原加权分数均值49.74%，真实开盘大跌率12.37%；强势子群校准后的估计均值13.11%，全市场校准为10.07%。平均水平明显改善，但不代表逐股排序已经可靠。

例如主模型原始分数0.8，在2025-08强势子群校准后约43.69%，2026-03约18.60%，2026-06约21.35%。每月原树、市场状态及校准样本不同，不能把跨月分数当成同一把概率标尺。

校准后的概率也有不稳定：全体B1中预测10%–20%的115个样本，实际大跌15.65%；预测20%–30%的43个样本，实际13.95%；≥30%仅7个样本、1次大跌。不能将后者视为已经校准准确的“高确定性危险区”。按月检查与Brier完整保存，未凭总体均值宣称模型可靠。

## 2. 高概率才轮空，实际作用很小

正式全期2025-08至2026-10-13，14:42 open买入代理、次晨09:40 close卖出，既定费用后现金复利：

|方案|笔数|总体净值收益|结算最大回撤|避开亏损/其中大亏/错过盈利|
|---|---:|---:|---:|---:|
|原B1成交额|222|−43.37%|55.94%|0/0/0|
|≥30%轮空（预设主）|215|−42.28%|52.38%|5/1/2|
|≥20%轮空（敏感性）|175|−13.32%|35.43%|28/15/19|
|20%半仓、40%轮空|219|−25.98%|43.80%|3/1/0|
|两模型均≥30%轮空|219|−43.50%|56.04%|2/0/1|

其余阈值与相对最高10%分位全部见README及summary.csv，没有把20%事后换成预设主方案。

只保留“两个模型都很确定”反而漏掉风险：2026-01-12的603169，主模型概率66.60%，两极模型16.43%，实际09:40净收益−5.98%，双模型规则没有拦。共识不是可靠性的充分条件。

## 3. 20%门槛、减仓有探索价值，但未建立可靠盈利结论

- 原2026-02至07区间：原B1 91笔+41.81%/回撤24.39%；20%门槛78笔+51.34%/18.73%；分档仓位91笔+46.74%/21.59%。30%门槛90笔+33.74%/24.39%，因误拦盈利反而变差。
- 全期20%门槛−13.32%，对比原B1恒定78.83%仓位−34.76%；分档仓位−25.98%，对比恒定88.74%仓位−38.85%。改善不完全是机械减仓。
- 同月同仓位分布随机置换1000次，随机收益不低于实际的比例：20%门槛9.5%，分档仓位4.9%。这是事后诊断，不能按普通p值宣称显著；预设方案不止一个，已有历史被多次研究。
- 相对恒仓位基准，20%门槛的日均收益差约+0.0998个百分点，10日块95%区间[−0.0664,+0.2722]；分档仓位+0.0638个百分点，区间[−0.0236,+0.1530]。均跨0，不能确认稳定优越。
- 剔除最大改善贡献日2025-11-20后，原B1−32.17%，20%门槛−13.32%，分档仓位−19.31%；改善不只依靠该日，但总体仍亏。
- 额外10bp成本下，全期20%门槛降为−27.26%，分档仓位−39.23%。交易成本与成交代理不能忽略。

## 4. 必须对准实际09:40损失，而不只优化开盘标签

20%门槛拦47笔：避开28笔亏损（其中15笔净亏超过2%），同时错过19笔盈利。只拦到6/27次开盘大跌；保留部分开盘大跌21/175=12.00%，原为27/222=12.16%，几乎没降。说明现有交易改善不能归结为已可靠识别开盘大跌。

例子：

- 2025-11-20，300390：风险20.33%，次晨开盘−12.68%，09:40净−16.52%。20%门槛拦住，30%门槛错过。
- 2026-03-03，600188：风险28.65%，开盘仅−0.76%，09:40净−6.34%。这是开盘之后继续下跌，开盘大跌标签本身没覆盖。
- 2025-10-22，600172：风险23.22%，开盘+9.15%，09:40净+12.32%，被20%门槛误拦。当天所在10月的收益从−0.59%降至−11.79%。

逐笔案例见p20_blocked_cases.csv；风险分箱与两种目标并列见b1_traded_risk_bins.csv。

## 建议的后续结合

维持独立全市场模型→固定B1候选→风险评估的结构。下一轮优先把独立风险目标对齐“14:42成交至次晨09:40扣费后大亏”，同时估计大亏概率和亏损幅度，比较软减仓与硬轮空；开盘风险作为辅助目标。中间样本用于校准和完整验证，两极样本只是训练对照。需要进一步独立时间验证及冻结后的前瞻记录。

Top5递补需要同身份完整候选和成交价单独检验，目前未取得本机对应归档，本轮不声称验证过；也不把B1第二高价达标概率与开盘下跌概率直接相减当收益评分。可考虑的后续策略是限制换股只在原Top候选内发生，同时给“不交易”独立选项，但必须以同一退出目标验证。

本轮没有改动线上B1，也没有把历史中表现更好的20%敏感性门槛升级为已可靠策略。
