异常规则：对 D2～D4 每天的数据库 `preclose` 与该股前一交易日 `close` 核对，任意一天差异超过 2% 标为“价格异常”。只有 **1 笔入选**触发：2024-05-21 D0 的 603773，在 D3 前收盘价由 33.48 跳到调整后昨收 25.71，原价连续收益不能直接代表持有收益。该笔在工作簿保留 D0 特征和封板标签，收益字段留空，不进入任何收益均值；未用事后异常替换 D1 当时已选股票。其它 99 笔仍为负，异常不是负收益的主要来源。价格异常标记只作事后审计，不能当成 D1 开盘可执行的筛选规则。
