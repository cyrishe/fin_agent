# 未排除历史 ST 的四分类最佳模型：14:40 涨停与选股核查

## 核查对象与方法

对象为原始 **3%–6%** 候选池训练的、未加权的小型提升树四分类模型，按“预测 `≥3%` 优先，缺额顺延 `1–3%`”每天选 Top1/Top2。它曾在 20 个折外日录得 09:40 卖出每笔平均 Top1 **+1.311%**、Top2 **+0.484%**；这些是未按历史 ST 状态过滤的旧模型结果。

用已核验的 `kcrp_stock_st` 信号日 `S/Y` 区间识别历史 ST，逐条连接 `kcrp_stock_price` 当日行情及 `aiia_stock_realtime_minute_snapshot_full` **14:40 精确 1 分钟 K**。40 个信号日原池共 300 条历史 ST 股票日；每折用前 20 天训练，故其中 **290 条至少进入过一个训练窗口**，最后一天的 10 条只作为测试候选、从未进入这 20 折的训练。旧模型实际入选的 Top1 20 笔、Top2 40 笔另行逐条核对。

`is_limit_price=1`、当日收盘高于前收盘，且 14:40 价等于收盘价，是“14:40 使用上涨收盘涨停价”的严格事后标记。另计算昨收 × 1.05 四舍五入到分的**名义 5% 价位**，但它不是各股票真实涨停价的通用定义。特别处理状态与实际涨跌幅限制不完全相同，不能只凭 4.99% 或 5% 判定封板。分钟 K 的成交量、开高低收用于查有无成交和价格波动；它们仍不能证明一笔模拟买单可以在该收盘价成交。

## 结果

| 核查项目 | 历史 ST 候选 300 条 | 其中实际进入过训练的 290 条 | 旧模型 Top1 20 笔 | 旧模型 Top2 40 笔 |
|---|---:|---:|---:|---:|
| 当日收盘标记上涨涨停 | 0 | 0 | 0 | 0 |
| 14:40 等于上涨涨停收盘价 | 0 | 0 | 0 | 0 |
| 14:40 恰等于名义 5% 价位 | 16 | 16 | 0 | 0 |
| 上述名义 5% 股票当日最高价继续高于该价 | 15 | 15 | — | — |
| 14:40 分钟成交量为零 | 16 | 16 | 0 | 0 |
| 14:40 分钟开高低收相同 | 97 | 94 | 0 | 0 |
| 信号日历史 ST `S/Y` 直接被选中 | — | — | **0** | **0** |

16 条恰在名义 5% 价位的历史 ST 样本中，**15 条当日最高价超过该价**，说明名义 5% 对它们不是当天的价格上限；剩下一条（2026-09-18，`600340`）的 14:40 分钟价在 **1.11–1.12 元**间波动、分钟成交量为 **2,301**，当日收于 **1.11 元**，未见持续封板。故不能把这 16 条机械算作“涨停买不到”。反过来，290 条进入训练的历史 ST 中有 **16 条 14:40 分钟零成交**，这类样本的记录价不能证明该分钟有可执行买价。其余 274 条该分钟有成交，也无法从 OHLCV 推出真实买单一定能按收盘价成交。

旧模型 Top1/Top2 **没有选中任何 `S/Y` 历史 ST**。40 笔入选股票日的 14:40 分钟 K 均精确、非 fallback、有成交且开高低收并非全相同；最小分钟成交量为 **138**（数据源原单位）。它们也没有当日上涨收盘涨停标记或 14:40 涨停收盘价标记。因此，旧 Top1/Top2 的历史收益**不是直接买入了封板 ST 股票所得**。这只能排除明显的 ST 涨停不可买问题，不能确认 14:40 模拟成交价、盘口排队或实际订单成交。

旧模型与按历史 ST 过滤后重新训练的模型名单和收益不同，是**训练样本改变后模型预测及排名变化**；不能把差异归因于旧名单直接选中了不可交易 ST。此次核查不证明在训练中保留 ST 一定更好，也不能把旧回测收益当成稳健的未来收益。历史 ST 状态比保存的名称更可靠：这 300 条 `S/Y` 股票在本次旧归档和 14:40 分钟行情的 `name` 字段里都未显示 `ST`。
