# 四分类七因子：最近 20 日滚动基准（含 ST、当日候选不看次日）

本页只把 `recover_53` 一组定义为基准。已在 2026-10-10 重新运行 `scripts.experiment_automl_recovered_morning_labels`，并逐日核对入池股票数和名单。历史研究，不发交易委托。

## 唯一口径

1. **候选池**：每个信号日 T 的 14:40 价格相对昨收涨幅在 **[3%, 6%]**，且七因子完整。**不按名称或历史状态排除 ST**；不使用 T 日 14:50、T+1 日行情、标签或停牌结果筛选 T 日候选。40 个信号日共 14,783 个股票日，含名称带 ST 的 414 个。测试阶段 20 日共有 5,984 个候选，含 ST 125 个；5,984 个都得到预测。
2. **七因子**：14:40 涨幅、量比、截至 14:40 换手率、T−1 流通市值、前五日成交量四日递增标志、5/10/20 日均线多头标志、当日截至 14:40 最低价高于三条均线标志。T 日行情来自历史分钟 K 还原的 14:40 快照，日线和估值来自 T−1 及更早。
3. **训练标签**：T+1 日 09:31–09:40 十根 1m K 的第二大 `high_price` 除以 T 日 14:40 价格再减 1，分 `<0%`、`0–1%`、`1–3%`、`≥3%`。相同最高价可以占据第一和第二位；不是第二个不同价格。
4. **训练**：每个测试日只选此前最近 20 个信号日，且仅将已有真实标签的历史股票用于监督训练。历史分钟表原有 14,724 个标签，另外 53 个从分钟行情 API 补齐；剩余 6 个次日停牌，无法定义这个价格标签，**只在其成为历史训练样本时不参与拟合，不从其信号日候选池预先删除**。未加类别权重的 `HistGradientBoostingClassifier(max_iter=60, learning_rate=0.05, max_leaf_nodes=7, min_samples_leaf=100, l2_regularization=5, early_stopping=False, random_state=42)` 每日重新拟合。
5. **排序**：每股输出四类概率；预测最大概率类别为 `≥3%` 的股票先按 `P(≥3%)` 降序，接着预测最大概率类别为 `1–3%` 的股票按 `P(≥1%)` 降序，最多取两只，第一只为 Top1；若均无合格类别则空仓。该 20 日每天都选出 Top1 和 Top2。
6. **价格代理**：T 日 14:40 分钟收盘价作为买价，T+1 日 09:40 分钟收盘价作为卖价，每笔收益为卖价 / 买价 − 1。无费用和滑点；看完 14:40 K 后按同一根 K 收盘价成交尚未证实。
