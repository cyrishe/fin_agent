# 个股规模、量能与换手率画像

接续[正样本先行研究](../20261008_positive_cohort/README.md)，本轮为此前选出的次晨前 5/10 分钟触及假设买价 +1% 的股票逐日补充市值、近 5/10 日成交量与换手率画像，并用同日未命中的股票作比较。聚合证据在 `summary.json`；逐股明细写在被 Git 忽略的 `outputs/stock_automl/cohorts/`，不进入仓库。

## 口径与时间

信号日 T 固定在 14:49:59 决策。近 5/10 日均成交量、成交额及换手率均截至 **T−1**，要求连续交易日的 10 条日线都有正成交量、正成交额，且 10 条记录当前版本的 `create_time`、`update_time` 均不晚于决策时点。总市值和自由流通市值也只取 **T−1** 的 `kcrp_stock_pricevaluate`，其当前版本的创建和更新时间同样须早于决策时点；否则对应值在明细中留空。市值单位为**亿元**，成交量为**百万股**，成交额为**百万元**，换手率为表内原始百分数。

继续沿用上一轮的回顾性队列：信号日最终收盘涨停者已剔除。该最终涨停事实不能成为实盘 14:49 的输入，因此以下提纯只是在这个已知结果的历史队列上作探索，不是可直接上线的筛选器。全部队列 123,536 条，其中前 5 分钟触及 +1% 为 42,272 条；严格 14:49 候选且日线历史可用的有 106,434 条。近 10 日日线画像在其中 106,259 条可核实，总市值在 96,876 条可核实；两类共同可用且模型因子完整的有 96,719 条。估值表的当前行存在事后更新，因此缺失市值不以未来值补齐。

## 正样本的画像

下表在各因子可核实的股票上比较前 5 分钟命中与未命中的中位数。AUC 先在每个信号日单独计算，再对日期取平均；0.5 表示同日不能区分。

| 因子 | 命中中位数 | 未命中中位数 | 同日平均 AUC |
|---|---:|---:|---:|
| T−1 总市值，亿元 | 60.38 | 68.01 | 0.469 |
| T−1 自由流通市值，亿元 | 31.41 | 35.14 | 0.470 |
| 近 5 日均成交量，百万股 | 8.59 | 9.26 | 0.494 |
| 近 10 日均成交量，百万股 | 8.67 | 9.59 | 0.487 |
| 近 5 日均成交额，百万元 | 140.63 | 113.06 | 0.557 |
| 近 10 日均成交额，百万元 | 143.52 | 118.45 | 0.549 |
| 近 5 日平均换手率，% | 2.41 | 1.68 | **0.632** |
| 近 10 日平均换手率，% | 2.44 | 1.75 | **0.624** |
| 近 5/10 日均成交量之比 | 0.988 | 0.968 | 0.542 |

将每个交易日的股票按近 5 日平均换手率分成五组，前 5 分钟触及率从低组到高组依次为 **21.4%、30.5%、36.5%、41.8%、47.9%**；前 10 分钟对应为 **25.8%、34.8%、41.0%、46.2%、52.1%**。这个关系在 22 个严格回放日的同日 AUC 都高于 0.5。按上市板块分别计算，沪主板、深主板、创业板、科创板的平均同日 AUC 约为 **0.657、0.633、0.600、0.615**；再按同日市值五分位分层，板块×市值组内的平均 AUC 仍约 **0.621**。这降低了“只是在识别高波动板块或小市值股票”的疑虑，但不能证明换手率有因果作用。

作为可解释的**前置粗筛诊断**，保留每个交易日近 5 日平均换手率排名前 60% 的股票：

| 区间 | 原候选五分钟命中 | 保留后的五分钟命中 | 保留比例 |
|---|---:|---:|---:|
| 训练，14 天 | 22,256/67,369 = 33.0% | 15,656/40,427 = 38.7% | 60.0% |
| 已看过的中段，3 天 | 8,043/14,567 = 55.2% | 5,634/8,741 = 64.5% | 60.0% |
| 已看过的后段，5 天 | 7,541/24,323 = 31.0% | 5,535/14,596 = 37.9% | 60.0% |

这道规则在后段减少约 40% 候选，同时也误杀约 27% 正样本，只适合讨论“去掉一部分噪音”。它的 60% 比例是在观察本批数据后形成的研究口径，没有独立验证。

## 对模型前排是否继续提纯

为了公平比较，只在同一批 **96,719** 条市值、量能都有时间证据的候选上重训上一轮的 5 因子逻辑回归；再加入四个不同维度的画像输入：总市值对数、10 日均成交量对数、5 日平均换手率、5/10 日量比对数。模型仍在训练段拟合，按每天分数前 1% 检查；中后段日期此前已被研究过，并非盲测。

| 区间 | 同批候选基准 | 原模型前 1% | 加画像后前 1% | 每日前五名：原 / 加画像 |
|---|---:|---:|---:|---:|
| 训练，14 天 | 32.3% | 292/588 = 49.7% | 264/588 = 44.9% | 37/70 / 36/70 |
| 已看过的中段，3 天 | 55.0% | 99/145 = 68.3% | 90/145 = 62.1% | 12/15 / 11/15 |
| 已看过的后段，5 天 | 30.9% | 143/244 = 58.6% | 147/244 = 60.2% | 16/25 / 15/25 |

加入画像提高了中后段的同日整体 AUC（中段约 0.549→0.630，后段约 0.609→0.653），但**没有稳定提高最前排命中率**。原模型前 1% 的股票本来就已经高度活跃：其近 5 日平均换手率中位数约 8.6%，在这批内部，换手率的同日 AUC 后段仅约 0.506。把上面的换手率前 60% 规则再加到原模型前 1%，后段只从 244 条删掉 3 条，而删掉的 3 条全部命中。按“每周少量出手”目标，现有画像还不能作为最终置信度门槛。

换手率可能同时提高向上触及和向下波动的机会；本轮标签仍是分钟最高价触及，不包含真实买入价、卖单排队与成交回报。数据日期也已反复观察，不能据这些命中率声称可交易策略已经验证。

## 复现与明细

先运行上一轮 `scripts.audit_automl_positive_cohort` 生成本地队列和 `scripts.experiment_automl_positive_first` 生成前五名明细，再运行：

```bash
python -m scripts.audit_automl_stock_profile --env-file /path/to/.env
python -m pytest tests/automl/test_stock_profile.py -q
```

可直接查看本地 `stock_profile_positives.csv`（正样本逐股画像）、`stock_profile_cohort.csv`（含未命中对照）及 `stock_profile_prior_top5.csv`（上一轮模型逐日前五名画像）。这些文件均在 `outputs/stock_automl/cohorts/` 下并被 Git 忽略。`summary.json` 记录脚本 SHA-256 和聚合结果；数据库没有冻结快照版本，未来重算可能受到源表修订影响。
