# R1：涨停后冷静 1–3 日再涨停的全年样本普查

**研究时点**：2026-10-13 收盘后；日线库该日 `update_time=15:08:01`。本实验仅识别历史样本，不训练模型、不产生交易信号或收益结论，不与 B1 的 14:40 模型比较。

## 样本与目标口径

- 范围：2026-01-05 至 2026-10-13 共 185 个交易日；`kcrp_stock_price` 中代码以 `0/3/6/9` 开头的沪深及库内北交所股票。包括当时的 ST 和退市风险股票，尚未做可交易性筛选。
- **封板涨停**：供应商日线 `is_limit_price=1` 且收盘价高于昨收。该批 15,515 个股票日均满足当日最高价等于收盘价、成交量大于零。触及涨停但收盘未封住的炸板不计入。日线不能排除盘中开板后再次封住的情况。
- **总样本**有两个层次：① 所有封板涨停股票日 15,515 条；② 用于后续冷静期标签的**连续涨停段** 12,342 段。连板合为一段，以该段首次涨停日标识样本；2025-12-25 起的数据用于识别跨年连板。
- 其中 48 个 2026 年涨停股票日延续了 2025 年末已经开始的连板，计入股票日总数，但没有作为 2026 年新开段重新计数。
- 从连板结束后的第 1、2、3 个**市场交易日**起观察：先连续出现 1–3 个非封板涨停日，接着的下一个交易日重新封板涨停，即主目标。需要各观察日都有该股日线记录；缺记录单列。若第 1–3 个目标日中先有非涨停的收盘涨幅 `≥7%`，另记大涨；如果之后又涨停，两者均保留，主目标仍算再次涨停。
- 截至 10 月 13 日观察期尚未结束的样本为右删失，不作为失败样本。历史股票名来自当前 `kcrp_stock_baseinfo`，仅供查阅，不能当作历史 ST 身份。

## 结果

| 项目 | 数量 |
|---|---:|
| 封板涨停股票日 / 不同股票 | 15,515 / 3,441 |
| 首板起算的连续涨停段 | 12,342 |
| 已有完整目标观察的涨停段 | 12,148 |
| 冷静 1–3 日后再次涨停 | 1,912 段 / 959 只股票 |
| 其中冷静 1 / 2 / 3 日 | 715 / 601 / 596 段 |
| 至少 7% 但观察期内未再次涨停 | 855 段 |
| 再次涨停或至少 7% | 2,767 段 / 1,404 只股票 |
| 右删失 / 缺该股观察日行情 | 191 / 3 段 |

在 12,148 个已完整观察的涨停段中，再次涨停率为 **15.74%**；把非涨停的至少 7% 大涨也算目标，比例为 **22.78%**。另有 52 段先出现非涨停的至少 7% 大涨、随后再次涨停，已计入 1,912 段，不重复计入 855 段。

- 复算命令：`.venv/bin/python -m scripts.analyze_automl_limit_rebound_2026`；脚本只读行情数据库。汇总和样本表随本实验提交，约 16 MB 的原始日线缓存留在本地。
- 若训练“冷静期中识别谁会再涨停”的模型，应把每个可交易冷静日作为**当时可观察的决策样本**，仅用截至当日可得的特征，按时间切分训练与测试。上述 15.74% 是事后连板段基率，不是买入后收益，也不证明冷静日能够以给定价格成交。
