# R1 冷静期决策特征：设计与生成

这是 [R1 涨停段普查](README.md)的下一层研究资产。目标是在一段连续封板涨停之后，每个**实际出现且未封板**的冷静交易日收盘，判断后续是否重新封板。变量及口径在本文定义，预测效果见[逐日预测实验](../20261013_limit_rebound_model_r1/README.md)；尚无交易收益结论。所有变量是候选假设，不预设方向或有效性。

## 观察时点和样本

一段连板结束后，冷静第 1、2、3 个**市场交易日**各生成一条决策样本；可将 `--max-cooling` 设为 4 或 5，但不允许超过 5 个交易日。若期间缺该股票日线或重新封板，该段停止生成后续冷静日样本。每行唯一键为 `symbol, first_limit_date, streak_end_date, asof_date, cooling_day`。特征只取 `asof_date` 收盘前已发生的股票、市场和原始首板分钟数据。实用上是每天收盘更新一次概率，不用先猜冷静期最后会持续几天。

主标签 `label_next_limit_up` 是**下一市场交易日**供应商 `is_limit_price=1` 且收盘高于昨收；同时保留下一日非封板但涨幅 ≥7%、下一日二者并集、未来固定 3 日内任一再涨停，以及未来 5 日至少两次涨停的辅助标签。它们在单独的 `labels.csv.gz`，训练时只能按唯一键连接。下一日缺行情或尚未到来时标签为空，不能当负例。3 日和 5 日标签只有完整观察时才给值；因此它们的样本分母与主标签不同。主标签与 R1 的“连续冷静 1–3 日后次日再封板”一致，但**12,148 段的 15.74% 事后基率不是逐日决策样本的命中率**。

## 候选变量族

完整、可机读的字段名与公式说明维护在 [`FEATURES`](../../../scripts/build_automl_limit_rebound_features.py) 字典；本批次的[因子目录快照](feature_catalog.json)也已保存。新增变量只需在对应族增加一条定义及计算，并由测试检查目录与输出列完全一致。

| 变量族 | 已实现的观察重点 | 当前可靠性 |
|---|---|---|
| 连板前与首板 | 首板前 5 日量额/换手基线与趋势；首板开盘跳空、实体、振幅、上下影、收盘位置、一字板日线代理；首板量额相对基线 | 日线可计算；前 5 日不连续则基线留空 |
| 连板段 | 板数、首板至末板累计涨幅、末板开盘/振幅/量额/换手、段内累计换手、末板与首板量比 | 日线可计算；涨停按供应商标志，不以固定 10% 猜测 |
| 当前冷静日 | 开盘跳空、实体、上下影、振幅、收盘位置；相对末板/首板价格；当日量额、换手及相对末板和首板前基线的比值 | 日线可计算，收盘后使用 |
| 冷静期路径 | 到当日累计收益、期间高低位、从低点恢复和从高点回撤、上涨/阳线/缩量天数、累计换手、平均振幅、日收益离散度 | 只用截至该冷静日的前缀，不补未来天数 |
| 同日市场 | 全市场封板数、非封板 ≥7% 数、上涨占比、中位收益 | 盘后环境；同日完整源表覆盖范围决定分母 |
| 首板分钟形态 | 首次触及与首次分钟收盘封板的分钟序号、最后一次分钟收盘回封序号、回封次数、触及后分钟最低价跌破板价次数、封板分钟占比、首小时成交额占比 | 可选原始非复权 1 分钟 K；必须完整 240 根且末根收盘与日线匹配。分钟 K 只能给**代理**，无法还原逐笔开板、排队封单和委托成交 |

当前目录共 **71 个候选特征**。`first_minute_complete` 是数据质量标记，建模时应先用它限定分钟数据覆盖样本，不能直接当作选股信号。此处首板分钟实验使用的 `mk_1m_compact` 覆盖 2026-01-05 至 2026-07-31；本地另有 `mk_1m_compact_2025`，覆盖 2025-01-02 至 2025-11-28 的 220 个交易日，尚未用于此处的首板分钟对照。数据库另有约 2026 年 8 月起的分钟 K，需单独核对完整性和源时点。在跨月份混合训练时直接填零会让模型学到档案覆盖时间。

`first_below_cap_after_touch_minutes` 统计首次触板**所在分钟及其后**的低价低于板价的分钟数；首次触板分钟内无法判断先有低价还是先触板，因此它只表示“有回落痕迹”的分钟代理，不能直接解释为真实炸板次数。

以后可加的变量及所需证据先登记如下，**未落到当前特征表**：① 冷静日是否“盘中摸板后未封”，需股票当日适用的历史精确涨停价或逐笔/分钟价，不能靠统一 10% 阈值；② 封单金额、撤单、开板次数和排队深度，需逐笔委托簿及源时间戳；③ 冷静日分钟 VWAP、尾盘回收与量价背离，需相应日期完整且未复权分钟 K；④ 同板块涨停扩散、行业相对强弱，需当日有效的行业/主题成员关系；⑤ 公告、龙虎榜和事件催化，需发布时间和可得时间。接入前先检查覆盖、时点与历史修订，避免把事后信息并入盘后决策。

研究动机：涨停制度可能使成交和波动迁移到后续交易日，因而把**量能、振幅与价格路径**分开记录；首板触板时间和回封则来自交易过程假设，而不是日线涨幅的另一种写法。实证研究对价格发现、波动和成交的方向并不一致，候选变量必须在新的时间切分上检验。[创业板价格限制实证研究](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0287548)考察了这些维度；[上交所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)列有不同竞价时段与涨跌幅规则。因此程序使用源表封板标志，而不把 5%、10%、20% 混算成统一阈值。首板分钟回封次数是已结束分钟 K 的近似值，不是交易所逐笔事件。

## 生成与保存

```bash
.venv-automl/bin/python -m scripts.build_automl_limit_rebound_features
```

默认只读查询 `kcrp_stock_price`，以已保存的 R1 连板段为样本，写入被 Git 忽略的 `outputs/stock_automl/limit_rebound_features_r1/`：`daily_source.csv.gz`、`features.csv.gz`、`labels.csv.gz`、`feature_catalog.json`、`manifest.json`。Manifest 保存日线快照 SHA-256、数据更新时间上限和当前 Git commit。可传 `--daily-csv` 复用固定日线快照，`--minute-root outputs/stock_automl/mk_1m_compact` 接入可选 `MK/none` 分钟 K，`--max-cooling 5` 扩至一周内，`--horizon 3` 设定辅助观察窗。分钟档案有空缺时只影响相应分钟变量。基础版本不用分钟档案也能产出完整日线特征表。

本地已有分钟档案时，单独生成增强版本：

```bash
.venv-automl/bin/python -m scripts.build_automl_limit_rebound_features \
  --daily-csv outputs/stock_automl/limit_rebound_features_r1/daily_source.csv.gz \
  --minute-root outputs/stock_automl/mk_1m_compact \
  --out outputs/stock_automl/limit_rebound_features_r1_with_minutes
```

后续只增加日线变量时，可把上次增强版的 `features.csv.gz` 传给 `--minute-features-csv`，复用首板分钟列，避免重复解压全市场分钟档案。程序会拒绝同一首板事件的缓存分钟值互相矛盾。

2026-10-13 的本地 R1 快照生成 **34,656 条**冷静日样本，其中第 1/2/3 天分别为 12,271 / 11,519 / 10,866 条；下一交易日标签已知 34,533 条、未知 123 条，已知样本中再涨停 1,912 条。分钟增强版有 **27,485 条决策行**拥有完整首板分钟特征（相同首板事件可对应多条冷静日）；其余行的分钟变量为空。两版样本键、日线变量和标签相同。此处只核对生成与覆盖；预测结果另见逐日预测实验。

训练前应按**决策日期**切分；同一连板段的多个冷静日必须留在同一训练或测试侧，按时间前推验证。优先先比较固定第 1 天、第 2 天、第 3 天各自表现，再研究统一模型；避免仅让已存活到第 3 天的样本代表第 1 天全体。缺失的前史或分钟形态应保留缺失与来源覆盖证据，不用事后价格补全。历史日线及分钟档案可能有后续修订，当前生成的盘后面板不能自行证明当时真实可得性，更不能证明买入成交。

前 5 日趋势使用逐日 `close/preclose` 复合，降低除权除息造成的原始收盘价断点影响。其余跨日期价位差（例如冷静日收盘相对末板收盘）仍按原始价格计算；若研究窗口跨除权日，应在训练前用复权尺度重算或隔离这些样本，不把原始价差误作回撤。
