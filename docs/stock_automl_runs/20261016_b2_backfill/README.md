### autorun和输出优化

1. 保存当月模型及规则来源、训练/验证窗口、D1和预定D2日期，方便按日追溯。
2. 为形态未通过、未激活、已有优先候选等情况输出明确原因。
3. 新增 `./b2.sh report --day YYYY-MM-DD`，从数据库展示最新事实。中文摘要保留评分、四K最高/最低/实体、模拟买卖、净收益、实际确认时间；完整因子保留DB，使用`--full-output`可查看。
4. 重复盘后任务从DB展示已确认的买卖状态，不用原D0快照覆盖输出。
5. 结算优先使用已记录的D1/D2，兼容往年日期；买卖各0.1%后的净收益写独立net_return_pct列。
6. 回填命令prepare/write/verify分离：先复现、校验哈希，再事务写入并独立回读；首次write保存DB备份，重复执行不重复插入。
