# 尾盘 3%–6% 候选训练样本（2026-10-08）

本轮只构造样本，不训练或评价模型。逐股明细留在本机忽略目录 `outputs/stock_automl/tail_sample/`，不提交数据库原始行。

## 两个候选视图

| 文件 | 用途 | 行数 |
| --- | --- | ---: |
| `candidates_1440.csv` | 按 T 日 14:40 分钟收盘价相对 T−1 收盘价上涨 3%–6% 筛选；用于事后观察 | 8,995 |
| `candidates_1430.csv` | 同样条件，改用 T 日 14:30 分钟价；逐行保留时点检查结果 | 9,034 |
| `trainable_1430.csv` | 14:30 候选中全部特征在 T 日 14:49:59 前可证明可得、次晨标签完整，且信号时非涨停/未知板块规则的行 | 6,706 |
| `execution_feasible_1430.csv` | 在严格训练样本上，再用 14:50 买入价代理排除接近涨停的行；仅供执行可行性分析 | 6,699 |

覆盖 2026-08-25 至 2026-09-29 的 25 个信号交易日，后一交易日最晚为 2026-09-30。8 月 24 日没有对应分钟信号。9 月 14、15 日 14:30 价格也未及时入库，因此这两天没有严格训练行。详情见 [summary.json](./summary.json)。

**时点限制：**现存分钟表的 14:40 K 线在 14:49:59 前到库数为零。因此 14:40 明细虽有完整事后变量，`feature_ready_1449` 均为 `false`，不能把它当成 14:49 决策时可用的回测训练集。14:30 视图逐股检查价格、此前整段分钟 K、T−1 及更早日 K、估值表的现存版本时间。历史源表没有旧版本档案；本检查只能验证当前留存版本的时间戳。

## 特征口径

| 字段 | 计算 |
| --- | --- |
| `signal_return` | T 日 14:30 或 14:40 最新价 ÷ T−1 日线收盘价 − 1。3% 和 6% 均包含，CSV 中收益率用小数。 |
| `volume_ratio` | 截至信号分钟的累计成交股数 ÷（T−1 至 T−5 日均成交股数 × 已过交易分钟数 ÷ 240）。14:30 用 210 分钟，14:40 用 220 分钟；当日不进入历史均量。分钟表实际单位为手，乘 100 后与日线“股”统一。此为按交易时长折算的常用量比，不是同钟点历史五日分钟成交量之比。 |
| `turnover_so_far_pct` | 截至信号分钟累计成交股数 ÷ T−1 流通股本 × 100。流通股本取前一日估值表，盘中股本变化未另行重建。 |
| `float_mv_100m_cny` | T−1 的流通市值，单位亿元；`free_float_mv_100m_cny` 另列自由流通市值，二者不混用。 |
| `volume_tminus5`…`volume_tminus1` | T−5 到 T−1 连续五个交易日的日线成交股数，按时间从旧到新排列。 |
| `ma_bull_5_10_20` | 截至 T−1 的后复权收盘价 MA5 > MA10 > MA20。各 MA 乘以 T−1 原始收盘价 ÷ T−1 后复权收盘价，恢复到 T−1 原始价格尺度以便比较。 |
| `price_above_all_ma` | 信号分钟最新价高于三条均线。 |
| `all_intraday_lows_above_ma` | 从 T 日 09:31 到信号分钟，每根 1 分钟 K 的最低价均高于三条 T−1 均线；这是“截至当时全天股价均在均线之上”的严格定义。 |

均线需连续 20 个历史交易日，五日量需连续五日且正数。估值及日线现存记录的创建、更新时间须不晚于 T 日 14:49:59。若条件不满足，相应特征留空；布尔缺失也留空，不写为 `false`。

## 三个目标

`entry_1450` 是 T 日 14:50 分钟收盘价的**假设买入价**，仅在标签侧使用，不参与候选筛选或特征计算。三个目标均相对于该价格：

1. `target_next_open_return`：T+1 首根 09:31 分钟 K 的开盘价 ÷ `entry_1450` − 1。
2. `target_next_high5_return`：T+1 09:31–09:35 五根分钟 K 的最高价 ÷ `entry_1450` − 1。
3. `target_next_high10_return`：T+1 09:31–09:40 十根分钟 K 的最高价 ÷ `entry_1450` − 1。

用最高价定义五/十分钟目标，是为了对应“挂高于买价 1% 的卖单是否有机会触及”这一研究问题。分钟最高价触及并不证明实际订单成交，且这组目标尚未扣除成本与滑点。`limit_buffer` 使用已有保守板块规则；名称带 ST 或无法确认板块规则的股票不进入严格训练文件。`entry_not_near_limit_proxy` 在标签侧检查 14:50 价尚未接近涨停阈值，不作为 14:49 决策特征，也**不决定严格训练样本**；仅供买入执行门槛分析。`t_final_limit_flag` 是 T 日最终涨跌停状态，只供事后查看，**不是特征或事前过滤条件**。执行可行子集中仍有 4 行在 T 日最终收于涨停，但其 14:50 买价代理未接近涨停；用最终状态删行会把决策时尚未知的未来信息带入样本选择。

## 已做检查与后续使用

- `trainable_1430.csv` 的 6,706 行，44 列均无缺失，日股键无重复，信号涨幅均在 3%–6%，五分钟最高价目标不大于十分钟最高价目标。
- 严格特征与完整标签原有 6,859 行；去掉信号时可识别的 153 行风险警示或未知板块规则，得到 6,706 行。再在独立执行可行子集中去掉 7 行 14:50 买价代理接近涨停，得到 6,699 行。完整候选仍保留。
- 14:40 明细中 8,825 行可事后算出完整分钟量比；量比缺失保留为空。14:40 的分钟信息一律不得用于严格时点训练。
- 不用 `t_final_limit_flag`、`entry_1450` 或任何次晨字段做特征。训练时还需按**信号日**前后分段评测，并监控不同日期的命中率；这里的逐行样本数量不是独立交易机会数。
- T 日除权除息可能使 14:30/14:40 价格相对 T−1 原始收盘价产生非交易性跳变；现有分钟表 `preclose_price` 与 `chg_ratio` 为空。事后用 T 日正式日线 `preclose` 核对，14:40 候选中有 5/8,995 行与 T−1 原始收盘价相差超过 0.5%。该字段的日线记录不能证明在决策时已入库，因此未用于本次筛选；正式建模前应从可证明在 T 日盘前可得的除权参考价补充核对，或单独处理这类日期。
