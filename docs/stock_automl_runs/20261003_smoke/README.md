## 证据边界与人工复核说明

- 程序在单次运行中隔离了训练、选择和最终测试，但开发时反复试跑过相同时间窗口。这是集成验证证据，不是一次性未揭盲的正式投资实验。
- 股票池为手工指定，留出公司恰为五粮液和贵州茅台。跨公司差异与行业差异混合，不能代表全市场泛化。
- 本次当前数据库连接没有分钟线表，实际未使用分钟特征。
- 行业分类和估值缺完整历史修订版本；新闻量只是已入库新闻数量代理，数据可得时点仍有文档列出的假设。
