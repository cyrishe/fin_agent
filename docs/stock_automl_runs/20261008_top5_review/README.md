# 每日模型前五：人工复核清单

沿用已保存的八因子二分类逻辑回归折外分数，不重新拟合模型。信号日为 2026-09-08 至 09-29 的 15 个交易日；每日在原候选池内按“通过分数”取前 5，共 75 个股票日。`前2`、`前3`、`前5` 是**包含式** 0/1 标签，分别覆盖 30、45、75 条。主表在本机 `outputs/20261008_top5/每日前五候选特征.xlsx`，可直接按这三个标签、日期和实际类别筛选。股票代码保持六位文本。

| 范围 | 条数 | 次晨 >1%（类别 1） | 0.5%–1%（类别 0） | <0.5%（类别 −1） |
| --- | ---: | ---: | ---: | ---: |
| 前 2 | 30 | 20 | 4 | 6 |
| 前 3 | 45 | 26 | 8 | 11 |
| 前 5 | 75 | 39 | 13 | 23 |

类别依据是 **T+1 日前十分钟最高价 / T 日 14:50 假设买价 − 1**。超过 1% 记 1，低于 0.5% 记 −1，其余记 0；“严重错误”即 −1。通过分数是未校准的模型输出，不能直接读成真实成功概率。次晨开盘、前五/十分钟、09:40 价格和当日最终涨停状态均为**事后核查字段**，不参与 T 日 14:40 评分。变量来源和时点见[一分钟 K 依赖与特征口径](../20261008_minute_api_backfill/README.md)。

一个值得后续验证的现象：在这 75 条中，“五日量存在四日递增”=1 的 18 条里有 2 条严重错误；=0 的 57 条里有 21 条。样本较小，且这批日期已经用于观察，不能据此加筛选规则并宣称折外有效。另两个均线位置布尔因子在本清单中完全相同，说明前五的局部排序里它们没有提供彼此独立的区分；扩大日期后再检验是否仍然如此。按单独名次看，第一名的严重错误为 4/15，第二名为 2/15，现有分数未表现出严格逐名次单调性。

复现清单底稿（从已保存的折外评分读取 75 条，只读数据库补全精确 09:40 价格）：

```bash
python -m scripts.export_automl_tail_top5 --env-file /path/to/authorized/.env
```

底稿输出到 Git 忽略目录 `outputs/stock_automl/tail_critical_review/daily_top5_sheet_data.json`。导出脚本要求每个测试日名次 1–5 齐全，且逐条核对 14:50 和次晨价格、09:40 分钟 K 的完整性；训练分数与价格结果只在选出前五后合并。
