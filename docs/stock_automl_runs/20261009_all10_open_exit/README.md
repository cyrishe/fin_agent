# 全开次晨前十分钟：尾盘跌幅核查与卖出重算

## 先回答两个问题

**1. 14:40 买入后到收盘大跌，是不是造成次晨亏损的主因？**此前资金回测实际把 **T 日 14:50 一分钟 K 收盘价**当作买入代理；14:40 是算特征和筛候选的时点。对旧七因子全部训练外的 **42 只前二入选股票**逐只查库内已完成、非回退的 14:40 一分钟价和 T 日正式收盘价：

| T 日价格变化 | 股票数 |
| --- | ---: |
| 14:40 → 收盘跌超 1% | 2/42 |
| **实际假设买入点 14:50 → 收盘跌超 1%** | **0/42** |
| 14:50 → 收盘跌超 0.5% | 2/42 |
| 次晨开盘高于 T 日收盘、但低于 14:50 买价 | 2/42 |

14:50 到收盘的涨跌幅中位数约 **+0.003%**。所以“尾盘普遍跌很多，次晨虽然高开却低于买价”**不是整体亏损的主因**；确实有个别股票符合后一种情况，例如 09-24 沪宁股份：14:50 买价 25.61 元、收盘 25.54 元、次晨开盘 25.60 元，开盘相对收盘涨约 0.23%，但比买价低约 0.04%。更主要的损益变化发生在**次晨开盘后的可卖时段及实际成交价**。[42 只逐股尾盘与次晨开盘价](./selected_tail_and_open_prices.csv)可核对。

**2. 前三分钟全部开放以后怎样？**维持同一批股票和相同的每日前二名排名、10 万元本金、第一名 60%/第二名 40%、14:50 买价、交易单位与复投；从 **09:31** 开始逐分钟检查最高价，首次严格超过买价 +1% 时，按该根分钟 K 的最高价模拟卖出；十分钟都未达到则按 09:40 收盘价卖。这个规则使用**实际达到的价格**，没有固定按 +1% 卖。

| 模型与测试日期 | 前三分钟不交易、最高价成交 | 十分钟全开、最高价成交 | 十分钟全开、确认后下一分钟开盘价成交 |
| --- | ---: | ---: | ---: |
| 旧七因子：全部 21 个训练外信号日 | −3.69% | **+16.78%**，期末 **116,775.97 元** | **+2.75%**，期末 **102,747.61 元** |
| 旧七因子：两模型共同 10 日 | −3.20% | +7.81% | −0.23% |
| 大盘形态新七因子：共同 10 日 | −1.35% | −0.17% | −3.00% |
| 新七因子：其全部 21 个训练外信号日 | −9.97% | −2.50% | −9.54% |

新旧模型的“全部训练外日”是**不同日期集合**；公平对比只能看共同 10 日。旧模型十分钟全开后结果大幅改善，说明原标签所依赖的早盘高点集中在前三分钟，禁止这段时间交易会砍掉很多原本的目标命中。但它**不能证明可实际赚 16.78%**。

## 两种成交价情景为什么差很大

“分钟最高价成交”相当于我们能在那一分钟看见首次达标价格后，恰好也以该分钟最高价成交；一分钟 OHLC **只记录事后极值，不记录先后顺序、盘口或下单时延**，所以它是乐观的价格情景。作为时序敏感性检查，另一列在该分钟完成、知道其最高价后，按**下一分钟开盘价**卖；若直到 09:40 才触发，则按 09:40 收盘价卖。它不是可实现收益的保证，也不必然是严格下界，但不借用已完成分钟内事后才知道的极值作为成交价。

旧模型全部训练外在两种执行情景下相差 **14.03 个百分点**，远大于过去针对特征的小幅模型差异。高点触及与实际成交之间的假设对本策略至关重要。要严谨估计“盯盘看到价格马上卖”，下一步应保存实时逐笔或至少更细粒度报价及委托回执，在真实时序下重演下单；仅凭一分钟 K 不能确定当时市场卖单的成交价格。
