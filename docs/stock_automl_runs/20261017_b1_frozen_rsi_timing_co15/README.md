# CO15：最高收益 B1 冻结回放 × RSI 市场时机

**方向补充**：本轮主要沿 RSI 形态策略的弱市激活思路研究，不能据此判断 B1 是否更适合大盘上涨时交易。用户指出这一遗漏后，已另以相同冻结名单、价格和费用完成[CO16 强市方向对照](../20261017_b1_strong_market_timing_co16/README.md)。CO15 归档包已冻结，不改写原包。

**结论**：在登记的高收益 B1 冻结名单上，已固定的市场时机规则没有提高总收益或稳定避开大亏。近10日市场下跌才交易，104笔缩为58笔，扣费账户收益由 **+78.05% 降至 +28.99%**，结算回撤只从24.23%降到23.69%；其收益与同月同笔数随机轮空中位数+30.53%接近。市场 RSI14<50 留54笔、账户+51.04%，高于同月随机轮空中位数+27.35%，但仍低于原名单+78.05%，结算回撤同为24.23%；它没有拦住7月20笔中的任何一笔。两种固定强弱仓位的结果也未超过原名单，且大盘弱势月份的亏损仍在。**不升级 B1 或实时交易开关。**

- 大盘：沿 CO14/KP7 的合格沪深股等权代理，以此前完整交易日和 D0 当日14:40部分行情计算近10日收益及 RSI14；不是上证指数。五日前 RSI 只取已发生的五个交易日前14:40值。逐笔市场指标及布尔开关见 `outputs/stock_automl/b1_frozen_rsi_timing_co15_20261017/frozen_decisions.csv`。

## 同月少做交易对照与集中度

每月保持相同交易笔数，从原有冻结交易中随机抽3,000次，只比较这一份历史名单的描述性参照：down10实际+28.99%、随机中位数+30.53%，52.7%随机组合不差于它。RSI<50实际+51.04%、随机中位数+27.35%，约4.6%随机组合不差于它；这说明它在已观察的同月交易中可能有局部筛选信息，**但它未提高基准总收益、没有降低最大回撤、没有改善7月，并且同时比较了多条规则及复用已研究历史**。该4.6%不能解释为独立验证的显著性。

辅助压力测试：原名单去掉收益最高的6月后为+39.72%，RSI<50去掉其最高的6月后为+18.52%；逐月事后删掉最高盈利一笔后，原名单仅+1.85%，RSI<50为+3.88%。这些删单需要知道未来结果，只用于展示盈利集中，不是可执行轮空规则，更不应作为唯一准入条件。所有规则、逐月、随机对照及压力数据分别见[全表](summary.csv)、[逐月](monthly.csv)、[随机对照](matched_random.csv)、[集中度](stress.csv)。
