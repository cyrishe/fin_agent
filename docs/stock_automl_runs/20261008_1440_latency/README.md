# 14:40 全市场候选筛选与冻结模型推理：盘后延迟实测

本次实现入口为 `scripts/benchmark_automl_1440_inference.py`。它只做一次推理，不训练或修改模型，也不写数据库。运行日必须是上海时区的当天。

## 计算口径

1. 从 `kingdomai.kcrp_stock_price` 取 **T−1** 的股票代码全集，向仓库已有的 `stockHq` 批量接口并发请求。2026-10-08 的全集为 **5,572 只**，28 批、每批至多 200 只、6 个并发，返回 5,572 只。新上市且 T−1 不在日线表中的股票不会进入本次全集；它们也没有模型所需的 20 日历史。
2. 用接口现价 ÷ 接口昨收 − 1 计算即时涨幅，**只保留 3%–6%（包含边界）**。随后按冻结模型的训练候选池规则排除名称含 ST 及不适用的证券代码。这两步均在读取候选历史数据之前完成。
3. 从 `kcrp_stock_price` 读取候选股票 T−1 往前 21 个交易日的收盘价、复权收盘价、复权昨收与日成交量；从 `kcrp_stock_pricevaluate` 读取 T−1 流通市值和流通股本。只将截至 T−1 可知的日数据用于特征。
4. 按现有七因子模型口径计算：14:40 涨幅、量比、截至当时换手率、流通市值、前五日中是否存在连续递增的四个成交量观察、MA5>MA10>MA20、当日最低价是否高于三条均线。接口累计成交量单位为“手”，换算为股后再与日线和流通股本比较。量比使用 **240/220** 时间归一化；均线用 T−1 复权收盘价并通过现价接口的昨收转回 T 日价格尺度。
5. 验证冻结模型文件 SHA256 与特征顺序，加载已有七因子逻辑回归模型，仅做预测分数计算。本机 scikit-learn 1.7.1 与模型保存版本 1.9.1 不同，因而使用模型已保存的变换器、系数与截距计算 sigmoid 分数；对存档前五条分数复核，最大差值为 **0**。无拟合或重训。

## 2026-10-08 23:17 上海时间实测

| 阶段 | 耗时 |
| --- | ---: |
| 读取 T−1 日历与代码全集 | 0.395 秒 |
| 批量获取 5,572 只行情（27.26 MB） | 2.072 秒 |
| 筛选涨幅 3%–6% | 0.001 秒 |
| 读取候选 21 日日线（4,586 行） | 0.254 秒 |
| 读取候选 T−1 流通估值（219 行） | 0.060 秒 |
| 计算与检查七因子 | 0.211 秒 |
| 加载冻结模型并推理 | 0.208 秒 |
| **程序总耗时（含连接等开销）** | **3.519 秒** |

涨幅筛选得到 **230 只**；按训练候选池证券规则留下 **219 只**，其中 **217 只**具备完整的历史与估值，另外 2 只缺足够的日线历史。抽查 200 只股票，接口价格与当日日线收盘、接口昨收与日线昨收均为 200/200 一致；接口累计成交量乘 100 后与日线股数在 100 股内一致，同样为 200/200。

这是**盘后延迟基准**，不是 14:40 实盘可用性证明。接口响应不含每只股票的交易所时间戳，抓取的 28 批并非原子截面；现在只能记录各批请求所在的本机时间窗，无法据此证明每只报价恰好是 14:40 已完成分钟的状态。脚本在 14:40 之外仍完成全链路计时和推理，但不输出选股前五名。要发布盘中信号，还需在真实交易日 14:40 验证接口更新延迟，并将它与已完成的 14:40 分钟 K 对齐；若该源无法证明新鲜度，就需要带源时间戳的行情或已最终确认的分钟 K。


## 2026-10-09 09:54 流程演练

按“现在假设是 14:40”的要求，只检查全链路能否跑通和耗时。首次直接执行在连接数据库前失败：脚本只认 `SIMPLE_BI_PLATFORM_DB_URL`，当前 `.env` 使用 `PLATFORM_DB_URL`。已让脚本兼容两种变量名并接受 `--env-file`；修复后直接执行成功。两次完整运行的程序内计时分别为 **3.926 秒**与 **4.142 秒**，其中获取 5,572 只股票行情分别耗时 **2.026 秒**与 **2.367 秒**，均为 28 批、6 并发，返回率 100%。第二次直接运行在 3%–6% 初筛后有 89 只，证券规则后 87 只，85 只完成特征和模型评分；[运行记录](./20261009_rehearsal.json)保留分段耗时。

演练发生在 **09:54**，不是 14:40。实时行情还在变化，因此两次运行的候选数不同；脚本按时间门禁只输出性能记录，不发布前五股票。本轮证明当前环境的流程约四秒完成，仍不证明行情在 14:40 的逐股新鲜度或源时间对齐。
