# CO16：最高收益 B1 冻结名单 × 大盘强势交易时机

用户指出 CO15 把 RSI 形态策略的“弱市激活”方向搬进了收盘—开盘 B1，遗漏了更符合该策略直觉的**大盘上涨时交易**。本轮纠正方向，固定同一份 B1 历史名单、价格、费用，分别比较强市开关。**近10日上涨开关能明显压低历史结算回撤，但收益筛选力未超过同月同笔数随机轮空；可作为待前瞻验证的风险控制线索，尚不替换 B1。**

## 相同名单和口径

沿用 CO15 已逐笔核验的104笔冻结交易，信号日2026-02-02—09-30，9/30交易于10/8结算。8月旧独立实验缺前20日完整训练候选，没有预测，**不能算市场开关成功轮空**。大盘是沪深合格股票等权收益代理，非上证指数；截至D0 14:40只取此前完整交易日和当时部分行情。14:40买、次晨09:40卖，100万元单仓连乘；买卖佣金各万2.5（最低5元）、过户费各万0.1、卖方印花税万5。允许分数股、无滑点或容量约束；回撤只按结算点计算。强势命中是次晨前10分钟第二高价≥入场价3%，不同于实际09:40卖出收益。规则在结果前写于[方案](DESIGN.md)。

**近10日上涨**拦住原19笔净亏>2%中的15笔，同时误拦27笔盈利；剩下4/46笔大亏，占8.70%，较原18.27%低。它的月度收益为2月+3.12%、3月+9.06%、4月+3.20%、5月+0.38%、6月+3.39%、7月−0.70%、9月+15.41%。即六个月盈利、一月小亏，但总收益由+78.05%降至+38.04%。7月只保留1笔，明显压低该月亏损；6月只保留3笔，也错过原名单6月+27.43%的大部分盈利。

**近20日上涨**在6、7月都没有交易，整段+0%，不能把7月风险规避单独算成功。**RSI≥50**也在6、7月都空仓，错过6月盈利；且全期只有+17.89%。说明“趋势为正”和“RSI偏强”不能简单叠加为更好开关。

## 少交易与仓位对照

每个月从原冻结名单随机保留相同笔数3000次。近10日上涨的实际+38.04%，随机中位数+37.25%，48.6%的随机组合收益不低于它；实际回撤7.35%，随机回撤中位数11.05%，约13.8%的随机组合回撤不高于它。**低回撤有方向上的线索，但没有充分证据说明它能在同样少做交易时提高收益**。近20日上涨的同月随机收益中位数+36.47%，约23.6%不低于实际；其回撤也处于随机组合中间附近。

满仓/半仓的近10日强市方案使用合计75个满仓等效笔数，收益+58.89%、回撤13.09%。同样75笔等效、每笔恒定72.12%仓位为+53.71%/18.00%；但按月固定满仓笔数、随机指定哪笔满仓3000次，收益中位数+57.89%、回撤中位数13.09%；约46.6%的随机方案收益不低于实际，约46.3%的随机方案回撤不高于实际。**温和仓位看起来改善了原名单的收益回撤取舍，但尚不能归因于强市指标本身。**比较全部随机结果见[同月随机轮空](matched_random.csv)和[事后风险诊断](risk_diagnostics.csv)。

按信号月的完整收益/交易数/大亏见[逐月表](monthly.csv)，按2—5月、6—7月、9月分段见[汇总](summary.csv)。辅助集中度检查：去掉各自最好月后，原名单+39.72%、近10日上涨+19.60%；逐月事后删最好盈利单笔后，分别+1.85%和+21.95%。事后删单不能执行，只揭示收益集中度，见[压力表](stress.csv)。

## 判断与复现

当前最值得保留的是**近10日上涨时交易**这个风险约束候选：它在这份历史名单上使7月损失显著变小，已交易月份较平稳；代价是错过大量盈利，绝对收益近乎减半。同月随机收益对照及既往重复研究提示它可能只是交易数量和月度行情共同作用。需要在以后未参与规则选择的月份，冻结阈值、费用和执行方式后继续验证，才能判断是否真有可用规律。当前不把 CO16 开关接到 B1 实时运行，也不称为新基准。
