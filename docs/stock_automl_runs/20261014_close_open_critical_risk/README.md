# CO6：严重净亏、跨档错误与模糊边界

## 结论

**用户指出的目标缺口确实存在：当前B1没有直接训练“09:40扣费后净亏超过2%”的风险，也没有专门处罚严重亏损被判为可接受/达标。** 原91笔成交中19笔净亏超过2%，其中14笔预测达标、5笔预测可接受；旧“次高价低于买价1%”标签还会漏掉其中5笔。早盘一度有高点，不等于09:40能够保住收益。

旧研究确实做过五分类、有序边界、代价矩阵和模糊标签，但各自留在独立实验中；**没有找到“已接入B1、后来因追求高收益而删除”的证据**。此次保留B1，新增独立风险过滤与六种净收益五分类规则，并完成全部滚动训练。

**尚未找到可升级的保护方案。** 决策加罚使净亏>2%比例从普通五分类的23.28%降至13.08%，但107笔每笔净均值仅+0.081%，删最好月份后−0.050%，每月删最好一笔后−0.525%；再加10bp总滑点假设即−0.019%。B1风险过滤误拦大量盈利，20%门槛留下交易的大亏比例反而23.81%。强加罚与严格跨档准入几乎不交易，不能当作风险控制已经成功。

## 2. 本轮如何加入保护

运行前固定的完整方案在 [DESIGN.md](DESIGN.md)。模型均为正则逻辑回归，全部76因子保留，C=0.01；没有根据测试收益挑阈值或惩罚系数。

- **实际净收益五类**：<−2%、[−2%,0%)、[0%,1%)、[1%,3%)、≥3%。严重边界严格小于−2%；费用计入标签。原“次高≥3%强势”另作业务指标，不与净收益≥3%混用。
- **独立风险过滤**：估计P(实际净亏>2%)，固定20%/10%门槛，加到原Top1后只决定是否轮空，不换股、不递补。使用无严重样本加权的概率模型。
- **普通五分类→决策加罚**：同一拟合概率，五类效用从[−4,−1,0.5,2,4]%改为[−8,−1,0.5,2,4]%，检验决策阶段的严重错误惩罚。
- **跨档代价准入**：普通概率乘代价矩阵，乐观误判代价为距离平方；真实严重类被判为后两类再×2。只有代价最优类别为可接受/强势才可入选。此次矩阵确实影响交易资格，仍不等于矩阵进入普通五类训练。
- **有序训练＋严重样本×3**：分别学习跨过−2%、0%、1%、3%四个边界；严重样本错跨多档会在多个二项交叉熵上受罚，每项再加权×3。累计概率整理为单调分布后用于排序。
- **模糊边界**：只软化0%、1%、3%附近±0.2个百分点，−2%严重边界保持硬标签。加权后的输出是偏向风险的决策分布，不能当作校准的真实风险概率。

有序、样本加罚和模糊方案均沿用严重类−8%的决策效用。因此可逐项对照“普通→决策加罚”“决策加罚→有序”“有序→严重加权”“严重加权→模糊”；强加罚的结果同时受训练和决策两层保守倾向影响。

## 3. 时间、交易与比较边界

- 数据与候选池沿用CO4/CO5冻结面板：14:40信号、当时涨幅3%–6%，76项原有与全天/末段因子；输入只使用截至14:40信息。
- 测试为2025-07至2026-10-13，311个信号日、16个月，其中10月仅4日。每月此前100个市场交易日：前80日拟合、后20日独立验证；随后100日重拟合、预测下一个月。只用决策前09:40已成熟标签，各拟合阶段单独估计截尾、缺失填充和缩放。
- 本轮固定C、门槛和惩罚；验证用于观察概率、混淆与跨档错误，**未用验证总收益择优**。保存每月发现期及重拟合模型。历史已多次研究，这次按时间隔离不等于项目级全新盲测。
- 模拟14:40分钟收盘价买、次日09:40分钟收盘价卖；沿用个股成交额不低于此前20个市场日同刻中位数的门槛。费用情景为每笔5万元、双边佣金万2.5且最低5元、双边过户费万0.1、卖方印花税万5；平价往返约0.102%。这是固定研究假设，不代表具体账户收费；未模拟实际成交约束。
- 原B1只能在冻结的2026年2–7月118日比较：115次选择、3次未选择；成交额91通过、20不通过、4未知。新同池七因子树的基础输入和历史B1不完全相同，不能冒称B1复现。
- 所有收益表按已知卖价的实际通过交易计均值；轮空日用于日均统计。未知门槛与卖价保留未知，不填0。净收益和去极端统计是单笔百分比口径，净收益求和及固定金额回撤不是账户复利。

## 8. 后续判断

1. 保留实际净亏>2%、>5%、严重类误判为可接受/达标、误拦盈利、交易覆盖与去极端收益为固定指标，不再只看总体收益。
2. 本轮保护手段保留为可复现研究分支，不接到默认B1。后续如做第二阶段风险模型，应先在训练期产生基础模型真正折外TopK/Top1结果，再学习“基础模型会选中的股票里谁容易大亏”；不能使用基础模型拟合内名单。训练和校准也须保持时间隔离。
3. 惩罚力度应在过去的验证段同时约束交易数量、盈利误拦和尾部损失，再冻结到下一月。本轮没有在看过测试后调轻惩罚来追求更好的表格，也没有证明神经网络能够解决此问题。

阈值与概率学习属于不同决策环节，相关方法依据见 [scikit-learn阈值文档](https://scikit-learn.org/stable/modules/classification_threshold.html)。本轮运行固定scikit-learn 1.7.1；在线文档会随版本变化，不代表本轮换了环境。
