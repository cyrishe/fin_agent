# CO6：严重净亏识别、跨档惩罚与模糊边界（运行前方案）

业务研究，不改 Agent 协议，不替换/重写 B1、CO4、CO5。沿用CO5冻结面板、311个信号日、16个测试月份、14:40买价与次晨09:40卖价、成交额门槛和每笔5万元费率情景。未知收益/门槛不填零。原B1只在原118日对照。云盘继续按用户决定暂缓上传。

## 已查清的现有处理

- B1：次高价四类 (<0、0–1、1–3、>=3%)，普通多类交叉熵；没有实际净亏2%标签、类别距离、严重错误专门权重或风险过滤器。
- 旧五分类：次高价<-1%为严重错误，四个有序二分类边界；另有“过度乐观跨档距离平方”的代价矩阵，主要用于评估risk_decision；实际选股试过概率、手写效用和原类别顺延，没有把矩阵写进训练或B1。旧五分类不是09:40净亏2%分类。
- 旧模糊边界：三分类在0%、1%附近±0.2个百分点软化，只在独立旧实验中。
- CO5：Ridge效用 min(net,5%)-max(-net-2%,0)已处罚超过2%的亏损；Logit仅P(次高强)-P(最高弱)，未分辨实际大亏幅度。
- 目前证据支持“独立研究尚未纳入基准”，不能断言有人为了更高总收益删除了已接入的保护。

## 时间与样本

每月取前100市场交易日，前80日拟合并在后20日独立验证；随后用过去100日重拟合预测下一个月。标签须于决策日09:40成熟。各阶段截尾、log与缩放只在对应拟合段估计。固定全部76因子（保留弱关联业务因子），C=.01，无测试后阈值/权重挑选。验证保留全候选风险AUC、概率校准、五类混淆和跨档严重错误；本轮不利用验证期总收益挑选参数，借此隔离机制。重拟合后模型整月不更新。

## 分支A：独立风险过滤器

不改变原模型所选股票，只另训无类别加权的正则逻辑回归估计 P(实际净收益<-2%)。固定两条门槛：估计概率<=20% / <=10%才允许原Top1继续交易，拦截后轮空、不递补。依次加到原B1、同池七因子树、CO5全76Logit、全76Ridge上。

概率只是模型估计，不保证真实风险满足20%或10%；报告验证与测试校准、拦截的大亏数/召回率、误拦盈利数/强势数、误拦大赚数、保留交易风险、收益及月度分布。与相同数量随机拦截的期望比较，避免把单纯少交易当成识别能力。

## 分支B：针对实际净收益的五类与误判成本

五类：净收益<-2%；[-2%,0%)；[0%,1%)；[1%,3%)；>=3%。这是新目标，旧次高强势标签仍独立保留作业务指标。

1. net5_nominal：普通五类Logit，按五类效用 [-4,-1,.5,2,4]% 排序，最高分必须>0才交易。
2. net5_cost_decision：同一概率，仅将严重类效用从-4%改为-8%，其他一致。检验决策阶段惩罚。
3. net5_cost_matrix：同一普通概率，类别距离悲观误判线性、乐观误判平方；真实严重类却决策为1–3%/≥3%再×2。先取最小期望代价类别，只有决策为后两类才能入选，再按严重类-8%的效用排名。矩阵真正进入选股资格，而非只记录评估。
4. net5_ordinal：分别预测净收益是否达到-2%、0%、1%、3%，四边界共同体现跨档错误；单调累计整理后转五类。按严重类-8%的同一效用排名。
5. net5_ordinal_critical：上述四边界，实际严重亏损样本每个错误越界的训练损失加权×3。仍按同一效用排名。
6. net5_ordinal_critical_fuzzy：保持严重净亏-2%硬边界；0%、1%、3%边界在±0.2个百分点内使用线性软标签。其余与上项一致，单独检验边界软化。

Ordinal训练等价于四个加权二项交叉熵之和；一次严重样本从最低类错跨至最高类会涉及四个边界，再受×3权重。用标签展开成0/1加权观测实现软标签，不增加随机优化器。加权模型输出属于代价倾斜后的决策分布，不能称校准的真实概率；独立风险过滤只使用无加权二分类输出。

所有规则都事先固定，整个测试期全部公布。交易量降为0时写无交易、不用0%每笔收益冒充改善。费用、滑点、月度稳定性、删最好月/每月最好单笔沿用CO5；不因本轮历史结果自动上线。
