# R4：历史 ST、类别均衡、市值与归一化实验

2026-10-14。研究对象仍是 R2 的可变 1～3 日冷静观察模型：在每个未封板决策日，预测此后 3 个交易日是否至少一次收盘封板涨停。没有改变事件、标签、封板判定或时间切分。训练期 2024-10-09～2026-03-26，验证期 2026-04-01～06-25，测试期 2026-07-01～10-08；切分沿用 R2 的事件隔离与目标窗间隔。验证用训练期拟合模型，测试用训练与验证可用行重拟模型。所有训练均用相同的 31 个基础特征和浅层 HistGradientBoostingClassifier、scikit-learn 1.7.1。

ST 身份按决策日查询 `kingdomai.kcrp_stock_st` 的 `[begin_date,end_date)` 有效区间，`S/Y` 为 ST；88,675 条有可观测标签的候选均匹配唯一有效区间。类别均衡仅在拟合时使用正、负类各占总样本权重一半的 `sample_weight`，未复制或删减训练行。普通股实验在训练、验证、测试候选池同时去除当日 ST；因此跨候选池的 Top K 不宜直接比较。

**每日决策时点。** 原连板最后一个封板日记作 D0。D1 若收盘未封板，当天收盘后用 D1 行情及此前已知信息计算概率，预测 D2～D4 是否再封板；若 D2 也未封板，D2 收盘后重新计算概率，预测 D3～D5；最多到 D3。某天再封板后，该轮冷静期候选停止。同日把所有仍处于第 1～3 个未封板冷静日的候选一起按**当日新分数**排序；不是在 D0 涨停收盘时预先评分，也不是沿用昨天分数。离线评测按决策日每日取 Top K；2026 年验证 57 日、测试 66 日恰好每天都有普通股候选（分别最少 96、93 只），一般运行规则允许某日零候选。当前只是离线按日回放，尚未建立每日定时信号与可成交回测。

金额方案在基础特征上新增当日成交额（亿元）；市值方案再新增当日总市值（亿元）。当日换手率已在原 31 特征中。归一化方案仅对成交额、换手率、总市值做 `log1p(max(x,0))`，再用当次拟合训练集的均值和标准差标准化；验证/测试不参与拟合变换。原值与归一化方案的逐行预测分数完全相同。

## 判断与数据限制

1. **去 ST 方案明显改变了选股结构**：训练、验证和测试候选池均剔除决策日为 ST 的股票，因此 Top1/2/3 选股的 ST 数量必然为 0。原 R2 验证 Top3 中 ST 为 133/171（77.78%），测试为 23/198（11.62%）。这直接解决了验证期选股过度集中 ST 的问题；若只在训练时剔除 ST、预测时仍让 ST 参与排序，则不能保证选股没有 ST，本实验没有采用那种口径。另一个独立问题是普通股预测能力：在相同普通股候选池，去 ST 重训的测试 Top3 为 59/198，原模型直接过滤 ST 后为 62/198；尚无证据说明重新训练提高了普通股的命中率。ST 占比随时期变化，应继续按决策日身份与交易制度分段看。
2. 样本权重均衡没有提升稳定的排序效果：含 ST 基础模型测试 Top3 从 63 降为 59，AP 从 .1871 降为 .1864。权重还改变分数校准，所以主报告以 AP、AUC、每日 Top K 为准。
3. 加成交额和市值的含 ST 方案测试 Top3 为 70/198，高于均衡基础的 59/198；但验证为 67/171，低于 68/171，验证 AP/AUC 也下降。已查看测试集后的增益只是探索线索，不作为模型升级结论。只加成交额的测试 Top3 为 63/198；加市值后的增量尤其需要数据核验。
4. 历史总市值字段直接覆盖 50.12% 的样本；缺值用最近一次已知总股本乘以决策日收盘价补算后覆盖 99.69%，共 43,957 行为估计值。补算所用股本距决策日中位 118 天、95 分位 387 天、最长 457 天。故市值实验不能代表高质量、完整历史市值训练。缺失处于 2025-05～2026-06 的数据库覆盖低谷；近期测试覆盖较完整，训练/验证与测试的数据质量存在时段差异。
5. 原值与归一化两种市值方案，在含 ST 和去 ST 情况下，逐行分数差均为零。对于此直方图树模型，当前单调变换没有实际作用。
6. **交易时序与目标策略不一致。** R2/R4 用冷静日收盘后才可得的特征打分，不能指导该冷静日开盘买入。若交易计划是在封板日 D0 收盘打分、次日 D1 开盘未封板时激活并买入，应重新以每个 D0 封板股票日建样本，只用 D0 及之前信息训练，在 D1 开盘可观察的候选池内按 D0 分数排序。D1 即使收盘重新封板，也应算作激活后的命中；不能先根据 D1～D3 实际是否出现冷静期筛选训练样本，否则会使用决策时尚不知道的未来路径。本报告所有命中率均不代表这一开盘交易策略的效果。

本地证据：`outputs/stock_automl/limit_rebound_st_size_r4_20261014/summary.json`、`market_cap_quality.json`、各方案验证与测试逐样本分数 CSV；生成脚本 `scripts/experiment_automl_limit_rebound_st_size_r4.py`。原 R2 的训练/验证/测试 Top3 分别复现为 552/1068、68/171、63/198；脚本在复现失败时会停止。训练、验证、测试结果都属于已经多次查看的历史样本，不能代替未来盲态验证；本实验也没有检验买入价与实际收益。
