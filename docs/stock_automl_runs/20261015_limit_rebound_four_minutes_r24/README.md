## 结论

四分钟能提前一分钟完成形态，但没有证据显示分类更强。共同买价/样本下，沿用门槛的通过组再板率由五分55.63%降至53.25%；四分重选仅43.69%，其D2大跌率31.98%还高于未通过组26.67%。四分重选在训练/验证可改善，而这些目标月份的区分度较弱，不能把总账户收益较高解释成形态模型更准确。

四分重选且同股延后一分账户+116.59%、回撤20.79%、夏普2.10；与五分同样延后相比，10个月6胜4负，收益/夏普较高但回撤更大；与五分原买点相比5胜5负、回撤更大且夏普更低。四分沿用门槛且延后为+81.24%/25.49%/1.95，追回原漏8笔中的4笔（其中原盈利3笔），仍不构成全面改善。本轮保留完整对照，不替换原策略。

按一个固定顺序替换账户路径，收益依次为：五K原方案73.0491% → 删除17个五K独有交易日40.4029% → 共同日期换成四K所选股票74.3007% → 同股交易采用四K买价74.3802% → 加入41个四K独有交易日116.5949%。对应变化−32.6462、+33.8978、+0.0795、+42.2147个百分点。这是事后解释路径，各项贡献依赖替换顺序与资金轮换；加入交易日同时改变交易质量和日期，不能解释成纯交易次数因果效应，也不是新可执行策略。

分类标签与收益含义不同：D1—D3任一天收盘封板即为1，交易却在D2收盘卖出，且标签不衡量买入价与盈亏幅度。已具备完整标签的实际交易中，五K再板57/96=59.3750%，四K57/121=47.1074%；再板组平均净收益分别4.8105%/5.6238%，未再板组分别−4.5836%/−2.1444%。五K还有1笔已卖出但D3标签未齐，故这里的96不等于全部已卖出的97。再板率较低仍可能有更高平均收益，不能只数正负标签来推导账户收益。
