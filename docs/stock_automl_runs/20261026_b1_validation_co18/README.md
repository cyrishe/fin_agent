# CO18：18日训练＋2日验证

**结论：本轮没有超过原20日滚动对照，不替换生产策略。两日盈利过滤能减亏，但两天选优没有显示可靠优势。**

## 口径

与CO17同一B1R快照、相同177个预测日：2026-01-19—10-15。这里的“工作日”按交易日处理；不覆盖10月16—26，不称新盲测，也不把同输入原模型对照混称为ACTIVE最高收益冻结拼接名单。

预测D：D−20～D−3共18日训练，D−2和D−1验证，固定模型预测D；不使用验证样本重新拟合。最后验证标签D日09:40成熟，D日14:40预测。三个模型与原七因子、四分类、Top1、成交额门槛、买卖价格均保持。每边0.1%费用；14:40买、次日09:40分钟收盘价卖均为价格代理。完整事前规则见[DESIGN](DESIGN.md)。

验证至少1笔已知交易、无未知条件才参与选优，以两日净收益率之和排序；轮空为0。D要求该和为正；E要求两日都交易且各自净收益为正。两日都没有可交易样本时不放行。训练不看验证或预测日结果；模型选定后，预测日收益仅用于评估。

## 主要发现

- A原最近20日滚动扣费−5.52%；B较早18日固定HGB−37.80%；C两日验证选优−63.71%。在这段历史中，挑最近两天表现好的模型反而更差。B同时改变了训练长度和截止日，不能把差异全部归因于数据新鲜度。
- D两日合计盈利才做为−22.81%，不如CO17的20＋10同类方案−15.62%。D验证通过后99笔，每笔净均值−0.203%；未通过组45笔为−1.557%。过滤有减亏迹象，但保留下来的交易并未盈利。
- E两日分别盈利仅38笔，扣费−16.46%、结算回撤17.95%。总亏损和回撤比D低，但每笔净均值−0.423%、胜率36.84%，都低于D；不能将减少交易直接解释为模型更可靠。
- 两日验证分数与下一日净收益相关系数约0.066，低于CO17的约0.146。每窗最多两笔交易、相邻窗口重叠，不能视作统计置信度。
- C相对A的按月配对重采样日均差为−0.520个百分点，95%区间约[−0.880,−0.128]个百分点；D−A和E−A区间均跨零。仅10个月、历史已研究，不当成独立确认。
- B轮空前Top1第二高价≥3%比例31.43%，高于A的24.86%，但09:40兑现收益更差。目标达标率不能代替固定卖出时点的实际回测收益。

下一轮若继续研究，可先固定原模型，只检查近期折外表现是否适合做交易开关，从而分离“模型切换”和“交易过滤”。本轮没有运行这个方案，也没有调整现有生产版本。

## 核验与资产

531份新训练模型，复用177份已核验原滚动对照；708份保存模型的预测概率回读通过。177日训练/验证/预测日期隔离、标签成熟、选择规则及逐笔收益核验通过；原对照与CO17完全一致；7项定向测试通过。

实际样本、模型、候选分数、逐日选股和交易、输入快照、源码及环境存于`outputs/stock_automl/b1_validation_co18_20261026`。完整包状态见`archive_receipt.json`：本地核验和数据库登记与云盘同步分开记录，云端未回读前保持待同步。

复现入口为`scripts.research_b1_validation_co18`和`scripts.analyze_b1_validation_co18`，使用独立scikit-learn 1.7.1依赖目录。输入依赖B1R及CO17原对照；包内也保存了原对照的训练样本、模型和分数。大模型材料未写入Git；研究代码与报告在策略分支。

以下收益按已知交易连续复投；数据未知日单列，不推定缺失条件满足。回撤为结算点回撤，不是持仓分钟回撤。1月从19日开始、10月止于15日，均非完整月份。
