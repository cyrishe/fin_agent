# B2：D0涨停，D1四K形态后延后一K模拟买入

用户于2026-10-15要求冻结当前策略、登记DB、在fin_agent服务器自动运行，并确认：原Top3用于每天上午查看；只有当天最终模拟买入候选actionable=1；模拟记录严格沿用研究回测方式。

## 固定的版本和业务口径

B2 = R18完整分段51因子随机森林 + R24每月四K形态选优 + `four_fit_delay`执行方式。既有模型、规则和研究样本均保存；不是重新搜寻一套新策略。业务定义的单一来源为`scripts/automl_b2.py::definition()`，DB的summary保存完整中文desc。

- D0收盘后给原口径封板股票评分，保存原始Top3，排名不因次日筛选而重排或补位。
- 日线模型6个月训练、2个月验证、下一月推理；RF参数固定，验证数据不参与重拟合。
- 形态从79条至多两条件的规则中选择；训练使用历史因果折外Top1，验证2个月，当月规则预先冻结后迁移Top3。不是仅有两个固定规则，也不看当月结果选规则。
- D1前三只同时观察前四根完整K，结束标签09:31—09:34。满足形态者在结束标签09:35—09:40内，最早出现“分钟open低于涨停价0.005元且有成交”的股票锁定；同分钟按D0排名。
- 锁定后实体须大于−8%，否则当日不交易、不顺延。通过者至少等待同股下一根K，以截止09:40首次再次满足条件的分钟open记模拟买价；不换另一只。
- D2是D1的下一市场交易日，收盘记模拟卖价。净收益按买卖各0.1%计算。

### 时刻含义

一分钟K的时间为结束标签。最早模拟买入使用09:36结束K的open，价格发生于09:35；程序必须等该K完整到达才确认，因此实际确认最早09:36加接口延迟。`entry_at`记录模拟价格时刻，`decision_json.actionable_confirmed_at`记录真正写出信号时刻。不可把回测代理价当作用户看到提示后仍可成交的价格。

记录每只的首次开板分钟、完整形态、选中及确认时间；不是秒级开板时间。未来实时交易可行性须用到达延迟、盘口和实际委托另行评估，本次不改变模拟盘买价来美化可成交性。

## 复现与交付边界

- 固定模型逐分数、每分钟可见前缀回放、独立原始日线因子重建和一个月独立重训分别检验。
- 日线评分与分钟执行分离。分钟原始接口直读，只消费已完成K，保留每次响应到达时间和原始量价证据。
- 新月生成模型、实际训练样本/权重、折外及验证预测、形态选择样本/规则、审计和哈希。沿用原研究的事件剔除，原始D0排名必须在剔除之前确定。
- 研究已有的分钟缺失/不合格行按原R20审计保存排除证据；未来新增缺失不会自动继承这种豁免。
- 线上保存Top3和逐笔模拟买卖收益；100万元账户回放为历史基准，线上未接入券商订单或真实账户。
- `automl_strategy_run`记录当日模型/环境和候选数；`automl_strategy_execution`记录Top3及actionable、买卖模拟价。旧四分类selection表不塞入伪字段。

服务器操作与云端哈希回读见本目录后续部署回执。运行说明见`deploy/stock-automl-b2/README.md`。仅有本地包不等于云端同步完成。
