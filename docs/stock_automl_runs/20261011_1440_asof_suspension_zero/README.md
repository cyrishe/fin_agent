# 14:40 信息边界与次日停牌零收益回放

本次按信号形成时点重新核对 2026 年 1–7 月原始一分钟 K 实验。**T 日 14:40** 只凭此前可观察的行情及已完成的历史日线计算七因子：当时因数据不足算不齐特征的股票不入池；当时特征齐全的股票全部参加推理，不按 T 日余下行情或 T+1 是否有 K 线删候选。历史样本若到训练时仍没有可定义的次晨第二高价，则不能参与四分类监督拟合，但其当年的 14:40 推理资格不变。

候选构造器过去要求原始文件里的股票有全天 240 根一分钟 K 才继续。现在逐股只要求 **09:31–14:40 的 220 根**完整；当时缺特征的股票单独丢弃，不连带丢掉当天其他股票。14:40 之后的 K 线不参与资格判定；十根次晨 K 只用于事后标签及卖出验证。原始 1–7 月文件已通过旧的全天完整性校验，因而这项代码修正不会改变已保存的 59,959 条候选及其七因子；抽查 01-05 原始文件，新旧 5,171 个股票快照及关键数值逐项相同。无需因为该修正重新拟合已保存模型。T 日 `preclose` 来自历史日线字段，代表当时可知的昨收参考价；T 日最终 `close` **没有用于 T 日七因子**，T−1 日收盘价用于历史均线和流通市值估算。

## 次日停牌回放约定

已选股票的 T+1 十根分钟收盘价缺失时，查询该日 `kcrp_stock_price.volume`。只有查得**成交量为 0**才按用户约定给本次回测记 **0%**，并保留 `next_day_suspended_zero` 标记；有成交量但分钟数据缺失、或无日线证据的记录仍标为不可观察，不伪造 0%。这仅是本回测的记账约定，**没有次晨卖出成交价，也不意味着真实持仓风险为零**。停牌行仍无四分类训练标签，不强制写成 `0–1%` 类。

原始三组 Top1 共 354 笔（每组 118 个测试日），只有两笔缺次晨分钟价，都在“19 日全量”组：2026-03-12 的 `000711` 和 2026-04-21 的 `000609`。对应 T+1 日线成交量均为 0。固定次晨 09:40 卖价口径重新统计如下；其余两组结果不变。
