# A9：倒数对数新近权重与七因子影响力

2026-10-13。此为 B1 的对照实验，不替换冻结策略。信号为 14:40，前 20 个交易日全部成熟标签逐日重训，七因子四分类与 B1 同参数；2–7 月 118 个预测日和 9/2–10/8 共 21 个预测日，均以次晨 09:40 历史卖价核算。Top1 先按 `ge3` 类、再按 `1to3` 类选；本股 14:40 成交额低于其此前 20 个交易日同刻成交额中位数则轮空，不以 Top2 递补。收益为逐日价格连乘，未计费用或滑点。近期保存母表与 B1 的原实时数据链尚未完成同等级复现，因此近期只作为相同保存输入下的比较。

## 公式与单折数值

令训练日距离预测日 `D=1…20`（最近为 1），正向近度 `K=21−D`（最远为 1、最近为 20、预测日为 21）。这里的 `log` 特指 **以 2 为底**：自然对数在 `D=1` 时给出 `1/ln(2)=1.4427`，不等于 1。预先定义两种权重：

- 普通倒数对数：`w_raw=1/log2(D+1)=1/log2(22−K)`。
- 温和倒数对数：`w_raw=1/sqrt(log2(D+1))`。

每折用当折**所有训练行**的原始权重均值归一化，使样本权重均值为 1。预测日 `K=21` 没有标签，不参加拟合，也不需要样本权重。此前 10 日半衰期方案的原始权重为 `2^(-(D−1)/10)`，三者最近日原始权重都为 1。最远日原始权重依次为 0.227670、0.477148、0.267943；故普通倒数对数的近远权重比 **4.392**，比 10 日半衰期的 **3.732** 更激进；平方根版本为 **2.096**，才是较温和的方案。

以 2026-07-30 一折的 9,755 条训练行为例，按行均值归一化后，最远日／最近日每条权重分别是：普通倒数对数 `0.600203 / 2.636281`，平方根版 `0.793675 / 1.663373`，10 日半衰期 `0.443299 / 1.654451`。三组有效样本量 `(Σw)²/Σw²` 分别为 `7,777.8 / 9,294.8 / 8,489.2`。每日行数不同，因此每日的**总**训练影响还受到当天候选行数影响。

## 七因子数值与影响力

直方图提升树没有每个变量一个固定的线性系数。模型由多棵带条件分裂的树构成，一个变量的影响依赖其他变量取值与落入的叶子。为给出可核对的替代量，对冻结 B1（sklearn 1.7.1）每个预测日重新训练、核对保存的**所有候选概率**，最大绝对差 `1.11e−16`；然后把**当日候选中的一个变量**随机打乱 3 次，记录折外四类 log loss 增量及 Top1 换股次数。打乱会改变多只候选的值，换股比例表示排序依赖，不表示单只股票的因果收益贡献。相关变量的作用可能被彼此分摊。

这一折 B1 的 Top1 东方材料 603110，训练 9,755 行、当日 153 只候选，四类概率按 `lt0、0to1、1to3、ge3` 为 `(0.256628, 0.198957, 0.307162, 0.237254)`；最高预测类为 `1to3`，回退排序分数 `p_1to3+p_ge3=0.544415`。它的历史 09:40 交易收益实际为 `−4.14%`，故概率不是确定性收益预测。

仅把这只股票的换手率从 `8.062356%` 改成当折训练中位数 `2.696734%`，其余六因子及模型不动，`p_ge3` 从 `0.237254` 降为 `0.115203`，`p_1to3+p_ge3` 从 `0.544415` 降为 `0.438094`。这是此股票、此模型的局部反事实；`8.06%` 对 `2.70%` 不存在一个可通用的“系数”。其余六因子的逐项中位数替换和四类概率见下方 JSON。
