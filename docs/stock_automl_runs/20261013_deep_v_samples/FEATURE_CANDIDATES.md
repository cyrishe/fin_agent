# D2：深 V 的候选特征设计（只设计，不训练）

日期：2026-10-13。沿用 [D1 标签](README.md)：全日一分钟收盘价的最高与最低相差超过 5% 才进入 `1/0/-1` 三类，最终收盘相对全日最高的 −1%、−3% 分档。这里列的是**待检验假设**，没有计算深 V 目标上的因子效果，更没有选股或收益回测。

## 先固定预测时点与可交易目标

- **T−1 收盘后初选**：只能使用截至 T−1 已发布并实际可取得的日线、历史分钟线、资金流、指数和行业信息。
- **T 日开盘后更新**：以 09:40 作为待核的示例时点，只能使用当时已完成且已送达的分钟 K。改成 09:35、09:45 时须重新计算可用性和触发机会。
- **盘中触发时重评**：若将来定义“跌超 5% 后买入”，可在触发时追加当时的量价与市场信息；触发基准必须明确为昨收、开盘价或此前已见高点之一。

D1 中 `1` 类的 **5,884/9,300** 个全日最低点已在 09:40 前出现；只有 **754/9,300** 个 `1` 类真的先有当日高点、再从该高点顺序跌超 5%。因此“预测全日形态”与“预测 09:40 后可买到且收盘回升”不能共用一个结果解释。若 T−1/开盘前先对全市场排位，建议同时记录 `P(当天出现所定义的可买回撤)` 与 `P(收盘回升 | 已出现可买回撤)`；即使模型训练先只看条件样本，评估也要把未触发日和触发时间列出来。

## 已核对的本地数据与旧模型

旧 14:40 七因子来自 [冻结基准代码](../../../scripts/benchmark_automl_1440_inference.py)：`signal_return`、`volume_ratio`、`turnover_so_far_pct`、`float_mv_100m_cny`、`volume_4of5_increasing`、`ma_bull_5_10_20`、`all_intraday_lows_above_ma`。它们原来预测的是 14:40 至次晨 09:40，目标和候选池均不同；可重用**计算思想**，不能沿用已训练权重或声称对深 V 有效。旧模型的日内放量比按已过 220/240 分钟归一；深 V 开盘版需要按**历史同一时段**的成交量曲线归一，不能直接套全天均匀成交假设。

| 来源 | 已核对的可用字段和范围 | 主要限制 |
|---|---|---|
| `kcrp_stock_price` | T−1 的复权／未复权 OHLC、成交量、成交额、换手、振幅；现表 2018-01-02 至 2026-10-12 | 复权序列与 T 日原价支撑位必须按同一基准换算；当天日线收盘不能进早盘特征 |
| `kcrp_stock_moneyflow` | 超大、大、中、小单买卖额和主力／大单／超大单净占比；8–10 月 45 个日级日期，每日约 5,197–5,213 行且主力比例字段齐全；有下一交易日的 44 日，其**当前保留版本**的最大 `update_time` 都早于次日 09:40 | 只有**日级**，没有 T 日 09:40 的大小单流；大单与超大单已包含在“主力”中，不能把三者当独立流量相加；原始划单阈值与历史修订链未核实，不能推断“机构买入” |
| `kcrp_stock_pricevaluate` | 流通市值、流通股数等 | 抽查旧交易日现存记录的 `update_time` 可晚至 10 月 11 日；必须按预测时点过滤，不能把当前改写值直接搬到历史 T−1 |
| `kcrp_index_price`、`kcrp_stock_industry` | 指数行情、申万行业归属，可构造市场和板块相对量价 | 用 T 日早盘信息时须有对应时点的指数／板块分钟数据；不能用 T 日收盘后的行业涨跌 |
| `outputs/stock_automl/mk_1m_compact` 与 `aiia_stock_realtime_minute_snapshot_full` | 本地 MK 逐日压缩档当前有 2026-01-05 至 07-31 共 139 日，字段含分钟 OHLC、股数成交量、成交额；KingdomAI 完整一分钟表从 2026-08-05 至 10-12 有可用日 43 个 | 两源的 `volume` 单位不同，合并前须统一；用户提到的更早分钟资料不在本次检查到的这个 compact 目录。分钟表有事后补录：抽查 8-17、9-16、10-08 三日，09:31–09:40 分钟 K 在**当日 09:40 前抓取入库数均为 0**；这不否定行情本身存在，但不能把现存表当成当时已送达的实时快照 |

资金流样例 `301356.SZ` 在 2026-09-22：`main_buy_value = large_buy_value + huge_buy_value`，`main_net_buy_value_ratio = main_net_buy_value / kcrp_stock_price.amount × 100 = 5.3712%`。优先用比率或用同一张日线成交额归一；不要依赖未核实的“万元”展示字段单位。

旧的[次晨目标因子审查](../20261010_second_high_factor_audit/README.md)发现 T−1 振幅和大单净买比例只有很弱的同日区分，合并更多资金流、融资和行业字段后也没有改善那个目标。它既不能证明这些特征对深 V 无用，也不支持先验认定它们有效。

## 候选特征清单

下表的 `P0` 是最先做覆盖与分布检查的一小组，`P1` 是有明确数据来源的扩展，`P2` 需要更强时点或数据核查。计算式中的收益、成交额均只用该行**预测时点之前**的数据。

| 时点／优先级 | 特征及具体计算 | 对深 V 的待检验关系 |
|---|---|---|
| T−1 / P0 | **前日位置与实体**：`(C−L)/(H−L)`、`C/O−1`、下影线占全天振幅；同时保留前日振幅 `(H−L)/preclose` | 区分已有下探后收回、收在低位继续承压；不能凭下影线直接断言次日再反弹 |
| T−1 / P0 | **相对波动**：ATR14/昨收、近 5/20 日高低振幅均值、近 20 日收益标准差、近 20 日振幅 >5% 的次数 | 同样的 5% 对低波动股和高波动股含义不同；也关系到触发概率 |
| T−1 / P0 | **连续价格位置**：昨收距 5/10/20 日均线百分比、均线 5 日斜率、昨收在近 20/60 日最高最低区间的位置 | 把旧布尔 `ma_bull_5_10_20` 细化为距离与方向；均线只描述已有走势，不是独立“支撑力” |
| T−1 / P0 | **相对量能**：昨日成交额／过去 20 日中位数、5 日成交额／此前 20 日基线、昨日换手及其 5 日趋势 | 检查先前参与强度、量能扩张是否伴随次日可回升形态；金额与股数单位在跨源时先统一 |
| T−1 / P0 | **日级大小单分歧**：昨日大单＋超大单净额／昨日成交额，以及 `(大＋超大净额−中＋小净额)/成交额`；3/5 日净占比均值与斜率 | 查看前日价格与不同单量档资金流是否背离；只作为供应商分类代理，不能识别真实投资者身份 |
| T−1 / P0 | **市场／行业状态**：前日指数和所属行业 1/5 日收益、前日行业成交额相对 20 日基线、个股减行业收益；前 20 日市场级深 V 条件比例 | D1 的逐日 `1` 类基率波动很大，市场共同状态可能比单股形态更重要；同日标签基率不能作为 T 日早盘输入 |
| T−1 / P1 | **跌涨量价配合**：昨日各分钟下跌段成交额占比、最大 10 分钟下跌对应成交额、下跌段与反弹段的量比 | 将“回调缩量／回升放量”变成有时点和基线的指标；可先用 MK 档，跨源核对后再拼 8–10 月 |
| T−1 / P1 | **前日内形态**：昨日分钟收盘最大顺序回撤、从最低点至收盘的恢复比例、低点时间、尾盘 30 分钟收益与成交额占比 | 检查深 V 是否有短期重复或过度反应后的修复，而非直接给“洗盘”贴标签 |
| T−1 / P1 | **近期相对强弱**：个股减指数／行业的 3/5/20 日收益、近 20 日最大回撤、距近 20 日高点距离 | 区分上升趋势中的回踩、横盘震荡和下跌趋势中的加速下探 |
| T−1 / P1 | **可交易约束**：流通市值、前 20 日成交额中位数、涨跌停距离、ST／板块、近期停牌或复权跳变 | 主要解释样本结构和成交可能性，宜作为分层或过滤信息，不先当“深 V 成因” |
| T 开盘截至信号 / P0 | **开盘位置与早段路径**：首分钟相对昨收跳空、截至时点收益、已见最高到最低振幅、当前价在已见区间的位置、此前已见高点到当前的顺序回撤 | 判断早段是直接下探、冲高回落还是已开始反弹；每一项都只用当时已经结束的 K |
| T 开盘截至信号 / P0 | **早段量能与量价**：前 5 分钟／下 5 分钟成交额；累计成交额对同股此前 20 日**同一分钟**累计额中位数；下跌分钟成交额占比；`∑sign(分钟收益)×分钟成交额 / 累计成交额` | 识别早段放量下跌是否持续、低位成交是否缩减、价格与成交强度是否背离；最后一项只是分钟涨跌代理，**不是真实主动买卖订单流** |
| T 开盘截至信号 / P0 | **相对市场早盘表现**：截至同一时点个股减行业／指数收益、市场下跌股比例、行业内振幅 >5% 的股票比例 | 分开个股异动和全市场共同下跌；必须由同一时点可用分钟行情构造 |
| T 开盘截至信号 / P1 | **均线和 VWAP 距离**：当前价距昨已知 MA5/10/20、截至时点成交额／成交量所得 VWAP；已见低点距 MA20／昨收 | 测试跌至先前密集交易区后是否更易回升；VWAP 使用相同单位且只累计已观察分钟 |
| T 开盘截至信号 / P1 | **波动强度与速度**：前十根分钟收益标准差、最大连续下跌根数、最大 3/5 分钟跌幅、极值发生时间；将已见跌幅除以 T−1 ATR14 | 区分缓慢下跌与瞬时冲击；若低点已经在信号前出现，不能再把“早段反弹”当成随后低吸机会 |
| 盘中真实触发时 / P2 | **即时承接**：触发前 3/5 分钟跌速与量速、触发后才可观察的 1/3 分钟反弹确认、相对市场同步跌幅、距跌停价和 VWAP | 仅供另一个“触发后能否回升”问题；触发后的确认会改变买价，不得提前放入 T−1/开盘预测 |

不先堆 MACD、RSI、KDJ 等一组由相同价格序列衍生的相近指标；若基础价格位置、斜率和波动已覆盖主要信息，再逐项查它们是否有**增量**。大／中／小单净额之间也高度耦合，先用少数比率与差值，避免把同一笔资金重复描述成多条独立证据。

## 外部资料的核实边界

- [Heston、Korajczyk、Sadka 的原论文存档](https://arxiv.org/abs/1005.3535)报告美股日内收益存在短时反转，且成交量、订单不平衡等有日内规律。这支持检验“时段标准化量能”和短时反转假设；**不证明** A 股某只股票会形成全日最高到最低超过 5% 且收在最高附近的深 V。
- [Cont、Kukanov、Stoikov 的原论文存档](https://arxiv.org/abs/1011.6402)研究的是美股订单簿最优买卖价处的订单流不平衡及短时价格变化。KingdomAI 的**日级大小单净额不是该论文定义的盘口 OFI**，只能作为较粗的资金流候选代理。
- 本地已对音轨和画面做过核查的 DY 资料：[量价与位置](../../research/douyin/张素芬/7693142310552341798/analysis.md)、[回踩与放量](../../research/douyin/猎人X/7691223828541820200/analysis.md)、[均线位置](../../research/douyin/猎人X/7691244645992500480/analysis.md)。视频都是示意性经验，没有带代码和日期的样本验证；这里仅提炼为可计算的“位置 × 量能”“下跌量与回升量”“距均线距离”假设，不采用“吸筹、洗盘、主力护盘”等不可由现有字段直接证实的解释。

## 下一步仅做特征审计

先选表中 P0 的少量非重复指标，逐日检查覆盖、时点、复权与单位，再在 D1 的 23 个 T−20…T−1 窗口上做**同日分位分组**：每个 T 日都列入样量、三类比例、因子分位中的 `1` 类比例及相对当天基率的差。分别统计“全日形态”和“信号之后仍可触发买入”两种目标，缺分钟日单列。只有方向在多个日期稳定且买入触发口径成立，再考虑训练；当前方案没有因子有效性结论。
