# CO10：沪深市场独立次晨大跌模型

用户明确更正：不能仅使用B1选中股票训练。本轮训练、验证和测试主体都是当日沪深市场可观测股票；B1只作为模型完成后的独立下游应用检查。CO9的B1小样本探索不作为本轮结论。

## 标签、样本和时刻

决策截止T日14:40。主风险类为T+1正式日线open / T日14:40分钟close−1 ≤ −2%；普通安全类为同一收益≥0（包括大涨）。−2%到0之间是边界样本，主模型训练暂不使用，验证和测试必须保留。另对照训练仅用风险类与≥+2%大涨类。标签参考决策价，不把T日收盘价当成当时已知买入成本。策略应用仍用B1 14:42入场、09:40退出。

当前日只从已完结14:40分钟取价格、此前分钟金额累计及预先已知的preclose；当前日最终open/high/low/close/全天金额不作特征。次晨正式open仅作成熟标签，保守到09:40可用。标签缺失/停牌不能填0；模型仍对当日可观测股票评分，未知结果不纳入标签指标并单列数量。历史跨除权成熟标签不参与拟合/验证选门槛，测试输出保留，无法恢复经济权益的标签记为不适用，禁止把除权状态当作预测特征。

当日股票池只由当前可见沪深14:40有效价定义，不依赖明天是否存续。已有分钟最终档案及日线修订限制需披露，不能宣称完成历史实时送达审计。

## 特征和模型

固定12项：市场14:40上涨比例/收益中位数/IQR/过去5日市场上涨比例；个股14:40涨幅、截至14:40成交额/过去20日同刻中位数、昨日收益、过去5日累计收益、5日及10日收益标准差、5日下行波动、5日最差收益。全部历史项截至T−1，连续市场日不足时保留缺失。训练段1%/99%截断、中位数填充、均值标准差缩放；测试数据不参与预处理。

固定两算法：Logistic C=0.1/lbfgs/max_iter=1000；HistGradientBoostingClassifier 60轮、learning_rate=.05、max_leaf_nodes=7、min_samples_leaf=100、l2_regularization=10、max_bins=63、early_stopping=False、random_state=1015，sklearn1.7.1固定。均对风险类赋5倍权重。各算法分别训练“大跌/不跌”和“大跌/大涨”两种样本定义，共4组。主方案为大跌/不跌的直方图树；不根据测试月更换主方案。分数为加权风险分数，非校准大跌概率。

每个测试月前100市场日，前60日训练、后40日验证、下一整月测试，验证后不重拟合。整日切分，禁止同日股票横跨训练验证测试。每个训练日总权重先归一到相近量级，防止股票数多的日期占比过高；风险5倍权重在日权重之后乘。所有模型至少每类100行，否则不启用。

## 阈值及应用

门槛只用全部市场验证样本选，完全不使用B1身份或B1收益。候选为0/0.01…1及不拦截；目标90%召回，主方案至少保留30%验证股票机会，激进版至少保留10%。达到目标时选保留最多；无法达到则先最大化召回、再最大化保留、再取高阈值。不按验证收益调阈值。验证事件不足30例时不启用。

逐月输出全部市场召回、漏报、拦截精度、非大跌误拦率、保留比例、各训练类数量、阈值。另列信号涨幅4%—9%的事先定义子群，评估不同股票分布的迁移；不据此调参。冻结模型评分后再将B1映射进去，B1缺少当前市场输入则保持原成交额策略并单列，不能用结果筛掉。

下游B1沿用CO8费用/10万元/14:42买入及次晨09:40退出，列逐月净收益/结算回撤/交易数/避亏/误拦盈利，以及原2026年2—7月区间；保留原成交额、不新增过滤、等平均暴露和同月等笔数随机轮空对照。评估主要看是否高召回同时保有可用交易，而非只报告训练准确率。

全市场样本按股票日计但并不相互独立，按日期聚合及分块评估；历史已研究多轮，不称盲测。保存所有输入源哈希、模型、划分和逐股评分；测试未来日线/截止时点/标签/边界样本，模型回读复核。用户授权研究不代表生产升级，本轮不修改线上策略。
