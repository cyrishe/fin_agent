# CO13结论：每日20日模型未改善固定概率门槛；排名过滤另有线索

## 本轮完成了什么

B1选股、原成交额规则及sklearn1.7.1不变。独立全市场风险模型改为每天用最近20交易日重训，预测次晨09:40实际净亏超过2%的概率及条件亏损幅度。沿用CO12相同12因子、树参数、日期权重、预处理、交易价格代理和费用。

预测T日时，训练用T−20至T−1成熟样本；校准用此前20日各自当时生成的样本外预测，只接入T日14:40前已成熟标签。当前模型训练日期与历史校准日期重合，但校准分数来自当时未见该行结果的模型。308日模型组含20日预热和288正式日，共616个预测头，训练与保存回读约1197秒；原B1及CO12逐日账户复现，15个月校准重建和仅因子输入推理误差均为0。16项定向测试通过。

测试期2025-08-01至2026-10-13；最后月份不完整。收益为10万元账户扣费现金复利；回撤为结算净值，分钟回撤另存CSV。买入代理为14:42结束分钟open，次晨09:40 close卖出；事件时间可核对，实时送达与真实成交未证明。原B1 Top1轮空前达标/可接受/错误率保持21.13%/29.58%/49.30%。

## 固定交易规则：20日没有胜过原60日方案

|规则|60日收益/回撤%|20日收益/回撤%|60→20交易笔数|60→20完全误拦盈利|
|---|---:|---:|---:|---:|
|概率20%轮空|−18.53 / 24.95|−28.70 / 29.18|64→62|71→70|
|20%半仓/40%轮空|−22.95 / 36.46|−33.94 / 39.89|212→218|3→1|
|尾部期望损失1%轮空|−12.14 / 36.19|−19.70 / 41.12|137→149|40→32|
|尾部预算0.5%减仓（预设主）|−18.61 / 34.39|−27.58 / 36.91|222→222|0→0|

部分盈利被减仓也属于机会损失：分档仓位为68→69笔，主减仓为82→87笔。主减仓20日仅6/15个月收益更高，9个月更低；尾损轮空虽8个月更高，但2026年1、3月明显变差，不能用获胜月份数替代收益与回撤。

同一222笔B1成交样本，60→20的平均预测大亏率24.39%→24.27%，实际22.97%；Brier误差0.1748→0.1848，条件亏损幅度MAE 1.273→1.347个百分点。20日的Brier还略差于其过去基率参考0.1835。因此问题不只是门槛碰巧选错，绝对概率与幅度的测试误差也变差。此处是已观察到的误差，尚不构成未来永久优劣证明。

具体例子：2026-01-12/603169实际净亏5.98%，20日把大亏概率由44.9%降至21.6%，主方案仓位由25.7%升至64.7%，扩大损失。2026-04-29/688021实际盈利7.57%，20日把概率由7.2%升至22.9%，仓位由100%降至58.6%，减少盈利。完整变化见DIAGNOSTICS.md及decision_changes.csv。

## 用户追加：只在风险前K名才轮空

K=100、250、500于整段日滚动结果产出前固定。对当日全市场校准概率降序排名，B1进入前K才轮空；排名不用未来标签。边界并列整组无法装入K时保留，实际风险池最多K只。

|K|60日收益/回撤%|20日收益/回撤%|20日拦截/原交易|20日避亏/其中大亏|20日误拦盈利|
|---|---:|---:|---:|---:|---:|
|100|−34.65 / 44.05|−25.81 / 39.29|74/222|43/18|31|
|250|−31.13 / 34.97|+2.41 / 24.50|131/222|76/33|55|
|500|−3.44 / 22.92|+24.31 / 10.33|170/222|97/42|73|

这是本轮值得保留的线索：20日的绝对概率门槛变差，但按当日相对风险过滤的结果改善。不过B1股票高度集中在风险排名前列，K500拦去76.6%的原交易、误拦73笔盈利，不能称为“只去掉几个危险操作”。K500仅52笔成交，15个月为6正、8负、1零；2025年8–12月−7.71%，2026年至10月13日+34.70%。2026年2月零收益源于零交易。

K500额外增加10bp执行成本后仍+18.03%，剔除最好一笔后+11.38%；相同平均仓位B1为−10.46%。因此这次正收益不能全部解释为简单减少仓位或只有最好一笔。但20日相对60日的10日块重抽样日收益差区间为[−0.0578,+0.2363]个百分点，跨0；历史反复研究且比较多组规则，不升级为已验证策略。K250加10bp后−6.50%，剔除最好一笔后−8.25%，其微正收益更脆弱。

## 真正只拦少数交易：追加小K仍未成功

发现K100仍拦74笔后，根据用户少量拦截的目标追加固定K=10、25、50，明确属于看过初轮覆盖率后的探索，不冒充预设盲测。

|25|22|10/5|12|−54.58|62.90|

K10确实只拦4笔：错过2026-03-24/688498的+7.84%，避开2026-06-18/003026的−0.47%、2026-08-03/002498的−1.07%、2026-08-17/301047的−3.29%。虽然“拦对3笔、误拦1笔”，金额方向仍不利。原B1全期−43.37%/55.94%；小K没有同时改善收益与回撤。相对风险第一梯队的概率也可能只有30%附近，不等于确定会大跌。

## 判断与文件

不把20日每日模型替换为线上风险开关。保留相对风险排名方向，尚未证明能够用极少的拦截稳定改善B1。之后若研究低频过滤，应将拦截数量、误杀盈利幅度及避免亏损幅度一并约束，并在未来未见日期验证；不能直接从本轮结果挑最赚K上线。

本轮比较同时改变了训练长度、更新频率、校准时效，不能把所有差异单独归因于20与60天。全部方案仍为探索，线上B1未变。
