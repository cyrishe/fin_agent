# 七因子滚动训练：10、15、20 日窗口

## 实验口径

使用 2026-08-05 至 09-30 的 **40 个有精确分钟数据的信号日**，共 14,292 条 14:40 候选股票记录。候选先满足当天 14:40 涨幅 3%–6% 等原七因子样本条件。每个测试日只取它之前连续的 K 个**可用信号日**训练：K=10、15、20；每天重新拟合，预测当日 14:40 的候选，测试日不进入当次训练。上一信号日的次晨标签在测试日 14:40 前已经可见；时间顺序无前看。

七因子沿用原定义：14:40 涨幅、量比、截至 14:40 换手率、T−1 流通市值、五日成交量四日递增、MA5>MA10>MA20、截至 14:40 日内最低价高于三条均线。买价为 T 日 14:40 价格；验证价分别为 T+1 的 **09:31–09:40 十根精确 1 分钟 K 的最大开盘价、最大收盘价、最大最高价**。三种价格**各训练一套对应模型并用同一价格验证**。涨幅 >1% 为达标，<0.5% 为严重错误，其余为中性。

模型两种：**逻辑回归**把“达标”作为二分类目标，数值因子在每个训练窗口内标准化，C=0.2；**回归树**拟合对应价格的实际涨幅，训练目标截在 −10% 至 +10%，树深 5、叶子至少 80 条，按预测涨幅排序。没有按测试结果选模型或调参数；同分按股票代码排序。SVM 暂未加入，因为这两种模型已足以检验滚动窗口和价格目标的基本效果。

## 结论与边界

- **窗口长度没有稳定赢家。**共同日期上，逻辑回归用最高价验证时 20 日窗口达标 25 只、严重错误 10 只；但用开盘价验证时三档达标分别是 18、18、20 只，差距小，收盘价为 17、16、15 只。不能只挑最高价这一列宣称 20 日最好。
- **回归树没有解决前二并列问题。**即便预测连续涨幅，其叶子预测值仍大量相同，前二分数门槛及以上最多有 13–239 只；按代码截取的前二结果对排序规则敏感。逻辑回归的前二门槛及以上最多数为 2。
- 这批回测是**裸选股标签测试**，没有模拟买卖成交或收益。最高价是十分钟内曾触及的价格，开盘价与收盘价更接近可观察时点；三者不能混为同一交易结果。历史结果已被反复查看，不能称为新的盲测。
- 原来的“严重错误 6、总数 30”来自**八因子、14:50 假设买价、三个分段模型**，与本次七因子、14:40 买价、逐日滚动的口径不同，不能并列比较。
