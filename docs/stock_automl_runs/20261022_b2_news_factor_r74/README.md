# R74：公司基本面与事前新闻

## 结论

新闻有风险信息，但“看到风险提示就不买”尚未证明能提高策略收益。本轮构造可追溯因子与固定规则对照，未训练或发布新闻模型。

- 冻结B2候选709笔，V2放行306笔；选中日2022-05至2026-09，按原记录D2至2026-10-09。
- D2、D3连续收盘跌停20笔、19家公司；恒尚两笔属于同一段行情，不能当20个独立事件。连续跌停是价格标签，不等同每笔实际亏损。
- 19家公司中，选股前最新已披露定期报告归母净利润亏损7家。盈利公司同样会连续跌停。
- 近期至少2个不同公告日提示交易风险：21笔中6笔连跌（28.57%）；未提示组285笔中14笔（4.91%）。这是描述性关联。
- 同一条件直接取消买入，全306笔原收盘假设下，每笔1万元净损益减少2876.87元；风险富集与交易收益须分别判断。

## 日常Python采集

collect_recent_news.py已在服务器准备，按候选股票收集最近窗口，保存原始响应、来源、发布时间、首次采集时间与覆盖。正常使用可在D0选股和D1买前更新，只使用已公开且当时确实收到的消息。--days是下载日历范围，因子5/10日仍由交易日历控制。

运行示例：服务器Python执行本目录collect_recent_news.py，参数 --stock 600053 --days 20 --out /data/cyris/work/b2_news_daily。多股票重复--stock。

默认公开公告；--with-media尝试新浪，遇登录/频率限制记录并停止，不把失败记0。媒体连接未完成运行验证。历史回溯的日期型公告按保守次日处理；日常采集则以首次实际收到公告索引的时间为可用证据，不必等到次日。索引只支持标题事实，若加入正文因子还须保存正文首次取得的时间。首次采集时间不可按历史发布日期倒填。
