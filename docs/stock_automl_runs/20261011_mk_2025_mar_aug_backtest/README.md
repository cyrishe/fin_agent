## 口径与限制

- 候选条件：T 日 14:40 相对昨收涨幅 3%–6%；特征只用当时及此前分钟 K、T−1 及以前的日 K。训练窗口固定为自然连续的前 20 个交易日，不跨越缺数据日期。
- 达标／可接受／中性／错误依据 T+1 09:31—09:40 **第二高价**相对 T 日 14:40 价，分别为 ≥3%、[1%,3%)、[0%,1%)、<0%。这与实际卖出收益是两个不同指标。
- 固定收益按 T+1 09:40 分钟收盘价；新规则按次晨逐分钟收盘价，首次超过买价 3% 卖出，或亏损中较前一分钟涨至少 1% 卖出，其余 09:40 卖出。买价统一用 T 日 14:40 价格。
- 月复利代理是假设每笔全额再投入的价格路径，不是实际资金曲线；未计买入是否成交、费用、滑点和冲击。2025 年主口径没有已选的 14:40 涨停 ST，也没有未知的次晨结局。
- 本半年 Top1 的固定收益有 3 笔 >+5%、5 笔 <-5%；剔除这 8 笔后固定平均仍为 −0.174%/笔。新规则虽改善平均收益，仍为负。3 月仅从 5 日开始测试，原因是此前 20 日用于训练。

本地候选数据与原始分钟 K 位于 Git 忽略的 `outputs/`；本目录保存折外选股、结果与可审计的运行摘要。

本地复跑入口为 `python -m scripts.run_automl_mk_1m_2025_replay` 与 `python -m scripts.report_automl_mk_1m_2025_replay`。最终两段回测都从 `outputs/stock_automl/mk_1m_2025_continuous/cohort/trainable_candidates.csv.gz` 这份 183 日连续特征母表切分；本半年切片在 `outputs/stock_automl/mk_1m_2025_mar_aug/cohort/trainable_candidates_continuous.csv.gz`。`source_days` 是指向已核验 2025 年 `.csv.zst` 的逐日符号链接目录。

连续母表可从分钟 K 重建：`python -m scripts.build_automl_mk_1m_candidates --archive outputs/stock_automl/mk_1m_2025_continuous/source_days --env-file .env --output outputs/stock_automl/mk_1m_2025_continuous/cohort`。现有本地运行先合并了两段已核验的逐日分钟摘要，再用同一份日 K 历史计算特征；这样避免分别从不同历史起点滚动计算均线时出现浮点末位分歧。

## 后续两个月检验

[9—10 月同口径报告](../20261011_mk_2025_sep_oct_backtest/README.md)继续使用此前 20 个交易日滚动训练，只运行“剔除 14:40 涨停 ST”主方案。Top1 在 39 个测试日均选出股票，固定 09:40 平均 +0.083%/笔，新规则平均 −0.108%/笔；其中固定收益有 3 笔 >+5%、1 笔 <-5%，剔除后固定平均为 −0.665%/笔。前六个月与这两个月结果方向不同，但后两个月的微弱正均值高度依赖少数大涨样本，不能视为稳定优势。
