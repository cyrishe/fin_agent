# CO28：低位候选池的因子分位、市场环境、相对标签与窗口对照

2026-10-27。**2025验证选择了12个月窗口的逻辑回归；在2026年1—9月，它比原6个月模型少亏，但D+3仍低于同日低位候选池，优势按月重采样的区间跨零。仅加市场状态没有稳定收益，且对逻辑回归D+2形成明显负增量。2026历史已被反复观察，此次各新变体都不能称为新盲测或生产升级。**

## 同一数据与时序

沿用CO26/27的1,260,732条宽低位L候选股票日、22个截至D收盘已知因子、D+1开盘参考进入、D+2或D+3收盘参考退出及单边0.1%费用。2024为发现/预热，2025-01—12逐月验证，2026-01—09逐月前推对照。未改变选股母池或价格代理；一价入场、疑似锁跌停卖出或缺价保留未知，不能把收益视作真实成交账户净值。

在每个D日的**同一低位候选池**内对22因子分别作百分位排序，同时保留原始因子值。市场状态来自CO25截至D日的全市场等权收益、近5/20日复利收益、20日波动率，以及宽低位股数占基础池比例。某日状态只由该日和更早记录生成；缺失、1%/99%截尾及线性标准化只在当月训练折拟合。D日样本的后续收益没有参与因子变换。

固定七个变体：`rank_lr/rank_rf` = 原值+当日分位；`state_lr/state_rf` = 再加市场状态；`relative_lr` = state因子、把同日**已知**后续收益排名的后30%/中40%/前30%作为训练标签；`short_lr/long_lr` = state因子、保持原绝对涨跌标签，把6个月训练窗口改为3/12个月。其他模型参数分别与CO26逻辑回归和CO27随机森林一致，按训练日期等权。相对标签模型的分数为P(同日收益前30%)−P(后30%)，仍用原始绝对净收益评估。方案和界限在训练前写于[设计](DESIGN.md)。

所有变体每月只用该月之前且标签已成熟的样本训练；测试2026年前的模型选择只用标签在2026-01-01前成熟的2025验证记录。共21个月、两个持有期、七变体、294个模型。最早训练窗口从2024-01开始；2026-09 D+2 的6个月/12个月样本分别约34.6万/57.4万股票日。同一股票跨日多次入样，不是独立观测。训练折成员以原CO26样本重新核对，6个月变体与CO26逐折股票日完全一致。

## 哪种处理带来变化

为避免因为新模型和原模型挑了不同可核定日期而误判增量，另对新变体两两取同一日期作消融。`rank_lr`再加市场状态成为`state_lr`，2026 D+2在168个共同日平均**下降0.511个百分点/笔**，9个月仅1个月改善，按月重采样区间[−0.807,−0.175]；D+3下降0.548个百分点，区间跨零。`rank_rf`加状态在D+2增加0.120个百分点，区间[−0.270,+0.546]；D+3减少0.100个百分点，区间跨零。因此市场状态不能简单理解为必然修复行情漂移。

相对排名标签`relative_lr`相对于同特征的绝对标签`state_lr`，D+2/D+3分别−0.124/−0.084个百分点，区间都跨零；它没有确认收益改善。把同特征LR训练窗从6个月换为12个月，2025 D+2同日多+0.600个百分点，2026仅多+0.294且区间跨零。3个月也未确认稳定增益。完整[同日消融](variant_ablation.csv)。

以D日前20日市场收益正负、以及2024年20日市场波动率中位数预先划分四种市场环境，对模型共同可核定日作事后分层。`long_lr`在2026 D+2四组样本数为22/45/9/76日，小组太少，某一环境的正收益不能做新门槛。完整[环境分组](market_regimes.csv)和[门槛来源](regime_definition.json)。行业状态未加入本轮，避免使用未经逐日核实的历史行业映射。

## 核验与边界

四个跨年份日期的22因子分位、市场5/20日收益与波动、相对标签做了108项独立复算；294个模型和预测文件抽样读回，训练折标签成熟与原CO26六个月成员匹配，见[核验回执](verification.json)。因子间相关性和随年份漂移的原始测算见[CO27](../20261027_low_base_rf_co27/README.md)。

结果只覆盖历史代理成交且2026已被观察；Top3未知价格日不能默认为零收益，持仓重叠没有账户复利，历史ST/停牌/延期退出不完整。多变体同时试验会放大偶然胜出的可能。下一步若继续，应固定少量方案，在新日期上前瞻记录选择、风险与真实可成交状态；本轮不改变正式策略。

完整样本、294折模型/概率、日期、成本口径、代码与哈希保存在本地训练包；数据库及云端回读状态见归档回执，云端未独立回读则仍为待同步。
