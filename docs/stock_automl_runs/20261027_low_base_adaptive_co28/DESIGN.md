# CO28 实验方案（运行前固定）
沿用CO26/27完全相同的候选、交易价格代理、费用、标签成熟和2025验证/2026前推期。D收盘信息：22原始因子、同日低位候选池内22因子百分位（保留缺失），加全市场等权日收益、近5/20日累计收益、近20日收益标准差及候选占基础池比例。状态仅用截至D的CO25日表；滚动不足20天保持缺失，训练折中位数填充。所有变换先按日期计算，缺失不使用未来行。
逐月，标签成熟后训练；按日期等权，延用CO26逻辑回归与CO27随机森林参数。预设比较：A 原始+分位，B A+市场状态（6个月，绝对标签，分别LR/RF）；C B +同日已知股票收益三分类（前30%/中40%/后30%，注意仅作事后训练标签）；D/E B+绝对标签（3/12个月，LR）。相对标签训练排序分数为P前30%-P后30%，仍以绝对净收益和下跌风险评价。选择模型及窗口仅根据2025标签2026-01-01前成熟的验证集；2026期此前已观察，不称盲测；各变体对照原始逻辑回归和原始森林，公共可核定日及单独未知日均报告。回测不模拟订单、资金与延期卖出。模型与预处理训练内拟合；同日截面分位只用D日可知的股票因子，不用未来信息。
