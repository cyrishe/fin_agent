# R67：D2 分时卖出与收盘卖出

## 固定规则

所有“当日涨幅”均相对 D1 收盘价；交易净收益另以 D1 买入价为基准，扣买卖各 0.1%。依次执行：

1. 上午任一已完成分钟 K 的最高价涨幅严格超过 7%，触发卖出。
2. 若尚未卖出，11:30 用上午 120 个分钟收盘统计时间占比。低于昨收占比至少 80%（96 分钟）的，下午等待分钟收盘价相对此前 D2 最低价反弹超过 2 个百分点。最低价取已完成的前序分钟，不使用当前分钟的高低先后顺序；分母仍为 D1 收盘价。
3. 上午不低于昨收占比至少 60%（72 分钟）的，14:55 判断卖出。
4. 其余情况，下午分钟收盘首次高于 D1 收盘价即触发卖出。
5. 触发后使用下一根有成交分钟的开盘价模拟卖出；不用触发分钟最高价当成交价。连续分钟模拟最迟到结束标签 14:57，之后未成交统一 D2 收盘结清。11:30 才触发的上午止盈，最早在下午首个分钟成交。

## 抽样与对照

冻结原 V2 放行月份、原月模型、四K、D0名单与D1买价，仅改变D2卖出。每年从V2放行月中按时间顺序取首、中（下中位）、末三月，先固定月份再计算新规则。2022—2026共15个月、193笔；2021只属于前置训练。每个月都从100万元独立起账，结清该月D0对应的全部跨月交易。此表不代表连续全年或全历史收益。买卖按时间先后重放，提前卖出释放的现金只有在之后买入时才能使用。同一时刻先买后卖。

## 结果解读

- 账户收益改善 8/15 个月，回撤降低 9/15 个月。
- 193笔费后笔均：+0.72% → +1.22%；费后胜率：48.19% → 52.85%。
- 逐笔卖得更好 78 笔，更差 77 笔，持平 38 笔。
- 主要提升来自上午7%止盈。弱势反弹2点组总体接近持平；其余翻红组反而退步。2026-09月账户由盈利转亏，不能认为每个月都更稳。

## 验证与范围

- 193/193笔D2均有完整240分钟；分钟OHLC与D2日线逐笔一致，日线前收与冻结D1收盘及D2收盘一致。分钟/日线成交量比例范围 0.99999744—1.00000610。
- 原收盘卖出的15个月全部复现R66已保存的独立月账户收益，最大差 4.98e-11（原表仅保留10位小数）。
- 10项测试覆盖7%严格边界、80%/60%占比、2个百分点与2%涨幅的区别、前序最低价、下一K成交、零成交量、收盘兜底和资金可用时间。
- 新规则尚未重算影子账户及下一月停摆决定；本实验隔离卖出效果。若正式更换影子卖出规则，须另做完整连续回测。
- 分钟开盘价是模拟成交代理，未模拟盘口队列和额外滑点。本次为已知历史抽样，不是未见样本验证。
- 正式V2定义、服务器买卖cron和生产交易记录未改。本实验与既有B2/B2_V2定义哈希关联保存；没有新增训练，也未新增数据库实验登记或完成云端独立回读。
