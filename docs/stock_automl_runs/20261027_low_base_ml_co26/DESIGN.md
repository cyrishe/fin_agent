# CO26：宽低位候选＋涨跌三分类

2026-10-27，在模型验证和测试前固定。本方案依据用户目标和2024发现段的样本/标签审计确定；2025验证、2026测试不参与候选框、标签及算法候选设计。历史已被研究，不称全新盲测。

## 样本与时间

D收盘后筛选，使用CO25全部历史沪深日线基础池，要求过去60个交易日有效、前20日均成交额≥2000万元且当日≥500万元。以近60日高低区间位置≤35%、20日涨幅≤8%作为宽低位L候选，不要求CO25的止跌S或收敛C；将收敛、位置、近期涨跌和量价作为模型输入。2024发现段L共418089股票日、242交易日、平均1728只/日；20/40/60/120窗口、L/S/C与±1/2/3%类别的完整审计见discovery_windows.csv和discovery_labels.csv。120日窗口样本因早期预热缺失不能简单与其他窗口比较。保留重复股票日，评价按日期等权并单列交易重叠。

D+1开盘买、D+2/D+3收盘卖各设独立标签，费用每边0.1%，价格为日线代理；一字入场、疑似一字跌停退出及缺失价格收益未知，不计作零。三类为净收益<-2%、[-2%,+2%]、>+2%，中间样本保留；两天和三天分别建模。2024 L的D+2已知417348条，正端107867（25.84%）、负端137462（32.94%）、中间172019（41.22%）；阈值同时对应有意义的收益幅度与足够类别数，不以2025/26结果选阈值。

## 因子和模型

因子22项：CO25已保存的相对位置、5/20日涨跌、均线坡度、窄幅/波幅收敛、量能收敛、收盘位置、5日相对市场及成交额10项；新增1/3/10日涨跌、20/120日位置、20日波动、价格距20日均线、当日量/此前20日均量、开盘跳空、实体、上下影线12项，全部只用D收盘及以前数据。120日不足记缺失，按训练折中位数填补；各折训练截尾和标准化参数只从该折训练集得到。未将事后更新的资金或融资数据冒充历史当时可见；资金暂不纳入首轮训练。

2025年12个月为逐月前推验证，2026年1—9月为逐月前推测试。每月只用此前连续6个自然月、标签结束早于该月第一交易日的L样本训练，日期等权。比较固定强正则逻辑回归C=0.2与浅层HGB（60轮、7叶、叶内至少200、L2=10、seed42、关闭早停）；不根据测试调参。

每个模型输出三类分数，按P(>2%)−P(<−2%)排序，每日Top1/Top3；分数仅为模型估计，未证明概率校准。各持有期分别在2025验证期以日期等权Top3净收益相对同日L池差为准选择模型，平局按原列顺序，不因测试结果变更；2026每月用固定所选算法、过去6月成熟样本重新训练并测试。验证数据在后来标签成熟后可进入向前滚动训练，这是部署模拟；报告不称2026为全项目独立盲测。
