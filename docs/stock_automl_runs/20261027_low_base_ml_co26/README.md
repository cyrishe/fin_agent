# CO26：宽低位候选、涨跌标签与机器学习排序

**结论：按“宽样本框→历史涨跌分类→时间前推选股”已完成一轮。2025验证有一定上涨富集；选出的模型在2026年测试中同时选中了更多大跌，Top3净收益低于同日候选池，尚不能作为交易模型。**

这是独立日线研究。D日收盘后建候选并计算因子，D+1开盘价参考买入，D+2或D+3收盘价参考卖出；买卖各0.1%费用。日线价格是代理，持仓重叠，没有建立账户复利或完整撮合回测。已研究过的2024—2026历史用于时间顺序检验，不称全新盲测。

## 1. 先确定大趋势样本与标签

基础池为连续60个市场交易日有效的沪深日线，前20日平均成交额至少2000万元、当日至少500万元。低位样本框为：**D收盘在近60日高低区间的位置≤35%，且近20日涨幅≤8%**。不要求先通过止跌或缩量条件；后者作为连续特征交给模型。这是用户提出的较宽候选范围，不是直接买入名单。

## 2. 因子、训练与验证

22项因子全部来自D收盘及之前：60/20/120日价格位置；1/3/5/10/20日涨跌和5日相对市场；5/20日均线形态；5日波幅、20日波动、波幅与成交量收敛；当日量相对前20日、成交额、跳空、实体、上下影线和收盘位置。120日数据不足保留缺失，填充值、截尾与标准化只由训练窗口计算。[结果前设计](DESIGN.md)。

资金与两融历史版本的到库时间尚未完成核验，本轮没有加入这些因子。原始日线来源、样本和特征哈希在build_manifest.json。D+2和D+3各训练一个三分类模型，概率用于排序，未经校准。

每月使用过去6个月内标签已成熟的宽低位样本、按日期等权训练，比较逻辑回归和浅层梯度提升树。本轮训练窗口固定6个月，尚未比较3个月或9个月。2025逐月前推作为验证；分别按Top3相对同日候选池的净收益选择算法，2026逐月固定算法、滚动重训后测试。验证选型只使用**2026-01-01以前已成熟**的结果。滚动重训时早前的验证样本在标签成熟后可进入后续训练，符合逐月部署时序。

2025验证共同可比较日，逻辑回归相对梯度树的Top3日均收益差更好，因此D+2/D+3均选逻辑回归：D+2共同203日的模型相对同日候选池+0.262个百分点；D+3共同208日+0.385个百分点。但在逻辑回归Top3三笔均已知的219个验证日中，D+2跌超2%为31.35%，同日期池17.65%，已经出现高波动风险。算法选择见[selection.json](selection.json)。

每折实际样本数、三类数量和标签截止见[训练窗口明细](fold_samples.csv)。D+2每折训练样本：2025验证期12.76万—20.43万，中位15.36万；2026测试期20.08万—34.55万，中位26.14万。D+3对应中位数分别15.25万和25.83万。

## 4. 未知执行价格不能忽略

2026每日Top3共543个位置。D+2有27个未知、涉及23日，其中20个为次日全天一价、6个为疑似退出一字跌停、1个为其他路径缺失；D+3有30个未知、涉及21日。全天一价并不直接证明具体订单能否成交。[未知明细](unknown_top3_detail.csv)。

对未知位置分别假设−5%/+5%仅作敏感性：D+2所有181日按位置等权的模型平均为−0.982%/−0.485%，同日池日期等权−0.186%；D+3为−1.220%/−0.667%，同日池−0.204%。这些假设不是实际收益或执行模拟。[完整敏感性](unknown_top3.json)。

## 5. 因子观察及局限

逻辑回归的标准化正端相对负端系数中，2026各月的5日相对市场强度和20日价格位置均为正，5日均线坡度均为负；5日个股涨跌与相对市场涨跌高度相关。系数受相关变量、训练样本及市场变化影响，仅解释模型如何打分，不证明因子有独立预测力或因果作用。[逐折系数](factor_coefficients.csv)、[汇总](factor_summary.csv)。

这轮验证显示：宽候选框有足够样本，标签分布跨年变化很大；单靠本轮量价分类仍没有控制头部大跌。当前数据缺完整历史ST身份及真实订单、资金占用和延期退出记录。下一轮可以在**同一候选框**单独检验更明确的风险目标、额外的资金及市场状态因子，并保留本轮作为对照；须先核验资金历史版本到达时点，不依照已看过的2026结果追加交易门槛。

## 6. 核验与资产
