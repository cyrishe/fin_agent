# K线形态六个月统计与研究候选

> 后续结论已按用户关注的“上涨比例相对提升”及逐月稳定性修订，见[月度复核](../20261016_kline_monthly_kp1m/README.md)和[时间尺度复核](../20261016_kline_monthly_kp1m/TIMEFRAME_REVIEW.md)。下文保留初次按平均收益差筛选的历史分析；原“优先三个方向”不再代表最新优先级。目前没有达到稳定强优势、可直接进入建模的候选。

已完成 2026 年 4–9 月、125 个交易日的全量形态扫描。源数据包含 5,259 只沪深股票，满足历史长度和有效日 K 条件的有 5,182 只、642,173 个股票日。64 条规则均保留结果，重点观察31条偏多候选；本轮没有训练模型。

**优先研究局部W底突破、10/20日均线金叉、RSI底部失败摆动；MACD金叉作为较宽候选池的对照。** 9条规则满足初筛，但相对收益为正不必然意味着自身平均上涨。RSI底背离虽然跑赢同期市场，后三日绝对均值仍为负，不列入优先三项。

## 频次与相对表现初筛

固定采用六个月500–25,000次（约4–200次/日）、至少60个交易日出现、逐日市场占比90分位不超过10%的描述性初筛。它用于排除太少和太泛的规则，不是模型或收益最优阈值。再要求后1、2、3天分别对同信号日全体合格沪深股票平均表现有正超额。

## 值得继续研究的三个方向

**局部W底颈线突破：优先研究的价格结构。** 日均57只、平均占当日合格股票约1.12%；自身后1/2/3天均值为+0.157%/+0.369%/+0.500%。最近三个月、排除收盘涨停和一字K、只取连续首次信号，三个期限的市场超额仍均为正。排除收盘涨停/一字后，三日自身均值降至+0.361%、市场超额约+0.098个百分点，说明可成交条件会削弱优势。6个月中有4个月三个期限都正超额；8月转负。这里是局部双谷颈线突破，不代表长期大底。

**10/20日均线金叉：样本量充分的趋势切换方向。** 日均142只、占市场约2.75%，自身后三日平均+0.413%；排除收盘涨停/一字后约+0.385%。近期三个月、连续首次信号、收盘可买代理过滤后三期限超额都为正。月度三个期限同时正超额仅3/6，仍有行情依赖。均线结构属于技术指标形态，不冒充单根蜡烛反转。

**RSI底部失败摆动：相对优势较强，但集中在特定行情。** 日均36只、占市场约0.69%；六个月三期限超额都正，后三日超额+0.775个百分点，自身后三日平均却仅+0.164%，因为它常出现在随后市场表现较弱的日期。7月贡献突出（三日超额约+3.095个百分点），4月和6月为负，9月只有38次。适合作为“何种反弹环境下有效”的研究入口，不能按总体均值直接认定稳定收益。

MACD金叉可作为对照：日均195只，接近本轮样本量上界；5/6个月三个期限同时正超额，但排除收盘涨停/一字后，三日自身平均约−0.002%，费用前已接近零。

## 暂不优先的原因

RSI底背离自身后1/2/3天平均均为负；MACD底背离首日均值为负，月度方向也不稳定。二者有4,140个相同股票日重叠，约占RSI底背离的58.7%，不当作两份独立证据。

启明星、内包线突破和红三兵在排除收盘涨停/一字K后，至少一个期限的市场超额转负；红三兵自身后三日均值也为负。它们保留全部明细，作为备选，不因名称看涨就列入优先项。

本轮有量且有相对区分度，但尚未证明稳定可交易优势。前三项的同日同板块三日超额区块重抽样区间都跨零；区间未做多重比较校正。它们是后续研究候选，不是已验证策略。前三项三日收盘亏至少3%的比例约为21%–24%，短持并不自动避免亏损。

## 保存与验证

所有64个形态的命中股票、日期、连续首次标记及后1/2/3天价格结果，按形态保存于 `outputs/stock_automl/kline_survey_kp1_20261016/pattern_matches/`。全体股票日布尔信号、未命中记录及标签保存在 `parts/`；原始日行情在 `source/`。下次筛选改变频次门槛、持有期限比较或市场基准时直接复用，不重新识别形态。`cache_manifest.json`核对缓存文件和计算代码哈希。

29项定向测试通过；独立原始价格逐日相乘核对1,863个标签值，最大误差约4.62e−14个百分点；真实行情截断前缀检查320项，64种形态的数量与均值全部回读一致，见[核验回执](verification.json)。独立全市场基准的样本数和均值与主扫描一致；胜率统一以1e−9个百分点容差处理浮点平盘。

数据源复权字段存在部分尺度断档，已通过统一原始价格/前收参考价链式口径处理，未改数据库；排除23只明显断档股后，前三项相对表现结论未改变。见[数据质量](DATA_QUALITY.md)、[完整计算口径](METHOD.md)。ST未单独排除；源库是否完整保留所有退市历史尚未独立证明。
