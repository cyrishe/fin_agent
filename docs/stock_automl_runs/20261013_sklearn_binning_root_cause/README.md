# A1：B1 / X1 的 scikit-learn 版本差异根因

核对日期：2026-10-13。仅审计已保存的 2026 年 2–7 月 B1 候选表和 X1 模型结果；未改实时选股、数据库或策略规则。

## 结论

直接触发差异的是 `HistGradientBoostingClassifier` **连续特征分箱算法**的改变。scikit-learn 1.7.1 对高基数特征的 254 个阈值使用 NumPy `percentile(method="midpoint")`；1.9.1 使用 `method="averaged_inverted_cdf"`，并去重相同阈值。官方 1.9 更新记录将其列为直方图提升树对样本权重的分箱修复；本策略虽然没有传 `sample_weight`，未加权路径也改变了。模型参数、七因子、标签和输入行没有因此改变。

在 **同一个 Python 3.12.14、NumPy 2.5.2、SciPy 1.18.1、pandas 2.3.3、joblib 1.6.0、threadpoolctl 3.7.0 环境**中，只切换 scikit-learn 1.7.1 / 1.9.1 wheel，7 月 30 日的分箱哈希、树节点、153 个候选的概率和 Top2 发生变化。两个 wheel 捆绑的 `libomp.dylib` SHA-256 均为 `be61ec108198547b38d6f8b797131f64032ac5013f912012cf5e42d961011e4a`。因此本次差异不需要 NumPy、SciPy、OpenMP 或 BLAS 版本变化来解释。

更强的因果对照：在 1.9.1 中**仅临时替换分箱函数为 1.7.1 的旧实现**，保持其余 1.9.1 代码和所有底层库不变。118 折的全候选四类概率 SHA-256 **118/118 完全相同**，Top1 也 **118/118 完全相同**，逐折哈希见[对照表](fold_probability_hashes.csv)。另细查 2026-05-28、06-10、07-30：分箱哈希、前两轮树节点、全部候选四类概率和 Top2 也完全一致（最大概率差 0）。临时替换只用于诊断，不属于生产修复方案。

## 放大链条

7 月 30 日训练折有 9,755 行。四个连续因子分箱后，各有约 1.28%–1.36% 的训练行落入不同箱；三个二值因子不变。小部分训练行换箱会改变某些树的分裂与后续残差。经过 60 轮、四分类概率 `argmax`、类别优先排序、每天只取 Top1、再判断是否轮空，变化被放大到选股动作。该日 153 个候选的四类概率最大绝对差中位数为 0.85 个百分点，11 个候选预测类别翻转；Top1 相同，Top2 从 `301357` 变为 `300191`。

逐日以 B1 冻结母表在 1.7.1 重训 118 折，并与保存的 X1 1.9.1 全候选分数按股票日对齐：49,279 个候选的四类概率最大绝对差中位数 0.826 个百分点、90 分位 1.640 个百分点、99 分位 2.717 个百分点、最大 13.392 个百分点；1,947 个候选（3.95%）的预测类别翻转。1.7.1 的 118 天 Top1 与原 B1 全部一致；相较 X1，31/118 天 Top1 不同或一方未选。其中 B1 原 Top1 在 1.9.1 下有 14 天被判成不参与选股的 `<0` / `0–1%` 类，另 17 天仍在候选类别但排序失利。

用同一份逐日成交额门槛和未复权分钟收盘价回放，B1 为 91 笔、+57.61%，X1 为 89 笔、−13.03%。87 个 Top1 相同日的复利对数收益差近于 0；全部差异来自 31 个不同日。差异最大的 2026-05-28（B1 `600545` +9.56%，X1 `688507` −6.40%）、06-10（B1 `300665` +11.94%，X1 未选）和 02-09（B1 `688498` +11.71%，X1 选股未通过成交额门槛）合计占总对数收益差约 64%。这是这段历史路径上的集中差异，不证明 1.7.1 将来比 1.9.1 好。

## 解释与边界

模型计算是确定性的，但**决策稳定性不足**：少量分箱边界移动会经提升树与硬类别/Top1 决策放大，单只股票全额复投又放大收益路径。这不是数学意义上已证实的混沌系统，也不能把历史胜出的版本直接选作未来最优模型。原 B1 的成交额门槛是看过研究期结果后形成，2–7 月收益并非独立样本表现；2025 年既有跨期回测也偏弱。

当前证据支持锁定训练和推理环境、保存每日训练行与模型，并把任何依赖升级当作**新模型候选**做时间外影子对照和交易成本评估。它不支持自动升级版本，也不支持因 2026 年这段收益而永久锁定旧算法作为收益策略。
