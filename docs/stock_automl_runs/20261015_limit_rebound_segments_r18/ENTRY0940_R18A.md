# R18A：09:40前最高价买入观察列

在原 R18 工作簿的“分段模型前五”末尾增加六列，原模型、排名和三日标签不变：

| 列名 | 定义 |
| --- | --- |
| 940前可买 | D1 09:31—09:40结束的十根分钟K内，至少一根有成交量且最低价低于涨停价，D1历史非ST。1=可买，0=不可买，空白=待核验 |
| 买入价 | 整个上述窗口内，有成交量分钟的最高价；仅对可买样本填写 |
| 买价触板 | 买入价达到涨停价为1，否则0。触板仍按该价作假设，不承诺涨停队列一定成交 |
| D2收益 | D2收盘/买入价−1 |
| D3收益 | D3收盘/买入价−1 |
| D4收益 | D4收盘/买入价−1 |

D0 是评分涨停日，D1 是下一市场交易日，D2—D4依次类推。收益未扣费；每个期限分别检查日线完整性与昨收/上日收盘连续性（绝对差不超过0.011元），不会因为D4尚未知而抹掉已完整的D2收益。

一分钟OHLC、交易时刻、首分钟开盘、末分钟收盘、全日成交量均核对日线。优先读取本地未复权分钟归档，缺失时从已完成且无回退的数据库分钟快照读取，手数换算为股。原始分钟摘录、来源与计算记录全部保存。
