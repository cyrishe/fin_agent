# A11：两项布尔量改比值、去量标记与极值处理

2026-10-13。用户要求逐项核查七因子预处理，并将近五日量递增标记先去掉、另两项 0/1 改成比值。本实验使用冻结 B1 同一四分类目标、14:40 信号、前 20 个交易日逐日训练、相同 `HistGradientBoostingClassifier` 参数、类别优先的 Top1 与次晨 09:40 历史卖价。新模型均为独立实验，不覆盖冻结 B1。早期 2–7 月 118 个预测日；近期 9/2–10/8 共 21 日只支持去量标记和原因子封顶，因近期冻结母表只保留七个最终因子，没有原始均线、日内最低价。

## 原来的 0/1 包含负距离吗？

包含。构建母表时，`ma_bull_5_10_20=int(MA5>MA10>MA20)`；若任一价差为负或等于零，该项为 **0**。`all_intraday_lows_above_ma=int(Lmin>max(MA5,MA10,MA20))` 也是负值或零记为 **0**。筛选条件是信号时涨幅 3%–6%、因子完整及其他原候选资格，并未把这两项 0 的股票剔除。A10 的负距分组正是这些股票。

本次比值定义为：

- `ma_bull_ratio = min(MA5/MA10−1, MA10/MA20−1)`，保留两段均线中较弱者的相对价差；正值当且仅当原均线多头标记为 1。
- `intraday_low_over_highest_ma = Lmin/max(MA5,MA10,MA20)−1`，保留日内最低价距最高均线的相对距离；正值当且仅当原低点标记为 1。

早期 49,229 条有标签候选上，两项比值的正负号与两个旧标记**逐行完全一致**。均线比值负／零／正分别有 **36,407／10／12,812** 条；日内低点比值分别有 **38,139／0／11,090** 条。前者取值 `−0.840～+0.206`、中位 `−0.0215`；后者 `−0.937～+0.353`、中位 `−0.0417`。这两个比值是无量纲的 float，不截掉负值；比 A10 的“价差／昨收”在退市低价股极端下更自然地受限。

B1 没有对这四项作 0～1 或 −1～1 缩放；树是按每个因子自己的阈值分裂，并不把“市值的 100”与“涨幅的 0.05”作数值大小比较。A10 的训练折内 z-score 实验已经验证两版各 139 折概率与 Top1 完全相同；本次继续逐折以训练最小／最大值把四项映射到 0～1，**不强行截断超出训练范围的预测值**，两版各 139 折的所有候选四类概率最大差仍为 `1.11e−16`，Top1 仍全部相同。因此单纯换单位或作线性归一化没有修复当前模型问题。预测值硬截回 0～1 则是封顶，会改变信息，必须另测。

真实预测日确有少量值超出当折训练极值：早期涨幅、量比、换手率、市值分别为 `8／15／12／19` 条，近期为 `0／2／3／1` 条。因此按训练极值作 min-max 缩放后，预测值也不保证严格留在 0～1；若硬截回区间，含义已从“归一化”变为“封顶”。近期的量比／换手率／市值 99% 分位为 `5.128／21.542%／1,647.04 亿元`，最大值分别为 `11.993／46.270%／18,151.46 亿元`，同样有长尾。

追加的**全因子归一化实验**进一步把七因子原版、六因子仅删量标记、六因子改比值的**每个输入列**都按当折训练最小／最大值映射到 0～1；常数列保持常数，预测值不封顶。七因子与六因子删量在早期 118 日及近期 21 日、两版 sklearn 的 Top1 均逐日相同；六因子改比值在早期 118 日、两版的 Top1 也逐日相同。所有十组检验的全候选四类概率最大差均为 `1.11e−16`，`>1e−12` 的差异数为 0。原 0/1 列本就处于 0～1；两项有符号比值虽然被重新映射，树的实际预测仍不变。这是逐折实测结果，不是仅凭树模型理论推断。

本次极值处理只预先选择三个有长尾的原因子：量比、换手率、市值。每折仅用当折训练行的 1%／99% 分位数作为上下界，训练和预测用同一界限截断；涨幅已有固定候选区间，不再截。早期 49,279 条预测候选中，量比、换手率、市值分别有 `1,259、1,026、1,097` 行会被截断（同一行可重复计入）。这不是普通归一化，而是主动合并尾部数值；市值大值也可能是真实大盘股，不因数值大就判为脏数据。

## 预先分开的模型对照

所有变体均沿用 B1 的标签、参数和类别优先选股，只改变所列输入；1.7.1 与 1.9.1 分别拟合。

| 变体 | 输入差异 | 时期 |
|---|---|---|
| `drop_volume` | 从七因子删去 `volume_4of5_increasing`，其余六项不变 | 两段 |
| `drop_volume_cap99` | 六因子删量不改比值，再对量比、换手率和市值逐折按 1%／99% 分位封顶 | 两段 |
| `ratio` | 删去量标记；两个均线 0/1 改为上述两个比值，共六项 | 早期 |
| `ratio_cap99` | `ratio` 加三个长尾原值的训练折内 1%／99% 封顶 | 早期 |
| `base_cap99` | 保留原七因子，只对三个长尾原值作同样封顶 | 两段 |

近期比值模型尚不能在**同一冻结母表**复现，因为其原始均线和日内最低价没有保存。不能用当前库中另一次计算的七因子与冻结近期候选混合后直接宣称跨期验证。
