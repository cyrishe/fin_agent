# R86：涨停冷静 V2「跌停对抗」同基线交叉复核

## 口径

固定既有月度停摆、轮空、D0候选、D1入场价及306笔V2放行交易，只比较其后的买前过滤与买后卖法；不重训原选股模型，也不改正式版本。D0年2022—26（35/65/54/54/98笔），D2结清至2026-10-09。用户指定的主基线是**D2收盘价全额卖出**，包括跌停收盘也按跌停价卖出的乐观价格假设；双边各0.1%费用，单一连续账户100万元起、不逐年充值。所有过滤不补票。

风险标签明确分开：D2任意分钟最低价触跌停 **100/306**；D2收盘跌停 **52**；D2全天一价封死 **14**；D2/D3连续收盘跌停 **20**。不把“只在开盘或收盘跌停”的67笔当作全部触板。D2任意触板的100笔取自R79完整分钟原档及官方跌停价。主收益是**每笔独立固定1万元**的避亏减去少赚；另列严格事件顺序的连续账户，二者不可混加。账户重放逐项对齐R76已有基线、Q75、Q80及资金组合的两种卖法。

## 交集与协同：先看同一批交易

1. **四K全跌停 vs Q75/Q80：** 五笔全在两模型禁买集合内；加规则后笔数、D2风险和账户收益均完全不变。
2. **D1否认热点 vs Q75：** 9笔中3笔已被Q75提示，新增6笔，额外拦2笔D2触板、0笔全天封死、1笔D2/D3连跌；新增误拦2笔盈利。固定每笔1万元相对Q75净增约**1,856元**。严格D0已知版本只有7笔，Q75外新增5笔、仅额外拦1笔触板，2025独立净贡献相对Q75反而下降。
3. **资金Q80 vs Q75：** 资金Q80的74笔中71笔已与Q75重合，新增3笔仅拦2笔触板、0笔全天封死；固定1万元净增约1,101元，但2025 OR组合较Q75少约702元、年度账户也从+47.38%降到+42.60%，2026没有新增拦截。历史资金可用时刻尚未通过，不升级。
4. **早卖 vs Q75：** D2收盘跌停且能在触板前早卖的3笔中，Q75已禁买2笔；剩下1笔相对收盘多约335元/1万元。对所有仍买209笔，早卖相对收盘卖的等额合计反而**−1,259元**（非跌停票提前卖的机会成本超过这笔）；全期连续账户从+1479.12%到+1477.12%，差−2.00个百分点。Q75加D1新闻后，早卖等额净−1,149元，但账户因仓位时序+6.42个百分点；不能把账户小增说成所有被保留交易都卖得更好。
