# 四条卖出规则：次晨分钟价回放（2026-10-10）

## 规则已经实现

统一买价是信号日 **T 14:40 一分钟 K 收盘价**；逐分钟只观察 T+1 **09:31–09:40 一分钟 K 收盘价**。按时间顺序走到当前分钟，第一次满足条件就退出：

1. 09:31–09:33，当前收盘价相对买价**严格超过 3%**，按该分钟收盘价卖。
2. 若此前已有至少一分钟，当前收盘涨幅比**此前各分钟收盘涨幅的最低值**高至少 **1 个百分点**，按当前分钟收盘价卖。例如此前 −3%、当前 −2%，本规则触发。此规则在前 3 分钟和后 7 分钟都适用，同分钟优先于第 3 条。
3. 09:34–09:40，当前收盘价相对买价**严格超过 1%**，按该分钟收盘价卖。
4. 始终未触发则按 09:40 收盘价卖。边界 `>3%`、`≥1 个百分点反弹`、`>1%` 在[测试](../../../tests/automl/test_second_high_four_class_and_exit.py)中固定。

规则 2 经常最早触发，尤其会在价格仍低于买价时卖出；它并非止盈规则。旧回归名单在这 20 日的四规则观察价回放为正，但**比始终等到 09:40 少 4,424.57 元**；四分类提升树也低于 09:40 基线。逻辑回归本身选股结果较差，四规则只减少了该情景的亏损。逐股触发价、时间和收益见[交易明细](trades.csv)，逐日资金见[日账](daily.csv)，完整定义和输入哈希见[摘要](summary.json)。

以上“观察收盘即按收盘成交”是理想化价格代理：收盘价要到该分钟结束才可确认。另做一次执行时差敏感性：在分钟收盘观察到触发后，以**下一分钟开盘价**作卖价；09:40 无后续 K 时仍按 09:40 收盘。旧回归名单期末 110,383.90 元，四分类逻辑回归 79,613.00 元，四分类提升树 96,494.88 元。[下一分钟开盘结果](next_open_summary.json)、[逐笔](next_open_trades.csv)、[精确分钟开盘底稿](selected_morning_opens.csv.gz)。下一分钟开盘同样不是已证明的实盘成交；T 14:40 买价、可买入性、委托排队及成本仍未验证。所有名单和卖法使用已反复查看的历史日期，不能据此给未来收益作保证。
