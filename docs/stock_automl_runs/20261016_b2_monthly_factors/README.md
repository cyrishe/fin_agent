# F27：四K五K的月度因子观察

## 样本和口径

沿用R26 immediate_next_mean_end0941，2026年1月至10月14日。四K122笔、五K98笔，重叠股日保留于各自策略；不得把两策略合并当独立样本。描述特征按买入月，收益为已平仓D2净收益（买卖各0.1%），不同于账户月收益。末笔未平仓不进入收益分组；月末跨月卖出仍归入买入月的单笔统计。

特征全部D0：总市值、成交额、成交量、换手率和PE(TTM)。市值优先历史估值表，缺失用同日担保券市值表（有取整）；219/220笔有值。PE只有95/220笔有值，其中44笔非正，正PE51笔。估值表历史记录存在后续update_time，未经point-in-time版本证明，所以PE仅作描述，不能直接用作当时可交易因子。未采用当前PE替代历史缺失。

## 方法

按月报告中位数和覆盖数。仅设未依据收益优化的整数分界：总市值100亿、成交额10亿、成交量1亿股、换手率10%、正PE50倍；低组≤分界，高组>分界。每月分别列两组笔数、平均净收益、亏损超过5%比例。月间一致性只计完整1—9月且两组各至少3笔；此门槛仅过滤极少样本，不代表达到统计显著。另算各月Spearman秩相关，须至少6笔且特征至少3个不同值。方向重复是探索线索，不是显著性或因果证明；多重比较、同股连续事件和两策略重叠均未形成独立验证。
