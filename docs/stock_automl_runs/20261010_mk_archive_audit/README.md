## 8 月衔接及在线接口

现有 `aiia_stock_realtime_minute_snapshot_full` 的 1 分钟记录从 **08-05 09:31** 开始，到 **10-09 15:00**；08-03、08-04 是交易日，日行情分别有 5,535、5,536 条，但该表及另外两张分钟快照表均无这两天记录。08-05 库内已有 1,326,720 根、5,528 只股票各 240 根，这是此前从原始分钟接口趁数据尚可取时补入的历史数据。

2026-10-10 对原始 `kLineData` 1 分钟接口按[已有请求函数](../../../scripts/audit_automl_minute_api_backfill.py)实测：`600519`、`000001`、`300750` 三只活跃股票在 `shtStartxh=9997,shtWantNum=1` 都返回 **08-05 10:53**，`9998,1` 都为空；一次取末端 598 根，三只均为 08-05 **158 根**、08-06 **240 根**、08-07 **200 根**。故当天接口最早的**完整交易日是 08-06**，不是 08-07；最早残余分钟属于 08-05。接口观察到的是约 9,998 根的滚动容量，不能称为固定的“两个月日历期限”。此前 10-08 的[接口核查](../20261008_minute_api_backfill/README.md)最早还可见 08-04 10:53，说明窗口确在随新增 K 线前移；没有 10-07 当天的精确边界实测，不倒推其具体起点。以上三只的接口边界不能替代全股票覆盖审计。

所以这两套现有数据在日期上**缺 08-03、08-04 两个交易日的精确 1 分钟 K**。本压缩包最后一天 07-31 的次晨标签需用 08-03 分钟 K，故 07-31 不能按现有严格标签纳入监督训练；08-03、08-04 本身也无法构造精确分钟特征。07-30 及以前的 7 月样本仍可在各自日期范围内形成标签，08-05 及以后也可单独使用；若跨缺口使用“最近 20 个有标签信号日”，须明确它不等于连续 20 个实际交易日。保持原连续窗口口径时，最早完整的 20 日训练信号日为 08-05 至 09-01，首次测试信号日为 09-02。
