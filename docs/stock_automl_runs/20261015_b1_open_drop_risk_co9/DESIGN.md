# CO9：两极样本次晨大跌风险识别

此设计在本轮模型训练及结果产生前保存。固定CO8/CO7的B1_171名单、日期和成交额轮空。主问题是能否通过高召回风险识别，减少B1隔夜亏损；不重新选股。

## 标签及输入

- 主大跌标签：次交易日09:31分钟open / T日14:42分钟open − 1 ≤ −2%。这是次晨首分钟开盘代理相对买入成本的价格损失，非相对T收盘的跳空，非已保证可成交价。次晨09:40固定退出用于策略收益评价，开盘风险和实际退出收益分列。
- 正极安全样本：同一开盘收益 ≥ +2%；负极风险样本 ≤ −2%。两极模型拟合时排除中间样本，但预处理也仅从拟合训练行学习。验证和测试保留全部B1样本，不能只评估两极。
- 对照为全部训练样本的二分类（大跌/未大跌）。所有模型都将大跌样本损失权重设为2，其余为1；不复制样本。两极样本及加权训练输出仅为风险评分，不能称真实大跌概率。
- 特征为CO8已审计9项，再加仅截至T−1的3日累计收益、5/10日收益标准差、5日下行平方均值开方、5日最差日收益、5日上涨比例，共15项。历史股票自身数据只取此前连续市场交易日。当前日盘后资金流不用。
- 下一晨价格仅做标签，不作特征；标签成熟采用保守的09:40时间。未来除权标志不作测试筛选；已成熟训练/验证标签中的跨除权记录排除。

## 固定模型和时间验证

每个测试月此前100市场日，前60训练、后40验证、下一月测试；不在验证后重拟合。复用CO8各折时间边界。各阶段标签成熟时间严格早于下一阶段14:40。

固定三组：全部样本Logistic、两极样本Logistic（主方案）、两极样本深度2决策树。Logistic固定C=0.1、lbfgs/max_iter=2000；决策树max_depth=2/min_samples_leaf=5/random_state=91015。连续特征训练1%/99%截断、训练中位数填充、训练均值方差标准化。没有其它超参搜索。训练任一类别少于3行则该折不启用过滤，注明证据不足。

验证阈值固定为0、0.05…1和不新增过滤。评分大于等于阈值则拦截。只在原成交额可交易日选阈值；至少15笔已知验证交易、至少3次大跌，否则不启用过滤。主规则优先达到90%大跌召回，同时保留至少30%且至少5笔验证交易；达到目标的门槛中保留最多交易。若目标无法达到，先最大化召回，再保留更多交易，再取更高阈值。不按验证收益选阈值。另预设保留至少10%且至少3笔的激进门槛作为敏感性，对应用户愿意误杀的偏好，不能事后选盈利版本。

## 评价与可靠性

所有变体公开，测试期间绝不重新选阈值。主要识别指标：原规则交易里的大跌次数、拦截数、漏报数、召回率、拦截精度、非大跌误拦率、剩余大跌发生率；另统计被拦截的开盘大涨≥2%、实际09:40净盈利及≥2%净盈利。

策略指标沿用CO8：14:42买入/次晨09:40退出，10万起始、全额可用现金、费用和分数股假设相同；逐月净收益、结算和分钟收盘回撤、交易笔数、避开亏损、错过盈利。单独列原B1盈利区间2026年2–7月。附开盘原始收益与实际09:40净收益交叉表。

对主方案做同月等保留笔数随机删单2000次及原名单等平均仓位对照。按日5/10日块重抽样2000次给出召回率/净收益差的不确定性，不能忽略小样本及多轮研究。保存每折训练两极/全部名单、验证/测试全样本、模型、阈值网格、逐日决定和源哈希；模型回读检查，标签和预处理定向测试。主运行sklearn1.7.1；不修改生产B1。

本轮是已研究历史上的时间外探索，不能称全项目独立盲测。数据来自最终态档案，不能证明当时实时送达或真实成交。无正收益或不能超过相同暴露对照，均不支持上线。
