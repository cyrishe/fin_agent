# R23D：原106笔费后交易的信号、分钟窗口与容量诊断

## 实施结果

直接导入R23C费后Excel，仅在买卖明细右侧新增14列，并在原总览末尾追加口径说明；四个sheet的原数值、格式、冻结窗格及表格样式均保留，原表收益+103.5817%、回撤18.8336%、年化夏普2.2476未改变。新文件名含R23D标签。

- 106笔规则/前五分钟信号重算全部通过，424项因子与保存值一致；D0评分只用于原前三排序，未新增评分阈值。
- 91/106笔买点分钟全部成交价低于涨停，15笔当分钟又触板。74笔从买点开始连续至少3根未触板K；67笔完整5根均未触板。95笔在剩余窗口内至少有1根未触板K，11笔只有混合开板分钟。73笔从买点至09:40未再次触板。
- 买量/买点整分钟成交量：中位1.42%，90分位5.21%，4笔超过10%，其中05-22为117.17%、10-14为136.71%。这2笔在Excel标红：历史整分钟成交量不足以支持原首笔价全额成交的假设；新增订单本身可能改变成交和价格，不能直接用历史成交量推定实盘成交率。
- 同股至少延后一根K、在09:40前再找开价低于涨停且有量的分钟，98笔仍有买价代理、8笔失去窗口；80笔延后买点分钟未触板。保持原两份资金轮换、买卖各0.1%费用、D2收盘卖出，延后敏感性收益+73.0491%、回撤18.9656%、年化夏普1.8423。该敏感性未替换原结果；仍是假设分钟开价全额成交，不能称为已落实盘口执行。

## 如何使用新增列

- R23D新增信号与窗口：原R23C买卖、费用、净值完全保留。评分为D0随机森林分数，沿用原Top3排序，没有额外评分阈值；触发条件为当月形态门槛＋实体>−8%。
- 形态在09:35完整五根K线结束后可判。五分最高/最低相对D1前收盘；实体=C09:35/O09:30−1；位置=(C09:35−五分最低价)/(五分最高价−最低价)。
- 原买点列是K线结束标签：09:36代表09:35–09:36；新增买点时段明确该区间。原买入价为该分钟首笔价代理，未预留计算和下单延迟。
- 六至十分依次表示09:35–36、36–37、37–38、38–39、39–40：下=有成交且最高低于涨停；混=既有板下成交又触板；板=全部成交在涨停价；无=无成交。
- 余窗从原买点分钟起至09:40：板下分=有板下成交的K数；未触分=最高价低于涨停的K数；连续未触分=从买点起连续未触板K数；混合分钟不计入未触分。
- 买后首触给出剩余窗口内首次触涨停的分钟区间；至09:40未触表示在这段没有触及。窗口单位是分钟K根数，不是逐秒连续可成交时长。
- 买量占分量=本次费后实际买入股数/原买点整分钟成交股数，包含涨停成交量，仅作事后容量参照；不能视为可用卖单、成交率或冲击模型。
- 延后一分可买：同一只已选股票至少晚一根K后，09:40前仍有开价低于涨停且有量的分钟；不替补其他股票。用于执行敏感性，后续窗口列均未用于选股。
- 同股延后一分：98/106笔仍有买价代理；按原费用/资金轮换重放收益73.05%、回撤18.97%、夏普1.84。该敏感性没有替换本表原收益。
- 容量核对：2026-05-22与10-14的模拟买入股数分别占原买点整分钟成交量117.17%与136.71%，标红提示。即使整段未触板，历史成交量也不能支持原价全额成交的假设。

## 可行性判断

信号是明确可编程的D0原Top3＋09:35后前五分钟条件；多数历史候选确实有多根板下分钟，说明不是普遍只有瞬间窗口。但从09:35完整数据算好后，直接成交于09:35–09:36首笔价未计处理/下单延迟；原正分钟成交量条件也是事后回测代理。延后一分后收益下降、两笔整分钟量不足，表明执行时点及容量仍需继续约束。可用于下一步执行设计，暂不能把原103.58%收益称为已验证可实现。

分钟OHLC只能区分全低/混合/全板成交，不能得到可下单的秒数、盘口可售深度或排队成交概率；本轮未按这些未来窗口结果重筛选或训练。
