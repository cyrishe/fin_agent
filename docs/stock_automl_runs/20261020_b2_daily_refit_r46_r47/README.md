# B2 日更模型研究：预声明与进度

记录日期：2026-10-20。用户要求比较日线和四 K 选择都按交易日滚动的三种方案。正式 `B2/v1.0` 不变，本轮不写生产数据库。

| 方案 | 日线 51 因子模型 | 四 K 精排 |
| --- | --- | --- |
| 日更六训两验 | 每个 D0 重训 RF，前六个月训练，最近两个月只作验证 | 每个 D0 重训六个月，最近两个月选参数 |
| 日更直接六训＋形态一验 | 每个 D0 用最近六个月成熟样本重训 RF，直接给 D0 Top3 | 每个 D0 重训六个月，最近一个月选参数 |
| 日更直接六训＋形态两验 | 同上 | 每个 D0 重训六个月，最近两个月选参数 |

日线层沿用已登记 B2 的 51 因子、RF 240 棵和三日再板标签。训练行要求 D1 开盘打开、标签完整；每日只纳入截至当时已成熟的历史样本。原 Top3 排名在 D0 固定，不用未来 D1 是否打开来补名次。验证数据不并入日线拟合。

四 K 层使用历史**当日生成的折外 Top3**，只读 D1 前四根完整分钟 K 及原 D0 排名。以候选股票若按 B2 延后一根分钟 K 买入并在 D2 收盘卖出的费后收益训练小型 Ridge 精排；四 K 实体不超过 −8% 或无有效模拟买入者记为零收益机会。每个 D0 对三种预设正则强度做六个月拟合，用随后一或两个月的已成熟结果选择；训练和验证逐日机会收益均不低于原 D0 排名时才采用，否则按原排名。D1 09:34 后在 Top3 中预选一只，再检查实体门槛和 09:35—09:40 可成交性；任一条件不满足当天轮空，不事后顺延换股。相对于正式 B2 的“最先打开者优先”，这是**研究方案有意改变的选择步骤**，须单独比较交易覆盖率。

主比较为相同历史区间的 D2 费后逐笔收益、连续资金账户收益、最大回撤、月度收益及 2023—24 年表现；三日再板命中率为辅助，日线 Top1／Top3 同时给出 D0 全量和 D1 开盘打开后的两个分母。原 B2、三种新方案均列不加额外停手与独立影子账户 30／10 日停手两个口径。所有月份均已参与过先前研究，此回放是严格按时间顺序的历史检验，不是全新盲测。

**当前进度：** `scripts/experiment_b2_daily_refit_r46.py` 已核对两个真实交易日、两种窗口共四个模型，重载评分差为零；完整日更训练正在运行，逐日模型、训练行索引、分数和哈希保存到 `outputs/stock_automl/b2_daily_refit_r46_20261020/`。`scripts/experiment_b2_daily_shape_r47.py` 已用独立历史样本做准备、三窗口拟合及分钟买价的流程冒烟检查；完整四 K 训练、账户回放和 Excel 需等待日线全区间完成。研究输出的 `specification.json` 固定了方法和源文件哈希，目标月结果不参与当日选模。

同口径原 B2 对照已独立复放：2023-05—2026-09 原始账户 543 笔、总收益 −93.08%、最大回撤 98.27%；影子 30／10 停手账户 310 笔、总收益 −19.41%、最大回撤 74.91%。原始账户 2024 年 141 笔，三日再板率 52.48%，但 D2 每笔费后均值 −2.83%；本实验因此以 D2 收益和账户回撤为主。
