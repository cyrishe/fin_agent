# R16：LightGBM / XGBoost / 随机森林，抽样与类别处理组合搜索

## 本轮结论

扩大搜索后，训练和验证成绩提高，但测试没有出现稳定提升，交易收益和回撤弱于R15。本轮保留研究记录，不替代原方案。

- 测试Top3：R15 51.84% → R16 50.84%；测试Top5：47.39% → 48.05%。
- 测试月间命中率标准差：6.61% → 7.57%，波动未减小；该指标为每月Top3/Top5命中率均值的标准差。
- 过滤后D2每笔毛收益：-0.05% → -0.67%；账户毛收益：-9.44% → -37.76%；最大回撤：28.91% → 42.62%。
- 14个月的选择为随机森林8个月（含2个月原基准）、LightGBM 3个月、XGBoost 3个月。不同月选择不同组合，逐月参数和实际抽样记录均已保存。
- 所谓选中条件是按训练OOF和验证期的既定准则选出的条件，并非根据测试回头挑出的全期最好配置。

## 固定实验口径

- 六个月训练、两个月验证、下一月测试；测试 2025-09 至 2026-10（10月仅截至14日可知结果）。
- 每算法3套树参数 × 4种类别处理 × 2随机种子，共24个单模型、12个双种子平均组合；三算法共72个单模型、36个组合。另保留R15原随机森林。
- 每月和每类别分层抽取约80%，无放回。四种类别处理为原比例、温和加权、均衡加权、欠采样1:1。欠采样在80%抽样后进一步减少多数类。
- 第一阶段35个特征保持不变。每个子模型只用六个月拟合。历史六个月OOF来自各自更早模型，沿用R15的两月间隔及历史预热，并非只在当前六个月内部K折。
- 第一阶段标签是D1-D3任一天收盘封板；历史拟合样本要求D1开盘低于涨停价。D0对全体收盘封板候选评分，先固定Top3/5再检查开盘激活。
- 同配置171/191种子等权平均概率后排名；不选择较优种子。171/191是随机种子，scikit-learn版本固定1.7.1。
- 选择分 = 训练OOF与验证Top3/Top5平均命中率的均值 − 0.25×两者差距 − 0.25×八个月命中率标准差 − 0.25×双种子成绩差。
- 挑战组合必须在OOF、验证两者均不低于原森林，且综合分更高；否则保留原森林。所有月份选择固定后才计算测试结果；测试比较仅作诊断，未反向选模型。
- 训练/验证汇总为14个重叠窗口的中位数；测试是14个月不重复样本合计。测试月份在此前研究中已被查看，不能声称全新盲测。
- 第二阶段沿用R15：8因子、逻辑回归或深度2树；内部前推验证；09:40打开涨停的D0前五候选，09:41开盘价成交代理。D2-D4无收盘封板且D4相对买价跌超5%为坏样本。
- 明细中的训练候选来自第一阶段历史OOF，但第二阶段训练风险分属于拟合内诊断；其门槛选择另用内部前推分数和独立验证期。
- 二阶段拟合、门槛选择和收益比较均保留原规则。所有收益为毛收益；账户每天最多一笔、每笔最多25%仓位。未重新启用D0最终封板09:40后筛选。
