# CO11：独立风险概率与B1结合交接

用户要求独立下跌模型可以在B1之后使用，并要求自主比较结合方式。已完成9方案，B1原名单和成交额规则不变、CO10全市场树不重训。代码在fin_agent的codex/stock-automl-strategies，本轮未提交，保留其他任务改动。

## 方法

CO10 nonfall_hist主模型及extreme_hist对照，1.7.1。60日树训练→20日完整标签校准（含中间样本，不加权大跌）→20日检查→下一月测试。全市场与当日涨幅4%–9%子群分别logit分数做Platt校准；B1身份不参与校准。参数、样本和日期审计保存在outputs/stock_automl/b1_calibrated_risk_co11/calibration。测试仍2025-08至2026-10-13的288日，已多次研究，非新盲测。

## 核心结果

- 原B1 222笔−43.37%/结算回撤55.94%；主方案≥30%轮空215笔−42.28%/52.38%，改善弱。
- 20%敏感性175笔−13.32%/35.43%，避28亏（15次净亏>2%），误拦19盈利；开盘大跌只避6/27，不能称已可靠预测开盘风险。
- 20%半仓、40%轮空219笔−25.98%/43.80%；双模型均≥30%219笔−43.50%/56.04%。
- 原2026年2–7月：B1+41.81%/24.39%；20%门槛+51.34%/18.73%；分档仓位+46.74%/21.59%。
- 20%门槛与分档仓位优于事后相同平均仓位对照；剔除2025-11-20大亏日仍有改善，但10日块配对区间跨0、全期仍负。不能事后将20%升级为预设主方案或上线。
- 平均校准：全体已知B1开盘标签283个，原分数49.74%，子群校准13.11%，实际12.37%；高概率区不单调、≥30%只有7例1跌。平均校准改善不证明分层可靠。
