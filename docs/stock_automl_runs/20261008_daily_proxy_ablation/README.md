# 14:40 特征与收盘日线代理：配对核查

## 问题和口径

模型仍按 T 日 14:40 决策。`signal_return` 并非重复造出一个行情字段：历史训练需把 14:40 分钟收盘价和当日昨收参考价按统一口径算成涨幅；实盘若实时接口已提供同口径涨幅，可直接取用并核对价格及昨收。收盘涨幅、全天成交量和全天最低价在 T 日 14:40 尚不可得。本页只评估它们作为**历史近似代理**的误差，不将其称为当时可交易的折外回测。

在现有 37 个有完整分钟数据的信号日、13,172 个 14:40 候选股票日上，对比同一股票当日收盘日 K。样本已按 14:40 涨幅 3%–6% 筛选，所以不能据此推算“收盘筛选会新加入多少股票”。

| 代理 | 与真实 14:40 特征的配对结果 |
| --- | --- |
| 收盘涨幅代替 14:40 涨幅 | 13,172 个原候选中 **1,774 个（13.5%）**收盘时已不在 3%–6%；收盘与 14:40 涨幅差的绝对值第 90 百分位为 **0.78 个百分点**。 |
| 全天量折算量比 | 用全天量/前五日日均量替代截至 14:40 的量比，中位比例为原值的 **1.008 倍**，相对误差绝对值第 90 百分位 **6.7%**。这是因为全天实际成交量中位数约为 14:40 累计量的 1.100 倍，接近按 240/220 分钟折算的 1.091 倍。 |
| 全天量折算换手率 | 用全天成交量 × 220/240 估计截至 14:40 成交量；相对误差绝对值第 90 百分位同为 **6.7%**。 |
| 收盘价高于三均线 | 与 14:40 价格是否高于三均线的布尔值不同 **260/13,172（2.0%）**。 |
| 全天最低价高于三均线 | 与“截至 14:40 每根分钟最低价均高于三均线”在这批**已覆盖分钟的候选**中一致，为 **0/13,172 不同**。全天最低价可以在事后近似这一布尔值；逻辑上只有“全天低点高于均线”必然推出 14:40 前也高于，反方向不保证成立。 |

两项均线变量是**单向包含关系**：截至 14:40 所有分钟最低价高于均线，则 14:40 当前价必然高于均线。现有 13,172 条里，3,830 条两者都为真，6,045 条只有当前价为真，3,297 条都为假。它们相关，但不相同。

## 删除变量后，固定模型怎样变？

保持原有训练日 **08-25–09-21，共 20 日、7,488 个股票日**；共同测试日 **08-07–08-21 和 09-22–09-30，共 17 日**。每组模型重新训练一次，其他因子、逻辑回归 `C=0.2` 和标签不变。

| 模型 | 每日前二：>1% / 严重错误 | 每日前五：>1% / 严重错误 |
| --- | ---: | ---: |
| 原八因子 | 21/34 · 6/34 | 49/85 · 21/85 |
| **删除“日内始终高于均线”**，保留 14:40 当前价高于均线 | 18/34 · 8/34 | 43/85 · 25/85 |
| **保留“日内始终高于均线”**，删除当前价高于均线 | 21/34 · 5/34 | 47/85 · 23/85 |

这一轮消融说明，直接删掉“日内始终高于均线”会使这批测试日的前二和前五结果变差；若两项只留一项，严格的“日内始终高于均线”在前二指标上较好，但前五目标次数少于原八因子。样本短、测试日期已被多次查看过，这不是稳定因果贡献的证明。

## 用收盘代理直接打分会怎样？

为单独测量输入替换误差，固定上述七因子模型和**同一批已知 14:40 候选**，仅在测试时把涨幅、量比、换手率、价格高于均线改为日 K 代理。全部候选的两种分数 Spearman 相关系数为 **0.960**；但每日前二只有 **20/34** 个选中股票相同，每日前五只有 **58/85** 个选中股票相同。前二两种输入都恰好为 18/34 目标、8/34 严重错误；前五真实输入是 43/85 目标、25/85 严重错误，代理输入是 43/85 目标、27/85 严重错误。**汇总次数接近，不表示选中的是同一批股票。**此比较还没有计入收盘筛选会更换候选池的影响。

14:50 买价也不能随意换成收盘价：在这 13,172 条上，收盘价与 14:50 买价的绝对涨跌差第 90 百分位为 **0.53%**；即使保持次晨十分钟最高价不变，仅替换标签分母，也有 **1,548/13,172（11.8%）**的三分类标签改变。若更早时期同时没有 T+1 前十分钟分钟 K，日 K 的次日最高价不能代替前十分钟最高价。
