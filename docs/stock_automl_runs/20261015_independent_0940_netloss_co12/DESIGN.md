# CO12：独立预测09:40净亏概率及条件大亏幅度

2026-10-15，在新训练及交易结果产生前确定方案。已研究过历史，仍是时间外探索；不称新盲测，不改线上B1。

## 数据、标签、可见性

- 样本为CO10全市场约211万股票日，不按B1入选过滤。沿用同一12项14:40及以前可见因子，严格白名单，不添加买价、卖价、未来成交量、未来复权标记或B1身份。
- 标签价格：T日14:42一分钟open、下一市场交易日09:40一分钟close，精确时间、有效OHLC。价格只用于标签，预测时未知；不能填补或使用其他时间的价格代替。
- 时间标签沿用分钟结束时刻口径：14:42条目的open是该分钟起始价代理（约14:41），不是使用14:42结束后才知道的整根信息做决策。这里只检验14:40事件截止下的价格代理；真实数据送达及计算延迟另需前瞻记录。
- 净收益按固定5万元单笔预算、CO8同一费用函数计算。`severe_loss = net_return < -0.02`。正负完整分布均训练概率模型，不丢−2%到0的中间样本，不额外加权大亏类。
- 幅度模型预测`E[-net_return | net_return < -0.02, X]`，即条件大亏平均幅度，不是所有交易平均亏损。两者相乘为这类大亏对平均收益的负贡献，称尾部期望损失，不是净期望收益。
- 原CO10未来公司行动、无有效成交/标签等规则仅用于成熟标签有效性；预测池不能因未来标签未知而排除。正常停牌按未知标签处理，不当作负例。
- 训练特征仅含：market_breadth、market_median、market_iqr、lag5_market_breadth、signal_return、relative_amount20、lag_return、prior5_return、prior5_vol、prior10_vol、prior5_downside、prior5_worst。14:40截面价格/成交额及昨日以前日线；特征来源和哈希继承CO10。
- 后补历史分钟可保证事件时间截止，不能证明每条记录在历史14:40已实时送达。标明最终历史档案回测；不据此宣称已验证实盘延迟、限价成交或流动性。

## 时间划分与模型

每个测试月沿用CO10日历的前100市场日：60日全市场训练→20日校准→20日独立检查→下一月测试；训练/校准最后样本的标签成熟时间必须早于下一段14:40。不会将同一天股票随机分到不同段，也不在校准后重训。

sklearn1.7.1；概率HistGradientBoostingClassifier和条件大亏HistGradientBoostingRegressor各一棵模型集，每个60迭代、学习率.05、7叶、min_samples_leaf=100、L2=10、63箱、无早停、种子1015，回归用平方误差预测均值。训练特征按训练段1%/99%截尾、中位填缺、均值标准差变换；不截尾真实损失标签。

每个训练日的样本合计等权，幅度模型沿用同一行权重后仅取大亏样本。概率在校准20日完整标签上做logit分数Platt校准（C=1、无类权重）；全市场及事先指定涨幅4%–9%子群分别校准；若少于30个正/负例或斜率为负，退回该校准群历史频率。其他股票用全市场校准。

幅度校准用校准期大亏样本的加权实际幅度总和/原模型预测总和作为乘数，限[0.5,2]；强势子群少于30大亏例时退回全市场乘数。在各自校准人群内按日期等权，幅度模型取大亏行后保留这些行的原权重比例，再归一至均值1；概率与幅度的校准人群权重口径一致。输出下限2%，上限100%。第二段20日只评价概率、幅度与乘积的误差，不挑阈值、不选择测试最优参数。
