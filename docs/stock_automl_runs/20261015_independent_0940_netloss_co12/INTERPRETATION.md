# CO12结论：目标对齐后有风险信息，但交易改善仍不够稳健

已完成独立全市场“次晨09:40净亏超过2%的概率＋发生大亏时的平均亏损幅度”模型，并在固定B1上比较6个预设交易方案。主方案预先指定为尾部损失预算减仓，没有按测试表现另选主方案。线上B1未修改。

## 1. 训练与验证口径

- 2,116,184股票日，2,106,742有效标签、201,391次净亏超过2%；12项因子只用14:40及以前。B1身份、买卖价、未来标签或未来复权标记不进入特征。
- 60日全市场训练→20日校准→20日检查→下一月测试，共15月、30个预测模型；按整日向前划分。原B1与CO11旧开盘20%门槛的逐日净值均精确复现，383条B1端点核对误差0。
- 1.7.1固定；模型、分箱和填缺只在训练段拟合，校准只用其独立20日。未来标签在进入下一阶段前必须成熟，校准后不重训。
- 标签为固定5万元预算按既定费用计算的净亏；账户回测为10万元现金复利并按实际仓位计算手续费。14:42结束分钟的open（约14:41起始价）作为入场代理，次晨09:40 close退出。此口径可核对事件时间，不能证明历史当时数据送达、运行延迟或一定成交。
- 历史已反复研究，仍是时间外探索，不是新盲测。30模型完整测试集回读误差0；8项定向测试通过；独立CLI用100行仅因子输入复现误差0，并拒绝14:41因子时间。

## 2. 风险预测比简单过去平均值有所改善

原B1通过成交额规则的222笔中，实际51次大亏，发生率22.97%。

|检验|新模型|只用过去校准期平均值|
|---|---:|---:|
|B1大亏概率Brier，越低越好|0.1748|0.1828|
|B1条件大亏幅度平均绝对误差|1.273个百分点|1.355个百分点|

新模型平均预测B1大亏概率24.39%，实际22.97%；发生大亏的样本中，平均预测幅度3.84%，实际4.15%。全部B1交易上的平均尾部损失贡献预测0.926%，实际0.953%。

全市场正式测试1,484,852个已知标签，概率Brier0.0892对照0.0925；幅度误差1.055个百分点对照1.142。强势4%–9%子群及B1的误差也有小幅改善，完整检查期/测试期结果见[MODEL_QUALITY.md](MODEL_QUALITY.md)。这些是平均误差，不表示逐股风险已被准确确定。

分箱仍有局限：B1预测10%–20%的50笔实际大亏率22.00%；20%–30%的101笔实际21.78%；30%–40%的47笔实际29.79%。40%以上仅10笔、4次大亏，样本少。不能把相邻概率档位当成精确安全边界。

主方案没有完全轮空，却使82笔盈利少赚，不能称零误杀。其减少的正收益敞口简单和97.62个百分点，减少负收益敞口125.45个百分点；这不是复利账户盈亏金额。主方案平均仓位为原B1成交日的61.77%。

新概率20%轮空的出手股票每笔净均值−0.290%，原B1−0.199%、旧20%门槛−0.035%；降低大亏次数并不自动改善剩余交易的收益。两个目标的基础发生率不同，旧开盘大跌约12%，新09:40大亏约23%，相同20%门槛会造成很不同的交易覆盖率。

尾部期望损失轮空在这个区间比旧20%门槛收益和回撤略好，但全期只从−13.32%到−12.14%，回撤由35.43%升至36.19%，误拦盈利由19笔增到40笔。多避免的亏损收益率简单和约48.94个百分点，同时多误拦盈利约50.03个百分点，收益代价抵消了风险识别的大部分好处。

逐月净收益/回撤/笔数和逐月完全误杀/部分减仓盈利，全部并列在[README.md](README.md)，底表为monthly.csv。2025年五个测试月，旧20%门槛、尾部损失1%轮空与主减仓方案均没有正收益月份，跨期问题仍然存在。

## 5. 对照与不确定性

- 主减仓−18.61%/回撤34.39%；原B1按相同平均61.77%恒定仓位为−27.48%/38.99%，说明不全是机械少投入资金。新概率20%轮空则不如同平均仓位：自身−18.53%/24.95%，恒仓位对照−12.88%/20.21%。
- 同月同仓位分布随机置换1000次，随机收益不低于主减仓比例1.4%，不低于尾部损失1%轮空比例2.3%。这是事后诊断，不是多重研究修正后的p值。
- 主减仓相对恒仓位的日均收益差+0.0379个百分点，10日块95%区间[−0.0440,+0.1259]；尾部1%轮空相对旧20%门槛为−0.0038个百分点，区间[−0.1434,+0.1369]。均跨0，不能确认稳定优越。
- 共同剔除最大改善日2025-11-20后：原B1−32.17%，旧20%−13.32%，尾部1%轮空−12.14%，主减仓−14.31%。改善不只来自该日，但仍未转正。
- 额外10bp执行成本下：旧20%−27.26%，尾部1%轮空−23.41%，主减仓−29.05%，仍没有盈利结论。

## 6. 具体案例与成交代理核查

- 2025-11-20，300390：预测大亏概率35.19%、条件幅度4.69%、尾部损失1.65%；实际净亏16.52%。尾部轮空挡住，主减仓保留30.32%仓位，仍承担较大实际亏损。0.5%预算是模型平均损失贡献预算，绝不是保证单笔最多亏0.5%。
- 2026-03-03，600188：预测概率50.05%、条件幅度3.61%，实际净亏6.34%。两种新轮空方案均避开。
- 2025-10-22，600172：预测概率33.96%、条件幅度3.94%，实际净赚12.32%；新旧轮空均误拦。风险较高的股票仍可能提供很大的盈利机会，目前两输出没有估计上行收益。
- 原B1有一笔2025-11-07的688767，其14:42入场代理分钟成交量为0，按代理价净−0.0566%。此点在标签抽取后补充核查发现；从全部方案共同剔除后，旧20%为−13.27%、尾部1%轮空−12.09%、主减仓−18.58%，结论不变。此剔除是事后成交敏感性，不是14:40可执行的新过滤规则。见zero_volume_common_exclusion.csv。

## 判断

当前证据支持保存独立09:40概率与幅度模型作为风险信息，但不支持替换现有B1或认定某个新门槛已稳定盈利。主减仓和尾部损失轮空各有收益/回撤代价，尚无明显统一胜者。目标对齐后仍有大量盈利被挡，下一步应检验收益机会是否足以补偿风险，并保留真正前瞻样本；不根据这轮月份继续追调阈值。

原Top1未换股，轮空前达标21.13%、可接受29.58%、错误49.30%仍相同。代码、完整实际训练样本、两类模型、逐折权重/校准成员、预测与证据均打包；本机/DB/云端状态以archive_receipt.json为准。
