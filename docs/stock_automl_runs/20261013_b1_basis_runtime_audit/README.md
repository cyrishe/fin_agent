# B1 与 X1 重训差异：分钟线口径和运行环境核对

核对时间：2026-10-13。当前分支已 fast-forward 到 `4c64dc9`。本审计只使用已保存的候选表、复权因子快照和历史结果；未修改数据库或线上选股。

## 结论

**“旧 B1 用未复权分钟线、10 月 12 日 X1 重训用了复权分钟线”不属实。**旧 B1 和 X1 的候选表都是未复权分钟线构成，58,317 个股票日键完全相同；七个特征、14:40 买入价与次晨标签在业务数值上相同。X1 与旧 B1 的主要差异是训练环境的 scikit-learn 版本：旧 B1 为 `1.7.1`，X1 为 `1.9.1`。两者都曾用 T−1 以前的复权日线收盘价计算历史 MA，并将 MA 转回 T 日未复权价格尺度。这不等于用复权分钟线训练。

原 B1 候选表：`outputs/stock_automl/mk_1m_jan_jul/tradable_st_candidates.csv.gz`，SHA-256 `d160e906712f8d9f0d7b1f052079c023fd2e8d7def5611fd71c31c738e4b90f2`。X1 候选表：`outputs/stock_automl/b1_rerun_20261012/tradable_st_candidates.csv.gz`，SHA-256 `975cdfcf39d786bbdb5af920d52da02392bd341978b065dba36fb767bb727dc4`。

## 输入逐行对照

两表各 58,317 行，股票日键差集均为 0。`signal_price`、`prior_close`、`prior_adjclose`、`minute_volume_shares`、`signal_return`、`ma_bull_5_10_20`、`all_intraday_lows_above_ma`、`second_high`、`close_40`、`label_complete` 完全一致。`volume_ratio`、`turnover_so_far_pct`、`float_mv_100m_cny` 仅有浮点末位差异，最大绝对差依次为 `3.55e-15`、`7.11e-15`、`7.28e-12`，最大相对差约 `4e-16`。原始 `float_mv`、`float_share` 的差异也仅约 `4e-16` 相对量级。没有复权价格尺度变化，也没有候选股或标签类别改变。

## 版本隔离实验

使用同一套 `fit_tree`、`select_training_samples`、`evaluate`，在临时目录安装 scikit-learn `1.7.1`，不覆盖仓库 `.venv`；用原 B1 候选表逐日重拟 118 个 20 日窗口。对照 `docs/stock_automl_runs/20261011_mk_1m_tradable_st_rolling20/top2_verified.csv`，118 日 Top2、预测类别均一致，四类概率最大绝对差 `1.11e-16`。将输入改为 X1 候选表、仍用 `1.7.1`，118 日 Top2 和概率依然一致，最大差 `1.11e-16`。

相反，X1 运行清单记录 scikit-learn `1.9.1`，历史 Top1 两者共同选股日中只有 84 日同股；旧 B1 选出 115 日，X1 选出 113 日，合并比较有 31 日名单不同或一方未选。仅 2026-07-30 这一个折，旧版第二名为 `301357`，`1.9.1` 重新拟合的第二名为 `300191`。旧模型文件的 manifest 写明 `1.7.1`；本次在 `1.7.1` 加载原模型，并重拟 2026-02-02、2026-07-30，Top2 与概率完全一致。**据此，先前 B1 无法复现的原因是依赖版本漂移，而不是所提的复权分钟线替换。**

## 真正改变复权尺度时会发生什么

原供应商 `mk/post` 分钟线及压缩包目前未能在本机找到，所以不能宣称这里完整复现了供应商后复权训练。现有配对实验以 `kcrp_stock_price.adjclose / close` 构造日复权因子，只把标签中的次晨第二高价乘以 `F(T+1)/F(T)`；候选、七因子与实际买卖分钟价仍为未复权口径。因子快照是 `docs/stock_automl_runs/20261012_adjusted_basis_sensitivity/daily_adjustment_factors.csv.gz`，SHA-256 `081238aa9bb95f9836874d7b31da734c5c2eac7d53a6b64aeef2a7f42a07ddd5`。

58,317 个候选中有 56,944 个成熟标签且两日因子齐全。按所有跨日因子变化换算，666 个标签翻档，占成熟标签的 1.17%；其中 572 个来自因子变化不超过万分之一的细微边界变动。只计跨日因子变化超过万分之一时，翻档 94 个。跨日因子比的中位数是 1，最小约 `0.999924`，最大约 `1.499135`；105 个样本变化超过 1%。例如 2026-06-01 `605128` 的未复权第二高价标签收益为 `−32.27%`，按日因子代理换算为 `+1.54%`，属于除权造成的价格断层。未复权标签中有 33 个低于 `−20%`，代理换算后仅有 1 个。

日因子本身的分布与模型收益率的数值空间不能混为一谈：候选日 `F(T)` 中位数约 `2.21`、99 分位约 `30.89`；若把 14:40 原价直接乘因子，价格中位数由 `19.94` 变成约 `50.43`，但同一日一致地换算分钟价与昨收后，`signal_return` 等相对量不应因此改变。跨日收益会在除权日受 `F(T+1)/F(T)` 影响。直接拼接供应商 `post` 价格、库内 `adjclose` 和未复权量价则会混用尺度；原供应商 `post` 的价格及成交量变换又与库内日线复权尺度不完全相同，不能把这个日因子代理当成完整的 `post` 特征训练。

已归档的[配对敏感性实验](../20261012_adjusted_basis_sensitivity/README.md)还报告了换标签后的选股和价格代理收益，那个实验回答的是**标签敏感性**，不能解释 B1/X1 的复现差异，也不能据同区间收益断言今后采用哪一种复权更好。为复现 B1，应固定候选表 SHA、scikit-learn `1.7.1` 及其余依赖版本，保留每个预测日的训练切片、模型和运行清单。
