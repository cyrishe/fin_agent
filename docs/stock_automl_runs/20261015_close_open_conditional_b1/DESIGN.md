# CO7：B1折外Top1/Top5条件大亏风险（运行前方案）

业务研究，保留B1原模型和旧包，不改Agent协议。用户本轮调整：主要考察逐月净收益、最大回撤、剩余交易数、大亏拦截与盈利误拦；去最好月/每月最好单笔只作压力测试，不作为必须通过的门槛。不因正收益月份多而忽略总亏损、最坏月份、样本量及交易覆盖。

## 第一阶段与输入身份

固定scikit-learn1.7.1、原七因子/四类/20日前推每日重训、原类别优先顺延规则，保存每一天全候选概率与最多Top5。一天的模型只用此前20个市场日、次晨标签在该日14:40前已成熟的样本。Top5仅用来增加第二阶段训练样本，交易仍只过滤原Top1，拦截后轮空，不递补或另选。

2025-02-05至11-03与2026-01-05至07-31使用原冻结候选、输入数值和第一阶段标签。其他可用日期使用CO4已核验分钟候选，再按原B1历史复权日线MA与股本代理计算七因子；扩展日期不是旧模型的冻结预测。原快照最后一日当时没有次晨文件，仅补这两个终点标签供后续日期训练；不改变任何终点以前的历史结果。必须核验2026年2–7月118日Top2及概率与原B1一致。原股票缺扩展特征时保留，第二阶段只在其训练段中估计缺失填充值。

历史从2025年1月开始；前20日生成基础训练，随后滚动产生第一阶段真正折外候选。第二阶段另需100个折外市场日预热。无训练资格的早期月份显示为预热，不能把它们当成第二阶段盈利或亏损月份。源数据沿用CO4覆盖至2026-10-13信号、10-14晨价，10月不完整。

## 第二阶段

目标：模拟14:40买入、次日09:40卖出，扣费后收益严格小于−2%。每天Top1或最多Top5均来自当天的第一阶段历史模型，禁止用基础模型在自己拟合样本上的排名。第二阶段每月前100个折外市场日：前60日拟合、后40日独立验证阈值，固定后用100日重拟合、预测下一月。验证标签须在测试月首日早盘已成熟；所有预处理都只在各自拟合段估计。

固定四种低复杂度方案，不用测试收益选择因子：

1. Top1训练，原7因子＋4个基础概率＋概率领先幅度＋当日合格候选数＋原排名（14项）。
2. Top5训练，同14项。
3. Top5训练，上述14项＋8个预先指定业务因子：日内最大回撤、末5分钟涨幅、末30分钟位置/振幅、全天振幅、相对20日换手、全天VWAP距离、午后涨幅（22项）。
4. Top5训练，全部76业务因子＋上述7个基础模型信息（83项），保留弱单因子关联的组合可能。

模型均为LogisticRegression，C=.03、lbfgs、最多1500次、tol=1e-7，训练按信号日等权，不给严重类过大的训练权重。每月保留发现/重拟合两个模型、精确训练名单与验证/测试风险评分。Top1样本少是已知局限，作为Top5训练的对照。

## 温和过滤与阈值

每个模型均报告固定风险门槛35%、50%作为不调参对照。另有仅在过去40日Top1验证结果上选择的温和规则：候选门槛35%、40%、45%、50%、60%、不拦截；验证至少15笔可核实原交易，至少保留70%原交易、盈利误拦不超过20%。评分为拦住大亏×1.5−误拦盈利×1−拦住其他交易×0.25；必须严格优于不拦截的0分才启用。同分优先较高门槛、较少干预；样本不足直接不拦截。1.5是温和业务代价，不是声称市场估出的最优值。

这些约束只限制验证期，不能保证下一月有同样覆盖/风险。测试月份逐一冻结后全部公布，不回看测试再调阈值。分类概率/Brier/AUC分开在Top1与Top5上检查；另报告同月随机拦截同样数量时的大亏拦截期望。

## 交易、净值与评价

保留原成交额门槛。原始未知门槛/卖价保留空值；执行模拟采用资料不足不下单的保守假设，单列跳过数，不称未知交易实际赚亏为0。卖价未知不得伪造退出收益；若出现持仓退出缺失，完整账户净值不能无条件跨过该笔续算。

主表给出统一的逐笔5万元费用收益（沿用佣金万2.5双边最低5元、过户万0.1双边、印花税万5卖方假设）。净值单独使用初始10万元、每次可用资金全部投入单只股票、次晨退出后再于下午入场，逐笔按实际模拟金额计算佣金最低值；无杠杆、无并行持仓，忽略整手和成交冲击。最大回撤按该净值相对此前高点比例计算，报告为已结算时点回撤，不冒称盘中最大回撤；另给累计额外10bp滑点的敏感性。若未知卖价导致净值不完整，必须明确标记并另给共同可核实日期的诊断，不用填零获得完整回撤。
