## 六类规则

1. 一致高位：平滑线P90-P10≤2.5点、末10分钟均值相对首10分钟均值变化绝对值≤1.5点；分钟涨幅中位数≥3%，至少80%分钟涨幅≥2%。
2. 持续低位：同样平缓；中位数≤−3%，至少80%分钟涨幅≤−2%。
3. 逐渐走高/走低：平滑线拟合首尾变化绝对值≥2点，R²≥0.45，方向效率≥0.35，末10对首10变化同向≥1.5点。
4. 反复震荡：至少两次被反向1.5点运动确认的转折，平滑全幅≥3点；可发生在正涨幅区，也可发生在负涨幅区。
5. 中位震荡：未归为上述类型，分钟涨幅中位数位于±3%内，平滑P90-P10≤4点，首尾差绝对值≤1.5点。
6. 其余留待复核，例如单次冲高回落/探底回升、高位大幅摆动或较弱趋势，不强行归类。

先判平缓高低，再判趋势，再判反复震荡，最后中位震荡。平滑只用于描述形态：每5分钟分钟涨幅中位数，共24点。图中保留全部原始分钟价格线。百分比是相对D1昨收的当日涨跌幅，非相对买入成本的收益。
