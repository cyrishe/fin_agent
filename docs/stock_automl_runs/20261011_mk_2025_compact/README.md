# 2025 年分钟 K 本地存储整理

两份源归档 `mk202501_202506.tar.xz`、`mk202507_202511.tar.xz` 各自包含未复权 `mk/none` 和复权 `mk/post` 两套分钟 K。当前策略使用未复权数据；按用户选择，仅保留 `none`，已删除 `post` 和两份源 tar.xz。

未复权数据存于 `outputs/stock_automl/mk_1m_compact_2025/YYYY-MM-DD.csv.zst`。共 **220 个交易日**，覆盖 **2025-01-02 至 2025-11-28**；1—6 月 117 日，7—11 月 103 日。每个文件保留原 CSV 的全部八列、原始行及原始字节序列，可直接用 `pd.read_csv(path)` 读取。

| 项目 | 字节数 |
| --- | ---: |
| 两份源 tar.xz 合计（含 `none`、`post`） | 7,444,282,012 |
| 提取出的 `none` 原 CSV 合计 | 18,983,785,596 |
| 逐日压缩的 `none` 合计 | 3,464,551,341 |
| 本次净释放磁盘空间 | **约 3,979,730,671** |

转换时，每个 `none` 文件都在写入后解压并比对 SHA-256；完成后又独立复核全部 220 个压缩文件的 SHA-256 和解压内容 SHA-256。逐日大小、来源归档及哈希见[压缩清单](compressed_manifest.json)。三个抽样日期也用 pandas 读取并验证八列及行内日期：2025-01-02 共 1,225,200 行，2025-06-30 共 1,233,120 行，2025-11-28 共 1,235,760 行。

读取入口是 `scripts.mk_minute_archive.COMPACT_ROOT_2025`、`day_files` 和 `day_file`。转换脚本为 `python -m scripts.compact_mk_2025_tar_archive`；如需重建，须先将两份源 tar.xz 恢复到 `~/Downloads`。分钟 K 本体位于 Git 忽略的 `outputs/`，本目录只保存清单和说明。`post` 已按用户决定舍弃，不在本次保留数据中。
