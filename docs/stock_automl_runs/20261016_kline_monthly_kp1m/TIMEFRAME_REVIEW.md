# K线形态的时间尺度与触发含义复核

本次以 KP1 保存的 definitions.json 和源码快照为准，复核31个偏多及4个背景条件，不更改公式或重扫。记录中的观察周期、形态形成周期、触发确认日、预期持有期是不同概念；现有定义没有证明任何形态在固定持有期必然有效。

原始视频笔记已明确：5/20/60日均线是不同期限的趋势参照，组合描述短期力量变化；没有可核验的证券日期和后续结果，不能把口令当成收益验证。来源：[原始笔记](../../research/zhang_sufen_kline_20260928/notes.md)。

StockCharts 对蜡烛反转的介绍，将常见短期观察范围描述为约一两周，并强调后1–3日出现进一步上涨确认。这里的1–3日是确认窗口，不是保证在三日内获利离场。该说明是形态语义参考，不是本样本的绩效证据。[蜡烛反转参考](https://chartschool.stockcharts.com/table-of-contents/chart-analysis/candlestick-charts/candlestick-bullish-reversal-patterns)

## 短期蜡烛组合与价格触发

| 已扫描形态 | 实际触发含义 | 与1–3日持有的关系 |
|---|---|---|
| 阳包阴 | 此前局部下行，长阳实体吞没前阴实体 | 可检验次日起的短期跟随，不能把吞没本身等同趋势完成反转 |
| 锤头、倒锤头 | 五日下行背景下的单根长影与小实体 | 偏早期警报，尚未要求后续收盘突破；低位不是长期底部 |
| 看涨孕线 | 长阴后小阳实体内包 | 描述收缩，未包含向上突破；直接当日买入与等待确认是两种策略 |
| 红三兵 | 局部下行后严格三根阳线、逐日推进 | 已连续上涨三日；统计从第三根确认后开始，不能把已发生涨幅算入未来 |
| 三阴不破阳 | 首阳之后三根阴线最低价不破首阳最低价 | 是整理守住结构，未要求第五根突破，和上升三法不同 |
| 上升三法 | 五根完整K线，最后一根长阳突破首阳最高价 | 有价格突破确认，符合短期延续研究；六个月仅18次，现有样本不足 |
| 启明星实体跳空版、十字版 | 三根组合，末根收复首阴实体一半 | 短期反转候选，已包含部分价格修复；两版有包含关系 |
| 底部镊子 | 前阴后阳、相近低点 | 支撑试探，未要求后收超过前高；不是“双锤” |
| 刺透形态 | 前长阴，当前开盘低于前低、收复前实体一半 | 短期修复候选；本地低开要求较严格 |
| 一阳吞三阴 | 三阴走低后长阳覆盖三根实体 | 当日已有强修复，需检验其后的延续，不能重复计入触发日涨幅 |
| 两阴夹阳 | 下行背景，阴阳阴、末阴与首阴收盘接近 | 支撑观察版，末日仍是阴线，尚无价格向上突破确认 |
| 内包线向上突破 | 前一日振幅内包，当日收盘突破母线最高价 | 明确短期突破触发，1–3日延续检验与信号含义相符 |

## 跨周期结构和趋势指标

| 已扫描形态 | 实际观察尺度或确认 | 时间尺度判断 |
|---|---|---|
| 局部W形颈线突破 | 两谷相隔5–60根日K，右侧两根确认极值，收盘突破内部颈线 | 形成期可长可短，但触发是当日价格突破。既不等于数月级大底，也不能仅因形成期长就认定要持有60日 |
| 5/10日均线金叉 | 当日短均线上穿长均线 | 短趋势变化，仍是过去价格的平滑结果；未给固定持有期 |
| 10/20日均线金叉 | 约两周与一月均价交叉 | 趋势切换候选，不能天然视为次日脉冲买点；本次1–3日检验回答的是短持适配性 |
| 20/60日均线金叉保持3日 | 两日前交叉，保持三日、20日线倾斜、收盘配合 | 定义明确用于中期趋势观察；确认日晚于原交叉日，不可倒填 |
| 20日线上缩量回踩 | 上行20日线背景，当日低点靠近线、收盘守线、量缩 | 中期背景加短期回踩触发，不能整体归为长期或保证马上反弹 |
| MACD金叉 | DIF上穿DEA，指标参数12/26/9 | 动量转向与趋势跟随候选，无独立价格突破条件，未定义固定获利期限 |
| DIF上穿零轴 | 平滑快慢价差越零轴 | 趋势背景变化，通常比单根蜡烛更平滑；不能据此声称长期一定有效 |
| RSI脱离超卖、RSI上穿50 | RSI14分别回穿30、上穿50 | 短期动量阈值事件，前者并不保证价格已止跌，后者并非独立价格结构 |
| MACD底背离、RSI底背离 | 两个价格谷相隔5–60根，同谷比较指标；右侧两根后确认 | 是潜在转折警报；保存的说明明确“背离可延续，未包含后续突破确认”，不适合自动解读为当日启动 |
| RSI底部失败摆动 | 第一RSI谷低于30，第二谷高于30，RSI突破谷间反弹高点 | 比单纯背离多了指标突破，但不是股价颈线突破。形成跨度不固定，不能由名称推定三日收益 |
| 布林持续收缩后向上越带 | 20期布林，前三日带宽在各自历史120日低20%区域，当日扩张越上轨 | 较长背景加短期波动突破。120日是基准回看长度，不是持有期；越带未要求股价突破前20日高点 |

## 持续背景条件

| 已扫描条件 | 为什么不能直接当成独立短线买点 |
|---|---|
| 5/10/30日多头排列 | 持续趋势状态，连续日可能重复命中；应与首次进入状态区分 |
| MACD负柱连续缩短 | 下行动量减弱，尚未金叉或翻红，可能持续多日 |
| 放量上涨、缩量上涨、缩量下跌 | 当日量价事实，比较基准为此前20日；不独立确定后续方向 |
| 均线粘合 | 收敛背景，尚未指定突破方向 |
| 十字星、小实体双长影（螺旋桨类） | 多空犹豫的几何形状，单独不是看涨确认；双长影版不混称普通纺锤线 |

上述分类完整覆盖31个偏多和4个背景条件。形式上更接近短线不等于实测有效；形式上偏趋势也不意味着1–3日必然无效。不能因本次短持表现弱，就事后把规则改称长期策略。5、10、20日表现尚未统计，本轮不对其作结论。

本轮所有信号仍依赖完整日K；下午推理时能否提前确认属于另一个尚未验证的条件。本轮仅研究，不建模、不改变买卖规则。
