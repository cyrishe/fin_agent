# CO23：首批六个条件型因子设计 v1

2026-10-26。按用户要求，从此前14个候选中收敛到6个，明确如何计算和解释。本次只设计、记录，不计算历史效果、不训练。适用场景为收盘附近形成信号、次日开盘阶段退出，不限定具体买卖分钟。

## 设计方式

将经验拆成“可观察的前提＋程度”，保留连续数值；不把它们直接变成必须全部满足的选股规则。六个变量描述的是价格和成交量，不能据此判定有人吸筹、洗盘或出货。方向是待验证假设，不预设越大或越小就一定盈利。

共同约定：

- `t`：信号截止时刻，只用截至t已完成的分钟。`P_u`为分钟u收盘价，`V_u`为成交股数，`A_u`为成交金额，单位一致。窗口按实际交易分钟计，午休不算；缺失分钟不当成零成交补齐。
- `R`：截至昨日的前20个完整交易日最高价，作为固定参考压力位。它不保证是横盘平台；平台宽度、前期趋势先作为已有背景变量，不另扩因子。
- `ATR20`：截至昨日的前20日真实波幅均值，真实波幅为`max(H−L, abs(H−前收), abs(L−前收))`；跨日价格先转到当前一致尺度，不使用未来复权信息。
- 30/60/5分钟、20日是本版固定起点，不是最优参数。后续仅在训练段评估敏感性。历史不足、零分母、无法形成所需路径时留缺失；“前提未发生”和“数据不完整”在审计说明中分开，不把缺失填成好信号。
- 本版使用S1—S6编号，避免把较粗的14因子草案当成完全相同定义。尤其S1改成固定30分钟分母，解决刚突破1分钟就被记为100%站稳的问题。

## S1 突破站稳程度 `breakout_hold_30`

**原话逻辑**：突破后要站得住，回踩原压力位不破更值得关注。来源：老庞财经的[突破—回踩](../../research/douyin/老庞财经/7696367217042148634/transcript.md)、猎人X的[平台放量与尾盘偷涨](../../research/douyin/猎人X/7696694986720496915/transcript.md)。

**定义**：最后30个完整交易分钟中，收盘价高于R的分钟数，除以30。

`S1 = count(P_u > R，u属于末30分钟) / 30`

**例子**：前20日最高价10元，末30分钟有21分钟收在10元以上，S1=0.70。最后1分钟才上去，只得0.033；30分钟全未突破是0。它描述站稳程度，不直接规定0.7才买。

**与旧因子不同**：原日涨幅或末段涨幅无法区分“早已站稳”和“最后一笔冲过”。S1只描述压力位上方的占比，不能单独排除先站稳后跌回；需要与S2和当前价格位置一起看。

## S2 突破后的失守深度 `breakout_support_breach_atr`

**原话逻辑**：回踩不破前面的上沿；跌回去则原来的强势解释可能失效。来源同S1。

**前提与定义**：当日从第一根已完成分钟至t，存在收盘价高于R的分钟。取最早一根为b；计算从b到t的最低分钟收盘价L。

`S2 = max(R − L, 0) / ATR20`

**例子**：R=10元，突破后最低分钟收盘9.94元，ATR20=0.20元，S2=0.30；一直守住R则为0。没有出现突破时留缺失，不能记作“完美守住”。

**含义**：衡量经历过多大的平台失守，较大值是假突破或脆弱承接的候选风险。即使后来收回，失守经历也保留；是否“收回后反而好”交给数据。只用分钟收盘，不能解读为没有盘中瞬时跌破。

**与旧因子不同**：已有最大回撤以自身高点为参照；这里以事前固定R为参照，问的是原压力位有没有成为支撑。它不是隔夜最大亏损或可保证执行的止损距离。

## S3 回踩缩量比 `pullback_relative_volume`

**原话逻辑**：上涨放量、回调缩量，再观察是否重新走强。来源：老庞财经的[一涨、二回、三主升](../../research/douyin/老庞财经/7690798422500183315/transcript.md)、张素芬账号的[量价趋势](../../research/douyin/张素芬/7693142310552341798/transcript.md)。

**先固定路径取法**，只在末60个完整交易分钟中找：

1. h为最高分钟收盘价首次出现的位置。
2. a为h之前最低分钟收盘价首次出现的位置。
3. l为h之后最低分钟收盘价首次出现的位置。
4. 只有a、h、l都存在且`P_a < P_h`、`P_l < P_h`时计算。上行观察段为`(a,h]`，回踩观察段为`(h,l]`。两个区间不重叠，不要求区间内每分钟都同向。

为去掉不同时段天然成交量差异，先算每分钟相对量：

`q_u = V_u / 前20交易日同一钟点分钟成交量的均值`

`S3 = 回踩段q的均值 / 上行段q的均值`

**例子**：上行段平均相对量2.4，回踩段1.2，S3=0.50；若回踩段变成3.6，则为1.50。前者只是“回踩相对缩量”，不能单独认定健康——没有成交也可能只是无人接盘。

**与旧因子不同**：已有总体量比、上涨分钟成交占比、后半段量比；S3绑定了“先上涨、再回落”的顺序，并校正钟点量能。a/h/l只是已知路径内的观察点，不用次日走势确认拐点；未来创新高可能改变窗口内选段，因此后续须检查轻微路径扰动的敏感性。

## S4 回踩后的恢复程度 `pullback_recovery`

**原话逻辑**：不是缩量就买，还要看回踩后是否有重新上行。来源同S3及老庞财经的突破回踩流程。

**定义**：沿用S3同一条路径的h、l。

`S4 = (P_t − P_l) / (P_h − P_l)`

**例子**：从10.50元回踩到10.20元，现价10.41元，恢复了0.21/0.30=0.70；现价仍在低点，S4=0。若l恰好是当前分钟，也记0，表示尚未观察到恢复，不删除这种失败/未确认样本。无有效回踩则留缺失。

**与旧因子不同**：最大回撤只记录跌了多少，S4记录跌完恢复了多少。由于h是截至t窗口最高收盘，该定义通常在0—1内；不把未来会不会再次跌破当作当前已知事实。

**与S3成对看**：S3低、S4高是“缩量回踩后恢复”的候选；S3低、S4低则只是“缩量但未恢复”。保留两个变量，不提前乘成一个难以解释的综合分。

## S5 末段急拉集中度 `late_positive_move_share`

**原话逻辑**：尾盘突然偷涨需要谨慎，持续走强与最后几分钟猛拉可能不同。来源：猎人X的[三不追](../../research/douyin/猎人X/7696694986720496915/transcript.md)、[开盘与尾盘规则](../../research/douyin/猎人X/7698946434829143338/transcript.md)。

以每分钟对前一交易分钟收盘的对数收益`r_u = log(P_u/P_(u−1))`计算，观察窗都在午后同一连续交易段；计算末30分钟时需额外读取其前一根分钟。

`S5 = 末5分钟 sum(max(r_u,0)) / 末30分钟 sum(max(r_u,0))`

**例子**：末30分钟累计正向对数变化0.03，其中末5分钟贡献0.009，S5=0.30；贡献0.024则为0.80。整个窗口没有上涨分钟时留缺失，不记作健康的低集中度。

**含义**：衡量上涨动作集中在多晚，不是“末5分钟涨幅/全日净涨幅”，避免净涨幅接近0导致比值爆炸。需配合已有窗口涨幅/振幅，不能把极小价格跳动的高集中度当大幅急拉。

**与旧因子不同**：已有末段涨幅和成交量HHI；这里是价格正向推进的时间集中度。高值可能是追涨风险，也可能是新信息引发的有效突破，方向不预判。

## S6 均价线持续承接 `vwap_support_30`

**原话逻辑**：价格受到均价线支持，与一直被均价线压着不同。来源：猎人X的[分时节奏与黄线](../../research/douyin/猎人X/7690835606829681974/transcript.md)。视频黄线口径未明确，本设计自行选择成交量加权均价作为可复现代理，不宣称完全等同原图。

每个分钟u都只用当日截至u的量额计算：

`VWAP_u = sum(A_v，v≤u) / sum(V_v，v≤u)`

`S6 = count(P_u ≥ VWAP_u，u属于末30分钟) / 30`

**例子**：24/30分钟处于当时均价线上方，S6=0.80。用整天结束后的最终VWAP去比较所有历史分钟会泄漏后续信息，本定义禁止这样算。

**与旧因子不同**：已有“当前价格距离VWAP多远”；S6补充沿途持续性。高值也可能伴随严重乖离，因此保留旧VWAP距离作控制，不当成越高越安全。量额单位或VWAP区间异常需单列质量记录。

## 首轮怎么用

只比较三个小组：**突破是否站稳（S1/S2）、回踩是否健康（S3/S4）、上涨是否持续（S5/S6）**。保留原日涨幅、相对换手、波动和历史位置作对照，不额外扩成几十个新变量，也不要求六个条件全部达标。

先在训练段按分位数比较，观察正向、反向或中间区间关系；验证段保持定义、方向和分组边界冻结。重点同时看次晨强势率、实际退出净收益、净亏超过2%的比例及逐月一致性。已有历史被反复研究过，不能再称完全未见的最终测试。

这些变量都可在收盘附近某个t计算；使用更晚的数据，就必须相应推迟可执行入场时点。完整收盘之后才确认的条件不能倒填为当日已成交信号。下一交易日的信息只用于标签或开盘阶段退出，不能进入本日选股特征。

本轮六个算例用于解释公式，不是历史交易，也不是有效性证据。尚未实施因子计算、回测或生产接入。
