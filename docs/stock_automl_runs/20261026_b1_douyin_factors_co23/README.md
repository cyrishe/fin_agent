# CO23：从抖音经验提炼收盘—开盘候选因子

**后续细化：用户要求先少量设计，首轮收敛为[六个条件型因子 v1](SIX_FACTOR_DESIGN.md)，含公式、算例和缺失口径；下面14项保留作候选库，不是本轮全部实施清单。**

## 结论和本轮范围

最值得研究的是**强势形成的过程及其失败征兆**：突破之后能否守住、回踩是否缩量并恢复、上涨是否集中在最后一小段、同类股票是否普遍得到接力。它们尝试回答CO22留下的问题：同样被模型判为强势，哪些只是波动大，哪些更可能延续到次日开盘阶段。

这是一份有来源的因子研究方案，**没有新增因子效果、收益或模型结论**。目录实际在`docs/research/douyin`，不是`data/douyin`。本地总索引575条；其中131条标有“音轨与画面”，本轮筛阅这些条目的摘要，重点阅读24条口述稿，并查阅相关分析。竹间老王40条只有页面线索；晓玉说大量条目只有平台摘要，未把这些当作已核实作者经验。来源来自既有自动转写与抽样画面整理，本轮没有重新听看全部视频。来源清单见[SOURCES](SOURCES.md)、[逐文件哈希](source_manifest.json)。

按用户纠正，策略范围是**收盘附近形成信号、次日开盘阶段卖出**，不预先锁死14:40和09:40。原B1的时点只用于历史对照。后续可分别研究较早尾盘、临近收盘和开盘阶段退出，但每种定义必须绑定当时可见信息与可执行价格；不能看完收盘再假设按已知收盘价成交。

## 从资料里得到的六条朴素逻辑

### 1. 突破之后守得住，比一瞬间冲过去更有含义

老庞财经先等突破、再看回踩是否守住平台上沿（S11、S12）；猎人X区分平台放量上行与尾盘突然拉升（S05、S07）。可以提取突破后的站稳时间、退回平台的幅度、回踩量能，而不是只保存“现在涨了多少”。

**隔夜假设**：收盘前已经经历一次卖压测试并恢复，比最后一分钟才突破、没有观察时间的上涨，次日表现可能更可靠。反例包括无回踩直接上涨、守住后隔夜利空下跌；都要进入样本。这个解释不是已证实的资金吸筹。

### 2. 回落不一定坏，区分温和回踩和失去承接

S03、S04、S12、S14、S17都涉及涨跌速度、回调与缩量。我们可观察“下跌腿比上涨腿成交是否更稀疏”“回撤恢复了多少”“后段低点是否抬高”。先涨后回、先跌后涨的同幅日涨幅不能视作同一种形态。

**对旧结果的启发**：CO4中末5/15分钟涨幅较低、末30/60分钟位置较低，对强弱标签曾有跨期关联。不能把它直接改写成“尾盘越弱越好”；新的问题是，回落是否发生在仍完整的上涨结构内。若跌穿支撑且未恢复，就与温和回踩分开。

### 3. 突然拉一下，与持续走强，应拆成两个维度

S01、S02、S05讨论尾盘拉升，S19讨论上涨末段加速。候选变量包括最后5分钟贡献了多少正向价格变化、创新高时相对同时段量能有没有跟上，以及上涨结束后回吐多少。

**不能预设拉升都坏**：放量突破和高位过热可能有相似量柱。应以既有位置、突破站稳及波动水平解释差别，不把“尾盘偷涨”这样的动机名称直接作为标签。

### 4. 看相对自身的量，再看量换来了多少价格推进

S07、S16、S17、S21、S24反复强调同一放量在不同位置意义不同。已有量比、相对换手并不新；更值得补的是**上涨腿与回撤腿的量能对照，以及创新高时量能是否衰减**。

不照搬视频中的量比2—3、换手5%或10%等阈值。不同流动性、板块、行情和时间段不能假定同一阈值有效。盘中成交量按过去相同时段归一，避免把开盘/收盘自然放量或午休当异常。

### 5. 趋势背景与买入位置要分开

S13、S18、S20提出多周期方向、位置与乖离。原七因子已有均线多头0/1状态，但没有完整表达趋势斜率和买入价离趋势多远。可以区分“趋势向上、回到合理位置”和“趋势向上、已远离均线”。

**避免重复失败条件**：CO20/21单独按60日低位置过滤没有通过验证。本轮不再推出“低位就买”；只把位置作为形态的背景，考察少数有业务理由的交互。

### 6. 别只看指数涨跌，要看接力和亏钱效应

S08强调强势股溢价、跌停和亏钱效应，S09强调大小盘风格分化，S15强调市场走出来的强者。可借鉴为：昨日已经强势的一批股票今天开盘是否有溢价、当前大跌股票占比、个股尾盘是否跑赢同类市场。

原CO14—16已试市场涨跌、RSI和上涨家数，不是新方向。新的差别是**尾部亏损广度与强势群体的近期接力表现**。既不照搬RSI“弱市激活”，也不规定大盘涨才做；先研究连续变量和条件差异。板块主线/龙头属于补充方向，需历史时点成分，不能用今天的题材标签反标过去。

## 第一批14个候选：优先级是研究顺序，不是有效性排名

记`t`为本次收盘附近的决策截止时刻；`P_t`为当时已完成分钟价格；所有日线基准截至D−1。`ATR20`为过去20完整交易日真实波幅均值，历史OHLC先转换到当日一致价格尺度；ATR为0时留缺失。窗口按**交易分钟**而非墙钟分钟计。以下公式是本轮研究者提出的操作化定义，不是作者原文或原有已验证规则。5/30/60和20只是预先选定的小组窗口，后续若改变需记录，不从全部历史选最赚钱窗口。

|编号／候选|可复现的起始定义|对应朴素逻辑／来源|与已有因子的关系|
|---|---|---|---|
|F01 突破站稳比例|平台R=此前20日最高价；当日截至t首次完成分钟close>R之后，close仍>R的分钟占比；未突破留缺失，另记录观察长度|突破后守住；S05/S07/S11|CO4没有显式突破后的持续过程；不把刚突破1分钟的100%和站稳1小时等同|
|F02 突破后失守深度|同一R、同一首次突破后，`max(R−min(close),0)/ATR20`；未突破留缺失|假突破／回踩守位；S11/S12|不同于全日最大回撤，参照价是事前平台|
|F03 回踩相对量能|最后60交易分钟内，取首次最高close为h，其后首次最低close为l；上涨段为窗口起点至h，回踩段为h之后至l。比较两段每分钟“实际量/过去20日同钟点均量”的均值，取回踩/上涨；无完整两段留缺失|上涨放量、回落缩量；S03/S12/S17|原量比和上涨分钟量占比没有保持这段先后顺序|
|F04 回踩恢复比例|同一h、l，`(P_t−P_l)/(P_h−P_l)`；无回撤或l尚无后续分钟留缺失，不用未来反弹确认低点|卖压后重新上行；S11/S12|原最大回撤不表达恢复程度；与F03成对观察|
|F05 后段低点抬升|`(末30分钟最低价−前30分钟最低价)/ATR20`|承接位置逐步上移；S12/S13|不等于末价位置或最低点出现时间，但需检查相关性|
|F06 最后急拉集中度|末5分钟正对数收益之和/末60分钟正对数收益之和；分母0留缺失|涨幅是否挤在最后一小段；S02/S05/S19|CO4有成交量HHI、末段收益；这里是正向价格推进的集中度，未证明增量|
|F07 创新高时量能变化|比较末30与前30分钟最高价；在末段创新高样本内，末段/前段的“同钟点归一量”均值比；未创新高留缺失|新高伴随量能衰减；S04/S07|原后半/前半量比未绑定创新高条件；同时保留新高幅度作控制|
|F08 均价线上方停留比例|最后60分钟中`close_u≥VWAP_u`的比例，VWAP_u只累计至u|持续获得均价线支持；S01/S04|原有t时点VWAP距离，没有沿途停留比例|
|F09 均价线方向|`(VWAP_t−VWAP_(t−30交易分钟))/ATR20`|均价线抬升还是压制；S04|与末价相对VWAP距离不同，但可能与日涨幅冗余|
|F10 中期趋势斜率|`(MA20_(D−1)−MA20_(D−6))/ATR20`|顺趋势的回调；S13/S20|原均线多头0/1不是连续斜率|
|F11 波动调整后乖离|`(P_t−MA20_(D−1))/ATR20`|强势是否已过度延伸；S19/S20|CO4已有百分比均线距离；仅为尺度调整候选，不能宣称全新信息|
|F12 尾段相对市场强度|个股末30分钟对数收益−同一历史可交易股票集合末30分钟收益中位数|区分随市场上涨和个股偏强；S08/S09|原末段收益未扣市场；先用广泛市场，风格/行业另做扩展|
|F13 当前严重下跌广度|截至t、相对前收跌幅超过5%的可观察合格股票数/同池有效股票数，同时记录全市场数据覆盖率|亏钱效应是否扩散；S08|不同于原上涨家数；5%只是风险定义，需区分涨跌停制度并做训练内敏感性|
|F14 昨日强势群体开盘溢价|D−1按当时日收益取同池前10%，用D开盘价/其D−1收盘−1的中位数；分组仅依据D−1，D开盘已在D收盘信号之前发生|近期强势股是否得到次日接力；S08/S15|原市场涨跌/RSI不直接度量这一群体；停牌/缺价/无法交易比例单报，不填0|

F03/F04的h、l只是**当前已知路径内的高点及其后低点**，不是认定未来不会破的拐点。所有窗口和事件必须截断到t，禁止使用全日或未来局部极值补齐。F01观察时长作为必要上下文随因子记录，不靠新增最短时长阈值在测试期挑结果。

第一批应先做F01—F09的路径与量价过程；F10/F11用于解释背景，F12—F14用于市场与群体背景。14个候选不意味着同时塞进一个模型。先检查与旧76因子的增量与冗余，再每组保留少量代表。

只预设四个业务组合，避免全排列挖阈值：①突破站稳×回踩缩量；②上涨背景×恢复程度；③末段急拉集中×乖离；④个股相对强度×当前亏钱广度。连续变量先看单因子与二维分组，不先制造“吸筹/出货”等不可观测标签。

## 第二批保留的方向

|方向|来源与含义|放到第二批的原因|
|---|---|---|
|板块共振与板块内领先|S08/S15；板块同向股票比例、相对板块强弱、量能排名|需要历史时点的行业/题材归属，当前标签可能回填；不能从未来涨停反定龙头|
|大小盘风格匹配|S09；小盘与大盘近期收益差×个股历史市值分位|历史市值及指数成分要核对；不是新增一个大盘涨跌开关|
|近期涨停后的冷却与守位|S22/S23；距上次涨停天数、回撤、换手冷却、是否守住当时关键价|借鉴B2的结构，但仍只做收盘—开盘目标；需板制、ST、除权、可买性资料|
|高量日关键价是否守住|S07/S22；过去20日最大量日的低点/均价与当前价格关系|可与突破平台区分，但日期选取和历史价格尺度须固定|
|趋势中的收缩整理|S13/S20；前5/20日振幅比、量能收缩、整理后突破|CO4已有波动和缩量比例，不应无差别重复；主要研究顺序与交互|
|日内向下破位后收复|S03/S16；早段跌破历史支撑，尾段收复的幅度和持续时间|要同时保留跌破未收复样本；不能用次日上涨倒推当日是“洗盘”|
|次晨开盘后的高开回落/低开修复|S02及猎人X开盘类内容；用于退出时机|属于第二天卖出规则，绝不用于前一天选股；需固定观察后下一可成交价|

不优先照搬固定第七天/第十天、神秘K线名称、主力意图和“龙头必涨”。经验中重复出现同一口诀不等于多个独立证据；图形示意和成功故事也不提供实际胜率。中长期估值、宏观周期及仓位纪律本次未硬塞进隔夜选股特征。

## 与旧研究去重，以及值得保留的矛盾

- **CO4/CO5已经覆盖**76个基础、历史和分钟路径变量：量比/换手/均线位置、尾段收益与波动、最大回撤、高低点年龄、量集中度、VWAP距离等。CO4发现弱关联，CO5简单模型没有稳定升级；不能把“视频也这样说”当作新验证。
- **CO20/21已经否定过简单低位过滤的稳定性**；新研究要区分“低位且确认恢复”和“低位继续走弱”，并检验相对于原条件是否有增量。
- **CO14—16已研究市场强弱、RSI、上涨家数**，保留原实验结果。本轮接力溢价与大跌广度是不同候选，方向未定。
- **有冲突的经验照样保留**：S02说尾盘急跌后可能高开，S01却建议尾盘急跌先避险；S16既把午后回落解释为洗盘，又把高开午后跌解释为出货。不能强行合成统一规则。用发生位置、先后路径、成交量和实际次晨结果检验分歧。
- **同一因子可能只减风险，不提高上涨概率**。CO22显示高强势评分也富集严重亏损；因此新的验证同时检查强势概率、净亏>2%概率、实际净收益，避免只报告“命中率提升”。

## 后续如何验证，避免再次被好月份误导

1. **先冻结定义再计算**：每条记录信号截止t、因子可用时间、入场代理、卖出观察终点与成交价。开盘跳空、开盘后可成交净收益、早盘次高价达标是三个不同目标，分表报告。最高/次高是标签或辅助评价，不是保证能卖到的价格。
2. **时点分开**：收盘前路径只能用已完成数据；最后几分钟或集合竞价因子只进入有相应可执行下单时点的方案。完整收盘后才得到的信息可做研究或次日条件，不能倒灌为当日可成交信号。D+1开盘行为只能控制D+1卖出。不同t导致候选变化，应同时做同池对照和各自可执行池比较。
3. **保留旧池，又不锁死旧池**：旧B1上涨3%—6%池保留作可比基线；另预设一个更广的、流动性可交易的收盘候选池做敏感性分析。不能只研究原Top1，因为有用因子可能帮助排序原模型未选中的股票；全候选、TopK、固定Top1删单三个层次分开。
4. **严格时间切分**：未来实施时先写定研究日期。阈值、窗口、方向、缩放和代表因子只由训练段确定；验证段筛少量方案；下一段测试冻结，边界剔除未成熟标签。可按每月滚动重做训练/验证，但不根据测试月份再改方向。现有2025—2026已被反复看过，只能称历史重检；扩展更早历史也必须分段，最终确认留给此前未参与研究的新数据。
5. **增量而非换名**：先在相近日涨幅、振幅/波动、流动性、市场状态内比较，特别检查是否只是把高波动股换掉；再比较原7因子、旧76因子代表、每次加入一个新逻辑组。不能将输入池、时点、训练窗口一起改了再归功于新因子。
6. **月度同等重要**：逐月公布交易数、强势率、严重净亏率、单笔均值/中位数、复利、最大回撤、最差5%均值、保留盈利/拦截大亏数。按月/交易日成块估计区间，处理同日股票相关性；去最好月作压力测试，每月删最好一笔只作辅助。过滤类与同月同笔数随机轮空比较。多个因子/组合需披露全表并处理多重比较，不能只挑赢家。
7. **不先上复杂模型**：先分组关联与稳定性，再尝试少量正则模型或浅树；需要序列时，与这些明确定义的过程特征做同输入增量对照。当前没有根据说新14因子一定有效。
