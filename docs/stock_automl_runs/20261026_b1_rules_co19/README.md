# CO19：原20日滚动模型之后的规则研究准备

2026-10-26。状态：**已有研究调研＋本地输入覆盖审计已完成；新增规则收益回测尚未执行。** 不新增策略版本、不改原模型、Top1、原成交额轮空或生产执行。

## 固定底座

用户明确指定CO17/CO18的A原最近20交易日滚动模型。同一B1R快照，2026-01-19—10-15共177日，174日有Top1，130笔原规则交易；每边费用0.1%，14:40信号价格买、次晨09:40分钟收盘价卖。原扣费复利−5.52%。不引用ACTIVE最高收益冻结拼接名单替代，不覆盖10月16—26，不称新盲测。

第一轮只在原本允许交易的130笔上做“保留/跳过”，不重新选股、不以Top2递补。这样能够区分新增规则的增量与换股造成的变化。先不同时优化买入和卖出。

## 能迁移什么

|层次|研究量|时点口径|优先级|
|---|---|---|---|
|价格位置|当前价格在过去20/60日收盘序列的分位、距高点、偏离20日均线；此前持续高位天数|历史只到D−1，当前点只用D日14:40；复权尺度通过前收锚定|高|
|此前走势|D−1结束的3/5/10日涨跌、上涨天数、连涨、最近一次回撤；与位置做少量交叉|完整过去交易日，不用D日最终收盘；N日收益须N+1个历史收盘点|高|
|资金变化|前一日/此前5日主力净流入强弱、连续流出；近期变化与位置的关系|仅D−1及更早已发布值；缺失不视作0。缓存可先算(买−卖)/(买＋卖)，不混称主力净额/全股成交额|高，须补时点证据|
|两融|融资余额/流通市值、融资净增相对余额、此前5日变化|D−1或更早且14:40前已知；区分非覆盖、缺行、尚未到库|次级|
|当日承接|截至14:40的位置、午后回撤、相对日内均价、末段量价|全部分钟截断到买入决策前，不能用14:40之后的路径|次级|
|次晨退出|09:31—09:39的弱开、反弹失败、量价承接，用于提前退出或保留09:40卖出|只影响已持仓卖出，不能倒作前日买入过滤；用判断后的下一可执行价格回放|独立后续实验|

价格位置与走势应一起看：低位回升、高位加速、高位横盘、深跌反弹可能不同。**不预设高位必差、低位必好，也不预设资金流入必好。** 先检验单项，再加入少量事前定义的交叉，避免大规模组合搜索。

## B2经验及迁移限制

- 原模型已有量比、换手、均线等因子，成交额轮空也已执行。新增规则必须检验条件增量，不能将这些已有信息再次过滤就当成新增优势。
- [CO7二阶段风险研究](../20261015_close_open_conditional_b1/README.md)已经试过原模型折外Top1/Top5、基础预测信息、8项盘中走势和全部76因子。全因子风险过滤的改善主要依赖避开一笔−16.35%，15个测试月仅6个盈利；不是从未尝试二阶段。应复用其折外样本与误拦统计方法，本次优先研究可解释的个股历史位置、前期走势和滞后资金条件；CO7的区间、费用、扩展名单不同，不将其收益与本轮直接相减。
- [R134资金研究](../20261026_b2_funds_conditions_r134.md)记录近期资金约D0 15:58到库、两融约D1 07:08—08:53到库。B2在次晨买，可以等D0数据；B1在D0 14:40买，不能使用D0日终资金或两融。这里只是近期到库观察，不是历史版本或未来服务保证。
- [B2最新交接](../B2_HANDOFF_20261026.md)中，某些资金条件保留组胜率高，但硬过滤反而错失更多盈利；高杠杆过滤只有小样本增益，且换一条选股路径就可能反向。应迁移“标准化、按阶段消融、统计避亏和误拦”的方法，不能照搬阈值。
- [R137位置研究](../20261026_b2_events_position_r137.md)不支持单凭持续高位硬禁买。2026与旧年方向不同；PE极端位置样本也小。
- B2 Q75使用D1买前早盘信息，不能直接作为B1 D0买前条件；若做B1第二阶段风险模型，必须重新构建D0 14:40特征和次晨09:40收益/亏损标签，且用原模型历史折外Top1训练。130笔不足以支持大规模复杂搜索，首轮先用少量规则。
- 已做过的[CO14市场开关](../20261017_b1_market_gate_co14/README.md)在2026某些月份改善、2025反向，没有跨期稳定通过。CO14费用、区间、数据范围均不同，不将其收益与当前−5.52%直接相减。此次优先补个股位置、前期走势与资金，市场条件作已有参照。

## 建议的下一轮检验

1. 固定上述A底座、价格和费用，先看位置、前期走势、滞后资金三组；每组少量预设规则，先单独检验，再检验必要交叉。未知样本与共同有值样本分别披露。
2. 在2026年上半年形成阈值或候选规则，7—9月保持冻结，10月至15日单独展示；这些历史已看过，称时间顺序检验，不称盲测。规则通过后再找额外年份同口径折外名单及后续新日期验证。
3. 每条规则并列展示保留/过滤数量、避亏、错失盈利、净改善、每笔净收益、亏损尾部、月度和资金回撤。分别检查等额逐笔增量与原账户复利，不把胜率或更少交易当成全部效果。
4. 用同月同笔数随机轮空作参照，并检查费用/滑点敏感性。强月少赚和弱月少亏都保留，不能只展示赢家月份。
5. 买前过滤和次晨卖法分开消融。原模型目标是次晨第二高价，不等于09:40可兑现收益；第二阶段目标应围绕实际退出的扣费结果，不直接沿用B2未来三日再板标签。

这是研究方案，不是已确认有效的交易规则。没有新增训练包、规则收益或生产写入；已有CO17、CO18训练包及数据库登记在本次开工审计中均核对为`ok`，云盘仍待同步。
