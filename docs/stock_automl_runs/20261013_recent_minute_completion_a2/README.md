# A2：10 月近期分钟线补缺与双版本 Top1

执行日：2026-10-13。此实验只比较同一输入在 scikit-learn 1.7.1 与 1.9.1 下的选股，**不替换 B1 历史基准**。信号为交易日 14:40 的七因子四分类，使用之前 20 个交易日的有标签候选训练；先按 `≥3%` 预测类排序，再按 `1%–3%` 预测类顺延。下表为模型裸 Top1，未进行成交额轮空，因此不是可交易信号。

## 分钟线覆盖与来源

`kingdomai.aiia_stock_realtime_minute_snapshot_full` 的 09:31–14:40 区间每股应有 220 根 1m K。2026-10-08 的 5,094 股均为 220/220；10-09 的 5,095 股有 469 股不完整，共缺 9,722 根；10-12 的 5,097 股有 1,451 股不完整，共缺 49,487 根。10-13 审计时尚未到 14:40，不能产生该时点的完整信号。

接口 `upchina_kline_1m` 对上述 1,451 只缺口股票均返回了相应交易日的完整 240 根日内分钟线。补缺时保留数据库原有行，仅用接口行填入缺失分钟。73 根抽样重叠行中有 18 根与接口当前返回值不同，因此不能直接用当前接口的完整日数据覆盖原库，也不能把接口重算值当作原日盘中实时快照。

接口补缺的本地输入与逐日结果保存在 `outputs/stock_automl/oct_20261013_gap_backfill/`。`missing_only_before_1440.jsonl.gz` 只含 59,209 根待插入行，SHA256 为 `a95903007862386b96db59f20de43d67c9c5ae3fab97b086dba0c105aeab03d1`。数据库写入作业遵守现有回填脚本的交易时段暂停规则，计划在 10-13 15:20 后执行；以同目录的 `commit_status.json` 与回读审计为实际入库证据，不能把本地暂存视为已入库。
