- 全部封板316笔：涨停183、跌停133。其中V2封板143笔：涨停91、跌停52。
- 次开/次收涨幅=下一市场交易日开盘/收盘价÷D2收盘价−1；不扣费，不是相对D1买入的整笔收益，也不是账户收益。
- 1笔次日无成交，保留该市场日期并留空涨幅，不跳到复牌日。1笔次日前收与D2收盘不同，保留价格变动口径，同时额外列行情涨幅（分母=次日参考前收）；不把未计分红/除权的价格变化称为持有总收益。
- 上午7%使用D2 09:31—11:30完整分钟最高价，严格超过D1收盘的7%；记录首个触发分钟。全天最高价≤7%的130笔可直接证明上午未触发；其余186笔逐笔核验240分钟。
- “首次触板”是分钟高/低首次达到涨/跌停价的分钟标签，不等于最后封住涨跌停的时刻。未提取分钟的跌停行该列留空。
- 用户最新简化口径为“上午超过7%卖，其他默认盘末”，本轮研究这一触发标志；不再采用R67弱势反弹/强势尾盘/其他翻红分支，也不继续R68形态建模。生产V2本轮未改。
