## 判定与边界

- 全天封死：09:31—11:30及13:01—15:00全部240根分钟K的最高价均等于跌停价，同时与日线最高价核对。日线开盘至收盘也均在跌停价。
- 下午全封：13:01—15:00全部120根分钟K的最高价均等于跌停价，包括尾盘收盘集合竞价对应的分钟；不是仅用分钟收盘价判断。
- 打开分钟：该分钟最高价高于跌停价至少一档（浮点比较容差0.001元）；记录上午、下午数量，另核对有成交且打开的分钟数。
- 本表反映成交价格路径。封死表示没有高于跌停价的成交窗口，不能从OHLC和总成交量证明买盘挂单、排队位置、订单成交或绝对无法卖出。打开也不能保证我们的订单成交，更不能事后假设刚好卖在某分钟最高价。
- 对“上午>7%才卖，其余盘末卖”的规则，即使上午/下午曾打开，也不代表当时已触发主动卖出条件。本轮没有增加提前逃离跌停的规则，没有重算账户或修改生产。
- 持续封板起始分钟为最后一根曾高于跌停价的分钟之后，全部后续分钟高价不再离板的第一根分钟标签；只精确到分钟，不声称精确到秒。若15:00那根分钟仍有高于跌停价的成交，标为最后一分钟仍打开。
