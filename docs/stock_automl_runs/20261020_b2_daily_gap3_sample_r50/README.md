# R50：月更日线再向前错开一个月的六个月训练

## 改动与对照

原 B2 目标月 M 的日线 RF51 用 M−8～M−3 六个月拟合；M−2、M−1 两个月的日线成绩**没有用于选日线模型或决定停手**。但目标月模型对这两个月的评分被第二层四 K 形态选规使用。R50 只把日线训练区间改为 M−9～M−4，留出 M−3～M−1 三个月，仍不依据这三个月挑选日线模型。目标月仍只训练一个日线模型，月内每天加载该模型评分。例如预测 2026-09，原 B2 训练 2026-01～06；R50 训练 2025-12～2026-05。

四 K **方法**仍是原 B2：历史各月因果折外 Top1 六个月训练，目标月模型给 M−2、M−1 两个月验证股票评分；79 条原规则、原选规门槛、D0 Top3、D1 前四根 K、09:35～09:40 锁股后同股下一可交易分钟开盘价、D2 收盘卖出、买卖各 0.1% 费均不变。因为日线 Top1 历史名单变化，按同一方法选出的具体月规则也可能变化。为了回答“ K 线选择不变”的另一种理解，本次另报**直接固定原 B2 已选月规则**的敏感性对照。

目标月在读取 R50 测试结果前，从 R49 已观察过的历史高低收益月中固定为 2024-04/08/10、2025-04/06、2026-09。六个月分布跨三个年份，含原 B2 的大亏月和盈利月；这是探索性压力样本，不是随机盲测。每个 D0 月独立以 100 万元账户回放，空仓投入半数现金、持有一笔时投入余款，最后一笔结清至 D2；各月之间不续接资金，也没有连续影子停手。因此以下是同口径**月样本对照**，不能相乘成六个月投资收益。

按原四 K 流程重选时，R50 为 **3/6 月盈利、73 笔、实买三日再板率 53.42%**；原 B2 为 **3/6 月、74 笔、47.30%**；R49 日线 6+1 为 **0/6 月、80 笔、42.50%**。六个月独立账户收益的算术平均分别为 R50 **−5.07%**、原 B2 **−7.23%**、6+1 **−18.73%**；平均月内最大回撤为 **20.61%／25.19%／27.72%**。这些平均值只描述选出的六个月，不是可投资的连续组合结果。

2025-04 改善最明显，但不能全归于日线训练间隔：固定原月规则时 R50 仍亏 **17.62%**，重新从当时可见的训练/验证数据选形态规则 r029 后才变为盈利 **13.19%**。2024-08 的亏损从原 B2 的 34.62% 降至 28.48%，仍属大亏；2024-04 几乎没有改善。2024-10、2025-06 的原 B2 盈利被削弱，2026-09 从小赚转为小亏。固定原月规则的 R50 仅 **2/6 月盈利**，六个月平均收益 **−11.23%**。这些结果不支持宣布三个月间隔已经优于原 B2；它是一个值得连续区间检验的候选周期。

日线分类指标与账户收益亦不等价。例如 2025-04，R50 的 D0 Top3 三日再板率 71.43%，原 B2 为 65.08%，但固定原形态规则仍亏 17.62%；2024-10，R50 的 D0 Top3 为 81.48%，原 B2 为 79.63%，账户收益却由 +33.12% 降到 +13.50%。[逐月日线 Top1/Top3 指标](daily_model_metrics.csv)含全 D0 与历史 D1 开盘可交易子样本。
