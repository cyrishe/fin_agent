# 第三个固定模型：全可用日期每日前五

模型只用 **2026-08-25 至 09-21** 的 7,488 条股票日样本训练一次；之后同一模型给当前完整的 **37 个历史信号日**和 **2026-10-08 当日**评分，每天按分数取前五。历史日期中 20 天属于该模型训练期，Excel 的“样本归属”列明确标记；它们是供逐股审查的拟合期表现，不与训练期外结果混报。08-05、08-06、08-24 仍在补录，股票池未完整，不进入本版排序。

Excel 在本机 `outputs/01a11438-ac83-7200-9974-4779891e238b/第三个模型_每日前五_截至20261008.xlsx`。`每日前五` 页共 190 行，包含八个模型因子、14:50 假设买价、次晨开盘/五分钟/十分钟涨幅、真实类别、严重错误 `0/1`、收盘涨停与可买性事后审计；`逐日统计` 页列每日期候选规模和前五结果。严重错误 `1` 表示次晨前十分钟最高涨幅 **低于 0.5%**；`0` 表示不低于 0.5%。今日尚无次晨结果，标签与严重错误单元格留空。
