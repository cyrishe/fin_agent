# 14,292 与 14,783 条候选池的差异核对

旧文件有 14,292 条，重建的 14:40 七因子完整、涨幅 3%–6% 候选池有 14,783 条。新增的 491 条按互斥组拆开：名称含 ST 且有标签 **414** 条；次晨一分钟 K 缺失、无法计算本次标签 **59** 条；其余有标签 **18** 条。这是**训练及预测候选池口径**的变化，七因子、四分类标签、未加权小型提升树、最近 20 日重训、20 个测试日和 Top1/Top2 排序规则均保持相同。旧 14,292 条的七因子数值与新构建结果逐项一致。

| 参与池 | 20 日 Top1 09:40 每笔均值 | Top1 与旧池不同的天数 | 20 日 Top2 每笔均值 |
|---|---:|---:|---:|
| 旧 14,292 条 | **+1.311%** | 0 | +0.484%（40 笔） |
| 旧池 + 59 条无次晨分钟记录 | **+1.311%** | 0 | +0.484%（40 笔） |
| 旧池 + 414 条名称含 ST | +0.748% | 9 | +0.058%（40 笔） |
| 旧池 + 18 条其余有标签 | +1.361% | 4 | +0.134%（40 笔） |
| 旧池 + 414 条 ST + 18 条其余有标签 | **+0.379%** | 9 | +0.253%（39 笔） |
| 完整新池 14,783 条 | **+0.379%** | 9 | +0.253%（39 笔） |

这几组是重新训练树模型后的**单独对照**，不能把各行收益变化线性相加。59 条未标注记录在这 20 个测试日没有改变 Top1/Top2；它们仍应在当日推理池中保留，因为 14:40 无法预知次晨分钟记录会缺失。新版的 20 个 Top1 都属于旧池原有股票，没有直接选中新增的名称含 ST 股票；414 条 ST 等新增**训练行改变了树分支和排序**，九天因此换了 Top1。不能把 +1.311% 到 +0.379% 的变化归咎于那 59 条缺记录样本，也不能把它简单视为新因子的效果。

## 59 条缺的是什么

这 59 条在信号日 **14:50 价格均存在且大于零**；但在对应次日的 `aiia_stock_realtime_minute_snapshot_full` 表中，09:31–09:40 **没有任何一根 1m bar**，因而无法计算“次晨第二高价”或 09:40 卖出价。对应次日的 `kcrp_stock_price` 日线里 **59 条均有记录，53 条日成交量大于零，6 条日成交量为零**。至少这 53 条确实发生过交易；这里的缺失是使用的分钟数据源没有覆盖它们，不能说股票次日都没交易或都停牌。缺失最多的日期为 2026-08-25（16 条）、09-14（18 条）、09-15（18 条），其余 7 条分散在其他日期。

旧候选文件来自要求标签完整的 `trainable_1440`，所以这些股票曾被事先排除。标签完整性需要信号日 14:50 价和次晨分钟 K；本次四分类训练的次晨标签不需要 14:50 价，但旧文件仍继承了这道筛选。对实际 14:40 决策，应先保留当时特征完整的股票，次晨验证时再标记无法观察的结果。本次四分类回测是价格代理结果，未计费用、滑点，也未证明在 T 日 14:40 分钟收盘价可成交。
