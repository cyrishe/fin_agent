## 强势段内部及全部历史

主对照同一连续账户中，2025-05—12 自然月原 B2 **+20.43%**，停摆 **+14.85%**，停摆少 **5.58 个百分点**；2026-01—10-14 原 B2 **+116.59%**，停摆 **+136.33%**，停摆多 **19.74 个百分点**。这两个分段以上一段期末资金承接，不是各自重置到 100 万元的独立测试。停摆没有逐段都超过原 B2，尤其错过了部分原策略的盈利信号。

在目前可完整回放的 **2022-05—2026-09 共 53 个 D0 模型月**，同样将末笔结清到 2026-10-09 后，原 B2 的 709 笔收益 **−95.67%**、回撤 **98.76%**；停摆的 306 笔收益 **+161.07%**、回撤 **38.56%**。这与 R60 曾报的 −95.46%／+173.75% 不同，原因是 R60 以 D1≤2026-09-30 截止，未纳入九月末 D0 的跨月交易。本次 2024 自然年停摆账户仍亏约 **28.64%**，不能称已解决所有弱市失效。

上述强势段本身是看过历史后选出的区间，R57 门槛也是既有历史上的研究结果；对照说明它在这些历史样本里保留了强势段表现，不构成未见样本验证或实盘收益证明。D1 分钟 K 的 open 仍是原回测成交价代理。
