# 14:40 选股、前五日成交额轮空：单一回测基准

当前展示只采用一个口径：沿用“仅剔除 14:40 已涨停 ST”的七因子四分类模型，以过去 20 个交易日滚动训练；在 T 日 14:40 选 Top1/Top2，并以 **T−1、T−2、T−3、T−4、T−5** 各日截至 14:40 的沪深 A 股成交额均值判断是否交易。均值低于 20,000 亿元时当天轮空；通过时，按 **T+1 日 09:40 分钟 K 收盘价**计算卖出收益。轮空日的股票、分类与收益在当前逐日表留空。

成交额由原始一分钟 K 的 `turnover` 累加得到，每天只累计至 14:40（含），单位亿元。选股当天 T 日的成交额**不参与这份基准的门槛**。日终成交额与新的分钟卖出规则均不参与当前结果。股票目标分类仍按 T+1 早盘前 10 分钟的第二高价相对 T 日 14:40 买价划分；分类与 09:40 实际卖出收益是两个不同指标。第二天无可用价格时遵循原实验的停牌记零处理。

[逐日表](gate_daily.csv)保留了前五个交易日各自的 14:40 成交额、均值、是否交易、Top1/Top2 的事后分类与 09:40 收益；[按月表](gate_monthly.csv)从同一逐日表汇总。收益简单求和只是逐笔百分比相加，不代表实际资金收益；分钟收盘价是成交代理，未计手续费、滑点及委托成交情况。

2 万亿门槛来自对这批历史数据的观察，以上回测不是独立样本验证。成交额因子和板块训练实验的原始结果保留在 [experiments](experiments/) 子目录，不作为当前基准；需要比较新方案时再单独呈现。
