- 306笔D0完整240根分钟K，逐笔开高低收均与日线一致。280笔来自本地Tushare/MK，26笔来自KingdomAI分钟表，查询仅取完整、非回退的1分钟记录。

- 210笔有D0当日历史总/流通市值；其余96笔用不晚于D0的最近股本乘D0收盘价估算。股本距D0为3—371个自然日，逐笔列明。自由流通市值和PE/PB缺当日值时留空，不拿估算替代。原模型的成交额/换手率估算流值另列。
- 行业按D0有效期匹配，306笔全部有值；当前简称仅为识别，不用于历史ST判断。D2跌停价使用D2历史ST状态及板块幅度，与日线跌停标志和前次研究集合核对。

## 使用边界

D0是买入前判断日，本模型所有D0均为收盘涨停；D1买入，D2计划卖出。D0因子及D1前四K因子可用于对应时点研究。D1收盘和D2结果仅供事后诊断，不能倒填到买前训练。历史市值及财务字段是本次读取的历史日期记录，不保证恢复原发布时间数据库快照；未用当前板块成员替代历史热点。

原收益仍沿用D2收盘全额成交假设；开盘卖出收益是假设按开盘价成交。跌停价格路径不能证明订单是否排到，打开也不保证成交。本表供人工寻找区分线索，未证明因子区分能力，也未改变影子账户月度停摆或重新计算持仓延期后的收益。
