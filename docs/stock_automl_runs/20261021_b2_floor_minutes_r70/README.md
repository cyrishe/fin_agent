# R70：分钟最低价离板比例与开盘跌停后的收盘分布

## 范围

- 49笔组：V2放行、D2收盘跌停且上午未超过7%的49笔，与R69逐笔一致。
- 开盘跌停组：从2022-05—2026-09全部709笔原B2交易的D2筛选，开盘价等于D2跌停价共85笔，其中V2放行34笔。全部85笔均为10%涨跌幅板块；不预先筛选收盘是否跌停。
- 首分钟全封组：在开盘跌停组内，再要求09:31分钟K的最高价也等于跌停价。与仅开盘价跌停分开汇总。
- “最终涨幅”指D2当日收盘相对D1收盘的涨幅，不是D3收益，也不是买入到卖出的交易收益。

## 你指定的分钟比例

未封死比例 = 最低价严格高于跌停价的分钟数 ÷ 240 × 100%。上午、下午各以120分钟为分母，含零成交分钟但另记其数量。49笔组符合最低价离板的零成交分钟合计1；按你的分母照计，明细另列排除零量分钟后的离板数和比例。

这一口径要求整根分钟K未碰跌停；与R69“分钟最高价曾高于跌停”不同。三种分钟互斥且合计240：最低价离板；最低价碰跌停但最高价打开；最高价也未打开（全分钟在跌停价）。价差使用0.001元浮点容差，A股报价以分计。

49笔的逐笔比例已全部列在49笔分钟比例.csv：

- 全天最低价离板比例均值：32.94%；中位数：14.58%。
- 零完整离板分钟：16笔；全天封死：14笔。
- 离板分钟超过半天：19笔；不超过全天10%：24笔（包含零分钟）。
- 整个下午无完整离板分钟：25笔；最高价也未打开的下午全封：23笔。
- 最后半小时仍有完整离板分钟：9笔；只要分钟高价曾打开则为10笔。
- 曾打开的股票，其最长连续完整离板段中位数为66.0分钟；午休打断连续段。

## 数据与执行边界

并集115笔，每笔完整240分钟，与冻结日线OHLC和D1/D2收盘核对。最低价离板/分钟内触板打开/整分钟封板计数逐笔合计240；对49笔全天全封14、下午全封23逐项复现R69。分钟源缓存、数据库日线快照和既有B2/B2_V2策略关联均有来源哈希。

所有计算和绘图在服务器/data/cyris/work/b2_floor_minutes_r70_20261021进行。开盘价、分钟OHLC和总成交量不能证明盘口封单、排队顺序或我们能否成交；完整离板分钟也不能保证卖在该分钟最高价。现有“上午>7%卖、其余盘末”的研究规则未增补其他卖出条件，本轮未改生产、未新增训练、数据库实验登记或云端独立回读。
