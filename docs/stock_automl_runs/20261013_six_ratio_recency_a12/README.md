# A12：六因子比值加倒数对数日期衰减

2026-10-13。按用户指定，在 A11 的**六因子改比值**模型上加入 A9 已定义的新近样本权重；无权重六因子是同源对照。六因子为当时涨幅、量比、14:40 前换手率、流通市值、均线多头最弱比值、日内最低价相对最高均线比值。日期衰减是训练样本权重，**不是第七个输入因子**。

## 口径与复现

- 2–7 月 118 个折外预测日。每折只用此前 20 个交易日有标签候选训练，同一冻结母表、四分类标签、14:40 信号、类别优先 Top1 和次晨 09:40 分钟收盘卖价；sklearn 1.7.1／1.9.1 各独立重训。早期原始均线与最低价完整；近期冻结母表缺这些同源原值，故没有可比的近期六因子比值实验。
- 训练样本距预测日 `D=1…20`，最近日 `D=1`；原权重 `1/log₂(D+1)`，每折按**训练行**均值归一到 1。相当于最远日 `K=1`、最近日 `K=20`，预测日 `K=21`；预测日不参与训练。最近日单行原权重是最远日的 `log₂(21)≈4.39` 倍。逐折实际归一化权重最小值 `0.476～0.762`，最大值 `2.091～3.345`。
- 输入、模型参数和源文件 SHA 与 A11 无权重六因子一致：`d160e906712f8d9f0d7b1f052079c023fd2e8d7def5611fd71c31c738e4b90f2`。A12 复算的无权重 Top1 三档、成交额通过笔数和每笔均值都与 A11 两版结果一致。
- Top1 三档用次晨 09:31–09:40 **第二高价**相对 14:40 信号价：达标 `≥3%`，可接受 `1%～<3%`，错误 `<1%`；分母是**轮空前标签已知的 Top1**。收益是次晨 09:40 分钟收盘价／信号价−1，已完成卖出的算术均值；未计费用、滑点。成交额规则为当日截至 14:40 成交额不低于此前 20 日同一时点中位数，失败不递补。缺有效历史成交额的股票日单列为“门槛未核验”，不算已确认规则轮空或已完成交易。

## 稳定性与判断

加入权重后，同一版本的 Top1 只保持 52/118 日（1.7.1）和 48/118 日（1.9.1）；跨版本 Top1 同股从原比值的 88/118 降为加权的 82/118。1.7.1 在卖价都已知的 63 个换股日中，权重选股较原比值好 28 日、差 35 日；1.9.1 的 68 个可比换股日为好 29 日、差 39 日。4 月两版加权后的月均值都明显更差，但 3／5／6 月的方向并不一致，不能把历史平均差外推为未来必然结果。

本次普通倒数对数衰减在六因子比值上**没有改善达标率、09:40 每笔收益或跨版本 Top1 一致性**，且加重选股变动；不纳入 B1，也不能据此判断较温和的衰减形式。这个结果与 A9 七因子普通倒数对数权重的早期不佳方向一致，但 A12 只验证了早期六因子同源母表，近期仍未验证。
