# CO17：20日训练＋10日验证的逐日对照

**结论：本轮不替换原模型。验证盈利过滤有减亏作用，但模型选优没有明确增益，更严的两段验证也未改善。**

## 数据与规则

2026-01-19—10-15，177个预测日，scikit-learn 1.7.1。使用B1R全年重建快照；A是同输入复现的原20日滚动，不是ACTIVE登记的最高收益冻结拼接名单。不包含10月16—26的新信号，不称盲测。

D−30～D−11训练20个交易日，固定模型在D−10～D−1验证，不合并验证集重训，D日14:40预测。最后一个验证标签于D日09:40成熟。候选为原HGB、强约束HGB、逻辑回归；验证至少3笔已知交易，以10日净收益之和选优。方案在出结果前冻结，详见[DESIGN](DESIGN.md)。

原七因子、第二高价四分类、Top1及成交额门槛保持不变。14:40买、次日09:40分钟收盘价卖，均为价格代理；每边费用0.1%，无新增滑点。账户按已知交易连续复投，回撤是结算点回撤，不是分钟持仓回撤。缺失成交额门槛或卖价单列未知，收益统计排除未知；不推定缺失条件满足。

## 判断

1. **窗口变旧是明显损失来源。** A扣费−5.52%，B−54.21%。该对照显示本样本对近期训练数据敏感，不能据此断言所有行情都如此。
2. **验证选优没有明确增益。** C与B接近；C−B日均增益仅+0.0032个百分点，按月配对重采样95%区间跨零。
3. **验证盈利过滤有价值线索，但没有形成盈利模型。** C的验证通过组80笔，次日每笔净均值−0.147%；未通过组54笔为−1.046%。D减亏，但仍不如A。
4. **更严不等于更可靠。** E仅36笔，胜率33.33%，两段验证均盈利没有优于单一总验证盈利。
5. **不能把10天验证解释成可靠性保证。** 每窗交易样本较少、相邻窗口重叠，且在验证集上挑选最大值有选择偏差。验证分数与次日净收益相关系数约0.146，只是描述性关系。

2个日期所有候选都未达到有效验证条件，按预设回退原HGB、可靠性不通过。选择次数：逻辑回归72、原HGB61、强约束HGB44。

按信号月份配对重采样10000次，D−C的日均增益约+0.325个百分点，95%区间约[+0.002,+0.632]个百分点；只有10个月且历史已研究，不是独立确认。其余区间详见[analysis.json](analysis.json)。

## 核验与后续

- 177日训练/验证/预测顺序、标签成熟时间和验证选择独立核对通过。
- 177日原模型全部候选的四类概率与已保存B1R逐日结果一致；Top1、执行判断、买卖价格无差异。
- 708份保存模型回读复算测试候选概率通过；逐笔净收益复算通过；4项定向测试通过。
- 下一轮值得检验：**保留最近20日训练，用此前滚动折外预测评价模型**，避免为了验证而把最终模型训练截止日推远10天。也可预先固定更短验证窗做对照；尚未执行，不宣称改善。
- 原模型本次扣费后也为负，本轮不构成对现有策略盈利性的确认。没有修改生产模型、交易规则或策略执行数据。
