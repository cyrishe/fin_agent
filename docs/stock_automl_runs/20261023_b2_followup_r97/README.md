## 1. 用户所问的“盘前低价”

深交所[交易时段说明](https://www.szse.cn/www/investor/knowledge/stock/deal/t20190626_568129.html)列明开盘集合竞价 09:15—09:25、连续竞价 09:30 开始；[集合竞价成交规则](https://investor.szse.cn/knowledge/t20200102_573001.html)明确其成交均为同一价格；[开盘价规则](https://investor.szse.cn/knowledge/stock/deal/t20200102_573002.html)明确集合竞价成交价即开盘价，无成交时首笔连续竞价成交价为开盘价。R96 三个典型极值缺口日的日线开盘价与原始分钟开盘价相同，而日线最低价更低。因此**这三例不能用“09:25 盘前发生一笔更低的真实成交，却不计入分钟开盘”解释**。未成交的集合竞价参考报价也不能充当日线成交最低价。仍不能在没有逐笔或独立原始分钟源的情况下断言缺失发生于哪根分钟、或供应商内部如何聚合。

R95 的 2019—2021 D1 候选 708 个超 0.011 元容差极值日，547 个仅缺低点、118 个仅缺高点、43 个两端都缺。分钟区间整体向内收窄；低点缺失涉及 590/708，**并非所有问题日都只缺低点**。2019、2020、2021 的此类日期分别 305、300、103；2021 一季度 91，4—12 月 12。R95 对其中九日各两次同接口重取仍相同，前两典型日低点另经新浪／腾讯日线核对。零成交 09:30 前值污染属于独立且已在研究转换代码修正的问题，不能和上述 2019—2021 缺极值合并归因。

## 3. 2016 “缺 12,225 股票日”是否停牌

[R96](../20261023_b2_minute_review_r96/README.md)的 12,225/652,864 是以**代码×交易日请求**计数；返回 0 行代表该代码该日整段分钟未返回，不是返回半天。不能仅从 0 行判断停牌。

本轮只读服务器 R90 日线 `raw/daily_2016*.csv.gz`，对 [7 个沪深缺档代码](../20261023_b2_minute_review_r96/2016_missing_codes.csv)逐日核对，得到：`000022.SZ`、`001872.SZ`、`300114.SZ`、`302132.SZ`、`601360.SH` 各 244 日；`000043.SZ`、`001914.SZ` 各 175 日；**这 1,570 条日线记录每条成交量均大于零**。R95 对 2016-01-05 的七码重取为零行，本地 2016-03-02 原始分钟请求回执也列出七码均未返回。因而它们不是“日线也无成交的正常停牌日”；至少存在请求代码身份或分钟源覆盖问题。日线正量不能替代缺失的分钟价来假装可执行。

三对代码的 2016 同日开高低收、量、额逐项完全相同：`000022/001872` 244 日，`000043/001914` 175 日，`300114/302132` 244 日。深交所公告分别确认 [000022→001872 于2018-12-26](https://disc.static.szse.cn/disc/disk02/finalpage/2020-04-30/6e5e7ddf-787b-43be-96a0-1bfd434ac24b.PDF)、[000043→001914 于2019-12-16](https://www.szse.cn/disclosure/notice/general/t20191211_572534.html)、[300114→302132 于2025-02-17](https://disc.static.szse.cn/download/disc/disk03/finalpage/2025-02-07/e2d8b9d3-879b-4587-9e1e-235ebf4c8a44.PDF)；上交所资料确认 [601313→601360 于2018-02-28](https://www.sse.com.cn/disclosure/fund/announcement/c/2018-03-28/510290_2017_n.pdf)。所以 1,570 是重复代码身份后的计数，折为这四家经济实体的 **907 个 2016 有成交股票日**。其中 000043 的另 69 个交易日未在上述有成交日线请求范围内，不属于这里 175 条“有日线无分钟”。

余下 124 个回溯 `.BJ` 代码的 10,655 个请求缺口尚未按当时 NEEQ/交易身份逐一核验；不能把全部 12,225 条都断言为同一种原因，也不能称为 2016 年北交所停牌。下一步应以**当日真实证券代码和上市／停牌状态**建立请求名单，对正成交量日线缺分钟单独列为源覆盖问题。

## 4. 对回测结论的影响边界

R90/R93 已证实 2018—2021 主账户 295 笔中，140 笔 D1 对应分钟极值缺口；宽松与严格完整回放 295/210 笔且 8 个整月停摆决定不同，7% 上午早卖连续账户分别 −30.53%/−36.74%。这说明输入问题**足以改变策略路径**，却不是同一交易的修前修后收益差，更不能据此断言早年亏损都由分钟源造成。D1 全天质量用于 09:35 前候选剔除也存在未来信息，前缀可重放的 15 日中 6 日选股改变。

2021 的正面证据仅限于较干净的 4—12 月：独立账户原／严格 7% 退出 +38.27%/+20.21%；严格账低于原账主要来自 7 月影子改变让 8 月放行并新增 18 笔亏损交易。它不表示“删除坏数据后原 44 笔盈利缩水”。全年原纯 D2 收盘 −14.37%，7% 早卖 +47.65%，退出机制贡献很大；2018 当年极值缺口仅 2/778 却亏 −35.70%，2020 严格口径仍亏 −26.97%。故**数据异常属实且影响选股／门控，是否足以扭转历史亏损尚未证明**。

更直接的可执行性阻碍仍未闭合：295 笔中 46 笔 D2 收盘跌停按全额卖出、5 笔 D2 全天零成交仍记卖出；订单排队、延期持仓、现金反馈未重算。早期报表只能用于诊断策略与数据敏感性，不能作为可实现收益。

后续验证顺序：以真实历史身份去重；取得独立逐笔或另一个原始分钟源核对 2019—2021 极值；仅用 09:35 当时已知前缀决策；重训受影响四 K 和月度门控；按未成交持仓与资金占用重新结算。每一步保留冻结候选、交易及账户前后对照，再评估 2021 正收益是否跨期成立。
