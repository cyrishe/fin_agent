# 14:40 日内 VWAP 因子：2026 年滚动训练与回测

本次是离线实验；没有改变实时七因子选股脚本、策略 ID 或数据库表。运行绑定的代码、依赖版本及数据校验值见 [manifest.json](manifest.json)。

## 指标口径

原七因子中的 `all_intraday_lows_above_ma` 表示 **截至 14:40 的日内最低价高于复权换算到当日价格的 MA5、MA10、MA20 中最高的一条**，并非“每分钟收盘价高于 20 日均线”。本次保留原七因子，再加一个新因子对照。

新因子逐分钟计算当日累计成交均价：`VWAP_m = 09:31 至 m 的成交额累计 / 成交股数累计`。比较该分钟收盘价是否**严格高于**其当时的 `VWAP_m`，只使用 09:31–11:30 和 13:01–14:40 的 220 根一分钟 K。首段无成交、VWAP 尚未定义的分钟计为“不在上方”，但该股票仍保留在候选池。归档成交量为股，数据库及分钟接口的成交量为手，后者乘 100。已用 2026-08-05 `000007` 的原始 220 根 K 与数据库汇总双重核对，均为 197/220。

- 二元指标：220 根分钟收盘价**全部**高于各自当时 VWAP 为 1，否则为 0。
- 训练档位：上方分钟数 / 220 `<85%` 为 0，`85%–95%`（含边界）为 1，`>95%` 为 2。它以有序数值进入小型提升树，不改变四分类标签和排序规则。

T 日因子只读 T 日 14:40 之前分钟 K；训练标签取 T+1 日 09:31–09:40 十根分钟 K 的第二高价，对 T 日 14:40 信号价分为 `<0%`、`0–1%`、`1–3%`、`≥3%`。收益代理取 T+1 09:40 收盘价。预测日的下一日结果只在选股后核对。

按追加要求，还把旧 Top1 每根分钟 K 的**最低价**与当时累计 VWAP 比较，记录严格高于的分钟数及其占 220 根的比例。137 笔旧 Top1 均有完整分钟线，重新计算的收盘价上方分钟数与原结果 **137/137 一致**。最低价全程高于 VWAP 为 **0/137**；占比最低 1.82%，中位数 75.00%，最高 99.55%。因此逐日表增加连续的[最低价上方占比](daily_with_vwap.csv)，不以“全程在上方”这个稀少事件筛选股票。

## 三档因子：样本本身与折外选股

两段候选池分别是 1–7 月原口径的 **58,317 条**和 8–10 月冻结的 **15,696 条**；VWAP 覆盖率均为 100%，未因新因子删股票。训练用此前连续 20 个交易日全部有标签样本。1–7 月有 118 个折外预测日（02-02 至 07-30）；8 月缺少完整的前 20 日候选，下一段从 09-02 至 10-09 有 22 个预测日。10-09 的次晨标签从 10-12 已保存的完整分钟结果补入，只用于事后验证。

候选总体的目标 `≥3%` 比例随 VWAP 上方比例升高反而下降。下表分母都是**有标签候选**，不是 Top1：

| 候选段 | 档位 0：样本 / 目标≥3% / 09:40≥3% | 档位 1 | 档位 2 |
|---|---|---|---|
| 1–7 月 | 27,650 / 17.26% / 11.57% | 14,537 / 13.91% / 8.95% | 14,757 / 11.41% / 7.22% |
| 8–10 月 | 6,450 / 14.05% / 8.54% | 4,161 / 11.87% / 7.52% | 5,058 / 8.92% / 5.71% |

同一交易日中档位 0 与档位 2 都至少有 10 条有标签样本的 174 天，档位 0 的目标达标率有 127 天更高、47 天更低。这个方向性关联不能直接推断加入模型会提升 Top1。详见[候选档位与结果](candidate_level_outcomes.csv)。

## 历史基准复现差异

本次重建的早期候选数 59,959、去除已涨停 ST 后的 58,317、各日训练样本数，与旧实验一致；抽查的旧 Top1/Top2 七因子和价格也逐项一致。然而当前代码和依赖重训的七因子名单并未完全复现旧报告：2–7 月共同 113 天中 **84 天同股**，旧报告另有 2 天选股；9–10 月 **19/22 天同股**。同股日 `P(≥3%)` 中位绝对差约 0.004–0.005。详细日期见[复现核对](baseline_reproduction.csv)。具体差异来源尚未定位，因此本报告的“新增因子提升”只按**同一次运行的七因子与八因子配对**判断，不能把本次七因子收益与旧报告的 +0.128%/笔直接相减。

回测是 14:40 信号价买入、次晨 09:40 分钟收盘价卖出的价格代理；未计费用、滑点和实际成交约束。下方另列现有个股成交额轮空规则的配对结果，避免把裸 Top1 与正式轮空策略混为一谈。
