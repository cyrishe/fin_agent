# R60：补入 2021、2022 年分钟线后的原 B2＋月初停摆回测

## 测试范围与口径

本轮新增 **2022-05—2023-04 共 12 个完整 B2 测试月**。2021 年 243 日和 2022 年 242 日的分钟文件均逐日与元数据哈希核对；KingdomAI 的日线补取 2020-11—2021-10，接上 R41 已冻结日线源。新增 2021 年 D0 涨停样本 15,610 行，接上原 71,690 行；新训 2021-09—2022-08 共 12 个固定随机森林月模型。首个测试月 2022-05 的日线模型用 2021-09—2022-02 训练、2022-03—04 验证；形态规则用 2021-09—2022-02 的折外名单训练、2022-03—04 验证。**2021 年是训练与形态历史，不能当作完整 B2 测试年份。**

原 B2 的 D0 Top3、D1 四根 K 形态选规、09:35—09:40 激活与原下一合格分钟开盘价、D2 收盘卖出、买卖各 0.1% 费用、100 万元起账及资金分配均不变。唯一新增的风险门槛沿用 [R57](../20261020_b2_sum_loss_r57/README.md)：每月开始前，用**原 B2 不停手账户**在上月最后 5 和 10 个交易日的收益相加；和 <0 或上月零最终候选则暂停该 D0 选股月全部新候选，下月再判断。首测月 2022-05 没有更早完整 B2 历史，照原规则运行，不能把缺历史当成零候选。暂停月仍计算原 B2 影子账户。月度账户收益按实际持仓估值日，D0 月末已放行的股票可能在下月 D1 买入或 D2 卖出；因此暂停月仍可能有旧持仓收益／费用，不能解读为当月新放行。

## 一致性与留存

新增候选 910 个股票日，903 个分钟质量通过，3 个价格冲突、3 个分钟缺失、1 个 D1 日线缺失按原口径排除。12 个新增月模型重载评分一致，**165 条新增信号与原早盘 `evaluate_morning` 判定逐项一致**。2023-05 以后 543 条原 B2 信号与 R41 完全一致；旧起点 2023-05 的原 B2 与 R57 整月停摆账户复算分别为 −93.08% 与 +156.94%，结果不变。2023-06 以后月初门槛的 5／10 日输入与停摆判断均与 R57 一致；2023-05 本次新增了 2023-04 影子历史，算得收益和为正，仍照常运行。[模型与生产判定回执](../../../outputs/stock_automl/b2_2021_minute_r60_20261020/verification.json)、[账户与源哈希回执](backtest_audit.json)可追踪。
