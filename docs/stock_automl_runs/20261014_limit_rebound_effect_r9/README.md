# R9：以效果为主的 D0 开盘模型对照

2026-10-14。本研究沿用 R5/R8 的 D0 当日封板评分、D1 开盘低于涨停价且非 ST 才激活、D1～D3 任一日收盘再封板为正例。训练集 D0 日期为 2024-10-08～2026-03-26；验证集 D0 日期为 2026-04-01～06-25，对应 57 个 D1 信号日；测试集 D0 日期为 2026-07-01～10-08，对应 66 个 D1 信号日。R8 只用训练与验证选择随机森林挑战者，测试期模型使用训练＋验证重新拟合。1.7.1 原提升树的验证和测试逐行分数均复现 R5 保存值。所有比较在相同日期和同一 D1 激活候选池上进行；简单对照为“D0 已连续封板天数最长”，并以代码排序打破平局。

同一交易日逐对比较，随机森林较原提升树的 **D3 毛收益均值差**：验证期 1.7.1 +1.35 个百分点、1.9.1 +1.64 个百分点；按交易日重抽样的 95% 区间分别为 −1.28～+4.08、−1.32～+4.59 个百分点，均跨零。测试期在双方都有 Top5 开盘候选的 **64 个共同日**，差异分别为 +2.34、+2.36 个百分点，区间 +0.19～+4.52、+0.92～+3.97 个百分点。不同模型有不同轮空日，若以 66 个日历信号日为分母并在无候选日记零，测试 D3 毛收益均值为森林 +3.81% / +3.59%，原模型 +1.69% / +1.45%。这些是“每日单信号均值”，不是有重叠持仓时可复利的账户收益。测试期此前在多轮研究中已被查看，区间不能当作预注册新样本的显著性结论。相较简单最长连板规则，随机森林验证期三日再板同为 29/57；测试期森林 40/64 或 39/64，对照 35/66，不同信号日不能直接相减。**模型超越简单规则的可靠增量仍需新日期确认。**

## 数据核对与边界

- Top1 的 D2/D3 价格覆盖均完整。随机森林 Top1 的 D1 全日零成交数在验证、测试均为 0；原提升树测试有 2/65 次零成交。事后仅剔除这两笔后，原提升树测试 D3 均值约为 +1.77% / +1.52%，没有解释森林的全部差异。零成交信息不能在 D1 开盘前作为实盘筛选条件。
- 随机森林 Top1 的 D1 开盘至 D3 收盘原价收益，与以每日昨收为分母连乘的收益，在全部入选股上均无超过 2 个百分点的偏差；测试最优两笔约 +33.13%、+29.52%。测试 D3 收益中位分别 +2.51%、+2.20%，但样本和行情阶段有限。
- 随机森林两版在验证 55/57 天、测试 57/64 个双方有 Top5 开盘候选日同股；D3 毛收益均值的版本差分别为 0.32、0.23 个百分点。原提升树两版验证 48/57、测试 55/65 同股。版本稳健性是辅助观察，不是模型选择的唯一目标。
- 固定 D2/D3 收盘退出只是可比较的代理。没有模拟封板后的可卖性、隔夜跳空、成交队列、持仓资金重叠或手续费，也没有证明 D1 集合竞价能以开盘价买到。D1 再板可能在开盘数分钟内发生，现实执行收益可能显著低于此处价格毛收益。

补充：如果**不限制 D0 Top5**，直接在 D1 全体激活股取 Top1，森林验证 29/57、30/57，测试两版都是 41/66；测试固定 D3 均值分别 +3.97%、+3.82%。这不是当前 Top5 规则的主结果。Top5 的测试分母是 64 天、两版命中 40 和 39 次；全池的 41/66 不能移植为 Top5 的成绩。

判断：**随机森林保留为 R8/R9 的 D0 Top5→D1 开盘 Top1 挑战者，尚不替换 R5 基准。** 它在验证和测试的 Top1 分类及固定退出毛收益都优于原提升树，符合“先看效果、再看版本波动”的顺序。但验证期相对收益区间跨零、Top2/3 不稳定、测试期非全新盲测，且简单连板规则的可靠增量未稳固。下一步应冻结 Top1 规则、入场方式和一个卖出规则，在未见新日期上逐日记录可成交信号与净收益。

`D1开板=1` 表示开盘价严格低于当日涨停价，`D1激活=1` 再要求非 ST 且开盘价有效。该模型训练和评分已经排除 D0 历史 ST，D1 激活也排除历史 ST，所以表中“当时ST”全为 0；这张表不能用于比较 ST 与非 ST 的模型效果。`D1首封时` 是首根分钟 K **收盘价**达到涨停价的分钟末时间；`D1终封时` 是最后一次回到分钟收盘封板的时间，仅在当日收盘封板时填写，不是逐笔锁单时间。分钟行情核对完整 603/615 行；测试的两笔入选且 D1 收盘封板股票（D0 日序 23、24）处于 8 月 3～4 日分钟档案缺口，故时间留空。空白首封时间也可能表示全天没有分钟收盘封板，需结合 `D1封板` 判断。

冷静天数按 D1 首次再封板为 0、D2 为 1、D3 为 2、D4 为 3；D4 仍未板记“未结束”，D4 行情缺失记“待观察”。`冷静末涨` 是首个再板日之前一个交易日的收盘价相对 D1 开盘假设买价的涨跌幅；D1 当日再板时为 0。`D2/3/4收涨` 均为对应日收盘价相对 D1 开盘价的完整持有期价格毛收益。`策略退出涨` 在 D2～D4 首次**收盘封板**时取该日收盘收益，否则取 D4 收盘收益；若 D4 尚未观察且没有此前再板，则留空。D1 再板不能当日卖出；但若 D2～D4 再板仍按新规则取首次再板日。用户关心的入选股验证 21/57、测试 33/64 笔在 D2～D4 再板退出，其余 36/57、31/64 笔在 D4 到期退出，均有收益值。退出收益已包含冷静期价格变化，不把冷静末涨再相加。所有退出都只是收盘价代理，没有验证封板时能成交卖出。
