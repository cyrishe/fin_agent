# R105：QDC 首根分钟 K 时间语义更正与 B2_V2 重放

R104 把 QDC `09:30` 行视为独立集合竞价并丢弃，从 `09:31` 起取首根 K。逐行核对发现旧档结束标记为 `09:31` 的首根完整 K，实际等于 QDC `09:30` 与 `09:31` 两行合并。例：`000004.SZ` 于 2024-09-24，QDC 两行成交量 5,617,100＋7,538,600＝旧档首根 13,155,700 股；合并后的开高低收 16.66／17.36／16.20／17.30 也一致。QDC `09:32` 起与旧档同名分钟对应。R105 因此将两行合为结束标记 `09:31` 的 K，再按冻结的 D0 Top3 分数、逐月四 K 规则、原停摆与买入轮空回放。**R104 的 QDC 买点、停摆和收益表已被本轮取数口径更正，不再作为新源结论引用。**

6,628 个冻结 D1 候选中，6,624 个有可合并的两行首根，4 个两行均缺。保留原 D0 模型分数、日线和资金规则；未重训。2022 仅 5—12 月有冻结规则，且 2022-05 缺上一月影子门槛，按旧研究口径默认放行，故 2022 数字是部分年份的敏感估计；2026 只计 D2 不晚于 9 月 30 日。
