# B2/V2 连板量能与跌停风险：R71

## 口径与交付

- 只读复用 R69 冻结的 B2 709 条 D0 信号，按已冻结月度停摆标志取 306 条 V2 放行交易。它们是 B2 的最终候选信号，不是原始 top3 全部股票；不把其余 403 条影子信号混进实买风险率。
- 所有量能均为日线成交量，单位万股。首板是本轮连续收盘涨停的第一交易日；首板前 5／10／20 日只取该股票更早的**实际有成交交易日**，不足 n 日留空。选股日 D0 已知全部量能；D1 前四分钟买入判断之前也已知。D2、D3 跌停仅为事后标签。
- 表格：`B2_候选连板量能特征_709笔.csv`、`B2_V2放行连板量能特征_306笔.csv`、`量能假设_分期对照.csv`。股票代码保留六位；所有可计算的量价与风险率列是数值列，无前置单引号。
- D2 风险标签为开盘或收盘跌停的并集；连续标签为 D2、D3 均收盘跌停。跌停价沿用 R69 的历史 ST／板块幅度口径，重新核验 V2 的 34 开盘、52 收盘、67 并集、20 连续。

## 观察

1. **首板缩量的方向跨期不稳定。**以首板量低于板前 20 日均量定义“未放量”，2022—24 为 8/25 对 34/121，2025 为 1/8 对 9/46，2026 反而是 1/24 对 13/73。改用前 5 或 10 日均量，2026 仍分别只有 1/35、1/31 命中跌停。不能据此把首板缩量直接设为禁买。
2. **二板应缩量的经验没有稳定区分。**2026 年二板缩量为 9/58，对照 5/38；2025 年 6/33 对 4/21；早期 28/103 对 12/40。差异小且方向不一致。
3. **三板放量跨期翻转。**2022—24 年三板放量 6/43，对照 24/55；2026 年却是 7/30，对照 2/23。二缩三放组合在早期 5/36 对 25/62，2026 年为 4/19 对 5/34。四板样本更少，无法确认“后续放量更安全”。
4. **连板至少 5 天值得保留为背景变量。**2025 为 3/10 对 7/44，2026 为 3/11 对 11/87；但早期 10/37 对 33/117，且 2026 仅 11 笔高连板，不能单独作为硬门槛。连续 D2/D3 跌停在全部放行交易中只有 20 笔，2026 只有 5 笔，不能从少量格子推断稳定保护。
5. **量能定义有限。**这里的“不放量”是日总成交量相对股票自身历史均量，不等于封单量、排队量、盘口撤单或首封时是否有量。表中的首板一字、D0 一字只给出日线极端形态；分钟／逐笔封单需单独研究。

## 特征说明与数据质量

- 每笔有完整的本轮连板日期和逐日量序列；固定列给出第 2／3／4 板、最近 1—5 板、相邻板量比、D0／首板量比、段内最高／最低量比与最低量板序。第 1 板量另有独立列。
- 首板前 5／10／20 日均量、最大量、最小量及首板／D0 对相应均量之比，均只使用首板前历史；二板缩量、三四板放量只在该板实际存在时有值，不存在留空。
- 全部 709 条中 678 条有完整板前 20 日、31 条不足；V2 放行 306 条中 297 条完整、9 条不足。25 条完全无板前记录；不能把空值当作零量，也不能推断其原因。
- 结果只描述历史关联，存在同股票相邻 D0 重叠和年份市场差异；不是独立盲测，也不是可执行账户收益。当前跌停卖不出的跨日持仓、排队和账户反馈问题仍未修正。正式 `imac/B2_V2`（定义 SHA-256 `54ebe0150dfefa6ce9837d403fd83b331f2720ad835271525e3106aae7529f00`）、月度停摆与买前候选模型均未改动；没有生产数据库写入或云盘同步。
