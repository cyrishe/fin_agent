# R26：锁定后下一分钟开收均价回放

冻结R25保存的四K/五K原始入选时序和月度规则，保持原Top3、原实体门槛、无替补；本轮没有训练、规则选优或生产变更。

具体步骤：完成4/5根形态K后，按原先逐根完整K激活机制选定唯一股票（分钟open低于涨停且volume>0，时间优先、同时间D0排名优先），在该激活K结束后的下一整分钟交易，模拟买价=(该分钟open+close)/2。下一分钟开价仍须低于涨停且有成交；否则即时下一分钟方案放弃，不换股。另保留next_available对照：允许等待同股后续第一根合格K。

例如四K最早09:35激活K确认后，用09:35—09:36一分钟开收均价；五K最早09:36激活K确认后，用09:36—09:37一分钟开收均价。形态完成与激活确认不是同一个时间。

end0940指整根买入分钟最晚结束09:40；end0941指允许最后09:40开始的一分钟，均价到09:41才能核定。均报告，避免重复混淆开始与结束时钟。主要按用户前述09:36—09:40开始买入窗口看end0941，严格09:40结束另列。

100万元现金轮换，D2收盘卖出，买卖各0.1%，2026-01-01至10-14。月底含未平仓估值，跨月按实际净值归属。三日标签为D1—D3任一天封板，未知不填零。相同n/timing/cutoff下开价和均价对照股票、买卖日期完全相同，因此命中率相同。

开收算术均值不是VWAP，也不是可预知限价或已证实可成交价；收价事先未知，只能用于事后估算在该分钟内执行的平均成本。下一分钟是否有成交、开价是否低于涨停仍用事后分钟事实，真实成交需要报价/订单数据。两版执行流程统一，但流动性、封板速度和延迟可能不同，不能据此断言实盘难度完全相同。
