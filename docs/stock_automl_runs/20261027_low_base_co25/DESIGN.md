# CO25：低位蓄势候选与2/3日涨幅，结果前方案

2026-10-27。独立于收盘—开盘B1的日线研究，不沿用当天涨3%—6%的旧候选池，不替换生产。先筛每日候选并研究关联，同时做固定简单模型对照，不根据测试结果追加阈值。

## 信息和价格时点

信号为D日收盘后，所有条件至D收盘可知；观察D+2、D+3收盘相对D收盘的涨幅。可交易参考另用D+1开盘进入、D+2/D+3收盘退出，买卖各0.1%假设费用，不额外加滑点。绝不假设完整D收盘信息可在D收盘成交。交易日按市场日历，非自然日。主标签为次日开盘进入后的净收益；后续最高价只作潜在路径，不作为兑现收益。

采用close/preclose递推的因果价格链构造历史位置、均线和未来参考收益；不使用可能被未来复权重写的adjclose。保存原价收益用于敏感性检查。中间停牌/无效行情导致对应标签未知；次日一字行情或退出日疑似一字跌停的执行收益未知，单列数量、不当零收益。没有完整历史ST身份和订单回执，本轮是研究筛选与排序，不能称可执行账户回测；日K回撤不等于盘中资金回撤。

## 三层固定规则

基础池：沪深历史股票日，不用当前成分股；连续60个市场日OHLC与成交量有效，过去20日均成交额≥2000万元、当日≥500万元。完整使用历史股票代码，不按未来结果删候选。数据源为仓库已有KingdomAI日线快照。

1. **L低位**：当前收盘在近60日最高/最低区间的位置≤35%；近20日涨幅≤8%。低位是相对价格位置，不等同于绝对股价便宜。
2. **S低位止跌**：L基础上，近5日涨幅≥−2%；MA5相对3日前下降不超过1%；近3日最低价不低于此前10日最低价的99%。允许缓慢筑底，不把持续创新低自动解释成蓄势。
3. **C低位收敛蓄势**：S基础上，最近5日高低区间幅度≤8%；最近5日平均真实振幅/此前20日平均真实振幅≤0.85；最近5日均量/此前20日均量≤0.90。这里的此前20日不与最近5日重叠。

三层全部保留，不筛出“最好阈值”。压缩可能只代表冷清，方向未知；必须比较同日基础池和低位池。另报告首次进入每层规则的事件，减少连续多天同一股票重复计数造成的假象。

## 时间隔离与预测

2023-10—12只作预热；2024为发现/结构检查，2025为历史验证，2026-01—09为固定规则后续检验。历史市场曾用于其他研究，不宣称真正未知的盲测。原始日线延伸至2026-10以成熟9月末标签。

简单模型：在S池上，以过去6个完整月为训练窗口，每月冻结，清除标签结束日期不早于测试月首的样本。D+2和D+3各拟合一个Ridge(alpha=100)，预测净收益；固定约10个连续量价/相对市场特征，训练段1%/99%缩尾、标准化、每日等权。只用训练参数转换下一月。2025-01起逐月预测至2026-09。不调参、不用测试月挑模型。每天按预测收益取Top3，与同日S全部、C全部，以及S内固定“区间更窄”Top3对照；不因预测为负再追加门槛。

指标：每日候选数、已知/未知标签数、平均/中位数涨幅、上涨概率、净收益≥3%与净亏>2%、最差5%均值；逐月及年度、日期等权相对同日基础池增量。预测检查MAE/均方误差对训练常数、日内排序相关、模型Top3。重叠持有的单笔收益不直接连乘成账户收益；本轮不虚报总账户收益与最大回撤。

验证：手算形态、公司行动价格尺度、未来扰动不改历史特征、标签成熟和月份隔离、模型落盘回读、独立原始行情样本复算及逐月重算。记录全部规则、每日名单、特征/标签、训练成员和模型。本地完整包核验、数据库登记，云盘按用户要求待同步。
