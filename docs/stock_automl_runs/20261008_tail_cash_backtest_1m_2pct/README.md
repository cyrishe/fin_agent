# 100 万元本金、次晨触及 2% 卖出的价格回测

**区间：**信号日 2026-09-08 至 09-29，次晨退出日 09-09 至 09-30；15 个信号日，每天按已有八因子二分类折外通过概率取前 2 只，共 30 只。更早的 08-25 至 09-07 用作首次训练，不计入本轮收益。这里沿用已保存的历史排序，没有重新训练；接口补出的 08-19 试抓尚未加入模型或收益。

初始现金 **1,000,000 元**，每天对两只股票平均分配当时资金，按 T 日 14:50 的 1 分钟收盘价做代理买入；次晨全部卖出后现金滚入下个信号日。交易单位情景按普通 A 股 100 股、688/689 股票至少 200 股后按 1 股递增；30 只全部买得起，剩余不足一股或一手的现金不买入。比较三种退出价格：

| 次晨退出规则 | 理想等权期末资金 / 收益 | 交易单位期末资金 / 收益 |
| --- | ---: | ---: |
| 开盘即卖 | 989,606.90 元 / **−1.04%** | 989,517.28 元 / **−1.05%** |
| 全部按 09:40 分钟收盘价卖 | 1,003,120.93 元 / **+0.31%** | 1,003,250.55 元 / **+0.33%** |
| 前十分钟最高价触及买价上方 **2%** 则按限价卖；否则按 09:40 价卖 | 984,928.51 元 / **−1.51%** | 984,891.71 元 / **−1.51%** |

2% 卖价向上取整到 0.01 元。如果开盘价已经高于卖价，理想化成交价用开盘价；其余触及用卖价。30 只中 **8 只**的前十分钟最高价触及 2% 卖价。价格曾触及并不证明订单排队成交；09:40 未触及者按该分钟收盘价立刻成交也是假设。三种情景均未计佣金、印花税、滑点、真实委托可成交性；因此结果是**价格情景回测**，不是可实现净收益。

2% 阈值在这 15 天的价格情景中表现较差。只作同一测试集上的参数敏感性检查，交易单位回测为：

| 卖出阈值 | 触及只数 / 30 | 期末资金 | 收益 |
| --- | ---: | ---: | ---: |
| 0.5% | 24 | 1,048,612.14 元 | +4.86% |
| 1.0% | 20 | 1,048,456.75 元 | +4.85% |
| 1.5% | 17 | 1,046,353.49 元 | +4.64% |
| **2.0%** | **8** | **984,891.71 元** | **−1.51%** |
| 2.5% | 4 | 957,752.47 元 | −4.22% |
| 3.0% | 4 | 967,536.78 元 | −3.25% |

2% 与 1.5% 间结果陡变，部分股票最高价达到约 1.5%–1.9%，未达到 2%，到 09:40 却已下跌；例如 2026-09-22 的 603960，前十分钟最高涨幅约 1.90%，09:40 相对买价约 −4.20%。**不能因这张表在同一批测试日选出最优阈值并宣称折外有效**；未来需在更早日期选参，再在新增日期验证。现有“每天前二”还强制每天交易，与用户允许不出手的目标有差别。

主结果与输入哈希见 [summary.json](./summary.json)；逐日资金和逐股价格/份数在本机 Git 忽略目录 `outputs/stock_automl/tail_critical_review/cash_backtest_1m_2pct_*.csv`。变量与数据依赖、1 分钟接口扩样实测见[特征与数据口径](../20261008_minute_api_backfill/README.md)。

复现：

```bash
python -m scripts.backtest_automl_tail_top2_cash --starting-cash 1000000 --target-pct 0.02
python -m pytest -q tests/automl/test_tail_cash_backtest.py
```

`--target-pct` 可修改。脚本依赖此前本地忽略目录中的折外排序、14:50/次晨价格及 09:40 分钟价；不会凭空重建这些输入。
