# 14:40 尾盘候选标准训练数据

本数据按用户确认的实盘场景构造：14:40 行情可由实时行情接口取得，因此历史分钟 K 的**入库时间不参与样本筛选**。历史 14:40 分钟 K 用作实时价格代理；T 日正式日线的 `preclose` 仅用作实时接口“昨收参考价”的历史代理。T 日的正式收盘价、全天成交量、最终涨跌停状态均不进入特征。

逐股 CSV 保存在本机 Git 忽略目录 `outputs/stock_automl/tail_standard/`，本次提交只包含生成代码及聚合审计。

## 文件

| 文件 | 用途 | 行数 |
| --- | --- | ---: |
| `candidates_1440.csv` | 14:40 涨幅在 3%–6% 的全部候选，保留缺失和完整性标记 | 8,999 |
| `trainable_1440.csv` | 目标和所列特征完整，并排除信号时可识别的 ST、未知板块规则及涨停候选 | 8,601 |
| `execution_feasible_1440.csv` | 在训练文件上，另用 14:50 买价代理检查未接近涨停；仅用于执行分析 | 8,597 |

样本覆盖 2026-08-25 至 2026-09-29 的信号日；次晨标签最晚至 2026-09-30。逐日数量及运行溯源见 [summary.json](./summary.json)。未拟合模型，也未用本数据报告策略准确率。

采用 T 日正式昨收参考价后，候选比上一版按 T−1 原始收盘价筛选多 4 行；9 月 14、15 日分别有 279、109 行 14:40 候选，现均正常进入候选文件。

## 特征定义

| 字段 | 口径 |
| --- | --- |
| `signal_return` | T 日 14:40 价 ÷ T 日昨收参考价 − 1；纳入 3% 和 6% 边界。昨收参考价可处理除权日的参考价变化。CSV 收益率为小数。 |
| `volume_ratio` | T 日 09:31–14:40 的 220 根分钟 K 成交股数之和 ÷（T−5 至 T−1 日均成交股数 × 220/240）。分钟表实测为“手”，乘 100 转为“股”；这是按已过交易分钟折算的量比。 |
| `turnover_so_far_pct` | 截至 14:40 的累计成交股数 ÷ T−1 日流通股本 × 100。 |
| `float_mv_100m_cny` | T−1 流通市值，单位亿元。 |
| `volume_tminus5`…`volume_tminus1` | 连续五个已完成交易日的日线成交股数，按从旧到新排列。 |
| `ma_bull_5_10_20` | 截至 T−1 的后复权收盘价 MA5 > MA10 > MA20。均线按 T 日昨收参考价缩放到盘中价格尺度。 |
| `price_above_all_ma` | 14:40 最新价高于上述三条均线。 |
| `all_intraday_lows_above_ma` | T 日 09:31–14:40 **每根**分钟 K 的最低价均高于三条均线，即截至 14:40 当日价格始终在均线之上。 |

完整性只检验数据本身：220 根真实、已完成、非回退的分钟 K；T−1 起连续 20 个交易日的有效日线；T−1 有正的流通市值和流通股本。来源记录的抓取、创建、更新时间均不作过滤。缺失特征留空，布尔缺失不会写成 `false`。

导出检查：8,601 行训练数据的 26 列无缺失，日期与股票代码组合无重复；`signal_return` 都在 3%–6%，五分钟最高价目标不超过十分钟最高价目标。训练文件只保留标识、19 个特征列和 3 个目标列；14:50 买价、次晨原始价格、T 日最终涨跌停等审计字段仅在候选文件，不会混入训练列。候选中有 8,829 行特征完整、8,959 行次晨标签完整，其余行的缺口可由完整性字段直接定位。

## 三个次晨目标

`entry_1450` 为 T 日 14:50 分钟价的假设买入价，属于标签侧，不参与 14:40 候选或特征计算。目标均相对它计算：

1. `target_next_open_return`：T+1 首根 09:31 分钟 K 的开盘价 ÷ `entry_1450` − 1。
2. `target_next_high5_return`：T+1 09:31–09:35 的最高价 ÷ `entry_1450` − 1。
3. `target_next_high10_return`：T+1 09:31–09:40 的最高价 ÷ `entry_1450` − 1。

前五/十分钟取最高价，是为对应高于买价 1% 的限价卖单是否曾触及；分钟最高价不能证明真实订单成交，目标也未扣成本和滑点。`t_final_limit_flag` 是 T 日收盘后状态，只供事后核查，不能作为 14:40 模型特征或筛选条件。`execution_feasible_1440.csv` 的 14:50 执行门槛同样不决定训练样本。
