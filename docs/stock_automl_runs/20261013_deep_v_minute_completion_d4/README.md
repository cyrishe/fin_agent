# D4：深 V 滚动窗口分钟 K 的 API 补库

执行时间：2026-10-13 15:32–16:11（北京时间）。本次只修复深 V 研究的分钟数据，不重新训练模型。范围为 2026-08-05 至 10-12 的 43 个交易日、沪深 `0/3/6` 字头且日线成交量大于零的股票日。`kcrp_stock_price` 的这一范围共有 **223,896** 个有成交股票日。

## 来源和写入规则

使用仓库已有的 Upchina `kLineData` 一分钟接口（`eLineType=1`）。按 API 返回的原始日期、分钟时刻寻址；只有一个股票日凑齐交易时段的 **240 个不同分钟**、OHLC/成交量检查通过，才写入 `kingdomai.aiia_stock_realtime_minute_snapshot_full`。使用原有 `upchina_kline_1m`、`historical_backfill` 入库口径。数据库主键冲突时只做同值 `stk_code` 更新，保留原有分钟记录的行情值；停牌或日线零成交日不造 K。写入后按日重新汇总最终、非回退、源时间等于分钟结束时间的 240 根记录。

先对旧 D3 的 `direct_prior` Top20 中 24 个原先不完整股票日补缺：17 个有成交股票日从 API 取到完整 240 根并补入 **3,841** 根；4 个已经由此前 A2 补库完整；3 个日线零成交。该 24 个原有候选目前不再有“有成交但分钟不完整”的股票日。

然后按全部有成交股票逐日扫描并补库：8 月 10 日至 10 月 12 日的 **40 个交易日**全部回读达到当日有成交股票日全覆盖。批量日志有 **5,260** 个成功写入或保留的目标股票日；按写入前缺少的时点数计算，新增约 **815,494** 根。8 月 5–7 日另补齐 8 个股票日、**1,920** 根。加上候选先行补入，本轮按日志计约新增 **821,255** 根；原有 K 的价格字段未覆盖。确定性抽取 100 个批量补录股票日，对比新库 15:00 分钟收盘价与日线收盘价，差异超过 0.011 元的为 **0**。

**最终覆盖**：43 日的 223,896 个有成交股票日中，**223,894** 个达到完整 240 根。仅 `688816` 在 **2026-08-05、2026-08-06** 两天仍缺整日一分钟数据。当前接口对该股 `shtStartxh=9997,shtWantNum=1` 最早返回 8 月 7 日 10:53；`9998` 返回空，无法从现有接口取得这两天的完整分钟线。它们应继续作为标签未知，不能作为非深 V 样本。

数据库同时存有 API 补录前的分钟记录，供应商历史 K 与原始采集在部分重叠分钟可能不同；本次只补缺失时点，没有重写旧值。**D3 的标签缓存、模型及 51 个 Top20 深 V 计数仍是本次补库前的快照，不能视为 D4 数据版本的模型结果。**下次建模须重新构建标签和 T−20 滚动窗口，并固定新的读取时间与输入文件。
