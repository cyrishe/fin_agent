# 固定三日冷静期再涨停：R3

2026-10-14 口径纠偏。此前 R2 的 `max_cooling=3` 表示**最多观察三个未封板日、每天都可决策**，并非固定三日冷静期。R2 的“次日”从每行 `asof_date` 起算；若板后第 1 日未封板、第 2 日封板，第 1 日决策行的次日标签即为 1。这类事件不会产生该轮的第 2、3 个冷静日决策行。板后固定三日行情窗可能包含再封板日，因此不能把窗口内每一天都称为冷静日。固定窗口的每日最低/收盘涨幅以**该日昨收**为基准，才可与当日封板标记直接核对。

本实验 R3 从 R2 的两年面板中**仅保留 `cooling_day=3`**：原连板结束后连续三个市场交易日都存在该股行情且均未收盘封板，第 3 日收盘决策。目标 `label_next3_any_limit_up` 从决策后第 1～3 个市场交易日计算，即原连板后的第 4～6 日。原板后第 2 日已再次封板的事件不属于 R3 的候选池。每个原涨停事件在 R3 至多一条决策样本。逐日最低/收盘涨幅以各日昨收为基准。

沿用 R2 选出的 31 个基础特征及浅层 `HistGradientBoostingClassifier` 配置，**只在固定三日样本上重拟**。本次没有重新比较八种模型，因而是固定模型的口径对照，并非新一轮择优结果。按时间切分，边界留出目标长度对应的市场交易日；同一事件不得跨训练/验证、重训/测试。训练集拟合内评分；验证集由训练模型评分；测试集由截至验证期的可用样本重训后评分。依赖为 scikit-learn `1.7.1`。

测试集同日均匀随机取三只的期望命中数为 23.54；实际 47 次约为期望的 2.00 倍。R2 混合冷静第 1～3 日的每日 Top 3 测试命中为 63/198，**样本池、训练输入和决策时点均不同，不应视为 R3 的性能**。R3 仍是已经查看历史区间后的回溯实验，不是完全盲态前瞻测试，且未检验可买性与交易收益。

证据位于本地 `outputs/stock_automl/limit_rebound_fixed3_20261014/`：`summary.json`、三个 `Top3_*.tsv` 及逐样本 Excel。生成脚本为 `outputs/stock_automl/limit_rebound_three_day_audit_20261014/run_fixed3.py`。脚本逐行校验：决策日恰为原连板结束后的第三个市场交易日、前三天均未封板、未来三日逐日封板标记的或值等于目标标签。原始日线截至 2026-10-13，来自 `kingdomai.kcrp_stock_price`；压缩特征和标签文件的 SHA-256 见 `summary.json`。测试集有 1 条再板连板仍延续至源数据截止日，完整连板数与断板日结果留空。
