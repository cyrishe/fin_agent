2026-10-23。只读服务器 R90 冻结面板、交易、源质量回执及正式代码快照；补充计数在服务器研究目录执行。没有改正式定义、模型、生产数据库或调度。[新计数](market_data_exposure_r93.json)、[计数脚本](../audit_market_data_r93.py)、[R90 回测](../README.md)、[R91 时序审计](../audit_r91/README.md)可复核。

哈希核对证明所用分钟文件与原始档一致，不能证明原始档的 OHLC 完整或真实成交可行。R91 独立重算复现 R90 的 690 笔影子信号与 295 笔主账户，证明的是**既定输入下的执行链条**，没有修复上述源数据和时点问题。正式 V2 截至本次审计仍按 D2 日线收盘做模拟结算；上午 7% 卖法是研究情景。

对当前 2026 模型，改革前创业板 10% 的历史代码缺陷不会进入最近六个月训练窗口；但它会影响把通用代码直接用于 2020 年以前的重训／回测。R90／R92 的旧年模型采用了研究版日期补丁，不能把它们称为正式通用代码原样运行的结果。分钟源和跌停卖出问题没有被“修好”；在解决前，不应把 2018—2021 连续账户的精确收益作为版本优劣的定论。
