需求理解 · 草案

筛出靠近 EMA20、没有明显放量的股票

  1. 距离：收盘价与 EMA20 的绝对偏离 ≤ 2%。
  2. 量能：当日成交量 ÷ 此前 5 个交易日均量 ≤ 1.5；均量不含当天。
  3. 结果：给出是否符合、两个指标值和原因；数据不足单独说明。

建议按收盘后计算。先做筛选，不包含买卖、仓位或收益承诺。
