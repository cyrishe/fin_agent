本版本冻结已验证的 DSH 目录生命周期修复、日 K / 分钟有界读取、交易日历序号兼容、三个月优先扫描与稳定并列排序。保留 CC 路径与公共工具协议，不纳入其他前端/工具开发工作区改动。

## 发布前复核

- 窗口数据层最终17组对照一致。135个相关 Python 测试与24个 DSH loop 测试通过。
- 原研报集完整184题。旧报告首跑180成功、4失败；重跑后184完成。入口覆盖169/184并非准确率。27道最终空结果不自动判错。
- 旧 SQL 复核指出 RTEF164（statement_type 中文枚举冲突）和 RTEF194（额外时间窗）异常；未找到已收口的同题证据，列入 MCP pilot。RTEF194旧核验同时显示指定公司+机构本来就无研报，不能仅据额外时间窗推断一定漏数。
- 旧67题子集仍有3道混合题把 stock.news 列为必需入口。新评测保留问题与原标注，当前数据库能力的入口覆盖剔除已退役 news，并明确这只是覆盖指标，不是答案正确率。
- BUS005 名称包含失败恢复、BUS012 分钟口径、BUS085 指数排名覆盖是已 review 的未收口项。它们不是这轮扫描优化已经解决的问题。
- 原始明细统一交易日窗口、2025及更早日历、债券/板块及其他企业视图的真实性能验收仍未完成。

## MCP 回归口径

复用原67题及增量117题，全部走 finance_data_query 的 MCP HTTP 入口；runtime=dsh、标准 Opt、response_mode=data，不传 conversation_id。每次独立查询，返回各数据集真实行数、schema与前2条，不生成 summary。使用服务器现有 Aliyun 模型和远端数据库。

从提交版本创建隔离源码快照，临时只监听 loopback 的真实 HTTP 服务；临时 key 仅存内存，关闭进程即失效，不改线上 key 和服务。关闭测试请求计数写入，其他金融执行路径不变。

先人工检查6题 pilot，再跑剩余题；并发3，不自动重跑计费请求。传输错误、意外 summary、单题超过120秒或完成至少10题后失败超过20%时停止投放，保存已在途结果。

评测报告独立列出请求完成、耗时、Token、所选数据、数据集条数/样例、入口覆盖和待复核项。不把数据为空、HTTP200、同入口或旧报告重跑成功视为真实性证明。
