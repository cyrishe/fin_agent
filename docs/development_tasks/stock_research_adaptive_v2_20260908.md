# 自适应个股研究 Skill：方法增强与验收

## 本轮交付

增强现有系统 Skill `stock-research`，保留身份、catalog 路径、显式 `$stock-research` 入口及原有快速/智能/深度模式。改动属于**业务 SOFT**：没有新建 Agent、执行状态、业务 validator、Output Schema 或数据库结构。

现有内容已经覆盖行业原型、基本面、估值、反证和深度报告。本轮不重建同名功能，重点补足“证据改变路径”和“多个专业方法共同贡献一次研究”的操作指导。

当前有 9 份渐进参考，其中新增：

- `references/adaptive-paths.md`：新证据支持/反驳什么，下一步查哪里，何时转向或停止。
- `references/method-composition.md`：个股与研报、估值、财务、同业等方法的组合与回收。

另外增强公司原型、热度/预期差、证据政策；同步 catalog 描述和 UI 提示。原有评分、个性化和报告模板继续复用，不在系统层固定行业规则。

## 有层级，但不是固定调用树

```text
用户问题 / $stock-research
└─ stock-research：研究目标、最小证据、主命题与综合
   ├─ 内部子方法：行业原型、证据选路、催化/预期、证据政策等
   ├─ 按需专业分支（同一个 Finance Agent 选择）
   │  ├─ equity-report-analysis → 按需研报子方法
   │  ├─ stock-comparison / valuation-analysis
   │  └─ 财务质量 / 财报 / 行业 / 技术 / 分红方法
   └─ 授权数据工具 → 新证据 → 保持、修订或收束研究方向
```

这是方法职责的层级，不是新的机器协议。多个注册 Skill 在 Runtime 中仍是并列、独立授权的方法。由 Finance Agent 统一读取和取证，不假装某个 Skill 会自行启动子会话、等待固定 JSON 或给其他 Skill 授权。每份内部参考直接在主入口可发现，无深层文件链。

纯研报问题可由研报 Skill 主导，纯比较可由比较 Skill 主导，单字段问题可直接取数；不会为了“使用个股 Skill”强制绕行综合研究。综合问题中的某个专业判断不足时，才增加相应分支。

## 外部研究依据及本地化取舍

以下是本轮查阅的一手方法来源，不是把外部文章全文塞入运行上下文。动态路径和热度组合表是本项目的设计推导，不声称来源提供了同样的 Agent 流程。

| 来源 | 借鉴内容 | 在本项目中的落地 |
| --- | --- | --- |
| [CFA：行业与竞争分析](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/industry-and-competitive-analysis) | 行业边界、行业与公司因素的区别、竞争位置 | 用业务与分部识别赛道；行业标签仅帮助寻找候选，不直接决定比较对象和结论 |
| [HBS：Porter 五力](https://www.isc.hbs.edu/strategy/business-strategy/Pages/the-five-forces.aspx) | 价值如何在产业参与者间分配，供需及议价关系如何变化 | 分析公司对客户、供应商、替代品及新增供给的暴露，不把五力变成五个必填章节 |
| [CFA：公司预测](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/company-analysis-forecasting) | 预测对象与方法取决于信息、业务和周期；经营驱动需与财务一致 | 查询结果决定下一项证据，连接收入、利润、营运资本和再投资；不要求缺乏数据时硬造预测 |
| [Damodaran：年轻与成长企业](https://pages.stern.nyu.edu/~adamodar/pdfiles/papers/younggrowth.pdf) | 历史有限、现金流不确定及失败风险影响估值 | 高增长与亏损公司优先商业化、可达利润、融资和生存，不用负 PE 或默认利润率做精确估值 |
| [Damodaran：周期与商品企业](https://pages.stern.nyu.edu/~adamodar/pdfiles/papers/commodity.pdf) | 价格波动影响盈利与资本，估值需考虑归一化 | 单期低 PE 转向跨周期盈利与成本暴露，避免峰值利润永续化 |
| [Morningstar：竞争优势来源](https://global.morningstar.com/en-eu/stocks/how-measure-companys-competitive-advantage) | 成本、无形资产、网络、转换成本、有效规模与持续优势 | 作为候选解释，用直接经营证据验证；品牌名不等于护城河，不冒充官方评级 |
| [McKinsey：公司金融原则](https://www.mckinsey.com/capabilities/strategy-and-corporate-finance/our-insights/the-ceos-guide-to-corporate-finance) | 增长与资本回报共同影响价值，股价也反映预期变化 | 分开“好公司、好价格、热门”，围绕预期兑现与失败条件组织分析 |

已有银行专属研究指导继续保留；本轮没有复制额外完整估值模型，也没有添加无法执行的计算工具。

## 灵活性的具体体现

### 四个可交叉的研究维度

1. **经济模型与赛道**：公司实际销售什么、向谁收费、收入与利润来自哪里。AI、新能源、出海等可能跨行业，需要看经营暴露。
2. **发展阶段与资本约束**：商业化、扩张、成熟、周期修复或困境，不由一项增长率机械分类。
3. **市场预期与关注**：用户感知、热点记录、研报覆盖和行情活跃度分别解释；缺数据不是冷门，热度也不是公司质量。
4. **证据与任务**：用户要判断什么，当前资料能支持什么，哪项新信息会改变判断。

没有为这些维度增加系统枚举、综合评分或固定阈值。主入口仍先用少量证据，不把“灵活”理解为无限追加查询。

### 行业方法

保留并加强八类经济模型：消费与渠道；银行/保险/券商；周期资源；制造设备；半导体/软件/平台；医药医疗；公用事业/地产/运营资产；多元集团与困境。

进一步区分：新能源材料/设备/整车、AI设备供应方/采购方/应用、订阅软件/项目软件、成熟药企/创新管线/CXO/医疗服务、地产开发/收租资产。跨行业公司按分部解释，不能因为同处热门赛道就统一倍数。

### 中途应变举例

| 初始问题 | 新证据 | 合理转向 |
| --- | --- | --- |
| 成长性如何 | 利润增长但回款恶化 | 先核实现金与营运资本；可能是正常季节性，也可能改变增长判断 |
| 市盈率低是否便宜 | 盈利依赖周期高价 | 从当期倍数转向中周期盈利、成本与负债韧性 |
| AI核心受益者吗 | 相关收入很少且尚未量产 | 从成长兑现转向商业化里程碑，不继续按概念写增长故事 |
| 机构判断变了吗 | 同机构报告明确提供旧值与新值 | 组合研报修订方法，区分预测变化与评级维持 |
| 同业谁更好 | 业务和资本结构不相同 | 先解释不可比项，以共同决策维度比较，而非统一PE排队 |
| 公司前景如何 | 研报零行但经营数据有效 | 保留经营分析，机构预期列缺口，不中止全部研究 |

路径可以收缩：疑点已被可信证据解释，就停止相应排查；新证据否定初始行业假设，就替换主方法而非保留两个矛盾叙事。

## 与现有数据能力的对应

下表是开发核对，不复制进 Skill 当成长期字段协议；运行时必须读取当前目录。**目录存在不代表某家公司有完整数据。**

| 当前代码中的能力 | 可以支撑的研究 | 尚不能直接推定 |
| --- | --- | --- |
| `stock.basic_info`、行业/板块成分 | 证券身份、行业候选、可比对象发现 | 标签证明竞争优势或业务受益 |
| `stock.business_segment` | 产品/地区/业务收入成本利润、前五客户供应商 | 精确订单、客户真实身份、完整产业链图谱 |
| `stock.financial_3_table`、`performance_notice` | 多期财务、现金、存货、应收及业绩变化 | 所有行业专属指标均有覆盖，或缺失 ROIC 可直接编造 |
| `stock.quote`、`pricevalue`、`corporate_action` | 价格、历史估值、复权与公司行为 | 已证明价格因果、已完成内在价值测算 |
| `stock.report`、`report_metric` 及聚合 | 机构观点、投资要点、风险、预测与时点 | 已读取全文、已有正式一致预期、全部机构名称已归一 |
| `hot_event` 及可用行情/资金数据 | 热点关系、活跃度与价格行为线索 | 完整情绪/持仓/拥挤度，或零行即无关注 |
| `shareholder`、`pledge`、公司行动 | 股权、质押、分红或融资的局部证据 | 全部治理事件、债务契约和管理层质量已覆盖 |

银行净息差/监管资本、软件 ARR/留存、临床成功概率、成本曲线、库存覆盖天数等需求，不能仅因方法提到就假定有字段。没有授权且可靠的资料则限定结论；只有摘要时不宣称看过正文。

当前 DSH 桥暴露金融目录、查询、结果读取及 Skill/参考读取，不提供通用开放 Web 工具。Skill 保留原来的能力声明但不能越权；运行时不能因此幻想能上网。默认 DSH 查询预算仍为 3 次，足够与否需实测；本轮不擅自提高预算。复杂报告预算耗尽时应交付已证实部分与缺口。

## 产品表达

使用现有进度通道，用简短自然语言说明研究方向的重要变化，例如“回款弱于利润，接下来核实现金质量”。这只是行为指导，**本轮没有新增前端组件，也没有证明现有界面已展示这种语义进度**。

最终报告回答一个统一问题，不拼接多个 Skill 报告。先展示判断、最重要证据、反证和限制，再按深度渐进展开；用户关心“为什么结论改变”时，可以解释新增事实如何改变判断，不展示内部思维链。

## 行为评测资产与下一轮

新增 `tests/evals/stock_research_adaptive_v2.json`：

- **13 道自然问题**：消费、银行、周期、热门、低关注、医药、同业、跨赛道、研报组合、深度报告、快速与直接入口边界。
- **3 组成对证据 / 6 个变体**：同题仅改变现金质量、业务暴露或研报可用性，验证模型是否真的随结果改选方法。明确标为虚构测试材料，不能当真实金融数据。
- 问题、原始证据与 reviewer 标准分开，评审标准不传给被测模型。这是新增待执行资产，当前没有冒充已被现有真实回放脚本执行。

建议分别观测：自然入口选择；真实读取的主方法/子方法；查询API、返回量与实际阅读范围；新证据后的转向或收束；结论回指、反证与数据缺口；token、延迟和调用数。未触达、工具错误、缺数据与业务效果不佳要分开记，不混成一个“失败率”。

人工业务复核每项可用 0/1/2（错误或未体现/部分/充分）记录：行业适配、证据应变、组合必要性、事实与时点、结论与反证、效率。分项附证据，不汇总成金融投资分数；凭据错误等运行阻塞记未评而不是 0 分。

在有效配置环境先跑银行、热门科技和安琪研报组合三题；再跑三组成对证据。比较旧版、新版与无 Skill 时固定模型、参数、授权工具、问题、数据快照和预算，只改变方法文本/可见性。命中不是专业增益的充分条件，必须读最终结果和转向证据再下结论。
