## 三道原题与评审锚点

### 1. 贵州茅台：共识与分歧

> 请比较2026年6月8日至9月8日各机构对贵州茅台的研报观点：主要共识和分歧是什么？分歧来自增长预期、渠道判断还是估值假设？请说明实际覆盖的报告与机构范围，并给出来源。

真实材料包含中银国际调整盈利预测、群益“TRADING BUY 区间操作”、多家机构关于 i 茅台/直营化改革的报告，适合对照。检查：是否自主加载研报 Skill，是否按需读取共识方法；区分同机构新旧报告、原始机构别名和不同评级体系；用可读内容支持分歧归因，而非看见数字不同便臆造假设差异。

### 2. 安琪酵母：糖蜜涨价传导

> 如果糖蜜采购价格上涨10%，会怎样影响安琪酵母的利润？请结合2026年6月8日至9月8日的机构研究，分析水解糖替代、库存和提价能否缓冲；如果资料没有量化测算，不要硬给利润变化比例。

ID 32045（太平洋）明确提到水解糖技术及糖蜜储罐；ID 31531（中邮）提到低位糖蜜成本、水解糖替代和海运/汇兑扰动。检查：事件方法是否进入执行；把“涨价 10%”识别为假设，不说成已发生；区分储罐能力、实际库存覆盖天数和提价证据；关键系数不全时不给虚构利润弹性。本题显式提示了不硬算，因此即使未来回答遵守，也不能单凭此项证明 Skill 的增量作用。

### 3. 安琪酵母：盈利预测修订

> 2026年6月8日至9月8日，机构是否调整了安琪酵母的盈利预测？请找出明确的上调或下调及原因，区分同一家机构的预测修订和不同机构之间的分歧，解释为什么下调盈利预测仍可能维持买入评级。

可直接核对的报告记载（不是对未来利润的保证）：

- ID 31466，开源：2026/2027 年归母净利润由 19.7/24.1 亿元下调至 18.3/22.5 亿元，理由包括海外短期扰动及汇兑损失，维持买入。
- ID 31407，东吴：2026–2028 年归母净利润从 18.23/20.80/23.60 亿元调整至 18.26/21.74/25.08 亿元，维持买入。
- ID 31480，群益：维持 2026–2028 年预测 17.4/19.9/23 亿元。跨机构差额不能当成时间上的下调。

检查：按需使用修订方法；直接引用报告内前值可作为证据，不强求两篇历史报告；分开预测修订、评级维持与跨机构分歧。上述锚点来自人工读取库中投资要点，**不是 Agent 已经输出的答案**。
