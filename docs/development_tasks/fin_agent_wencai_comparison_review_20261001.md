# Fin Agent 与同花顺问财：30 题前端对比复核

日期：2026-10-01。测试截止时点主要为 2026-09-30。本文件只整理已完成的前端对比，不修改产品代码、数据或测试结果。

## 结论与可信边界

30 个问题曾在两个产品的前端各运行一次，并保存原始回答。本地原始记录位于 `outputs/019f9dcc-ed09-7131-9b9c-838f451b71d5/compare30/`；该目录被 Git 忽略，**不属于本次推送的远端证据**。问题由测试者设计，其中不少要求明确的时间窗、复权口径和证据边界，更贴近 Fin Agent 的设计目标；没有随机抽样、盲评、完整独立标准答案或重复运行。因此，这是一组定性诊断样本，不是市场份额、准确率或产品总体胜率评测。

原表的主观“胜出”标签约为 Fin Agent 23 题、问财 4 题、其余 3 题。这个计数混合了答题完成、解释充分、事实正确、来源质量和展示体验，且对 Fin Agent 的过程透明度赋权过高。**撤回“Fin Agent 明显胜出”的概括；不从该计数推导客观胜率。**尤其 C21、C26、C28 虽曾被记为 Fin 相对占优，分别存在无效整月窗口、证券代码硬错误、重要现金流风险遗漏。C25 两边都未完成；问财会员限制属于本次访问条件，不等于其能力缺失。响应时长也未采用两边同口径端到端计时，不作速度排名。

相对可靠的定性判断：Fin Agent 在同源财务比较、复权与交易口径、事实和推断分离方面表现较好；问财在公开经营指标、事件覆盖、可行动的研究线索和短表格展示方面有明显可借鉴之处。两边均有会直接影响金融结论的错误，不能以“回答很长”或“回答很快”代替正确性。

## 最值得补的能力

1. **公开数据的可达性，而非笼统“加数据”**：中芯季度经营指标、比亚迪月度产销、公司公告／行业政策原文、概念成分及板块历史。先用具体案例区分源头无数据、未入库、目录未暴露、检索未命中或 Agent 未发现。渠道批价、机构预测等非公司披露材料则应另标来源等级，不把问财能给出的二手数字直接当真值。
2. **分析方法的最小闭环**：问题所需交易日与截止时点、同一窗口和同一比较对象；财报事实／预测／推断分层；公司研究中主动核对利润、经营现金流、资本开支和可推翻判断的事实。C19、C21、C28、C29 是优先复盘样本。
3. **交互与可靠完成**：借鉴问财短表格和行动性线索；Fin 首屏先给结论、关键数字和不确定性，细节可展开。复杂查询要能给出完成结果或清楚的业务级失败说明，不直接泄漏模型／编排异常。避免为了“专业”无限延长取证链。

按仓库原则，上述是数据接入、业务 Skill／Agent 判断和展示问题的候选方向，不是新增状态机、通用 validator 或提示词规则的授权。未复现根因前，不按单一案例堆叠协议字段。

## 下一轮如何公平评测

先固定题目、日期、账户权限、产品版本和真实端到端计时。由公司公告、交易所日历等独立材料建立逐题事实锚点；盲评“完成、事实正确、需求覆盖、来源质量、交互成本”，把会员限制、生成失败、数据缺口分开记。每题重复运行，再按基本面、技术、事件和筛选分别报告，而不是仅报一个总胜率。当前报告不能用于生产放行或证明总体产品优劣。
