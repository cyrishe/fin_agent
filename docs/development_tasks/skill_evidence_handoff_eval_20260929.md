# 个股分析：冻结证据的阶段交接对照

本记录对应 [框架调研与设计](skill_execution_framework_research_20260929.md)，基于 [原始真实调用测试](stock_technical_live_case_20260929.md)。本次验证的是已保存证据进入综合分析的边界，不是线上完整调度器。

## 方法

使用同一问题、同一批真实查询结果、相同已选 Skill 正文及当时读取的 references、相同字段定义、同一模型 `BL/deepseek-v4.1-flash`、相同推理档位 low 和输出上限 16384。每组由现有 DSH SDK 启动一个全新会话；禁用所有执行工具，不再读取市场接口。三组顺序运行，计时含启动和模型响应，不代表纯模型服务耗时。

原问题：分析平安银行最近一个月是走强、走弱还是震荡，结合量价和技术面找出关键变化与反证，具体指标由系统选择，不逐项罗列指标，以最新可用完整交易日为准。

三组：

1. `envelopes`：工具结果原始结构与完整数据，包括请求、返回 schema/sample/rows 等。
2. `handoff`：程序整理的证据包。保留所有行和值，以列名加行数组降低重复键开销；保留引用、哈希、实际日期和行数、provider evidence 与 warnings；移除请求执行结构。
3. `handoff_calculated`：第二组加程序计算的区间收益、最高最低比幅和两融余额变化，保留输入引用、实际窗口、公式与数值。

注意这是三种“综合输入”的对照。原始端到端运行的 8 次 LLM 调用、工具 schema、目录发现和中间推理没有原样重演。不能把这里的单次综合耗时直接和原始整轮 148 秒相除，声称全链路提速。第一、二组的差异同时包含组织形式和系统明确提供覆盖范围，不能把效果完全归因于 token 减少。第三组计算计划由 [评测用例](../../tests/evals/stock_skill_handoff_v1.json) 指定，尚未验证模型自主生成计算计划。

本次不是稀疏摘要：10 份结果合计 184 行全部保留，未删除不利证据、未用模型摘要替代原始数据。全量反向还原一致，见 [投影复核](../../outputs/skill_evidence_handoff_20260929_r2/projection_verification.json)。修正准备脚本后的输入字符数分别为 92528、32159、34546；字符数不是 token 数。

## 复核标准

人工逐项检查实际覆盖范围、ATR口径、算术与时间对齐、是否从一个快照推导连续变化、反证是否充分、是否遵守用户的输出要求。机械断言只检查数据与执行事实，不以关键词命中代替业务验收，也不要求固定章节或固定金融判断。

在原始结果组中，模型虽正确写出 ATR/价格，但仍把低带宽解释为“区间收敛”，并出现成交量单位混写。进一步查看目录发现 `stock.quote.volumn` 明确说明日 K 为股，实时快照的同名字段却缺乏同等清晰的单位说明；provider 当前直接映射原始 `lVolume`。这是数据口径表达的真实缺口，阶段隔离本身无法补足。此发现未通过修改输入或生产契约来美化本轮实验。

## 结果

### 先导运行（保留，不能冒充最终复测）

准备脚本初版对同一API重复查询的字段说明采用覆盖，导致日K的部分字段说明被快照字段列表覆盖。该问题对三个组一致存在，后来修正为并集，补充测试并另开目录重跑。先导运行完整保留，见 [汇总](../../outputs/skill_evidence_handoff_20260929/run_summary.json)。

| 输入 | 模型输入token（含缓存） | 输出token | 耗时 | 结果 |
|---|---:|---:|---:|---|
| 原始工具结构 | 36535 | 14704 | 160.68s | completed |
| 证据交接 | 16677 | 11118 | 133.07s | completed |
| 交接＋计算 | 17667 | 16384 | 172.17s | max-tokens，无正文 |

原始组仍把低带宽解释为持续收敛；交接组减少了部分资金意图的过强推断，但仍写“均线走平”“波动未扩张”等无指标历史支持的变化，也加入了未查询交易日历的休市解释。交接＋计算组的全部输出预算被推理消耗，未完成回答。先导结果只支持“可以降低上下文负担”，不能支持“阶段化已解决幻觉”或“提供公式后必然更快”。

| 原始工具结构 | 36629 | 16384 | 168.10s | max-tokens，无正文 |
| 证据交接 | 16771 | 16384 | 162.48s | max-tokens，无正文 |
| 交接＋计算 | 17761 | 14389 | 137.20s | completed |

见 [运行汇总](../../outputs/skill_evidence_handoff_20260929_r2/run_summary.json)、[人工复核](../../outputs/skill_evidence_handoff_20260929_r2/manual_review.json)、[完成的模型原文（含错误）](../../outputs/skill_evidence_handoff_20260929_r2/handoff_calculated_1/answer.md)。每组都是一次模型调用、零工具调用；空回答不计为事实正确。

交接包使输入 token 减少约 **54.2%**。这项减负有实际测量支撑；稳定的耗时改善和业务正确性提升没有通过验证，不能用先导运行的 17% 延迟下降宣传性能收益。

完成的“交接＋计算”组正确使用了所给区间收益、最高最低比幅和两融余额变化，但仍有以下问题：

- 把 9/1 的 152316453 股写为 **15.23 亿股**，应约 **1.52 亿股**；9/3 的 110513439 股写为 **11.05 亿股**，应约 **1.11 亿股**。确定性计算之外的数值单位换算仍出错。
- 技术指标只有单日快照，仍写“MACD转负”，没有变化时点证据。
- 明确区分了行情与指标的截止日期，未再把指标说成45日，但没有充分说明只有一个指标快照的限制。
- 本组未解释 ATR，不能把未出现错误等同于 ATR 口径已经修复。
- 相近的个股/行业区间收益被进一步解释为行业导致回调，因果表达强于证据；价格区间的未复权口径与开头“复权口径”没有充分分开。

## 验收与采用

代码层：9项边界测试通过，10表184行无损还原，引用归属与真实覆盖分离可执行；保留了输入快照和模型执行证据。

业务层：**未通过，不切换线上默认流程。** 两轮共6次模型调用中3次完成、3次耗尽预算；样本仅一个问题、各组一次且先导输入存在准备缺陷，这只是运行事实，不是统计成功率，也不能据此断言计算增加或减少失败概率。

本轮验证的是已取证数据的交接，不是自动规划/并发调度/断点恢复。下一步应分别验证：当前阶段只携带必要方法与已交付的分析成果，减少从头重做；数值换算与显示使用确定性结果；方法准确区分状态与变化；模型与预算配置能否稳定生成正文。保持现有 SOFT/HARD 边界，不对这个案例堆关键词判断，也不要求每步增加一个审核 Agent。
