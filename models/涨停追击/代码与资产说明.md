# 涨停追击代码与资产

本目录记录三模型加 F 风险过滤的试运行研究，策略定义见[策略说明](策略说明.md)。此版本是历史研究归档，尚不是自动取数、实时信号发布或自动交易系统。

- 11 月三模型训练、打分、候选、行情核对和账户回放脚本在 `outputs/最近两周三模型_20261113/`。脚本绑定当时的数据快照及日期；尤其六训二验需要 scikit-learn 1.7.1，每日和每月模型原训练环境为 1.9.1，不可随意混用。
- F 模型逐股评分、开板卖出回放和核验脚本分别是 `scripts/research_three_nov_f_score_20261114.py`、`scripts/research_three_nov_f_replay_20261114.py`、`scripts/verify_three_nov_f_20261114.py`。2026 年两个固定风险模型及阈值保存在 `outputs/三模型全月_20261113/D0预测弱势与撤单_20261114/` 的两个 `F_2026_numpy模型.npz`；阈值来自 2025 年验证，不能当成已校准概率。
- 11 月隔离复跑代码和结果在 `outputs/涨停追击十一月复核_20261115/`；本地可执行 `.venv-automl/bin/python outputs/涨停追击十一月复核_20261115/复跑.py`，校验历史输入的哈希、F 分数和模拟卖出结果。该命令会重写该目录的复核输出。
- 投票和连续落后分析分别在 `outputs/三模型投票分析_20261115/`、`outputs/三模型近期连续落后_20261115/`。这些是过滤前选股研究，不是已确认的 F 过滤后策略。
- 2018—2026 逐月三模型研究的主脚本在 `outputs/三模型全月_20261113/`，F 历史研究脚本在 `scripts/research_three_f_risk_*.py` 等文件。

本次 Git 仅保存相关代码、部分小型模型、11 月关键输入和逐笔结果，以及历史汇总；完整多年分钟、完整训练样本、逐笔行情及账户数据仍在本地 `outputs/` 等研究目录，没有全部纳入 Git。完整训练资产的 KingdomAI 数据库登记和云端独立回读仍待完成；换机器不能只凭本提交宣称完整复现多年研究。

研究中的模拟订单和收益不等于实际委托与成交。真实账户、密码及券商会话不纳入策略仓库。
