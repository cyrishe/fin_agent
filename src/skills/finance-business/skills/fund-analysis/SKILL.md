# 基金分析

## 研究目标

说明这只基金提供什么投资暴露、可观察表现如何、承担哪些风险，以及与用户的比较对象或持有目标有何关系。单项疑问沿最相关的方法完成；综合问题从产品身份和首批证据开始，按发现深化。Finance Agent 持有会话、取证和最终回答，子方法按需加载。

## 默认方法

1. 确认基金身份、份额类别、观察区间和用户问题，复用已有代码与材料。产品类型以可靠身份或披露为准；简称只作定位线索。名称存在多个份额或上市市场、且会改变答案时再澄清。
2. 首先确认当前能获得什么数据，读取 [数据口径](references/data-evidence.md)。取得回答问题需要的行情、净值或用户材料即可，不预设每只基金都有场内价格与完整净值。
3. 选择一个主要判断：表现来源、交易价格相对净值、同类差异或持有风险。明确价格回报与基金资产回报的区别，再决定是否需要另一种方法。
4. 用证据调整路径：价格与净值表现背离时检查折溢价和时间错配；表面低波动伴随稀疏报价时检查交易活跃度；同名基金差异先核对份额、费用和跟踪对象；持仓披露不足时保持暴露判断的边界。
5. 用户要求比较时，按相同时间、份额口径和可比投资目标并列证据；目的不同的基金以风险来源和用途解释取舍。相关信息已能回答问题，或关键判断依赖不可得材料时，给出当前结论及下一核验点。

## 证据与表达

- 当前目录的基金基础与行情能力是起点；实际非空结果才是本次可用证据。经理、持仓、费用、复权净值和申赎机制须来自另行取得的可信披露或用户材料。
- 序列计算与精确派生指标交给当前授权的确定性能力；只有原始单位净值时不包装为含分红再投资总回报，没有同口径基准序列时不生成跟踪误差或超额收益结论。
- 基金资产披露日、净值估值日和交易价格时点分别保留。特别关注跨境市场收盘不同步、份额折算和分红。
- 先给主要判断、适用期间、关键风险与缺口，再给少量比较证据。把已观察表现、产品机制和本轮推断分开。
- 历史表现不等于未来承诺，成交活跃不等于底层资产无风险；现金管理、长期配置或其他持有用途需结合期限、流动性和实际材料解释，不替用户直接交易。
