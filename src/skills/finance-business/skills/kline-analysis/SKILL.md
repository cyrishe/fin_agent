# 个股K线与近期形态解读

## 任务与入口

用户可直接说“看看K线”，也可在个股研究中关注价格走势、突破、反转或近期量价变化，无需点名形态或指标。直接看图以本方法为主；综合个股研究由 `stock-research` 按问题加载本方法，不因提到股票就强制扫描所有形态。仅问一个报价或指标值时直接查询即可。

继承当前证券、分析时点、用户期限和已有证据。用户图表先按可见内容解读；未上传或截图缺失成交、日期、完整结构等重要信息时，主动通过授权数据工具补齐。截图无法辨认证券或周期时先说明可见结构，询问真正影响取数的缺项，不猜股票。

## 主线

1. **确定所看对象**：读取 [输入与时间口径](references/input-and-time.md)，确认证券、周期、图表截止时刻、复权与用户问题。分别确定“要找信号的窗口”和“理解背景、计算指标所需的历史”；用户问最近两周，不等于只取两周数据。
2. **取得最小充分证据**：复用用户图和已有行情，无图则取数。按当前数据目录选择日线、分钟K或分时序列及少量相关指标，不从图像反推精确OHLC，不把分时价格曲线当成蜡烛图。细节以同源数值计算，缺少的数据如实保留。
3. **独立基础解读**：用本轮授权的“K线独立看图与形态复核”工具；其基础分支遵循 `kline-basic-reading`，只传简短任务说明与一张近期图。默认看10根日K、MA5/20/60和成交量，随用户期限调整；图上只保留坐标、图例和范围标记，不重复印量价数值或附计算事实。指标先用充分历史计算再截取，精确统计留给文本综合。
4. **数值判断与保守排弱**：依照 [形态方法](references/method.md) 检查已完成周期，必要条件全部成立才成为实例。按 [强度与选择](references/strength-routing.md) 计算相关程度、位置与后续演变；仅多项都弱且无重要背景时省略专门看图，未知不当弱。普通特征通常并入基础，用户关注或明显反证可提升分析优先级；罕见不等于可靠。
5. **独立选择、逐例解读**：形态选择是独立短上下文调用，只传用户问题、计算背景和实例摘要，不加载主Agent历史或整套形态库。任何候选数量都检查，按用户明确及隐含关注选择0—3个。每个入选只调用一次 [局部分析](references/visual-prompts.md)，只给简短提示、该形态定义和一张图。图中保留主体框、信号日及直到分析截止日的行情，同一数值不同时用图形和数字标签表达；MACD/RSI等副图仅随对应形态添加。复杂结构不典型则说明不足并结束该典型形态的延伸解释；不补选凑数。
6. **文本综合**：主 Agent 按 [综合提示词](references/synthesis.md)，仅接收基础解读、逐形态结果、关键计算事实及信号后的行情，不再接收总览图或重新识别形态。区分历史信号当时的含义和当前演变，合并同一过程，保留反证。引用程序统计，不自行重算；纠正冲突时同步舍弃依赖错误事实的论据。
7. **按需比较环境**：市场相对表现用 `relative-strength-analysis`，行业驱动用 `sector-theme-analysis`。独立取证可并行，共享证券和时点，最终由主 Agent 给一份综合分析。
8. **停止并交付**：无形态命中时直接结合基础解读和计算事实回答。基础分支或其他工具失败时保留已有证据，说明未验证范围，不能把缺数说成“已扫描且没有形态”。

## 实际能力边界

Skill 提供分析方法，不自行赋予数据、图片读取、计算或模型调用权限。先使用本轮真实提供的授权能力；没有图像通道就不能声称看过附件，没有扫描或渲染工具就不能声称运行了形态库或生成了K图。可继续交付已有证据支持的部分，并说明哪部分未验证。正式聊天的“K线独立看图与形态复核”工具覆盖已完成日线；基础看图和局部复核在工具内部隔离执行，最终综合仍由当前主 Agent 完成。分钟图与用户原图的观察须以各自真实可用通道为准，不把日线重绘图当成原图。

可用的日线数值能力见数据目录中的“K线数值形态扫描”和“日线技术指标序列”。前者返回形态命中、后续演变及扫描背景，后者提供同口径历史指标；调用参数与口径以目录为准，保留实际截止日、未知检查数和结果引用。需要看图或形态复核时优先使用“K线独立看图与形态复核”，它已经包含所需取数与数值扫描，不先重复查询这两份数据。只问精确指标/扫描明细才用数据目录。工具未配置或视觉请求失败时，保留数值事实并明确未完成的视觉部分。

精确关系、收益、指标、基准对齐由确定性工具计算；模型负责理解图形背景、证据冲突与业务含义。必要数值条件不成立时，视觉相似不能将其改判成立。工具或图片失败只结束依赖它的分支，不阻止独立证据的分析。

表达精度随证据走：图上未精确标注、同源数据也未给出的价位和指标，只作定性描述，不从像素估算后报精确值。有同口径数据时可引用其数值；变化、极值和跨期比较须有对应序列或计算结果，单点数值只能说明当时状态。

## 表达

较完整回答用 `## 当前结构 {#technical}`、`## 形态与演变 {#patterns}`、`## 后续观察 {#watchlist}` 等实际需要的二级章节。基础图和局部图引用工具给出的 figure id，分别放在对应解读附近；图注标明所观察的证券、期间及形态。对尚未完成视觉复核的图，只说明同源行情与计算结果，不称为视觉确认。原始扫描清单留在参考区。

首段给当前走势判断、最值得注意的变化、最强反证及数据截止时点。按需要展示原图/重绘图和简短时间线，区分用户原图与补取行情；历史形态带日期、周期和后续表现。只展示影响结论的形态及指标，不铺满扫描清单。

结尾给可观察的延续、震荡、失效条件。形态成立不是收益保证；不把相对强弱叫作独立确认的多份证据，不编造资金主体、胜率或精确目标价。事实与条件推断分别表达；读图或模型判断与数值冲突时明确保留冲突，不替任一方掩饰。
