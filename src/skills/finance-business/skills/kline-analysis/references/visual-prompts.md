# 基础与单实例视觉调用

基础分支独立使用 `kline-basic-reading`：简短任务说明加一张近期K线/成交量图，默认10根、叠加MA5/20/60。仅保留坐标、图例和范围标记，不叠加量价数字、不附计算事实段落，不带候选形态。

正常数值链路使用 [单实例分析](pattern-analysis.md)：简短任务说明、单个形态定义、一张图。图保留信号前背景和完整主体，并画到本次分析截止日，框选主体、标记信号日及其后行情。图上保留证券、日期、图例与范围框，不重复打印图形已经表示的数值；不附逐日OHLC、程度分数或文字版后续事实。只有MACD/RSI等对应形态才增加相关副图。

数值真值由程序确定。复杂结构的典型程度可由视觉解释；不典型则说明不足并停止该典型形态的延伸。不另开视觉请求重查开收、包含或小数比较。

原 [视觉判断](visual-qualification.md) 与 [条件解读](visual-interpretation.md) 仅供历史复现、纯截图或隔离反例实验；正常完整数值流程不再双调用。截图数值未知时不能伪称程序确认，按可见结构解释并补数。

绘图和计算事实只从同一份冻结行情/指标序列派生，按日期定位，不手填第二份数据。视觉分支负责定性解读；最终主Agent仅接收日期、计算事实和单实例结果，按 [综合提示](synthesis.md) 输出。请求、输出、图和usage完整留证据，失败不补选。正式聊天通过授权的“K线独立看图与形态复核”工具执行同一证据流程；完整图像保存在本轮参考数据中，主 Agent 只接收文本证据。
