# 按业务问题使用形态

形态首先要帮助回答一个具体问题：短线节奏是否改变、中期趋势是否切换、反转是否仍停留在迹象、关键区间是否被突破、回撤是否在收缩。出现次数用于发现过宽规则，不作为保留、删除或重要性排序的充分理由。重要性来自对当前判断的增量信息；同一段价格衍生的多个指标不相互充当独立验证。

## 时间尺度与交叉

用户关注几天的节奏时，5/10、10/20日交叉可作为基础背景；关注数周至数月趋势时，20/60日组合更匹配。50/200日描述更长周期，不用它替代最近两周分析。默认特殊目录新增20/60日交叉的确认变体：交叉后保持3根完整日K、20日线同向倾斜、确认日收盘在两线同向一侧。它晚两个交易日才成立，可能漏掉或追不上快速行情；成交量和长均线方向用于解读，不额外堆成必须同时成立的门槛。交叉当日可以描述“刚交叉”，不能提前说满足3日确认。

MACD保留12/26/9口径。金叉发生在零轴下可表示下行动量修复，零轴上可表示顺势动量重启；死叉对称解释，但必须结合实际价格。零轴穿越、DIF/DEA交叉、同号柱收敛是不同事件。小幅反复穿越不宜作强判断；用程序提供的幅度事实说明程度，不通过无限加大周期制造稀有信号。

## 形状、位置、力度、后续确认

| 家族 | 成立后真正能说明的事 | 进一步解读与边界 |
|---|---|---|
| 吞没、刺透、乌云、启明星/黄昏星 | 特定区间内收盘力量转向 | 看此前移动幅度、实体相对常态、收复深度、量能和后续越过/守住边界；不能仅凭名称宣称趋势反转。跳空贡献与日内实体贡献要分清。 |
| 锤头、倒锤、吊颈、射击之星 | 价格在单日某一侧被收回 | 此前方向决定名称；长影和小实体不证明重要顶部/底部。程序给出振幅/ATR，细小波动不包装成强信号；后续是否越过高点或跌破低点另看。 |
| 孕线、十字、小实体双影、镊子 | 收缩、犹豫或邻近价位的重复试探 | 通常是背景或待观察结构。与关键位置、母线边界及之后突破结合才有方向；普通几何不硬加放量、超买等条件改变其原意。 |
| 红三兵/黑三兵 | 多日同向实体推进 | 看此前是否已过度延伸、末端影和实体是否衰减；连续推进不是低风险追价许可。 |
| 三阴不破阳/三阳不破阴 | 首根极值暂时守住 | 只有四根，不包含第五根突破；不得表述为上升/下降三法已确认。 |
| 上升/下降三法 | 原方向推进、收缩、再突破 | 首尾长实体，中段小实体；本库要求中段反色，是严格变体。后续回到整理区会削弱延续判断。 |
| 一阳吞三阴、三明治 | 连续收盘变化或同一价格区域被再试探 | 一阳吞三阴必须先有三阴收盘递降；三明治有此前下跌但仍欠向上价格确认。三根颜色排列本身不能识别吸筹/出货。 |
| 内包线后突破 | 母线区间压缩后出现收盘越界 | 保持几何定义，突破距离/ATR、母线规模、量能决定力度；缩量不会把已发生的价格突破改成没发生。 |
| 缩量回踩MA20、放量跌破MA20 | 从线上靠近并守住，或价格自身下穿且参与增强 | 回踩要有靠近过程，持续贴线不同；跌破看收盘自身是否下降，区分均线移动造成的换位。均线不是保证有效的支撑。 |
| 局部W/M（双底/双顶结构） | 两个已确认摆动极值及中间颈线被突破 | 当前是5–60根间隔的局部变体，几天形成的结构不能说成数月级反转；此前趋势决定是整理后的延续还是反转候选。只找最近相邻两极值，未涵盖所有人眼多尺度结构。 |
| MACD/RSI背离 | 同一组价格极值与指标不同步 | 程序给出价格/ATR与指标变化，允许弱背离，但不把极小差值叫强背离；背离不是突破确认，趋势可能继续。 |
| RSI回到30上方/70下方、失败摆动 | 脱离极端或指标自身结构转变 | 30/70不机械改成更极端以减少次数。强趋势可钝化，失败摆动的突破属于RSI，价格是否突破需独立证据。 |
| 布林持续收缩后越带 | 低波动后价格开始向一侧扩展 | “连续3根收缩＋越带”是当前子型；此前20根价格区间是否被突破另作确认事实。尚未过前高的放量越带也可能有早期观察价值，不应直接剔除；进入趋势仍需后续价格证据。 |
| 普通量价、均线排列/粘合、KDJ高位变化 | 参与程度、趋势状态、动量降温 | 基础事实仍有用；KDJ下拐明确指K下降并下穿D。日成交量不能识别交易者身份或意图。 |

## 汇总方式

对选中的最多3个实例，分别说明：观察到什么、对当前问题意味着什么、支持/削弱它的事实、接下来什么价格行为会验证或否定这一解释。最后按时间和同一市场过程合并，别把“形状成立”“信号有力”“价格趋势确认”混成一个结论。

程序生成的 `context_notes` 是同源程度信息，没有统一强弱评分，也不是让模型重复计算。比较使用相同单位和窗口；公式中未要求的量能、位置、幅度可调节解释力度，但不反过来否定数学定义成立。未来K线只用于带日期的后续演变，不用于回填当时信号。
