# 近期K线基础解读

用 [简短看图提示](references/visual-prompt.md) 和一张图独立解读。仅把任务说明交给视觉模型，不附逐日数据、比较结论、扫描结果或其他模型解读。

默认看近期10根日K，可随用户期限调整。重绘图只含K线、MA5/20/60与成交量（含此前20日均量线），指标用足够历史预热后截取。图上保留证券、日期、坐标、图例和必要范围框。默认不另印开收、阴阳判断、量比或统计表，同一行情只以图形呈现。基础图不附MACD、RSI等副图；特定指标交给对应形态分支。

当前主 Agent 综合成一个回答；需要逐个形态解读时再采用 `kline-analysis`。图与计算事实来自同一份冻结行情/指标序列。程序事实是精确数值、方向比较和统计的依据，图像观察补充定性背景；两者冲突时沿用同源计算事实，并舍弃依赖误读的论据和观察条件。用户图缺少必要信息时按授权能力补齐，保留原图与重绘图的区别。

## 聊天中的执行

完整看图回答可用 `## 走势与量价 {#technical}` 与 `## 后续观察 {#watchlist}` 组织；在解读旁引用工具返回的近期图 figure id。正文说明证券、实际截止日与窗口，精确价格和均线关系引用同源计算事实。简短追问直接回答，不重复整份图文报告。

通过本轮授权的“K线独立看图与形态复核”工具取得已完成日线的基础看图结果，关闭形态复核即可只看基础走势。沿用证券、截止日和用户窗口；默认10根，不额外重复取同一份行情。工具负责独立图像调用，主聊天综合返回的图像观察和同源计算事实。此方法不启动另一个自主 Agent。
