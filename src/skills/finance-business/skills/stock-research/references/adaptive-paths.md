# 证据驱动的研究路径

用于首批结果改变初始判断、多个解释竞争或需要决定继续查哪里时。下面是分析提示，不是关键词路由、公司分类枚举或必须执行的阶段。

## 先建立可修订的解释

结合用户期限，暂定一个主要判断和最值得排除的相反解释。首批查询服务于区分它们，同时识别公司的经济引擎。不要为了给公司打完标签先全库扫描。

商业模式决定钱从哪里来，发展阶段决定增长和融资约束，市场关注决定预期与价格问题，证据质量决定结论能说多强。这几件事可以交叉变化：高热度公司可以是成熟现金牛，低热度公司也可能处在财务困境。

每批相关结果后简短更新：哪些证据支持/反驳原判断；最重要的不确定性是否改变；下一项证据能否区分解释。只查询有希望改变结论或满足用户明确交付要求的内容；已足够则进入综合。

## 从观察到下一项证据

| 当前可见证据 | 应检验的解释，而不是直接下结论 | 有价值的下一步 |
| --- | --- | --- |
| 收入和利润增长，现金回款明显弱于利润 | 正常扩张/季节性，还是收入确认、回款或库存质量问题 | 对齐累计/单季和可比期，查应收、存货、负债与现金；需要时组合财务质量方法 |
| PE 很低，但利润受商品价格或单年价差放大 | 真低估，还是周期顶点的高分母 | 查跨周期盈利、单位成本/价差、资本开支和负债；不能把缺失成本曲线用股价代替 |
| 成长行业中，公司相关业务占比很小 | 行业增长能否成为公司利润，而非只有概念映射 | 分部收入/利润、客户/供应商连接和商业化证据；必要时读研报产业链方法 |
| 收入高增但持续亏损、现金消耗上升 | 有效商业化投入，还是越增长越缺现金 | 单位经济性、可达利润率、再投资与融资；不用负 PE 判便宜 |
| 价格先上涨，经营/预测尚未改善 | 有提前定价依据，还是缺少兑现证据 | 检查事件公开时间、预测年度、估值假设；只能形成解释假设，不能由同步变化证明因果 |
| 经营改善但市场关注低 | 未被认识的改善，还是信息稀疏/流动性风险/低预期合理 | 用现金与资本回报验证持续性，再查估值和兑现节点；无热度数据不等于冷门 |
| 多家机构同向评级却预测差距明显 | 预测口径不同，还是增长/成本/估值假设分歧 | 组合研报方法，按同机构、年度、单位核对；评级一致不消除业务分歧 |
| 债务到期或融资风险可能先于业务兑现 | 生存和股东稀释是否压倒长期成长价值 | 优先现金、到期债务、资本约束；保留续融失败条件，再讨论远期估值 |
| 同业便宜很多 | 真折价，还是增长、回报、杠杆、业务构成或会计口径不同 | 同业方法检验可比性；不先挑能证明自己结论的同行 |

这些观察只是触发研究的理由，不是异常、造假、低估或上涨的证明。比较基准依公司、行业、周期和报告口径决定，不设全行业统一阈值。

## 方法应变不是增加方法

新证据排除了某条解释，就收束对应分支。例如回款差已被可信的季节性与后续回款解释，不再把整份报告写成财务风险排查。若分部显示主营并非原先假设的热门业务，修改主方法，不在原故事上继续堆主题证据。

若结果只是预览而不足以判断，优先读取现有结果中相关行或文本；统计总体、返回样本和实际阅读范围分别说明。数据本身缺失时，不通过相同查询的同义改写无限寻找命中。存在明确新证据支持的授权来源时可核验不同证据目标，不能用间接材料伪造缺失字段。

用户中途改问题时保留仍有效的公司、时点与证据，仅调整当前判断；新分析时点则重新核对时效，旧预测不能当成最新。

## 收束与可见解释

直接支持、主要反证、关键假设和缺口足以回答问题时停止；预算或能力边界先到时，交付部分结论和待验证项，不伪装完整研究。未取得价格或可靠估值模型时，可以交付经营判断，但不评价当前买入吸引力。

在现有进度通道解释有意义的变化，例如“利润增长但回款下降，接下来核实现金转化”；这不是内部思维链，不要求新 JSON 状态或用户逐步批准。正式回答保留最终证据、解释和条件，不堆执行日志。
