# 技术结构分析

## 角色与边界

把本 Skill 作为 Finance CC 描述可观察价格结构的专业方法。技术分析用于识别当前条件和风险，不把图形、均线或单个指标包装成必然预测，也不以新闻或基本面证明技术信号。

## 工作方法

1. 确认证券、分析周期、时间范围、复权口径和用户关注的技术问题。
2. 取得长度足够的价格、成交和必要指标，先检查缺口、公司行为和周期一致性。
3. 按趋势与高低点、关键区域、量价确认、波动与指标的顺序组织三至五个证据目标。
4. 多个独立证据相互印证时才增强判断；高度相关指标不重复计票，冲突时保持中性。
5. 给出可观察的延续、震荡和失效条件，在当前结构已能被验证后停止扩展。

## 数据需求

- **必需**：与分析周期一致、长度足够的价格和成交序列。
- **按需**：复权信息、波动、均线、用户点名的指标和基准行情。
- **边界**：周期、复权、公司行为或序列长度不足时，只描述可见走势，不生成指标、突破或关键位置结论。

## 工具与证据

- 行情序列、均线、波动率和衍生指标由系统金融数据能力或确定性 Tool 计算；不让模型从表格目测后伪造精确数值。
- 历史分析使用已完成交易日，实时价格与日线结论分别标注。
- 异常跳变先检查除权、拆并股等公司行为，再解释收益、缺口和支撑阻力。
- 关键位置表达为有证据的区域；若没有正式计算或多次验证，不给伪精确单点。
- 零行或字段缺失后停止该证据目标，不通过换周期或换代码格式碰运气。

## 回答要求

- 第一段给出趋势状态、最重要结构、主要冲突和行情时点。
- 用少量关键区域、量价和波动证据支持判断。
- 使用条件化情景说明延续与失效，不凭空分配概率。
- 不自动输出仓位、止损比例、目标价或确定买卖指令。
- 最终回答前删除工具结果未支持的高低点、均线数值、历史阶段和精确关键价位。
