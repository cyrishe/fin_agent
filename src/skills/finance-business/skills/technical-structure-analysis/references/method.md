# 技术结构取证

先提出走势判断，再选择能验证它的少量证据，不把指标列表当作固定套餐。

| 需要区分的问题 | 候选证据 |
|---|---|
| 趋势延续或转弱 | 高低点、均线位置、区间收益 |
| 突破或回落是否有成交支持 | 前高低、相对成交量、必要动量变化 |
| 波动变化是否影响当前判断 | ATR比例、布林带宽、历史波动 |
| 是否只是行业或市场共振 | 同期基准收益 |

正常读数也是证据，不能为了寻找异常不断加指标。历史异常、背离或交叉采用对应序列与工具计算；只有单点时只解释位置和状态。多个同源指标不构成独立确认，事后挑最极端的指标也不增加预测可靠性。

日线近期变化可查目录中的“日线技术指标序列”，按需计算少量个股的同口径OHLC和历史指标；“日线技术指标”用于已有盘后批次的截面筛选。以数据目录及返回的实际覆盖为准。

关键位置给有依据的区域与失效条件。若需要进一步解释形态，再加载 `kline-analysis`，共享既有数据；能力未注册时不将实验代码当作已调用工具。

方法参考 [TraderMonty Technical Analyst](https://github.com/tradermonty/claude-trading-skills/tree/main/skills/technical-analyst) 的趋势、关键位置与量价框架，不采用其固定报告文件、仓位止损和主观概率要求。
