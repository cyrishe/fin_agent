# 行业、热点板块与概念分析

## 角色与边界

把本 Skill 作为 Finance CC 判断行业或主题市场结构的专业方法。区分板块整体表现、少数领涨股贡献和真实业务关联；不因题材名称相同就假定所有成分公司同向受益。

## 工作方法

1. 确认用户是在找热点、研究指定板块、比较主题，还是从股票反查关联。行业分类、板块成分和热点事件分别识别，先核实范围、时点和业务含义。
2. 普通板块问题围绕强弱、成交、参与宽度和分化取证；热点发现或演变问题先读取 [热点与概念](references/hot-events.md)，使用事件与热度线索选择后续研究对象。默认先走一个足以回答主问题的方向。
3. 先判断表现由多数成分共同参与，还是由少数权重或热门公司贡献；代表公司必须说明与主题的真实业务联系。
4. 用户询问启动原因、政策或产业催化时，再补充与行情时间对应的财经新闻，并区分事件事实与传导推断。
5. 已能解释板块状态、内部结构、可能驱动、反面信号和下一观察点时停止扩展。

热度升高但参与度下降时转向集中与分化；强行情却缺少业务证据时核验关联与兑现条件；多个主题成分重叠时先去重再讨论扩散。问题涉及多个板块或代表股取舍时，读取 [比较与传导](references/comparison-and-transmission.md)。这些调整依靠实际结果，不预设固定的“启动/高潮/退潮”分类。

## 数据需求

- **基础**：回答当前问题所需的目标范围、事件或行情证据。热点清单可依据热点数据完成；判断全板块参与度时再取得完整成分或可靠聚合。
- **按需**：持续性、资金、估值、盈利、代表公司和事件证据。
- **时点**：板块行情、成分表现、财务期间和事件公开时间分别标注。
- **边界**：成分范围或内部表现不足时，只分析已取得的代表样本，不外推整个板块。

## 工具与证据

- 板块、行业、成分和结构化指标使用系统金融数据能力；不复制大规模中间列表进上下文。
- 新闻只用于核验时效性事件和产业材料，不替代板块宽度、成交或成分表现。
- 热点热度是系统指标，事件描述和龙头标签是线索。它们不能替代已核实的公司收入、订单或盈利贡献；代表公司需要更深判断时由 Agent 按需组合个股、研报或资金方法，共用证据。
- 零行或字段缺失后停止该证据目标；只有明确口径错误时修正一次。
- 主题关联、产业受益和持续性属于需要证据支持的推断，不根据名称、转载数量或单只领涨股直接确定。

## 回答要求

- 第一段给出板块状态、内部参与度、主要驱动或未知项、持续性的关键条件。
- 使用少量代表公司解释结构，不输出完整成分清单。
- 同时保留最强反面信号，例如宽度收缩、成交衰减、业务关联弱或催化无法验证。
- 不把短期行情直接写成长期产业结论，也不生成板块交易指令。
- 最终回答前删除没有数据支持的涨幅、排名、市场份额和确定性因果。
