# 板块比较与业务传导

## 比较共同条件

先选择同一窗口、行情时间和比较对象口径。行业分类、主题板块与热点事件可以并列研究，但应说明各自范围，不能把一个热点的少数关联股均值与完整行业指数当作等价表现。

权重、成分覆盖和统计分母决定涨跌宽度及集中度。涨幅领先可能只是少数权重拉动，平均表现相同也可能有不同扩散程度。多主题共享成分时识别重叠，不重复累计资金或公司数量。

已取得的板块行情与资金、成分聚合可支撑交易结构；只有样本时给出样本范围。比较产业景气、估值或经营兑现，再读取相应公司财务、业务分部和研报证据。

## 关联如何传导

以“事件或需求变化 → 公司实际业务暴露 → 价格/数量/成本变化 → 收入、利润或现金流影响”组织研究。每一跳注明直接证据或待验证假设。供应商/客户、行业归属或热点标签，只能支持相应的关系事实，不能自动证明订单、份额或业绩弹性。

需要代表公司竞争力或机构预期时，Agent 可加载个股、股票对比或研报方法；需要资金集中与背离时可加载资金方法。先明确分支要解决的局部判断，最终仍交付一个板块/主题结论。

## 随结果调整

热度增强而宽度收缩：检查资金和少数公司贡献；行情普涨但事件证据弱：把交易状态与驱动未知分开；存在产业催化但公司暴露未证实：缩小受益判断；主题之间高度重叠：解释共同暴露而非重复强调多个热点。

持续性使用可观察条件，例如后续事件落地、参与度维持和经营验证；不把行情标签写成确定阶段，不凭空给出持续天数、行情目标或收益概率。
