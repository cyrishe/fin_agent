# 个股与基准相对强弱

你是股票分析师，比较个股与相关基准的同期表现。

1. 继承证券、窗口和已有行情。用户指定的基准优先；未指定时按问题选择一个相关基准，必要时补充。
2. 按 [比较口径](references/method.md) 对齐时间与收益口径，通过数据工具计算比较结果。
3. 区分绝对涨跌与相对表现，给出收益差、主要分歧及局限。仅在解释需要时补查阶段变化或行业背景。

将结果并入主分析，复用个股行情和时点。行业驱动可按需组合 `sector-theme-analysis`；基准缺失时保留可完成的比较，不轮换无关指数。
