# 比较场景与路径调整

## 同业竞争与代表公司

先核实业务、客户、区域、收入构成和成长阶段。行业成分能发现候选，不能独自证明业务可比。共同指标之外，保留足以解释差异的行业指标；当前目录未提供的经营指标使用已取得披露，否则标记缺口。

同业样本只选胜者或估值有利的公司会歪曲结论。用户已指定对象时保留对象；可以解释业务不完全可比，而不是换成更容易排名的公司。

## 跨行业或不同阶段

银行、制造业、软件的盈利和资本结构不同，使用各自适合的原始指标，再回到共同决策语言：资本需求、现金可见度、增长兑现、定价假设与下行情景。不同指标不是先换成统一分数再比较。

成长公司与成熟公司分别检查再投资、未来兑现和当期现金分配；亏损公司不进入机械 PE 排名，周期利润高点用跨周期证据观察。缺少跨周期资料时明确当前利润可能失真，不自行造“正常化利润”。

## 单一专题与机构预测

用户只比较一个指标时，取得同一口径数据并解释差异即可。盈利预测比较核对预测年度、机构、发布日期及会计口径；需要机构分歧、假设和修订原因时，Agent 加载研报方法。两家公司的实际财报增长不能替代它们未来年度的预测增速。

## 证据触发调整

| 发现 | 后续处理 |
|---|---|
| 低估值来自亏损、一次性收益或周期高点 | 调整估值锚，核对跨期经营与现金证据 |
| 同行业但主营/客户差异很大 | 改为分业务或共同风险维度比较，保留不可比项 |
| 增长接近而现金转化相反 | 深入最相关的应收、存货和资本需求，不重复整套公司研究 |
| 看似预测差异实际来自日期或年度错位 | 先修正比较口径，再讨论预期分歧 |
| 只有一个对象关键数据缺失 | 保留双方可见事实，说明无法完成的比较，不把缺失判作劣势 |

共享取证由 Agent 使用当前目录中的个股身份、业务分部、财务、估值、行情与研报能力完成；行业/板块成分只承担候选发现。最终用紧凑对照表达“差异—依据—代价—适用前提”，不分别拼贴两份报告。
