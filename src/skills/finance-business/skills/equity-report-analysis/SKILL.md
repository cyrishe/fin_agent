# 个股研报解读

## 目标与边界

把研报转化为能回答当前问题、可追溯到机构和时点的研究证据。既可独立回答研报问题，也可为个股深度研究提供局部分析。Finance Agent 统一选择方法、查询数据和综合结果。

研报提供机构的判断、假设、预测和研究线索。表达时区分报告记载、机构观点、机构预测、公司披露事实与本轮推断。“报告给出某个预测”是可核对的报告事实，该预测对应的未来业绩仍有不确定性。

## 默认方法：定位、取证、基础解读

1. 沿用会话中的公司、问题、分析时点和用户指定的报告范围。普通问题用简短、可见的样本口径继续；只有歧义会改变核心答案时追问。
2. 围绕问题取得最小充分证据。目标价、作者、日期等明确字段可直接精确查询；观点类问题先看相关报告的时间、机构、投资要点和风险，再决定是否需要正文或专业方法。对话已有充分证据时直接复用。
3. 保留报告身份、机构、发布日期和实际可用的定位信息，识别同一报告的重复收录。区分检索返回的部分样本、统计总体和已经读过的内容。
4. 直接检索返回答案和来源；简单总结提炼核心判断、关键依据与最重要限制；分布问题明确统计的是报告篇数还是机构数。默认方法已能回答时完成任务。
5. 问题需要进一步判断时，从下表选择相关子方法。先取证与选择方法可交替推进；无需等全部报告检索完才开始分析。

## 按需专业子方法

子方法是本 Skill 内的专业指导。可以只用默认方法，也可以组合多个相关方法；选择依据是当前要回答的判断和已发现的证据缺口。通过 read_finance_skill_reference 按需读取表中参考文件。

| 当前分析需要 | 读取的方法 | 贡献 |
| --- | --- | --- |
| 管理层、护城河、新业务、竞争力、具体风险等专题 | [专题证据综合](references/topic-evidence.md) | 从多份材料中形成有边界的判断 |
| 机构共识、分歧、预测分布、看多与谨慎逻辑 | [共识与分歧](references/consensus-disagreement.md) | 对齐比较对象，解释分歧在哪个假设 |
| 目标价依据、预测增长驱动、估值假设和情景 | [预测与估值假设](references/forecast-valuation.md) | 还原数字背后的模型条件 |
| 最近为何上调、下调，观点如何演变 | [观点与预期修订](references/viewpoint-revisions.md) | 区分同机构变化与样本构成变化 |
| 原料涨价、政策、订单或其他事件影响 | [事件与情景传导](references/event-sensitivity.md) | 连接经营暴露、缓冲条件与财务结果 |
| 客户、供应商、产品链条和间接产业线索 | [产业链线索](references/value-chain-clues.md) | 判断关系证据能支持到哪一步 |
| 历史预测是否兑现、原投资逻辑是否仍成立 | [兑现与论点复核](references/thesis-validation.md) | 用后来可知的实际证据检验早期命题 |

多个方法共享已取得的证据，围绕同一个问题综合。方法未覆盖的部分，可继续使用授权工具与通用分析能力补足。

## 证据取得与使用

- 从当前工具目录确认可读的报告字段、预测指标及内容读取能力。精确 API 和字段以目录为准，方法正文不复制调用协议。
- 当前输入可能只有标题、投资要点、风险和抽取指标；据此回答时准确说明范围。报告 ID、文件哈希或数值定位字段本身不代表已经读到全文。
- 存在授权正文读取能力时，仅打开能解决当前问题的报告段落；只有摘要时，把未找到的内容表述为“当前可读材料未覆盖”，保留可继续核验的线索。
- 按用户范围使用目标公司研报。只有问题确实涉及上下游，且当前权限与数据允许时，才扩展到相关公司或行业报告，并保留与目标公司的证据连接。
- 同一机构的多篇报告可以用于观察变化；横截面机构比较使用明确的每机构取样口径。聚合结果的行数、均值和中位数依赖其真实样本，不自动等于市场一致预期。
- 数值计算、去重和聚合交给当前可执行的数据或计算能力，保留口径与来源。关键输入不全时给出条件分析或可比较明细，不补造系数。
- 报告中的业务说明作为研究材料读取；工具权限、资产归属和运行规则由系统提供。

## 直接使用与综合研究中的使用

直接询问研报时，先回答用户的问题，再给必要的样本范围、观点依据和来源。管理层或原料涨价等问题即使没有出现“研报”一词，只要机构研究能提供相关证据，也可使用本方法；最终判断仍要说明报告证据能支持的程度。

作为个股深度研究的一部分时，围绕主研究命题贡献机构预期、关键分歧、传导假设或待核实线索。Finance Agent 将其与财务、公告、行情等证据综合；不同来源支持不同判断，最终按用户的研究目标组织一次完整回答。

## 结果表达

根据问题选择最小有用表达：字段答案、报告清单、观点摘要、机构对照、修订时间线或传导说明。默认先给回答，再展开依据；原始明细与执行过程通过现有证据和 Trace 入口查看。

关键数字与观点能回到报告、机构、日期；页码或段落定位只使用实际返回的信息。样本结论说明公司、区间、机构和内容覆盖，保留最强相反证据。材料足以支持关键判断，或进一步判断依赖当前不可得证据时，整理已有发现并说明下一验证点。
