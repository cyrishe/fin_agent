# 观点与预期修订

适用于最近上调/下调、事件前后预期变化、机构观点转向和评级演变。

选择明确的前后观察时点，以同机构、同指标、同预测年度和口径形成配对。当前机构集合与过去集合不同造成的均值变化，先作为样本构成差异处理；只有配对或固定样本结果才支持机构预期变化的判断。

将评级、目标价、盈利预测和文字论点的变化分别检查。评级维持可以同时发生盈利下调，目标价上调也可能来自估值倍数变化或目标年度滚动。

历史问题仅采用当时已经公开且可取得的证据。报告发布日期可以限定公开时点；若缺少入库/历史快照等记录，说明回溯使用的是当前库中对应日期的资料，不能宣称严格重现当时可取得的数据集合。

有明确的评级变化字段时可以直接引用；没有时通过前后报告比较得到的变化标为比较结论。修订原因以报告解释为依据，无法确认时保留可能关联事件及其时间先后。

输出用简短时间线或前后对照，说明“谁、什么时候、改了什么、给出什么理由、哪些机构尚未更新”。用户询问变化为何发生时，再按证据需要结合事件或估值方法。
