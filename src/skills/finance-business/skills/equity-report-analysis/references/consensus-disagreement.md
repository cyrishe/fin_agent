# 共识与分歧

适用于机构立场比较、预测分布、目标价区间及看多与谨慎逻辑。目标是说明共同判断、真正分歧及其对结论的影响。

## 形成可比较样本

先沿用用户指定时点、报告窗口、机构和指标。未指定时采用适合问题的可解释范围，并在结果中说明。报告分布可以按篇数统计；当前机构立场和预期比较，通常按同机构在该范围内最新的可比预测取样，并明确实际执行口径。用户指定的正式一致预期数据源沿用其方法。

预测年度、实际/预测、单位、币种和指标定义一致后再做数值比较。同机构跨报告期更新保留为时序证据；重复收录不增加独立观点数量。每机构最新的可比指标未必来自该机构最新一篇报告，应保留该指标自己的发布日期。

研报数量、机构数量与有效指标样本数分别说明。评级保留原始措辞和可用的评级基准，不把不同机构评级名称机械折成同一分数。目标价单点与区间、期限不同的材料分开解释。

## 找到分歧的原因

围绕同一经营命题比较需求、售价、成本、产能、竞争、资本开支或估值假设。数字差异本身能证明预测不同；只有报告解释或模型依据足够时才归因到特定假设。

同向评级可能包含重要的盈利或估值分歧；未覆盖某一主题不是反对。样本全部积极时直接说明采样范围内的倾向和缺失的反方覆盖，不制造看空观点。

优先输出“共同判断—争议假设—机构证据—需要观察什么”。需要量化时提供可比明细及真实计算结果，并称为“本次样本统计”；只有数据来源和方法支持时才称为正式市场一致预期。
