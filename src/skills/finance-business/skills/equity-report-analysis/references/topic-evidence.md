# 专题证据综合

适用于管理层、治理、护城河、新业务、竞争力、市场空间和具体风险。专题对象不同，但共用“主张—依据—限制”的综合方法。

围绕用户要判断的命题检索相关内容。对每项重要观点，确认机构说了什么、以何种事实或假设为依据、观点日期和适用范围。将同义复述合并，将不同来源引用同一公司表述视为一条共同来源，而非多份独立验证。

按专题选择真正影响判断的观察角度：

- 管理层：战略承诺及兑现、资本配置、治理安排、激励与股东利益；将机构评价与可核验的经营或治理行为关联。“经验丰富”等评价只能支持报告态度。
- 护城河：客户切换、成本位置、定价、渠道或技术优势的具体机制与可持续条件；行业景气和短期高毛利不单独构成长久优势。
- 新业务：行业需求、公司可服务市场、竞争份额、产能或产品阶段、收入与利润兑现。行业市场空间与公司可取得收入分别表达。
- 风险：风险暴露、触发条件、经营或财务传导、已经出现的迹象；区分常规风险措辞与有新证据的具体风险。

有原文时核对关键措辞与上下文；只有摘要时将结论限制在摘要支持的范围。把信息缺失、机构没有明确表态和机构持相反观点区分开来。

输出围绕用户命题归纳支持、反证和缺口，保留机构与报告定位。若不同机构的核心前提冲突，可结合共识与分歧方法；若用户要检查承诺或论点是否兑现，可结合兑现与论点复核方法。相关方法均由总入口按需选择。
