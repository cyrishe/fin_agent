# 产业链线索

适用于从研报寻找客户、供应商、产品关系、产能、订单或产业扩散对目标公司的意义。

以目标公司及其业务命题为中心，先找报告明确记载的实体、产品和关系。只有线索需要且权限允许时，再查看相关公司的报告或已提供材料；扩展范围始终服务于目标公司判断。

每条关键连接保留主体、关系、时间与来源，并说明它是公司披露、机构判断还是本轮提出的待验证联系。同一主题、概念或终端需求相近，可以成为检索线索，不能单独证明供应关系。

将认证、送样、定点、订单、交付、收入确认等进展按原文分别表达；前一阶段不自动证明后一阶段发生。一个终端客户扩产，也不直接证明目标公司份额、订单或收入会增长。

对有依据的链条进一步核验受益所需条件，例如产品匹配、供货资格、份额、产能、合同与交付时间。关系连接缺证据时在该处停止推断，列出最有价值的验证问题。对单一目标公司有用的线索已形成后停止拓展。

输出“已确认关系—机构解释—潜在线索—缺失连接—对目标公司的条件性影响”。图示仅表示证据支持的关系，推测连接需显式标注，且不把图作为第二份权威数据。
