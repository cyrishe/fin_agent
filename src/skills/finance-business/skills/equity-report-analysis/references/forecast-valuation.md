# 预测与估值假设

适用于目标价依据、EPS 或利润增长驱动、估值方法比较和情景条件。单独查询一个目标价或预测数值使用默认方法即可。

将结论追溯为“业务假设—财务预测—估值依据—目标价或情景”。先取报告已有的论述、预测年度、指标口径和目标价期限，再补充确实影响解释的输入。

- PE 类估值核对使用哪个年度、何种利润或 EPS、采用的估值倍数及其理由。
- DCF 类估值关注报告实际披露的现金流、折现与终值假设；缺失项保留为无法复算的部分。
- 分部估值核对分部范围、估值锚及净债务等调整；将公司整体与分部估值分开。
- 根据目标价和 EPS 算出的隐含倍数标为本轮计算；即使数值接近某个倍数，也不足以证明原报告采用了 PE。

比较目标价时核对价格币种、股本或复权口径和目标期限。当前价格对应的潜在空间与报告发布时的潜在空间分别命名。期限、口径不兼容时展示明细及差异，不强行合成单一平均值。

解释敏感性时保留原报告的基准、冲击、假设和结果。只有合法可用的公式与必要输入齐全时才交给计算能力复算；结果是本轮情景分析，来源仍可追溯。机构未提供模型时，回答可确认的预测与估值假设及缺口。

输出重点是“目标数字依赖什么、哪些假设最容易改变结论、可复核到哪一步”。
