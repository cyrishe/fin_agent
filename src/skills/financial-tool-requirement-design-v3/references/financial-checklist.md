# 金融设计检查清单

只检查当前需求相关的内容，不机械逐项提问。

## 标的与市场

- 市场、板块、证券类型和标的池。
- ST、停牌、退市、上市天数等特殊范围。
- 指数、行业、概念、个股或组合。

## 时间与频率

- 日线、分钟线、逐笔、报告期或事件时间。
- 盘中、盘后、历史回测。
- 时区和交易日历。
- 是否使用未完成 K 线。
- 信号何时生效。

## 行情与价格

- 前复权、后复权或不复权。
- 价格、成交量、成交额和比例的单位。
- 精度和舍入。
- 除权除息、涨跌停、停牌和缺失行情。

## 指标与规则

- 指标定义、窗口、阈值和比较关系。
- 全部满足、任一满足、评分还是优先级。
- 模糊术语的可计算定义。
- 规则冲突。
- 数据不足时的行为。

## 排名与筛选

- 排序指标和方向。
- Top N 或阈值。
- 并列、重复和空结果。
- 多阶段筛选顺序。

## 热点与外部数据

- 热点来源和定义。
- 聚合窗口、衰减、去重和实体映射。
- 发布时间和可用时间。
- 数据缺失或延迟的替代方案。

## 基本面

- 单季、累计、TTM 或年度。
- 报告期和公告日。
- 同比、环比、行业分位。
- 历史时点可得性，避免前视偏差。

## 回测与实盘

- 分析、信号还是自动交易。
- 成交价假设和生效时点。
- 佣金、滑点、交易成本。
- 仓位和风险控制。
- 前视偏差和幸存者偏差。

## 数据质量与审计

- 字段缺失、重复、乱序、延迟和异常。
- 数据源单位和代码映射一致性。
- 输入时间、数据版本和规则命中是否需要记录。
- 是否需要输出命中原因和中间值。

## 必须提问的情况

- 不同选择会显著改变最终结果。
- 不明确会导致输入输出无法定义。
- 数据可能不可获得。
- 无法形成可测试的验收结果。
- 可能引入前视偏差或实盘风险。

## 可以假设的情况

- 低风险、可逆、配置化的展示偏好。
- 对核心结果影响很小的排序展示。
- 后续容易调整的名称和描述。

推荐选项不能自动视为用户选择。
