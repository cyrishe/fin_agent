# Coding 工作区索引

- 需求和 Design：读取 `CONTEXT.requirement_brief`、`CONTEXT.design` 或对应引用。
- 当前代码与反馈：读取 `CONTEXT.current_implementation`、`coding_feedback` 和 `test_feedback` 指向的资产。
- 平台模块示例：首次实现参考 `DYNAMIC_TOOL_TEMPLATE.py`。
- 金融数据接口：先读 `api_catalog/CODING_GUIDE.md`，再按需读取 `task_context.json`、subject 索引和相关 dataview 文件。
- SDK 接口：读取 `custom_tool_sdk.md`。
- 编译与运行：使用 `CODING_WORKSPACE.md` 给出的命令，临时测试放在 `scratch/`。
