Fin Agent MCP 使用说明

接入金融分析、Skill 方法与结构化数据查询。提交问题即可自动选择，也可显式指定方法。

数据说明 API 文档 OpenAPI
连接地址
https://ai-agent.kingdomai.com/fin_agent/mcp

传输协议为 MCP Streamable HTTP。所有请求都需要 API Key，推荐使用 Authorization: Bearer <FINANCE_API_KEY> 请求头。

可用工具

  • finance_task：通用金融任务；只传问题自动选择 Skill 和数据工具，传 skill_ids 指定有序方法。
  • list_skills：发现当前身份可用的已发布 Skill ID、用途与版本。
  • finance_data_query：直接查询行情、财务、估值、资金流、研报等结构化数据。
  • 这是封闭数据查询能力，不调用通用 Web Search。

鉴权方式

二选一即可：

Authorization: Bearer <FINANCE_API_KEY>
X-API-Key: <FINANCE_API_KEY>

请通过客户端的密钥或环境变量配置保存 Key，不要写入公开代码仓库。

任务与查数调用参数

list_skills 无需参数。下表适用于任务和数据查询入口。

参数是否必需说明
query是自然语言金融数据问题。
skill_ids否仅 finance_task：传 Skill ID 列表，按顺序采用方法、共享基础数据、综合回答；省略、null 或空列表时自动选择。
response_mode否data 返回原始行数据，summary 返回结论，both 同时返回；默认 both。
detail否默认 false；设为 true 附带模型轮数、每步 Token、耗时、API 请求与静态检查/重试记录，不改变查询行为。DSH 提供逐步事件耗时，其他运行时未采集的项留空。
runtime否cc 或 dsh；不填写时使用服务端默认值。
research_mode否fast、auto 或 deep；通用任务默认 auto，直接查数默认 fast。
execution_mode否standard 或 fast；DSH 的快速执行模式省略检查与重试。
conversation_id否默认不传，每次独立，不继承前次问题或结果。显式传相同 ID 时续接当前用户的会话；不同用户之间隔离。
max_rows否每个结果集最多返回 1–100 行，默认 100。

Python 快速示例

import asyncio
import os

from mcp import ClientSession
from mcp.client.streamable_http import streamablehttp_client

MCP_URL = "https://ai-agent.kingdomai.com/fin_agent/mcp"
HEADERS = {"Authorization": f"Bearer {os.environ['FINANCE_API_KEY']}"}

async def main():
    async with streamablehttp_client(MCP_URL, headers=HEADERS) as (read, write, _):
        async with ClientSession(read, write) as session:
            await session.initialize()
            result = await session.call_tool(
                "finance_task",
                arguments={
                    "query": "海尔智家近四年的营业收入和归母净利润走势如何？",
                    "response_mode": "both",
                    "runtime": "dsh",
                },
            )
            print(result.structuredContent)

            # 指定方法：先发现当前身份可用的 Skill。
            skills = await session.call_tool("list_skills", arguments={})
            print(skills.structuredContent)
            result = await session.call_tool("finance_task", arguments={
                "query": "分析海尔智家的盈利质量和估值，给出综合判断",
                "skill_ids": ["earnings-analysis", "valuation-analysis"],
                "response_mode": "both",
            })
            print(result.structuredContent)

asyncio.run(main())

MCP 调用时需要指定入口工具名；调用 finance_task 后，内部方法与数据工具可由 Fin Agent 自动选择。多个 Skill 在同一次 Agent 任务中指导分析，未授权或未发布的方法会被拒绝。工具工坊自定义工具不在本接口范围内。

返回值包含 data_sources、结构化结果、摘要和执行元数据。data_sources 使用“股票 · 研报明细”“行业 · 成分股”等公开业务名称，列出每个查询目标及实际记录数，便于核验查询逻辑；不会暴露内部目录路由标识。只需要裸数据时，将 response_mode 设为 data。
