# 兑现与论点复核

适用于历史预测是否实现、管理层承诺或机构投资逻辑是否仍成立。它需要早期观点与后来独立可得的实际证据。

先固定要检验的早期报告、预测年度、核心命题和当时前提。检验预测时使用当时发布的预测，而不是财报公布后修订的数字；实际财务优先使用公司披露或权威财务数据，并核对口径、修订和单位。

将数值误差、方向判断与核心假设是否成立分开。例如预测增长但低估幅度，不等于增长逻辑完全错误；利润达标但主要来自一次性项目，也未必证明原经营逻辑兑现。

对管理层或业务论点比较承诺、行动和结果，说明可归因范围。研报中的历史实际值也可能是抽取结果，关键判断需要核对其来源与可靠性。

通过现有计算能力得到可比误差或差异；缺少必要实际值时只说明已取得的后续证据。区间、亏损转盈或不同会计口径不适用同一个简单百分比误差表达。

输出原命题、最新证据、支持或削弱之处，以及后续验证点。单一预测样本只支持该次预测的判断，不据此给机构或分析师生成长期能力排名。
