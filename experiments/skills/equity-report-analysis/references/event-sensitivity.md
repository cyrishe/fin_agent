# 事件与情景传导

适用于原材料涨价、产品价格、政策、客户订单、技术或其他事件对目标公司的影响。

先明确冲击是什么、已经发生还是用户假设、发生或公开时点。检索研报中关于公司相关业务暴露、传导机制和历史情景的证据。较早的机制分析可以用于理解暴露，但不能被称为机构对新事件的最新回应。

围绕问题连接：外部变化 → 公司处于产业链何处 → 收入/成本/营运资金或资本开支 → 利润/现金流 → 可能的估值含义。只展开实际相关的环节。

原料涨价场景重点核对净采购或销售暴露、相关业务占比、库存与长协、定价传导、套保、时间滞后。公司同时包含上下游业务时看净暴露；“材料涨价”本身不能确定公司净受益方向。

把三种回答清楚分开：

- 机构已给出测算：注明报告、时点、情景和量纲，说明是否仍适用于当前问题。
- 本轮条件测算：说明公式、数据与假设，通过可执行计算完成，检查成本、毛利、净利及税前/税后口径。
- 方向性传导：关键系数缺失时给出有条件的影响与待验证项，不把成本变化比例直接转为利润变化比例。

评价股价反应时将公开事件、机构报告和行情的时序对齐。时序和机制可以支持解释假设，单日涨跌与事后研报不能单独证明因果或价格已充分反映。

输出先回答最可能的影响和成立条件，再展示支持与相反机制。报告没有回应新事件时明确区分旧机制与当前推断。
