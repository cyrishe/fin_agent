# 个股研报解读：实验方案与用例草案

日期：2026-09-08。对象：[实验 Skill](equity-report-analysis/SKILL.md)。本文件位于 Skill 包之外，不进入运行时方法上下文。

## 要验证的假设

1. 相比不加载本 Skill，专业方法是否改善机构观点、数字口径和推断边界。
2. 相同方法内容组织为单体正文或总入口加渐进 References，是否改变质量、触发、上下文消耗和延迟。
3. 直接使用和个股深度研究中按需使用，是否都能贡献可溯源证据，并避免重复取数、重复输出。

## 对照设置

- A：当前 Agent 与相同工具权限，不提供新增研报 Skill。综合研究场景保留原有 stock-research。
- B：单体研报 Skill，将本草案默认方法及专业方法的相同语义放入一个正文；只调整必要的导航表达。
- C：本草案，总入口加按需 References；与 B 使用相同 name/description、数据、方法知识和其余 Agent 配置。

先固定证据做解释层对照，再在支持 Skill 的真实 Runtime 中做检索加分析对照。前者用于分离方法效果与取数差异，后者允许查询路径不同以衡量真实使用成本。保留样本更换公司、机构组合、日期或冲击，不只替换公司名称。B/C 共享完全相同的方法语义；触发评测以完整可见 Skill 集合为环境，单独区分选择与加载后质量。

每次运行绑定 commit、相关工作区差异指纹、Skill/Reference 内容哈希、Runtime/provider/model、提示与目录版本、权限、数据快照、样本和 scorer 版本、预算、实际结果及 Trace。真实数据须有授权链，使用已有授权数据或脱敏/合成材料，不将客户或生产原文复制进实验包。

以下是案例规格，不是带真实 GT 的已完成数据集，也不能直接作为现有 runner 的生产 Gate。先为所选用例准备证据与独立判定口径，再执行。

## Scorer 与判读

- 可确定事项：公司/机构/日期/年度/单位匹配；引用是否存在；去重与样本统计是否按声明执行；数值是否有可复算来源。使用独立核验或确定性计算。
- 专业质量：命题与证据是否对应、机构分歧是否被准确解释、推断条件是否可见、回答是否真正服务用户目标。使用预先制定的业务 rubric 和隐藏版本身份的人工/模型评审；模型评分需要与人工判断校准。
- 效率：总 Token、总耗时、取数和 Reference 调用、重复读取，以及最终可用结果。Reference 阅读次数不是越少越好；对照其对任务的贡献。
- 方法选择：观察所需指导是否被正确使用，允许等价的有效路径；不以固定调用顺序或“所有子方法都调用”作为成功标准。
- 联合使用：对最终综合答案核验来源与结论，检查研报部分是否带来额外信息、是否遗漏反证、是否重复完整报告。

结构验证、合成材料演练和真实 Runtime 效果分别记录。尚无绑定当前配置与 workload 的真实运行时，运行效果为 `NOT_READY`。本实验不代替生产可信七维评审或发布许可。

### 问题一：简单事实

用户问题：“截至2026-09-08，青禾证券给星澜材料的最新目标价是多少？”

代理回答正文：

> 截至2026-09-08，在提供的合成材料中，青禾证券给予星澜材料的最新目标价为30元，期限12个月，出自2026-09-03发布的《定价传导能力改善》（F02）。

回答附合成材料来源链接。执行记录显示只读总入口和材料，没有读取专业方法；重复件不重复计数，截止日之后的F04被排除。人工核对数字、机构、报告时点和期限与材料一致。

### 问题二：组合分析

用户问题：“截至2026-09-08，机构对星澜材料的分歧主要在哪？M原料涨价10%到底影响多大？Q客户进展能否成为缓冲？请给出简短分析并附来源。”

代理回答正文（仅将原来源链接集中说明）：

> 截至2026-09-08，主要分歧在于M原料涨价能多快、向客户转嫁多少。青禾预计未来两个季度约一半涨价可以传导；远帆认为下一次合同议价前难以提价，未来一季度主要由公司承担。两者观察期限不同，不能视为完全相反的判断。相应的2027年归母净利润预测分别为12亿元、9亿元，但摘要不足以把全部预测差额归因于原料成本。
>
> M原料涨价10%的可用量化依据只有青禾测算：销量及其他基准条件不变时，毛利率下降1.2个百分点。这不是净利润下降1.2%，也不足以推算净利润减少多少亿元；远帆仅提供成本承压的方向判断，没有对应敏感性数字。
>
> Q客户目前只能视为潜在缓冲。截至分析时点仍处于认证阶段，没有量产订单披露，订单金额、供货份额也不明确，尚不能确认其收入或利润能够抵消成本压力。接下来应观察认证转订单、交付规模及盈利贡献。
>
> 以上仅为合成材料演练：采用两家机构截至分析时点最新报告，F02重复件不重复计数；9月9日的F04不纳入判断，不代表真实市场一致预期。

原回答前三段分别附有F02/F03的合成材料来源链接。执行记录显示读取共识与分歧、事件与情景传导、产业链线索三个方法，其余方法未读。人工核对发现：正确保留机构观察期限差异、毛利率量纲、认证与订单区别，以及日期和去重边界；没有补造净利润敏感性或将全部预测差额归因于成本。
